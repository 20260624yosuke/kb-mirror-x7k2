# Nekojira 21. 色彩明度

## 要旨

[[nekojira]] **色彩明度(レンダリング)の理論章**。最大の核は **エッジ 4 段階**(シャープ/ファーム/ソフト/ロスト)による形と構造の表現。「**繊細な式調値の制御よりエッジコントロールに注力**」する戦略を提唱。また「**敷張(色調)変化を多重に重ねるとフラット感が失われ線画の情報が消える**」という **過剰レンダリングの罠** を講師自身の初心者時代を例に告白。**3 トーンで構成する**(ベース+影+ハイライト)単純化哲学を明示し、自身のスタイル(「グレー+局所高彩度」)の核を完成させる。

## キーポイント

### エッジの 4 段階

| レベル | 名称 | 用途 |
|---|---|---|
| **レベル 1** | **シャープ** | シルエットの端、近くの影の輪郭、キャストシャドウ |
| **レベル 2** | **ファーム** | 物体が離れるにつれて、しっかりした転換点 |
| **レベル 3** | **ソフト** | トランジション部分、丸い表面の転換点 |
| **レベル 4** | **ロスト** | 形が消えていく部分、中間調 |

- 「**覚えておくべきはシャープとロストだけで十分**」「**ソフトを使う状況はトランジションと飛車体の構造に基づいています**」(ch21_01 6:45)

### Nekojira の 4 要素

- **フォームライト**(法線が光に向く明部)
- **コアシャドウ**(明暗境界)
- **キャストシャドウ**(投影)
- **反射光**(セカンダリ)
- 「**必要な場合を除きハイライトは使いません。私のスタイルはフラットで光原を一点とします**」(ch21_02 0:32)

### 過剰レンダリングの罠

- 講師の初心者時代の例: **金属棒に多段階のトーン変化** を入れた結果 → **線画の情報が消えた**
- 「**テクスチャがリアルになるほど洗画の情報が見えにくくなります**」(ch21_01 1:29)
- 「**通常 3 つ以上の式張は使いません。白色に入色暗いテーマを組み合わせるだけ**」(ch21_01 8:38)
- 「**車実的にしようとすればするほどフラットに保った場合と比べて洗画の情報が目立たなくなる**」

### 微差調整(2-3% の式変化)

- 「**5 から 7 以上の変更を加えると変化が明らかになってしまう**」(ch21_01 12:47)
- **62% → 60-65% の範囲で微調整** → 拡大すると微差、縮小すると豊かな情報量
- これが Nekojira の **フラットに見えるが情報量がある** スタイルの数値的根拠

### グラデーション制御の限界

- 「**フォルマント構造に合わせて格闘トランジションラインの形も考慮する必要があり、これは極めて困難**」(ch21_02 5:27)
- だからこそ **エッジコントロールに注力** することを推奨

### ソフトエッジ追加で「仕上げ」が生まれる

- ハードブラシだけだと「**純粋な形しか作れず仕上がりが劣る**」(ch21_02 8:02)
- **ソフトエッジを追加** することで「**仕上げが始まる**」 = エッジが完成度の核

### エッジ追加の連動原則

- 「**イラストの特定部分にエッジを適用する場合、全体スタイルを合わせるため他の部分も調整が必要**」(ch21_02 8:35)
- **片所だけ仕上げ度を上げると他の部分が低く見える** → 完成度に差が出る

### ファーム/ソフトの実例(身体の各部位)

| 部位 | 推奨エッジ |
|---|---|
| お尻の丸み | レベル 2(ファーム) → 離れるにつれレベル 3 |
| キャストシャドウ(脚を覆う影など) | レベル 1(シャープ) |
| 胸の柔らかい部分 | レベル 3(ソフト) |
| 胸の谷間 | レベル 1(シャープ、近接影) |
| 鎖骨周辺 | レベル 2-3 で柔らかく |

### 跳ね返り(バウンスライト)による細部追加

- **暗部** に **もう 1 つトーン(反射光)を追加** → 形を明確化
- 「**お腹の構造を定義するためもう 1 つトーンを追加**」(ch21_03 4:31)
- 56% → 60-62%(微差)で **構造の輪郭を出す**

### 光の減水(光原から離れるほど暗く)

- グラディエントツールを **上山モード** で使う
- **微細な変化** を加えて自然な減衰を表現

## 引用に値する一節

> エッジには 4 種類があります。ファーム、ソフトそしてロストもあります...シャープなエッジは通常シルエットの橋や近くの影の輪郭に現れます...距離が遠くなるにつれて徐々にファームになります。そして効果がほとんど見えないほど柔らかくなります。(ch21_01 5:53)

> 通常 3 つ以上の式張は使いません。白色に入色暗いテーマを組み合わせるだけです。これが私の単純化の方法で情報を強調するために式張の変化を抑えています。(ch21_01 8:38)

> 5 から 7 以上の変更を加えると変化が明らかになってしまいます。このようにリテールを加えるとこのグループが急に暗くなってバランスが崩れてしまいます。(ch21_01 12:47)

> イラストの特定部分にエッジを適用する場合、全体スタイルを合わせるため他の部分も調整が必要です...エッジを追加する時は注意が必要です。形や構造を表現するなら全体スタイルを統一する処理が必要です。(ch21_02 8:35)

## 個人的な所感 / 残った問い

- 本章の **エッジ 4 段階** は ye_jji 講座には明示的に存在しない概念(ye_jji では境界処理は [[totoneru-definition]] や [[bokashi-control]] の用語で扱われるが、4 段階分類はしない) → **Nekojira 独自の主要貢献**
- 「**初心者時代の過剰レンダリング**」を講師自身の失敗として開示するパターンは ch01 / ch13 / ch26 でも反復される **Nekojira の特徴的な誠実さ**。同じパターンを ye_jji も `ye-jji-individual-history-narrative`(?)で持つが、Nekojira の方が頻度が高い
- 「**フラットに見えるが情報量がある**」スタイルは、**2-3% の微差調整** + **エッジコントロール** という具体的な数値・操作レベルで初めて完全に説明される。これは Nekojira スタイルの **テクニカルな再現可能性** を保証する重要章
- ye_jji の **色塗り 6 工程** において、工程 3(オクルージョン)と工程 4(髪・目)の中間に相当する内容 → ye_jji にはこの粒度の理論章がないため、**Nekojira の独自貢献度が高い**
