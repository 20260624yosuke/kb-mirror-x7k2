# 第 08 項 キャラクター描写中心(Section 2 本格始動・キャラクター中心の実演)

## 要旨

Section 2 の本格的な実演開幕章。第 07 項で提示した 3 軸分類のうち **テーマ軸 = キャラクター中心** の彩色法を、バニーガール衣装のキャラクターで具体的に実演。**キャラクター中心の特徴 = ①誰なのか分かる ②デザインがよく見える ③設定の魅力が伝わる** の 3 条件を満たすため、**固有色維持 + 影領域を 6:4 に広げる + テクスチャ多用 + 質感描写特化 + 空間色は最小限** の方針で進行。長所は **死認性(接近性)が高い・初心者でも入りやすい・コミッション需要が高い**。欠点は **作家性が薄い・依頼制作(ローディングイラスト等)で使いにくい・ライティング自由度が落ちる**。本章では肌のしっとり感をオーバーレイ + 水滴ハイライトで演出するセクシー表現のコツも解説。次回 sec09 は同じスケッチを雰囲気中心で塗って対比する予定。

## キーポイント

- **キャラクター中心 3 条件**(主題定義): 誰か / デザイン / 設定の魅力 を読み取れる
- **長所**: 接近性(死認性)が高い、絵の美学に詳しくなくても楽しめる、コミッション/ファンアート向き、初心者の最初の彩色法として最適
- **短所**: 技術的(個性的)配色を入れにくい、ライティングのリアリティが落ちる、作家のフィジカル能力(空間色 / 画面構成)が見えにくい、**依頼制作の量が減るリスク**
- **影の比率を 7:3 から 6:4 へ広げる**: 通常「目に心地よい比率は 7 対 3 = 黄金比率」だがキャラクター中心では情報を内側に圧縮するため意図的に **影領域を広げて 6:4** にし、視線を長く止める(= 「ノイズマーケティング」ともchan の表現)
- **固有色を維持**: 水中・夕方・夜などの環境に関わらずキャラクターのライティングを統一する。空間色を反映させない選択
- **使う情報の優先順位**: **明度差 + 色相 + 密度 中心、彩度は控えめ**(衣装デザインは異なる)
- **質感描写が成否を決定**: 肌・衣装・髪のテクスチャ書き込みが命。エアブラシでの肌グラデ + テクスチャ(ストッキング素材等)を Multiply/Overlay でモード変更して合成
- **しっとり感 = セクシーさのコツ**: 水滴のハイライトを「小さく鮮明に・所どころに」入れる(コントラスト大 + 密度高い水滴の特性を利用)
- **オーバーレイレイヤーで肌グラデ強調**: 暗い部分を選択 → グラデーションをかけて肌のさらに丸み(ボリューム)を演出
- **男性向けと女性向けの境界**: 鮮明で直接的な描写は伝統的に男性向け、ただし最近は曖昧化
- **コミッション需要との適合**: ライトな消費者層はキャラクターを見たいニーズが強く、本彩色法が直接当たる
- **作家のスタイル印象が残らない弱点**: 「絵はイラストレーターの名刺」だが本スタイルは名刺になりにくい
- **空間色が苦手な人ほど自然にこの彩色法に流れる**: 苦手の補強として空間色や画面構成を別途学ぶ必要あり

## 個人的な所感 / 残った問い

- **「キャラクター中心は最初に通る道」**としての位置付け(chan 自身も初期はこの彩色法から始めて空間色を扱えるようになって移行した) = 後の sec14 (Section 3) の「弱点を補う」勉強論と接続する。「強み 6 弱点 4 で勉強する」原則の根拠
- **6:4 比率は ye_jji の視線誘導論および Nekojira の主役強化論の数値化版**として読める可能性。3 講師横串 analysis 候補
- **「ライトな消費者層」と「ADクリエイティブ層」のニーズ二分** は ye_jji の [[fanart-vs-original-rights]] や Nekojira の "依頼 vs 個人作品" 論と並列性
- 本講座で初めて「影 = 視線圧縮の道具」と数値化された記述。視線水流モデル([[shudai-fukudai-sub]] 由来)の物理量パラメータ化として記録
