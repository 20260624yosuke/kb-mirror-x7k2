# Nekojira 23. 最終ドローイング：カラースケッチ段階

## 要旨

[[nekojira]] 最終ドローイングの **カラースケッチ実装章**。ch17 で確立した 5 段階ワークフローを実適用: (1) 影の形を **マルチプライ + ハードブラシ** で大胆に配置 → (2) 影の **肌周辺に黄色や赤を塗っておく**(後でマルチプライしても自然な肌色を保つため)→ (3) **青基調**(完触系)で全体雰囲気を統一 → (4) **後ろ髪を反透明効果 + 明るい色** で奥行きを出す → (5) **顔周辺は意図的に暗めにシルエットを際立たせる**。「**全体の雰囲気を 1 つの大きな色として決める** = 青色」というコミット哲学を実演。

## キーポイント

### レイヤー整理(線画の分離)

| パーツ | 理由 |
|---|---|
| 目と眉 | 形の調整が独立してできる |
| 紙(髪) | 形の調整が独立してできる |
| スカート / 袖 / 紙(髪) | 重なりがあるパーツは独立レイヤー |

### ベースカラー塗布

- **キャラクター全体をまず塗ってからパーツ分け**(はみ出さない作業性)
- **透明度を下げて塗り出る** → 簡単に作業

### 影付けの 5 段階手順(本章実演)

1. **ハードブラシ**(必圧なしの四角ブラシ)で **光部分を白で素早くマーク**
2. **コアシャドウとキャストシャドウ** を 1 つのトーンで扱う(細部後回し)
3. **大償のコントラスト + 都(密度)コントロール**(ch20 の 4 原則)
4. **三角形・雨粒・直線** のランダム形を加える(CSI ストローク)
5. **ペン圧をオンにして書き始める**

### 影の肌周辺に温色を隠す(影の下塗り)

- 「**マルチプライした場合、肌の部分が青すぎたり灰色っぽくなりすぎたりする可能性**」(ch23_02 6:49)
- そこで **影の部分の肌周辺に黄色や赤みのある色を塗っておく** → マルチプライ後に赤みが溶け込み自然
- **大きめのブラシで肌外まで広げてもOK**(髪の毛など周囲に面白い色変化をもたらす)

### 後ろ髪に反透明 + 明るい色

- 「**より明るい色を選ぶことで強い光が紙を投化している効果**」(ch23_02 8:17)
- 髪の柔らかさと光の表現を強調する Nekojira の **お気に入り髪表現手法**

### 顔周辺を意図的に暗めに(シルエット強調)

- 「**顔の部分が非常に明るくなることを考慮してこの周辺は意図的に暗めの塔**」(ch23_02 8:59)
- これで顔の **暗い式 = シルエットを際立たせる**

### 青を貴重に(基調にする)

- 「**落ち着いた上品な雰囲気が出る**」「**完触である青から始めるとコントラストを表現する色を簡単に加えられます**」(ch23_02 6:19)
- これは [[grey-plus-local-high-saturation]] の青版 = グレーの代わりに **青基調** にすることで温色を局所的に際立たせる

### グラディエントマップで遊ぶ(明度調整)

- ch23_02 で講師が **グラディエントマップ + トーンカーブ** で全体雰囲気を実験
- これは ch17/ch21 でも繰り返される **Nekojira のお気に入り** ツール

### スカートを黒に変更(全体バランス)

- 「**キャンバス全体が白い面が多すぎる**」 → スカートを黒に
- 「**より多くの変化とコントラストを作り出します**」(ch23_02 14:04)
- 影に塗った青色がスカート黒化後も **面白い色変化** として残る

### カラーモードレイヤーで色変化を試す

- ch23_02 終盤: **カラーモード + 純白塗りつぶし** → 色だけ変えても式は変わらない確認
- 「**式張値はそのままに色の変更を始めます**」 = 明度を維持して色相だけ変える

## 引用に値する一節

> 青を貴重にするのが好きです。落ち着いた上品な雰囲気が出るからです。完触である青から始めるとコントラストを表現する色を簡単に加えられます。(ch23_02 6:19)

> マルチプライを使った色手順の紹介でも同じことをします...影の部分の肌周辺に黄色や赤みのある色を塗っていきます。後でマルチプライ想効果を適用するとこの赤みが肌に溶け込んでより自然な見た目になります。(ch23_02 6:31)

> この段階ではブラシを大きめにして男色を肌の領域にはみ出させても構いません。髪の毛など周囲の部分に面白い色の変化をもたらすことができるからです。(ch23_02 7:36)

> まず全体の雰囲気を 1 つの大きな色として決めていきます。この場合は青色になります。そして意図的にデザインします。影の色は肌の周りを赤みがった暖かい色にしてベースカラーと調和させます。(ch23_02 15:05)

## 個人的な所感 / 残った問い

- 本章は **ch17 で言葉で説明されたワークフローを最終キャラクターに実装** する第一段階。ch17 が **理論章 + 別キャラ実演**、ch23 が **最終キャラの実装**、ch24/25 が **細部仕上げ** という構造
- **影の肌周辺に温色を塗っておく** 技法は Nekojira スタイルの **肌色のリアリティの核**。ye_jji は同じ効果を [[wet-skin-2-step]] や色 layer 加算で実現するが、Nekojira は **ベース色レイヤー段階で先取り** する点が独自
- **青基調** は Nekojira の代表色。ティアキャラなど多くの作品で確認できる。ch26 でも「**青と白のカラーモードが大好き**」と言及
- **顔周辺を暗めに** はキャラ絵で **顔を商点とする** 古典的手法だが、Nekojira は **シルエット境界としての暗部** という形態論的な根拠で説明する点が独自
