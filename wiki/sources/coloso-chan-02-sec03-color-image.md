# 第 03 項 色の「イメージ」と絵への応用

## 要旨

第 02 項の錯視の延長として **「色のイメージ」**(=記憶に残る色と実際の色のズレ、思い出補正)を扱う。映画館 = 赤、コンサートホール = 金、水族館 = 青 — 人は「場所にあった最も強烈な色」を一色に統一して強く記憶し他の色を捨てる。イラストでは **その記憶側の色(イメージ)を再現する方が共感を呼ぶ**ため、ありのままの色ではなく **色をデフォルメ(省略 + 強調)** して描く。逆方向(ホラー系で現実色を強調)もあり得る。3 枚の旅行写真(夕焼け / 室内黄色光 / 真昼の青空)に補正をかけてキャラクターを合成する一連の実演を行う。**「色のデフォルメ = 背景中心色を強調 + キャラクターを鮮明化」** の二段階ワークフローを確立する。

## キーポイント

- **イメージの 2 種類**: ① **色自体のイメージ**(暖色 = 温かい / 青緑紫 = 冷たい等の文化的連想) ② **色を記憶する過程で生じるイメージ**(思い出補正、強烈色の一色統一)
- **イメージ補正の根拠**: ありのまま色のままだと「観察したことのある色」止まりで人の感情を動かしにくい。デフォルメによって「自分が感じた印象」を見る側にも追体験させる
- **背景にキャラクターを溶け込ませる 3 段階ワークフロー**:
  1. キャラクターの基本明度を下げる(背景光が弱い分)
  2. カラーバランスで背景色のイメージ(夕焼け = 赤、室内 = 黄、真昼 = 青)をキャラクターにも加える
  3. オーバーレイレイヤーで背景イメージを強化 + クリッピングで逆光を表現 + 全体コントラストを下げる(キャラを際立たせるため)
- **カジュアルアートの追加 1 段階**: キャラクター鮮明化を「もう 1 段階」強めて背景はぼかしの方向に逃がす
- **逆方向の応用**: 現実的・冷たく書きたい時はイメージ補正を **最小限**に。ホラー系イラストでは現実色強調が逆に怖さを増す
- **個人差**: カジュアルイラスト系は **イメージを極端に強調**(子供向けアニメは特に高彩度傾向、子供の認識傾向に合わせている)、シリアス系はイメージを弱める
- **CSP 補正ツール 3 種の常用セット**: ① コントロール+U (色相・彩度・明度同時) ② コントロール+B (カラーバランス = 色相特化) ③ コントロール+M/N (レベル/カーブ = 明暗 + RGB チャンネル別調整)
- **選択範囲のセット**: スポイト + 自動選択(W キー、許容範囲調整)+ Select > カラーレンジ(進化形自動選択)
- **空間色の練習法**: 自作イラスト → 様々な写真背景に補正合成 → スポイトで色変化を観察 = 空間色と色イメージを同時に学べる「ベストの自習法」(講師推薦)
- **観察の 3 つのチェックポイント**: ① 絵で強調されている色は何か ② イメージより弱い実際の物体色は何か ③ 描画時にどのようにその色が強調されているか(逆算)
- **理論化の意義**: 多くは感覚的に既に運用している。しかし「絵は感覚ではない」を実装するために、自分のデフォルメパターンを言語化して安定させる

## 引用に値する一節

> 「美しい絵を見たら美しいと感じ、悲しい絵を見たら悲しいと感じる必要があります。」
> 「ありのままの色を使っても必ず美しく見えるわけではない。キャラクターの人体をデフォルメするように色もデフォルメできる。デフォルメとは基本的に省略と強調を意味します。」
> 「絵は感覚ではないということを思い出すために、感覚で適用していたイメージを理論化することが本講座の目的です。」

## 個人的な所感 / 残った問い

- 色をデフォルメするという発想は **ye_jji ch12「カラーラフ」 + ch08「3 ライト設計」** と粒度が異なる。chan は **「背景全体を 1 色に統一」** を起点に置き、ye_jji は「3 ライト + 環境光で分解」する方向。両者を横串する analysis 候補
- **Nekojira ch22「アンビエント vs ドラマチック光」 + ch23「青基調」** とも接続。Nekojira は「ライティング設計」、chan は「記憶イメージ」という別の入口から同じ「色統一」のゴールに到達している
- 子供向けアニメが高彩度傾向、というのは ye_jji の SSS 高彩度 3 ポイントとは別根拠(知覚範囲の狭さに合わせる)。**観察対象側の特性で彩度を決める** という視点が独自
- 「ベスト練習法 = 自作キャラを様々な写真に合成」は実装が簡単なので [[me-do-training]] の発展形として概念化価値あり
