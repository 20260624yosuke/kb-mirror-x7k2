# ドルフロ2 ヘレン「星夜のワルツ」MMD資料化の最短導入調査

## 要約

武田さんが、MMD 制作ではなく**3D 作画資料としてヘレン「星夜のワルツ」を自由角度から観察したい**
という目的を明示した最初の依頼文。優先ルートは「公式配布 MMD モデルを Blender で開く」であり、
ゲームデータ抽出や規約違反の疑いがある手段は避ける前提。特に見たい部位として、胸部・ドレス・
横向き/斜め横の前方突出シルエットが指定されている。

## ソース内の主要主張

- 目的は動画制作ではなく、**スクリーンショットと角度別資料化**。
- 環境は `Mac mini M1 / 16GB / macOS`、資料管理は `Eagle`、メモ管理は `Obsidian`。
- ユーザーは Blender / MMD の知識がほぼ無く、Mac 内で完結したい。
- 調査対象は、ヘレン / DP-12 / 海伦 / Starlit Waltz / 星夜のワルツの各名称。
- 導入手順は非エンジニア向けに 1 手順ずつ必要。
- 成果物は `結論 / 手順書 / トラブルシュート / 資料化テンプレ` の 4 つを要求。
- 禁止事項として、ゲームデータ抽出、規約違反の疑いがある方法、高度な MMD 動画制作への脱線を挙げている。

## 抽出されたエンティティ

- `Girls' Frontline 2: Exilium / ドールズフロントライン2`
- `ヘレン / Helen / DP-12 / 海伦`
- `Starlit Waltz / 星夜のワルツ`
- `Blender`
- `MMD Tools`
- `Eagle`
- `Obsidian`
- `AplayBox`

## 抽出された概念

- 公式配布モデル優先
- 3D を作画資料として使う
- Mac での最短導入
- 自由角度観察
- 胸部・衣装シルエット観察

## 不確実・要確認

- この段階では、公式配布ページの実在確認、ダウンロード条件、配布物の中身は未確認。
- 導入後に必要な観察ポーズやカメラ自動化の具体像は、この依頼文だけではまだ固まっていない。
