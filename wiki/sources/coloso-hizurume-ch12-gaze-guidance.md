# coloso ひづるめ ch12 ― 視線誘導とサブ視線誘導

> Section 03 の中核章(動画 2 本)。視線誘導の定義・9 手法・サブ視線誘導(情報の抜き方)を解説。元 md は Whisper 逐語(誤変換多数)。本要約は補正済み(例: 「2 色課 / 日課 / 西下」→2 値化、「保食 / 捕食」→補色、「昭和対比」→調和対比、「サイド / 歳度」→彩度、「スグマートウ」→スマッジ)。「明暗比較連鎖」「サブ視線誘導」は本人造語のまま残す。

## 要約

視線誘導 = 視線を目的の場所へ導き、迷いにくくする設計。**メイン視線誘導**(意図した場所に視線を集める)と、ひづるめ造語の **サブ視線誘導**(それ以外の情報を抜いてメインを際立たせる)に二分。**視線誘導は基本"後出し"**で、見えにくいと感じた都度修正する。手法は 9 種(明度 / コントラスト / 色 / 調和対比 / 視覚心理 / 質感 / シェイプ / 遠近 / 流れ)で重ね掛け可能。

## ソース内の主要主張

### 視線誘導の枠組み
- **メイン視線誘導 / サブ視線誘導**。サブ = 情報を抜く(本人造語、[[sub-shisen-yudou]])。
- **視線誘導は"後出し"**: 最初から精密計算せず、見えにくい所をその都度直す。
- **9 手法**: ①明度 ②コントラスト ③色 ④調和対比 ⑤視覚心理 ⑥質感 ⑦シェイプ ⑧遠近 ⑨流れ。重ね掛け可。

### ①② 明度・コントラスト
- 明度で視線を集める(スポットライト)。線を抜いた状態(= 2 値化で確認)で顔がはっきり見えるよう調整。
- **明暗比較連鎖(本人造語)**: 隣接する明暗で **面積の小さい側に視線が行く**。黒を目立たせるなら黒:白 = 3:7 が目安。これが連鎖(1→2→3)し、最も連鎖した点が最も目立つ。目立たせたくない所は連鎖させない([[meian-hikaku-rensa]])。
- 明暗対比を強める実装: 表示レイヤーのコピーを結合 → 2 値化で顔を出す → ソフトライト + 不透明度を落とす → 境界をぼかして馴染ませる。

### ③ 色
- 主役は **補色**。**補色残像**(グレー背景で反対色が見える)のメカニズム = 高彩度色を見ると視細胞が補色を作り抑制 → 周辺の同補色も加算され強調。**補色強調**は「片方の彩度を高く」しないと起きない。連鎖もする(**補色比較連鎖**)([[ho-shoku-kyouchou]])。
- 実例: 全体黄色 + 目 / バニー服の青で、目の彩度を「嘘でも」高くして補色強調。

### ④ 調和対比
- 調和(同じ要素の反復)を **一点だけ乱す** と、そこに視線が集まる(まっすぐな柱の中で 1 本だけ傾く 等)。これも後出しで足す([[chouwa-tai-hi]])。

### ⑤ 視覚心理
- 連想・錯覚で視線を操る(「8 っぽい何か」を 8 と認識させる 等)。**シミュラクラ現象**(目・顔は無条件で目立つ)も含む。詳細は ch13 錯覚と嘘へ。

### ⑥ 質感(= 情報密度の操作)
- 力場の青い部分 = サブ視線誘導(情報を抜く)場所、赤 / 黄 = 情報を高くする場所。**書き込めばいいわけではない**。
- 情報の抜き方: **くすみ / ぼかし / 溶かし(スマッジ)/ シンプル化(2 値)/ 空気遠近法**。端やくすみは本能的に避けられるので端ほど有効。
- 情報を高める順序の一例: 陰影 → 色 → 光(通常レイヤーでグリザイユ寄り)。

### ⑦⑧⑨ シェイプ / 遠近 / 流れ
- シェイプ: 形(△□○)で連想させる。ポジティブ / ネガティブシェイプ、難形は分解。詳細は後章。
- 遠近 3 法: **ぼかし遠近法 / 空気遠近法 / ライン型遠近法**([[atmospheric-perspective]] と接続)。
- 流れ: 線で焦点を集める(集中線・渦・たなびく髪)。「フォース」とも。

### 市場・SNS 観察(本人の主観)
- **流れ(たなびく髪)の非現実的に"軽い"絵は 2025-2026 の X で伸びにくい**(見飽き・流行飽和)。本人も最高 3.6 万いいね止まり。ただし商業では喜ばれる。
- 最近の流行 = **「心理的に重い絵」**。キャラを心理的に重く / 背景を心理的に軽くする **心理対比** で視線誘導。「重い絵」は 10 万いいねを取りやすい([[shinri-tai-hi]])。
- ポップで明るい絵は 10 万いいね到達しにくい。ポストアポカリプス / 廃墟のくすんだ絵は伸びやすい。
- 大きい仕事はフォロワー 2 万人以上 or 名声がないと来にくい(本人の認識)。
