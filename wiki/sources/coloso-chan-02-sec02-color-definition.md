# 第 02 項 色の定義、そして落とし穴

## 要旨

色彩理論を 1 講に圧縮して提示する密度の高い章。① 色相環と色の関係(類似色・補色) → ② 光と色の関係(RGB と物体反射のプロセス) → ③ 錯視 3 種(前進/後退色・膨張/収縮色・**類似色による認識妨害**) → ④ 空間色(光の色)による色の変化を 1 本に詰め込む。中心メッセージは **「観察には必ず落とし穴がある、避けられないが落ちたことに気づく目を持て」**。

## キーポイント

- **色相環の親密度**: 類似色 = 隣同士、相性◎(調和) / 補色 = 真反対、相性✕(片方の主張を抑えれば共存可能、ケミストリーが出る)
- **光と物の認識**: 物は **光源から来た光のうち自身の色を反射、残りを吸収** して目に届く。赤いカップは赤光を反射、他を吸収
- **RGB = 光の三原色**。混ぜると白(加色混合、絵の具とは逆)
- **錯視 3 種**:
  1. **前進色 / 後退色**(暖色/寒色、白/黒)
  2. **膨張色 / 収縮色**(白いレギンスは太く見える、黒は細く)
  3. **類似色による認識妨害**(=「同時対比」): 周囲の色によって対象の色が違って見える。明るい中の少し暗い色はより暗く、暗い中の少し明るい色はより明るく見える
- **空間色 (= 光の色) のリアル例**: 黄色い光下では青い物体は実際 **オレンジ寄りの灰色** に変色する。スポイトで取ると驚くほど元の色から離れている
- **講座最重要メッセージ**: 「落とし穴は避けられない、**落ちたことに早く気づくこと** が観察力の正体」
- **暖色 / 寒色**: 「断食 / 完食」(誤変換)、講師は段(暖)+ 寒で説明

## 引用に値する一節

> 「お年穴を避けることは不可能なので、落とし穴にはまっていることに早く気づくことが重要です」
> 「自分の目にはこの色が青に見えるとします。しかし周りの色を見ると既に黄色の光が当たっている状態です。そのような場合に自分だけが青く見えていることに気づき、実際の色を予想して当てられるようになる必要があるのです」

## 個人的な所感 / 残った問い

- 「**落とし穴に気づく目**」というメタ認知志向が ye_jji の「補正は意図ファースト」([[intent-first-correction]])と思想的に近い。ye_jji は「補正の意図性」、chan は「観察の自覚性」と異なる文脈だが哲学は同型
- 空間色の説明は ye_jji ch07/ch08 の「思考補助光・補助光・環境光」3 ライト概念と接続するが、chan は **「光源色を見抜くこと」を観察力の中核** に据えており、ye_jji の「3 ライト設計」より上流(観察フェーズ)に置く点が差分
- 同時対比の例(青の中の低彩度紫が赤に見える)は実演画像必要 → PSD 配布物との連携で精度確認可
