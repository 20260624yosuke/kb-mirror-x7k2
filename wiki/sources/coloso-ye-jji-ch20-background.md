# ye_jji_20. 色塗り 06:背景描写

## 要旨

色塗り 7 工程の **工程 6(背景描写)**。Section 07 の冒頭章。**ビーチの背景**(ヤシの木 / パラソル / サンベッド / 砂浜 / 海 / 遠景の山と灯台 / 雲 / 飛行機雲)を実演で描き上げる。中心メッセージは **「背景はキャラと並行して育てる」**(力が抜けて雑にならないように)と **「遠景は大気色に溶かす + 近景は情報量を集中」**。シルエットの **穴開け** で繰り返し感を破る技、**指先ブラシでラフブラシ跡を雲化**、**輪郭線(アウトライン)機能** で近景だけ完結感を上げる、**3D 素材は元データを残して構造を保つ** など、CLIP STUDIO PAINT の機能を組み合わせた効率テクが詰まる。

## キーポイント

### 背景はキャラと並行して育てる

- 「通常この背景の段階で **力が抜けて背景のクオリティが下がる**」 → 前段からコツコツ作っていたので大きな苦労なく仕上げられる
- **教訓**: 背景を後回しにせず、ラフ段階から並行作業する
- 「物足りない部分を感じたらいつでも戻って修正」 → **完璧主義を捨てる** 作業哲学
- ch16 の「軽く 1 周触る」(時間管理)と対をなす **構造原則**

### 距離による情報量・色味の操作

| 距離 | 階調 | 色味 | 描写 |
|---|---|---|---|
| 手前のヤシの木 | 多階調 + アウトライン | 鮮やか | キャストシャドウまで描く、ハト葉間の影も詳細 |
| 中距離のヤシの木 | 1〜2 階調 | やや大気色寄り | シルエットのみ |
| 遠景の山・灯台 | 1 階調 | 強く大気色(青)に寄る | シルエットだけ、区別もつかない |
| 遠景の海 | 大きなグラデーション | 砂浜寄り = エメラルド、遠 = 青 | 波の細かい描写は省略 |
| 飛行機雲 | 単一階調 | 白 | 指先ツールで形を作る |

→ [[atmospheric-perspective]] / [[distance-information-gradient]]

### シルエットの穴開け(繰り返し感の破壊)

- 葉の塊が **似た太さ・明度** で並ぶと退屈
- **真ん中に穴を開ける** → シルエットが軽やかに、複雑に
- 「同じ感覚、同じ形の繰り返しは避ける」(山のシルエットでも同じ)
- 後ろのヤシ・ココナッツの口にも穴を開け、シルエットを複雑化
- 真ん中に固まっていた歯の形を修正、丸すぎるシルエットを分割

### ラフブラシタッチを雲にする(指先ツール)

- **「ぼかしツールの中の指先」ツール** で **ポンポン**と打って境界を崩す → 自然な雲の外角ラインに
- 流れに沿って動かすと **筋雲・煙雲・集中線型雲** を描き分け可能
- ぼかしだけで物足りなければ通常ブラシで補強
- CLIP STUDIO 素材の **にブラシ** も活用可能
- 飛行機雲も指先 + ぼかしで作る

### 雲は「キャラへ向かう集中線」に

- 上方の雲は **主題部のキャラへ集まる方向** に配置 → 視線誘導(→ [[shi-sen-yu-dou]])
- 後ろの雲は横方向に散らす
- 雲のラインを集中線として活用

### 手前のヤシだけ「アウトライン」機能で完結感

- CLIP STUDIO の **アウトライン(輪郭線)機能** を手前のヤシだけにかける
- → 陰影が少ない段階でも「**線が入っているだけで仕上がり感**」が出る
- 後方のヤシには線を入れない → **前後でクオリティの差** を意図的に作る(後方は線消し)

### 砂・布のディテール

- 砂のキャストシャドウは **でこぼこに沿って** 取る(直線的にしない)
- 砂は「綺麗なものではない」、固まった部分・積もった部分が存在する
- パラソル布: **端のラインに細かいシワが集まる** + **力点(中心の柱)に向かって放射状のシワ**
- パラソル内側に **砂の反射光**(黄〜暖色)を強く反映 + 全体的に明度を上げて **コントラストを抑制** → 「遠くから見て目立たない」
- パラソルの ワイヤー / 細かい構造(中央の力点)も観察して描写

### 3D 素材は元データを残す

- 3D 素材を使う時はトレース後も **元の 3D 表示を消さずに残しておく** ことで構造の理解を保つ
- 「自分で直接書いたものではないから構造が分からなくなる」
- 3 ベッドの固定構造などはこの方法で描く

### パラソル長さ調整パーツの追加

- 講師が忘れていた追加パーツ(パラソルの長さ調整部品)を最後に追加
- **対象定規** を活用して左右対称に
- 「**延中の形を間違える方は対象性の問題が大きい**」 → 対象定規の活用を推奨
- 黒いボタンパーツ、上下に広がる形を反映

### キャストシャドウとパラソル下の暗化

- パラソルの **キャストシャドウは画面の大部分** を覆う
- 全体的に 1 トン下げて統一
- 主題部より遠い部分は大気のトーンで変化をつける
- チューブの白/赤い部分は **下から砂の反射光(暖色)** で暗化

### 大気色との関係

- 手前のヤシの木が空より明るすぎないように **明度を下げ** 違和感を解消
- 遠景の山/灯台はほぼシルエット 1 階調 + 大気色青
- エメラルド色の海(砂浜近) → 青色(遠) のグラデーション

## 引用に値する一節

> 通常この背景の段階で力が抜けて背景のクオリティが下がることが多いです。私たちは前回の講座で背景を少しずつ作り込んでいきました。背景を完成まで持っていくのに全く苦労しないでしょう。

> 同じ感覚、同じ形の繰り返しは避けなければなりません。

> 3D 素材を使うと構造がどうなっているか分かりにくい場合があります。…そういう時は必ず元の 3D 資料を確認してください。または私のように消さずにこのまま残しておくと分かりやすいです。

> 通常延中の形を間違える方は対象性の問題が大きいです。…延中のドローイングが難しい方は対象定規を活用してみましょう。

## 個人的な所感 / 残った問い

- 「キャラと背景の並行」は時間管理の話でもあり、ラフ段階で背景の方向を決めておく必要がある — 単発描画では効果が薄いかも
- 「アウトライン機能」は近景のみという使い分けが上手い。**デフォルメ強度のグラデーション** とも読める([[line-as-shadow-deformation]] との接続)
- 集中線型雲は構図的に強力だが、屋外シーンで雲が「集中線として配置できる位置にある」のはやや恣意的 — どんなシーンでも使えるわけではない
- 「**対象定規で延中を直す**」運用は ch04(円柱比喩)の対象性原則と接続している
- 「物足りない部分はいつでも戻って修正」は **完璧主義を捨てる** 作業哲学として明示される — 速度を優先する商業現場に通じる
