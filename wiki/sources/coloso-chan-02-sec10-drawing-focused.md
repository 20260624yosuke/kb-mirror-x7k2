# 第 10 項 ドローイング中心(ドロー vs 色塗りの第 1 章 = ドロー中心)

## 要旨

スタイル軸の前半。**ドローイング中心 = 色塗り情報を意図的に減らし、線・構図・要素の情報を最大化する** 方針。chan が学生時代の塾で指摘された「優れたドローイングを生かせていない」体験から発展した教え。**コンパクトな色塗り**(広い面と狭い面の極端な分配、書き込みを我慢する)が確信。色塗りでは **オクルージョンシャドウ + ハイライト + リムライト** の点的書き込みでクオリティを担保し、タッチは最小限。途中で **モーションブラ** を使って色塗り情報をさらに減らす技も紹介。chan スタイルでは「**見えない色線装置**」(同トーン微差の細い色帯を画面に走らせて視線を顔へ集める)が個人技として登場。シャープな絵柄に偏りやすい弱点(柔らかい絵が描けなくなる「フリル恐怖症」のジョーク)も明示。

## キーポイント

- **ドローイング情報 = ①要素(キャラ/背景/エフェクト)② 構図(投資/アングル)③ 線(太細/質感)**
- **色塗り情報 = ①明度差 ② 色相 ③ 密度 ④ 彩度 + タッチ感**(タッチ感は色塗り個性の最大源)
- **両感(明暗の塗り重ね)の入れすぎ = 過剰内化** = 初心者の最頻ミス
- **コンパクトな色塗りの原則**: 広い面と狭い面の差を極大化、タッチを「入れたい衝動を我慢する」
- **オクルージョンシャドウ + ハイライト中心**: 物体を完全な黒で抑え、ハイライト(高彩度のポイント色)を線のように当てて形を示す
- **リムライト**(逆光のエッジライト) = ドロー中心では効果的、色塗り中心では使い過ぎ注意。「リムライト中毒」のミーム化
- **モーションブラ で色塗りを減らす技**: レイヤー結合 + Filter > Blur > Motion Blur で部分的にタッチをぼかす
- **見えない色線装置**(個人技): 同トーン微差の色帯を画面に複数本走らせて視線を主題部へ誘導。「ただの装置 = 見えてはいけない」が原則
- **ドロー中心はシャープに偏る弱点**: 柔らかい/フリル系のキャラが描けなくなる(冗談混じり)
- **「矛盾しているようだが、激しいドローイングには繊細な色塗りが必要」**: タッチが少ない分、1 筆 1 タッチが貴重
- **石の破片のような同的アクション要素は外側に流す**: キャラ内に集中させない演出
- **同的構図 = 日本向け、立体重い書き込み = 西洋向け** という伝統的二分法
