# ye_jji_04. 量感の描写

## 要旨

Section 3 のコア理論回。**明暗の発生原理(光の角度 × 面の傾き)**、**陰影の 6 種類**(フォーム/キャスト/オクルージョン/ミドルトーン/コアシャドウ/反射光)を整理し、それぞれの **描写方法と注意点** を解説。図形(円柱・立方体・球体)で実習したあと、キャラクター全身に同じ原理を適用するライブデモを行う。**ランバートのコサイン法則** を「徐々に暗くなるのではなく **急激に暗くなる区間が生じる**」というワンライナーで圧縮的に伝えるのが特徴。

## キーポイント

### 明暗発生の原理

- 面の明度は **光の量** で決まる。光量は距離と角度に依存するが、太陽光・蛍光灯では距離影響は小さい → **角度** に集中せよ
- [[lambert-cosine-law|ランバートのコサイン法則]]: 「面の傾きが変化すると、徐々ではなく **急激に暗くなる区間** が生まれる」 = 明暗の境界([[ta-mi-na-ta|ターミネーター]])
- ターミネーター = 光の入射角と面の傾きが 180° をなす地点

### 陰影 6 種

| 名称 | 位置 | 性質 |
|---|---|---|
| [[form-shadow|フォームシャドウ]] | 物体の形によって光が当たらない面 | 全ての影の総称(韓: 携帯の影) |
| [[mid-tone|ミドルトーン]] | 明部内で光量が少しずつ減る部分 | 横軸と縦軸の 2 段階で描写 |
| [[center-light|センターライト]] | 入射角と面の角度が 90° をなす地点 | 最も明るい |
| [[cast-shadow|キャストシャドウ]] | 物体が光を遮って他面に落とす影 | **ハードエッジ**で描写 |
| [[core-shadow|コアシャドウ]] | 明暗境界が反射光によって相対的に最も暗くなる線 | 見落とされやすい |
| [[reflected-light|反射光]] | 周囲から跳ね返った光が暗部を弱く照らす | 元光の反対方向(右・下・後ろ)から |
| [[occlusion-shadow|オクルージョンシャドウ]] | 物体同士が近接する隙間 | **光方向に依存しない**、グラデーション |

### 描写の重要原則

- **フォームシャドウのぼかし**: 一律ぼかしツールでは平面化する。**部位ごとにぼかし強度を変える**(滑らかな曲面は大きくぼかし、角面はシャープに)
- **コントラストが急激に上がる区間を残す**: ぼかし過剰は禁物
- **キャストシャドウ**: 基本はハードエッジ。物体間距離が遠いほど境界がぼける。**他のキャストシャドウやフォームシャドウの暗部に重ねて描写しない**(影は重ならない)
  - 逆光時の暗部にキャストシャドウを描いてしまう間違いに注意
- **コアシャドウ**: 反射光と明暗境界をセットで描写することで自動的に立つ。コアシャドウだけ単独描写ではなく **反射光の副産物** として捉える
- **キャストシャドウの位置計算**: 光の **角度線** と **方向線** の交点で取れる(円柱・立方体・球体で実演)。実際は目分量、おかしいと感じたときに引いて確認する
- **オクルージョンシャドウ**: 光方向無関係。物体同士が近づく全ての位置に発生(まぶた、唇の合わせ、髪の塊同士など)
- **ミドルトーンの 2 軸**:
  - **横軸**: 明暗境界の溶け具合(ぼかし → グラデーション)
  - **縦軸**: 光源から遠ざかる方向のグラデーション。**見落とされがち**(円柱に「下面が暗くなる」事実を忘れる例)

### よくあるミス(講師がデモ中に列挙)

1. **逆光で暗部の寂しさを埋めようとキャストシャドウを描いてしまう** → 影は重ならない
2. **各パーツに必ず明部と暗部があるべきという思い込み** → 角度次第で全パーツが暗部 / 明部になり得る
3. **髪の毛の流れを描く際、密度・明度差を一律で取ってしまう** → 立体感が消える
4. **ぼかし具合を全体一律にする** → 平面化する
5. **キャストシャドウを物体の後ろに直線的に押す** → 距離感を無視して破綻

### 講師の効率テクニック

- **「片側だけぼかす」コツ**: 滑らかな丸みを表現したいとき、明暗境界の上側だけぼかして下側はシャープに残す。両側計算するのは大変なので片側省略
- **大胆なタッチのため**: キャンバスを縮小して全体を見ながら描く。拡大すると消極的なタッチになり永遠的に見える
- **オクルージョンの描写**: レイヤー結合後、自動選択ツールで領域を取りエアブラシで一気に塗ると効率的
- **ぼかしブラシ(濃い鉛筆ブラシ)** が基本。クリスタの「不透明水彩」のような半透明ブラシで色を吸って塗るループ

### デフォルメ

理論を厳密に守らず好みでデフォルメ可。例: フォームシャドウの境界をはっきりさせる(A)、オクルージョンの境界を強調する(B)、コアシャドウや反射の描写を省く等。

### 「明暗境界のシルエット = 内部描写よりも強い情報源」

ch03 で学んだ **シルエット = 第一印象** の原則が、明暗境界の輪郭にも適用される。**遠目では明暗境界線の輪郭が一番目立つ** ため、ここの精度を上げると絵全体が「詳細」に見える。

## 引用に値する一節

> 物足りない部分を作ってはいけないという心理が原因です。角度によっては全パーツが暗部や明部になることもあります。それは決しておかしなことではありません。

> 大勢でダンスの練習をする時 1 人だけ間違えると目立ちます。でもみんなで一緒に間違えると見ている人には間違いだと分かりません。
> ― 周囲の面と比較して明暗境界を決める意義の説明

## 個人的な所感 / 残った問い

- 「縦軸ミドルトーン」「コアシャドウは反射光の副産物」の 2 点は明確に新規発見。多くの初心者本では分離されていない
- ランバートの法則を「急激な暗化区間」のワンライナーで切り出すのは効率的だが、PBR ベースの 3DCG 解釈とは記述が異なる
- 「明暗境界 = 内部より重要なシルエット」原則は ch03 と直結。**ラフ段階で 6 種類すべてプリプランすべき** という示唆

### `c04_要約ノート.pdf`(全 6 ページ)

講師制作のスライド集。本文中で語られた理論を視覚的に整理し、いくつかの **数値・図解** を新規追加している。

- **p1 明暗の基礎理論**: 「距離による光の量の変化」vs「角度による光の量の変化」を電球と球体図で並置。距離変化は太陽光/蛍光灯では現れない → 角度に集中、という結論を強調
- **p2 角度による明度変化を計算する**:
  - **ランバートの余弦則** を 1 文で再定義: 「面の明度は、傾きが変わることで徐々に暗くなるのではなく、急激に暗くなり、対比が高くなる区間が生じる」
  - **明度数値表(90°→180°)を追加掲載**:
    - 90° = 100%
    - 100° = 99%
    - 110° = 97%
    - 120° = 94%
    - 130° = 89%
    - 140° = 82°(注: PDF 内の表記が "82°" だが文脈的には 82% が正)
    - 150° = 73%
    - 160° = 62%
    - 170° = 45%
    - 180° = 0%
  - 「明暗境界線 = 入射角と面の傾きが 180° になる地点」→ **形態力(物体の形状を理解し明確に表現する能力)が必要** という追加メッセージ
- **p3 明暗の種類**: 球体に Center light / Mid tone / Terminator / Core shadow / Reflected light / Occlusion shadow / Form shadow を全てラベリングした図 + 各用語の英訳併記表
  - **コアシャドウについての重要な追記**: 「コアシャドウの部分(明暗境界)を暗くせず、反射光の部分を暗くすると、コアシャドウと反射光の描写がはっきり区別できなくなる」 — 本文より明確に注意点を整理
- **p4 フォームシャドウ**: ぼかしの度合い(=ミドルトーンの範囲)で「角張った形状 ↔ 柔らかい形状」のスペクトラムを 3 段階の立方体で図示
- **p5 キャストシャドウ**: 円柱の例で「基本的に境界を硬く表現」「暗部では消滅(影同士が重ならない)」を図示。注意点として「地面とオブジェクトの距離感に注意。習慣的に物体の後ろを一直線に塗りつぶしてしまうと空間感がすべて失われる」と本文を補強
- **p6 オクルージョンシャドウ**: クマぬいぐるみ 3 体に同じオクルージョンを適用したサンプル(光方向に依存しないことを実証)。注意点: 「面によっては広くグラデーションのように表現されることもあるため、注意が必要」

### `c04_講座教材_補足.jpg`(追加教材画像、講師による補足図)

**「明暗の境界ラインは他の部分と比較しながら合わせる必要がある」** という本文中の「みんなで一緒に間違えるとダンスの間違いが分からない」の説明を、**4 本の円柱イラスト** で図解した補足資料。

- **上段**: 側面光源で 4 本の円柱を描いた場合、正しく明暗を表現できているのはチェックマークが付いた **2 番目の円柱だけ**。しかし、その 1 本だけが他と異なる明暗を持つため、観る人の立場からはむしろ「2 番目が間違っている」ように見えてしまう
- **中段**: 逆に、すべての円柱が同じ「間違った」明暗を持っていれば、観る人は違和感を感じにくくなる
- **下段**: 1 本目の円柱の A 面を明るく塗った場合、同じ角度を持つ B/C/D 面も同じ明るさで処理すべきという原則 を、色付き枠で示す

→ 結論: **「誤った明暗であっても、すべての形の明暗が統一されていることが重要」**。これは本文では比喩的に語られていたが、JPG では具体的な指示として落とし込まれている。
