# Nekojira 07. 人体練習パート 3

## 要旨

[[nekojira]] の人体練習 3 つ目。**腕の重なりが強い難ポーズ**(座り姿勢 + 腕が体に巻きつく)を題材に、ch04 の CSI とミックス&マッチを応用。後半は「**形最優先主義の理論的根拠**」を CPU 使用率の比喩で説明する哲学パートを含む。`02.md` は空ファイル(transcript なし)。

## キーポイント

- **ポーズの大きな流れ観察**: 頭部の直線 + 体の曲線 + 下向きの直線、足は十字で表現。最初は「**大きな四角形として扱う**」ことから始める
- **腕は重なりが多いから最初には描かない**: 「**重なりに惑わされないように**」(1:32) — 肩甲骨筋肉から内側に向かい、ジェスチャーの大流れだけ先に確定する戦略
- **足は CSI(C/S/I)で個別ストローク化** + 三角形で足を表現 + 単純な形に分解
- **ネガティブスペースの再強調**: 「キャプチャーしたネガティブスペースが正しく観察できているか確認します」「**これが作業の性能に大きく影響する**」(5:18)
- **再度の CSI チェック**: 「**全てを統合して再び CSI テクニックを適用できます**」「今あるもので CSI をチェックしながら観察」(5:11)
- **腕の重なりは細分化で対処**: 三角系の変極点(脇の下)を捉えて、1234 と細かい単純形で内側を構築
- **「**観察力を養うことが目**」明言**: 「**ここでの実習の主な目はごとを形として見る目を養い観察すること**」(8:30)
- **CPU 使用率の比喩**: 「**スキルとは頭内の CPU 使用率を下げるようなものです**」「複雑なものを単純化することで難しい問題解決により多くの脳細胞を使えるようになります」(9:19)
- **形 → 解剖 → 遠近 → 構造 の優先順位**: 「**解剖学・遠近法・構造、これらの高度な知識は確かに重要ですが、結局それらは全て形になる**」「より信頼性のある現実的な形を作るためにそれらを理解しているのです」(8:59)
- **資格(視覚)的なライブラリ構築**: 「**形として観察してから、特定の角を描く時は視覚的な記憶から呼び出すだけ**」(9:31)

## 引用に値する一節

> ここでの実習の主な目は物事を形として見る目を養い、観察することです。これによりその後の作業がより簡単になります。(8:30)

> 解剖学・遠近法・構造、これらの高度な知識は確かに重要ですが、結局それらは全て形になるのです。より信頼性のある現実的な形を作るためにそれらを理解しているのです。(8:59)

> スキルとは頭内の CPU 使用率を下げるようなものです。複雑なものを単純化することで難しい問題解決により多くの脳細胞を使えるようになります。(9:19)

> 形として観察してから、特定の角を描く時は視覚的な記憶から呼び出すだけです。形がどう見えるかを知っていれば高度な知識を取り入れる時にずっと簡単になります。(9:31)
