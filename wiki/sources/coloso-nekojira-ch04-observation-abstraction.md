# Nekojira 04. 形態観察と抽象化

## 要旨

[[nekojira]] のキャラクターデザイン Section 02 の中核章。**CSI ストローク**(C / S / I の 3 種の線だけに自分を制限する)を導入し、**観察 → 抽象化 → 再構成(ミックス&マッチ)** の 3 段階で人体の脚・足を描く実演 3 セット。Krenz Cushart から学んだ技法として明示。

## キーポイント

- **CSI ストローク**:
  - **C カーブ** = 文字 C のような形。最頻出。「調整が非常に簡単」。最初に試すべき線
  - **S カーブ** = S 字。**ランダム性が必要な描写**(髪の毛・流れる対象)に有効。「2 つの C で代用可」と初心者には提案
  - **I ライン**(直線) = より硬い対象(立法体・骨格・足の硬い部分)に有効
  - → **「ほとんど全てのものをこの 3 種の線だけで描ける」**(6:50)
- **自己制限が創造性を生む**: ゲーム序盤でリソースが限られているのと同じ。「自分を制限することで脳が働き始め、より興味深いです」(16:40)
- **形を抽象化する → 解剖学はあと**: 解剖学を初心者が追うと絵が硬くなる(本人の失敗史)。まず形(C/S/I + 円・円柱)で大きく捉え、解剖学の知識は **形が安定してから適用** する
- **観察ポイント = 変極点(turning point)を分けてセグメント化**: ライブドローイング中、本人の線が止まる位置はすべて変極点。ここで C/S/I の切替が起こる
- **ミックス&マッチ**: 異なる参考資料(2 枚の写真)から **足と脚を別々に抽象化** → 組み合わせて 1 つのポーズにする。「足のポーズが気に入らない」場合に別資料から差し替え可能。**アズールレーン時代に「グループリーダーに見せる素早いポーズスケッチ」用に確立** した実務技法(4:51 言及)
- **斜めの脚 = 2 つの起こった顔として覚える**(6:37): 上下で「起こっている」感じを使って斜めの脚のリズムを記憶する(独特な記憶術)
- **足の指の描き方**: 「最初の 1/3 が親指」「3 本の指が 2 番目の大きなカーブの中」「3 番目はとても小さい」のテンプレ
- **オクルージョンシャドウは線画段階で線の太さ変化で表現**: 指と指の間の黒い空間を、線を太くすることで暗示する(12:10〜12:28)

## 個人的な所感 / 残った問い

- **CSI ストローク + 形の抽象化** は本講座全体の基盤技術。ch05–13 はすべて CSI の応用として展開する
- 「自己制限が創造性を生む」は禅的・ゲームデザイン的な発想で、[[ye-jji]] 講座の「4 サブスキル」([[four-sub-skills]])の **ドローイング部分** と直接接続できる:
  - Ye Jji の [[curve-drawing-practice]] 「曲線の極率を 1 つ 1 つ数える」 vs Nekojira の **「C カーブで近似してから細部を足す」** は **粒度の選び方が逆**(Ye Jji = 詳細を数える / Nekojira = まず C/S/I に粗化)。両論あり、初心者は Nekojira 流(粗化)から入る方が挫折しにくい
  - [[drawing-large-with-thick-pen]](Ye Jji)と Nekojira ch04 の方針は補完的(大きく描く × 形を抽象化する)
- **ミックス&マッチ** は分業生産現場で生まれた実務技法。アズールレーンのスタジオ満獣でのワークフローが体験談として開示されている(4:51)
- 残った問い: Nekojira の「立ち」と Ye Jji の「形態力 [[keitai-ryoku]]」は **同じ概念か別概念か**。両者ともキャラ造形の前段階を指すが、Nekojira は CSI による平面的線で、Ye Jji は陰影前提の立体感で語る。これは別 analyses で整理価値あり
