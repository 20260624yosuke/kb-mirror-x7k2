# ye_jji_16. 色塗り 02:明部の描写

## 要旨

色塗り 7 工程の **工程 2(明部 = 中間トーン描写)**(`c14_要約ノート.pdf` 工程表上は「工程 2: 明部の描写」)。ch15 で設定した影領域に対し **中間トーンで形を作る** 工程。本イラストは安部の領域が大きく、明部の描写は短時間で終わる(全 2 部)。横軸 → 縦軸の順に中間トーンを入れ、**「コントラストが急に上がる区間を残す」**(ch04 の原則)を守るためぼかし過剰を避ける。背景も並行して触り、近景は中間トーンを入れ、遠景は色味だけで処理する。「**先送りせず全てに 1 度ずつ触れる**」が本回の作業速度原則。

## キーポイント

### 中間トーンのブラシ運用

- 必圧で不透明度が変化するブラシ(CLIP STUDIO 基本の「濃い鉛筆」、または講師購入の「Good 1」ブラシ)を使用
- 講座資料の「ブラシ資料」に購入元情報あり
- **彩度を下げない**: 上を向いていない部分も思い切って明度を上げる。光が当たらない方向は安部の境界面で **急激なコントラスト** に
- ぼかし過剰で境界を溶かし過ぎないこと(ch02 / ch04 で確立した原則の再強調)

### 体の中間トーンの順序

1. **横軸の中間トーン**(回転する形のグラデーション)
   - 骨盤・腹筋・胸の膨らみに沿ってブラシを進める
   - へその部分は **内側にくぼむ形** で抑える
   - 線画で描かれていたガイドラインは中間トーンを取った後に消す(骨盤位置の微調整含む)
2. **縦軸の中間トーン**(光源方向との距離による暗化)
   - 骨盤側面のくぼみ、福部の縦軸 → 多くの人が見落とすポイント

### 服(水着)・フリル

- シは **片面だけ書く** 省略テク(ch04 で学んだコツ)
- フリルのキャストシャドウは **硬く保ち**、フォームシャドウだけ柔らかく
- 繰り返しのパターンを避ける(ch03 シルエット原則の継続適用)
- 水着の下を向く面 = 肌反射の暖色 / タオル側 = ピンク反射

### 太もも同士の反射

- 太ももが接している部分は **互いを反射** → 鮮やかな色味が現れる
- ピンク系の色味を **強く** 入れる(暗部だが彩度高)

### 肌の調整と顔

- 全体の色味調整: オレンジ系よりピンク系へ
- 太ももの境界線・横筋肉ラインで明暗
- 肌は **完全マットではなく少し艶あり** → 表面の荒さ高めの混合反射として、**ハイライト「のようでないような」ぼかしハイライト** を入れる(ch06 ハンバーガー回と同じテクスチャ感)

### 3 ベッド・タオル・小物

- 3 ベッドの中間トーンは高彩度の色で入れる
- パラソル・髪・足のキャストシャドウは **くっきり残す**(中間トーン段階で削らない)
- 3 ベッド布の部分はキャストシャドウなので明るくしない、境界面に高彩度色だけ反映

### 背景の中間トーン

| 距離 | 処理 |
|---|---|
| 手前のヤシ・モンステラ | 葉の表/裏/茎の構造が見える程度の明暗 + 茎を基準に表面/裏面/折れ曲がりを分ける |
| 中距離のヤシ | コントラスト・階調をさらに少なく |
| 遠景のヤシ | 色味だけが見える形、明暗描写は省略 |
| 雲(近) | 側面 + 低面(下を向く面)で分ける |
| 雲(遠) | シルエットのみ、ラフな色味だけ |
| 薄い雲 | **光が透過するので影を作らない** → 明るい色味で塗るだけ |

雲は **資料を見ながら**「どこが低面でどこが側面か」を把握。シルエットは **穴を開ける** 工夫で繰り返し感を破る。雲全体の流れを **キャラクターの方向に集中** させ視線誘導に使う(集中線型雲)。

### 進行戦略:「軽く 1 周触る」

- **「キャラが終わってから背景」は非効率** — 講師の自戒として明示
- キャラ + 前景 + 円形 + 雲 + 海を **1 度ずつ触る** → 作業速度向上
- 「先送り癖を断つ」実用 Tip

## 引用に値する一節

> 名安の段階で言いました。最初はラフに進めると言いました。ここで仕上げなくても大丈夫です。

> 先送りせずに全ての部分に 1 度ずつ触れていくような感じで進めていくのがいいです。

> 薄い雲はただ明るい色合いで描写してください。難しい場合はブラシを使用していただいても構いません。

> 肌は完全にゴムのようにマットではなく、少し艶が出ることがあります。…ハンバーガーを描いた時のようにぼかしていきます。

## 個人的な所感 / 残った問い

- 「軽く 1 周触る」は時間管理の実用 Tip — 先送り癖の自己批判が含まれる珍しい開示

- ch04 の「縦軸ミドルトーン」が依然として **最頻出の見落としポイント** として強調されている
- 「先送りせず 1 周触る」は ch20 の「背景はキャラと並行して育てる」原則の **時間管理版** として読める(構造原則 vs 速度原則の二重実装)
