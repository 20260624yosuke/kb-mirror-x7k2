# Nekojira 10. 練習 1：顔のドローイング

## 要旨

[[nekojira]] の Section 03 の **顔の実習**。ch09 で構築した 3 種の顔(大人っぽい / 重大 / 若い)に対し、**目とまつ毛のディテール** + **3 種の髪型(前髪・横紙・後ろ紙の 3 セクション分け)** を実装する実演。Section 03 の「コントラスト 3 種」(ch08)を **目とまつ毛のメイク・髪のデザイン** に具体適用する章でもある。

## キーポイント

### 目とアイメイク

- **上まつ毛の厚みのある部分 = アイライナー**
- **アイライナーが太く濃いほど大人っぽく / 細めで柔らかいと無邪気**
- **元の形(6 セグメント)を崩さない** → 線を太く整えるだけで細部を加える
- **「私の例を唯一の答えとして扱わないでください**」「**自分なりの表現を探求し、面白いと感じる目のデザインを信じてください**」(1:01) — 個人の主観を尊重する姿勢
- **二重まぶた**を加える(目を大きく見せるため、人間より多くの形デザイン)
- **瞳の上下に空白** を残す(瞳を下まぶたと合わせず、糸的に少し空ける)→ 「目の内部構造を表現」

### 髪の 3 セクション分け

1. **前髪**(forehead)
2. **横紙 / サイド**
3. **後ろ紙**

- 「**できるだけ詳細にではなく明確に**部分を分ける」(6:10)
- 大きな形が見えてから細部を追加

### 髪の毛のコントラスト 3 適用(ch08 から継承)

- **大きいと小さい / 曲線と直線 / 密集と空間**(11:14)
- **斜めに切る**(対称回避)
- **三角形を使って流れと太さ変化を表現**
- **オクルージョンシャドウ**を線として髪の層の重なりに使う(9:40)

### 髪型バリエーション 3 種(3 顔に適用)

| 顔 | 髪型 | 設計意図 |
|---|---|---|
| **若い** | ツインテール | 大きな前髪 + 横サイド + 大きな後ろ髪。顔を小さく見せて可愛く |
| **重大(ティーン)** | 自分のオリジナルキャラのスタイル | 前髪 + 横サイド + 後ろ髪 |
| **大人っぽい(お姉さん)** | 短めの紙(肩より上) | 額をあまり見せず、横顔として考える。3 つのレイヤー構造 |

### 細部より大きな形のコントロール優先

- 「**形を修正する時は、コントラストと 3 つの大きなポイントを考えます。大きいと小さい、密集と空間、曲線と直線**」(11:07)
- 「これを完全な丸にする代わりに何がもっと面白いでしょうか?少し直線と曲線を入れてみましょう」(11:18)
