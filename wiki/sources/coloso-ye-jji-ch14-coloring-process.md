# ye_jji_14. 色塗りプロセス

## 要旨

短い章だが本講座 Section 6〜7 の実践全体を貫く「**色塗り 6 工程(+ 線画 / 下塗りの事前準備)**」のメタ説明回。`c14_要約ノート.pdf` が **公式の工程表** を提示しており、wiki ではこの PDF を一次資料として工程番号を確定する。各工程を分けて理解した上で、慣れたら統合してよいと講師は述べる。**主題部(キャラ)→ 背景** の順序、**カラーラフで色相は既に決まっている** ため本塗装ではスポイトで吸って使うこと、などワークフロー上の重要原則を整理。

## キーポイント

### 公式色塗りプロセス(c14 PDF より、講義の規範)

PDF は 6 ページで以下の工程を順に提示する。これが ch15〜22 のシリーズ実演を貫く骨格:

| # | 工程(PDF タイトル) | PDF 補足 |
|---|---|---|
| 0 | **線画・下塗り** | (前提) |
| 1 | **暗部の領域と色の設定** | 入射角に対して 180 度を成す地点・物体に遮られ影ができる地点を探して暗部の領域を設定。ブレンディングを早く行うと色が濁り変更も困難になるので、明暗境界を薄くして形を作る前に **全体的な色を確定**。一般的にカラーラフの段階で色が確定するので **カラーラフの色をスポイトツールで抽出し、その色を塗る形で作業を進める** |
| 2 | **ミッドトーンの描写(= 明部の描写)** | 色が確定したらミッドトーンを作り、明部の形態を描写。**ミッドトーンの範囲と色味に注意** |
| 3 | **オクルージョンシャドウ・反射光の描写(= 暗部の描写)** | 暗部の領域ではミッドトーンやキャストシャドウ、フォームシャドウなどの描写が難しいため、**反射光やオクルージョンシャドウで描写する** |
| 4 | **材質の描写** | (PDF はタイトルのみ) |
| 5 | **仕上げ(整理 & 補正)** | 最後にすべてのレイヤーを統合し、最も小さいブラシで抜けているディテールを 1 つ 1 つ補完。整理が終わったら、補正を加えてイラストを仕上げる |

ch15 = 工程 1 / ch16 = 工程 2 / ch17 = 工程 3 / ch18・19 = 工程 4 / ch20 = 背景全般(同時並行) / ch21 = ディテールアップ / ch22 = 仕上げの 1 対 1 対応。

### 講座教材(資料 md)の 8 工程表(動画スライド)

資料 md 側のスライドは **より細かい 8 段階** で示されている(PDF より細分化された講義用):

| # | スライドタイトル |
|---|---|
| 1 | 線画 |
| 2 | ベースカラー(下塗り) |
| 3 | 明部 / 暗部設定 |
| 4 | 色設定 |
| 5 | ミッドトーンの描写 |
| 6 | オクルージョン / 反射光の描写 |
| 7 | 質感描写 |
| 8 | 仕上げ(整理 + 補正) |

PDF と動画スライドで **工程の粒度が異なる**:

- PDF:「暗部の領域 + 色の設定」を 1 工程にまとめ、最終仕上げで補正も統合(計 6 段階に圧縮)
- 動画スライド: 領域設定と色設定を分離、仕上げと補正も分離(計 8 段階に展開)
- どちらも **同じ流れの粒度違い** であり矛盾はない

### 工程上の注意点

- **明暗のブレンディングを早めにすると色味の変更が困難に** → 工程「領域設定」→「色設定」の順序を守る
- **自動選択ツールが効くタイミング** = 2 トーンに綺麗に分かれた直後(後段ほど領域抽出が難しくなる)
- カラーラフが既に色相を確定しているため、本塗装は **スポイトで吸ってそのまま使う**(c14 PDF p2 で明文化)
- 暗部領域では中間トーン・キャスト・フォームシャドウの描写が難しい → **反射光とオクルージョンシャドウで描く**(c14 PDF p4)

### キャラ ↔ 背景の進行戦略

- 下塗り・暗部の描写は **キャラ + 背景同時** に進める
- ただし **詳細描写はキャラから**(主題部優先)
- 理由: 人の体力には限りがある。背景を先に作業して疲れるとキャラの完成度が下がる
- 副次的理由: 背景が主題より目立ってしまうと **塗り直し** が発生し非効率

### 「工程の分離」の意義(初心者向け)

- 講座では各工程を細かく分けて説明 → 初心者の理解のため
- 慣れれば **複数工程を同時並行** で進めてよい
  - 中間トーン中にハイライトを足す
  - 暗部設定中に色味も調整
  - 明部描写中に暗部も描写
- プロセス化の意義 = **「自分が何 % 進んでいるか」「あと何をすれば完成か」が明確に** = スケジュール管理が楽になる

## 引用に値する一節

> 明暗のブレンディングを直接するとくすんだ色味になってしまいます。色味の変更も非常に難しくなってしまいます。

> プロセスを確立することはプロの段階で非常に重要な役割を果たします。自分が今何 % 進んでいるのか、そしてこれから何をすればどう完成するのか明確に分かれば、スケジュール管理の面でとても楽になります。

> (c14 PDF p4)暗部の領域ではミッドトーンやキャストシャドウ、フォームシャドウなどの描写が難しいため、反射光やオクルージョンシャドウで描写する。

## 個人的な所感 / 残った問い

- 「工程を分けて学習 → 慣れたら統合」は教育設計として優秀。ch15〜22 がこの工程の 1 つずつを実演する構成と一致
- **自動選択ツールが効くタイミング** という具体的な実装 Tip が地味に重要(色相変更の効率を激変させる)
- **キャラ優先 → 背景後回し** はサブカル系の鉄則。風景画派とは正反対のため、自分のジャンルでどちらを採るか意識する必要
- 「暗部はオクルージョン + 反射光で描く」(c14 PDF p4)は ch17 の核心原則になる予定 — Batch 3 でも要確認
- PDF が **6 段階** に圧縮しているのに対し動画スライドが **8 段階** に展開している、この粒度違いは「実装時の細分化」と「俯瞰時の単純化」の使い分けと解釈できる
