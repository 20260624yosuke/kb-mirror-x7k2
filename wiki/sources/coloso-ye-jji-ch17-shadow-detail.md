# ye_jji_17. 色塗り 03:暗部の描写

## 要旨

色塗り 7 工程の **工程 3(暗部詳細描写)**。ch15 で設定した暗部領域 + ch16 の中間トーンに対し、**オクルージョンシャドウ + 反射光 + コアシャドウ** を入れて立体感を完成させる工程([[shadow-area-via-occlusion-and-reflection]] = c14 PDF p4 で命名された原則の本格適用)。本キャラは安部領域が大きく、本回が最も時間を要する(全 3 部)。**オクルージョン主導の描写戦略**が貫かれ、麦わ帽子の模様も「主題部(顔)に近い部分だけ密度を上げる」原則で省力化。複数素材(顔・水着・髪・麦わ・小物・前景植物)を順に処理し、最後に背景の安部を **構造把握できる程度** で省略仕上げ。

## キーポイント

### オクルージョンシャドウの 5 原則

1. **隙間ならどこでも生じる**(光の方向と無関係)
2. **柔らかい境界**(エアブラシで描写、教会線が立たない) — ただしデフォルメ次第ではくっきり描いてもよい(講師は柔らかく)
3. **黒まで下げてよい**(クリアでコントラスト高めにしたい時)
4. **物体同士が近づくほど濃く**(重ねる)
5. **三角形を意識**(直線ではなく面積差のあるライン)

### 顔の暗部描写の順序

1. 二の上、髪と肌の隙間、首と鎖骨の隙間
2. 胸と胸の間、胸と腹の境界、胸の膨らみ強調ライン
3. 服と肌の隙間、腕と体の隙間、指と指の隙間
4. **鼻筋の側面に明暗** → 立体感強調、大人っぽい印象(明暗の入れ方でキャラ印象が変わる、ラフの印象とのずれに注意)
5. 頬・鼻・耳・指先に **赤み**(乗算系レイヤーで)、関節・肘にも

### 反射光とコアシャドウ

- **反射光は床から**: 床を向いている面に色味を入れる
- **反射光は主光より弱く** が原則(主光のボリューム感を保つため)
- 上を向いている面は **直射光も反射光も届かない** = **コアシャドウ** で 1 段暗く(肩のライン・指の上面)
- 指の上に入れると **量感がさらに出る**

### 透過光と耳

- 耳は **厚みのある場所だけ** ピンクの高彩度で明るく(SSS = [[saido-no-3-points]] の 1)
- 厚みのある部分は暗いまま残す
- 光の色味自体をピンク系に変えて全体調和(本工程の途中で色相微調整)

### 水着のシワ描写

- 紐に近い部分に **細かく / 濃く** シワ集中、遠ざかるほど **粗く / 浅く**
- **三角形 + 階段状変形 + 繰り返し回避** を貫く
- 同じトーンで塗り続けると単調になる → **カラーサークルを継続回転**(オクルージョン中もカラーフリップを忘れない)
- シワの **片側だけ溶かす** タッチで「強く挟まれる/緩い」を描き分ける
- 肌の反射光をフリル裏に追加 → 紫色トーン(ピンクの類似色)で深い影
- レース部はシースルー = 厚み描写で表現(C スルー実習の応用、ch07)

### 後ろから透過光

- C スルーのフリルや厚みの薄い部分に **透過光**(高サイドの空色)
- 不透明度を下げて重ねる

### 麦わ帽子

- リボン接触部 + 上を向いている面 = オクルージョン + コアシャドウ
- 麦わテクスチャ(横島 + 縦島の模様)は **顔に近い部分だけ密度を上げる**
- 残りは「でこぼこがある」程度のラフタッチ、感覚は性格的(均一)を目指すが完璧でなくて OK
- 麦わの隙間からの **透過光**(高サイドの鮮やかな色)を入れる(ただし密形なら強くは透過しない)
- ブラシは濃い鉛筆系では手首に負担 → **G ペン** で軽くタッチを入れる(講師のブラシ運用 Tip)

### サブ素材(リボン・サンベッド・パラソル)

- リボン → **シルクのデフォルメ** → **異方性反射**(折り目に沿ってハイライトを伸ばす、細長く)。パラソルの反射ハイライトで描写
- 3 ベッドの内面 → グラデーションでオクルージョン
- パラソル布の **内側 = 砂の反射(暖色・下から)**

### 前景の植物

- 後でブラ処理(ガウシアン)する予定だが、**認識できる程度には描く**
- 「**前景の品質が低いと全体の完成度が下がる**」 → 最低限の完成度
- アウトラインを活用して線の感じを出す、ゴミ取り機能で外側のでこぼこを整理
- 茎/葉/花のオクルージョン + 軽いハイライト(熱で艶やか)

### 工程上の Tip

- **同じトーンで塗り続ける** と単調になりやすい → 自動選択ツール + エアブラシで色味追加
- **彩度レイヤー** で副題部の彩度を下げて視線誘導を補強
- レファレンスが足りないとコントラスト判断ができない → **レファレンス探索を判断材料に**

### 背景の暗部(省略運用)

- 後ろのヤシ・ココナッツ:**構造把握できる程度** に省略
- 「**第 20 回で進めるので今はラフ**」と明示 — 工程の意図的な前後送り
- 暗部にあまり時間をかけないことが背景設計の鉄則

### Section 6 締めのバリュー確認

- 遠くから見て **明暗が違和感ないか** チェック
- 胸の下に男色系反射(暖寒対比)で情報量を上げる修正例

## 引用に値する一節

> オクルージョンシャドウは黒まで生じる可能性の陰営影です。クリアでコントラストの高いイラストなら黒まで下げても良いです。

> 反射口の強さは常に主な光原より弱くなければなりません。そうすることで主な光原の大きな溶感を損わないようになります。

> 前傾の植物の品質が変だったらどうでしょうか?イラスト全体の完成度が下がってしまいます。

> 強弱の時間に学びました。今日を作るには弱が必要だということ。このようにラフな部分があることで主題部のタッチが完成度高く見えるんです。

## 個人的な所感 / 残った問い

- 「オクルージョン主導の暗部描写」は安部領域が広いキャラ絵で特に有効。サブカル系夏キャラ実演として典型例
- 「主題部だけ密度を上げる」が複数素材(髪・麦わ・水着)で繰り返される → 本講座の中核戦略([[mitsudo-management]] / [[kyou-jaku]] の実装)
- 顔の側面に明暗で立体感を作ると年齢感が変わる → ラフ段階のキャラデザの印象と本塗装で乖離するリスク(チェックリスト化の余地)
- 「**G ペンで手首を守る**」というブラシ運用の身体的 Tip は珍しい開示
