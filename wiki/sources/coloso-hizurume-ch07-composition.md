# coloso ひづるめ ch07 ― 構図

> Section 02。構図の発想法・差別化・パース簡略法。**ye_jji が視線誘導から除外した「構図」を、ひづるめは正面から扱う**(両者の射程差は [[shi-sen-yu-dou]] に記録)。

## 要約

構図は **0→1 ではなく 1→2**(良い写真・映像の構造を借りて要素を入れ替える)。連想ゲームで発想し、足す要素は **後出し**。差別化は「埋もれる構図ではなく浮く構図」を狙い、SNS で大量の絵を見て流行構図の特異性を掴む。パースは難しく考えず、**アイレベルと消失点だけ** で簡略化できる。

## ソース内の主要主張

- **構図 = 1→2**([[kouzu-1-to-2]]): 良い写真の構造を拝借(そのまま使うのは NG)→ 概念を足す → 要素を入れ替えると別構図に(花 → ラッパ → 音楽団 → 黒服…の連想)。
- 構図が決まっているなら **連想ゲーム**で発想。足すのは仕上げで画面が寂しい時(基本 [[atodashi|後出し]])。
- **構図の差別化**([[kouzu-sabetsuka]]): 絵を描かずとも鍛えられる。「浮く構図」を狙う。SNS で流行構図を直感保存(煽り・ネタミック・流れのある構図)。半年以上見続けると、双子を親が見分けるように特異性が分かり、「飽きていない構図」が一瞬で分かる。
- **パースと構図**: 構図にパースは必要だが難しく考えない。ラフで思うまま → 後で整える(パースは後でよい)。
- **パース基礎**: 1〜4 点透視。3 点はキャラが可愛くなくなることがあり使い分け、端ほど魚眼化 → 「嘘」で補正。4 点 = 魚眼。
- **アイレベル法**([[perspective-eye-level-method]]): キャラありの構造を描く → アイレベルを引く → 消失点 → ラフ調整。複数人キャラもアイレベルだけ引けば簡単。煽り = アイレベル下 / 俯瞰 = アイレベル上で調整。本人が仕事で使う技術。
