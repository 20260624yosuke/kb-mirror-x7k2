# 第 20 項 終わりに(講座総括 + 持論)

## 要旨

全 20 章の最終章 = **講座の総まとめ + chan 事論**。本講座のもう 1 つの目的を再宣言: **「皆さんが今後 200/2000 時間を勉強するための材料を提供する」**(本講座 20 時間のみではない)。

中核命題の数値化:
- **色塗り = イラスト第 1 印象の 50%**(残り 50% はシルエット)
- **感覚 = 頭で解決できない難しい問題を放棄するための言い訳**(本講座の最も鋭い学習哲学)
- **カジュアル絵 = ファストフード**(高級料理ではなく、適正情報量で満たす絵)
- **アニメは キャラ単純 + 背景複雑 で情報バランス**(情報総量論の応用)
- **縮小された工程 = 弱点発見ツール**(自分が手を抜いた工程を逆算して弱点を見つける = メタ認知技)

業務形態別のおすすめ:
- 同人イベント → キャラ中心 + 平面中心(グッズ需要)
- ゲームイラスト → 雰囲気重視 + 立体中心(空間色重要)
- ポートレートイラスト → 鮮やかカラー + 平面要素 + 視線処理

**chan 自己開示の最深層**:
- 「私はあまりマメな人間ではない、基本的にとても怠け物」と明言
- それでも絵だけ長く続けられたのは **自己暗示の効果 + 小さな達成感の連鎖**
- 「成功 = 自分が描きたい絵を描けるようになること」(自己定義)
- **「やらねば × やりたい」交点が最強の勉強タイミング**
- **3 日坊主前提の計画** = 怠け物としての自分を前提に立てる
- **他人と比較しない**、1 日 1 個でも自分のペース
- 学習効率の極端な引き上げよりも長期継続を重視

最後の実演おすすめ: **綺麗いな色ラフが描ける能力 > 完成品作る能力**。短時間でラフをハードブラシ + 投げ縄 + スポイトで仕上げる練習を勧奨。タッチ慣れと白黒トーン正確観察は **時間がかかる** ので、長期的に取り組むよう推奨。

## キーポイント

- **本講座の真目的**: 皆さんの今後 200/2000 時間の勉強に役立つ材料の提供(本講座 20 時間のみではない)
- **色塗り = 第 1 印象の 50%**(残り 50% = シルエット)

- **業務形態別おすすめ塗り方**: 同人 = キャラ中心/平面中心、ゲーム = 雰囲気/立体、ポートレート = 鮮やか/平面要素
- **「やらねば × やりたい」交点 = 最強の勉強タイミング**
- **chan 自己開示**: 怠け物自認、自己暗示 + 小さな達成感で乗り越えた
- **成功 = 自分が描きたい絵を描けるようになること**(自己定義)
- **3 日坊主前提の計画**: 怠け物としての自分を前提
- **他人と比較しない、1 日 1 個でも自分のペース**
- **綺麗な色ラフ > 完成作**(優先度): 短時間でラフを仕上げる練習を勧奨
- **タッチ・白黒トーンは時間がかかる**: 長期的に向き合う必要
