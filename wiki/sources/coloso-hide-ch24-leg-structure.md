# coloso hide ch24 ― 脚の構造と単純化

## 要約

脚を、大腿骨・膝・脛骨 / 腓骨・大腿筋群・下腿筋群から整理する章。大腿骨は骨盤から内側へ斜めに下り、膝と足首の位置関係、男女差、股関節可動に影響する。筋肉は大腿四頭筋・内転筋群・ハムストリングス・腓腹筋 / ヒラメ筋などの大きなグループとして扱い、前後左右のシルエットリズムに落とす。

## ソース内の主要主張

- 大腿骨は骨盤から膝へ内側に傾き、女性は骨盤幅や大腿骨頸の影響で角度が大きくなりやすい。
- 膝蓋骨は逆三角形の目印として扱え、膝関節の前面に位置する。
- 大腿前面は大腿四頭筋、内側は内転筋群、後面はハムストリングス、外側は外側広筋や腸脛靭帯で捉える。
- 縫工筋は上前腸骨棘から内側下腿へ走り、太もも前面の斜めランドマークになる。
- 下腿では腓腹筋・ヒラメ筋・アキレス腱がふくらはぎから足首へのシルエットを作る。
- 内くるぶしと外くるぶしの高さは異なり、足首の左右非対称に現れる。
- 脚の描画では、内側 / 外側、前面 / 背面の曲線と直線を交互に使うと自然なリズムを作りやすい。
