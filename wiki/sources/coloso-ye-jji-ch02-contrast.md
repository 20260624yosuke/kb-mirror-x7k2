# ye_jji_02. 対比を活用してイラストにメリハリを付ける

> [Obsidianでこのページを開く](obsidian://open?vault=LLM%20Knowledge%20Base%20_01&file=wiki%2Fsources%2Fcoloso-ye-jji-ch02-contrast.md)

## 要旨

[[shi-sen-yu-dou|視線誘導]] を達成する第一の手段として [[tai-hi|対比(コントラスト)]] を活用する方法。[[kyou-jaku|強弱(メリハリ)]] の定義から始まり、最重要の [[me-do-tai-hi|明度対比]]、補助的な彩度対比・補色対比・暖寒対比を扱う。実習として 1 体のキャラクター全体に対し「描写を増やさず明度コントラストだけで情報量を 1 段上げる」過程を実演する。最後に [[me-do-training|明度トレーニング(モノクロ推測)]] のスタディ方法を提示。

## キーポイント

- **強 = 対比 / 密度 / 立体 / 情報量が **多い**部分(主題)、弱 = それらが少ない部分**
- 「情報量が多い = コントラストが高い」: 対比が低いと色同士が混ざり 1 つに見える → 情報が減る
- **A/B 比較**: 全画面均一に描き込んだ A よりも、背景品質を意図的に落とした B のほうが「品質が高く」見える(主題のクオリティが相対的に押し上げられる)
- **明度はデジタル数値ではなく "実際の色の明るさ" で見る**: カラーピッカー上部 = 数値 100 だが、色相が変わると実際の明るさは変わる。検証法: レイヤー効果「カラー」で黒を重ねると、Hue/Saturation を反映した真の明度が見える
- 明度対比の操作 2 パターン:
  - **接している前後オブジェクト** → 後ろを **暗く** 抑える
  - **離れている前後オブジェクト** → 後ろを **明るく** 抜く
- 主題から遠い領域(キャラの足元・後髪等)では **逆にコントラストを潰す** ことで主題への視線集中を強化
- 描写を一切足さなくても、明度メリハリの再配分だけで完成度が体感的に大幅に上がる(実習で実証)
- **明度を見る目を養う実習**: モノクロ画像を見ずに色画像から明度を推測 → 後でモノクロ化して誤差を確認 → 自分の癖(例: 「明るく見る癖」)を発見・矯正する
- 他の対比 3 種:
  - **彩度対比** — グレーに近いほど低彩度。鮮やかさの差で分離
  - **補色対比** — 色相環の反対側(赤↔緑/橙↔青/紫↔黄)。強い分離
  - **暖寒対比** — 暖色(左下)/寒色(右上)/中性色。隣接で強く分離
- 対比は配色だけでなく **照明色・ハイライト色・反射色** にも適用すべし

## 主要登場人物・概念

- [[tai-hi]] — 4 種の対比(明度・彩度・補色・暖寒)を束ねる上位概念
- [[me-do-tai-hi]] — 最重要の対比種
- [[kyou-jaku]] — 強弱(韓: 강약、메리하리)。対比の効果としての主題強調
- [[shi-sen-yu-dou]] — 対比の目的
- [[shi-tsuyo-tai-hi]] — 彩度対比
- [[ho-shoku-tai-hi]] — 補色対比
- [[dan-kan-tai-hi]] — 暖寒対比
- [[me-do-training]] — モノクロ推測スタディ
- `shi-tsu-no-mehoku-ji-ben` — 「実際の色の明るさ」(レイヤー効果カラーで黒を重ねて確認)

- 左の表: 강(強) = 대비(対比)・밀도(密度)・입체(立体)・정보량(情報量)が高い → 시선을 유도(視線誘導)。약(弱) = 全部が低い → 시선을 분산(視線分散)
- A (左) = メリハリなしのキャラクター 2 体(背景・主題が均一情報量)
- B (右) = 背景の対比を抑えキャラクターに集中 → 主題のクオリティが押し上がる体感

## 引用に値する一節

> このメイドはデジタル数値上の明るさではなく実質的な色の明るさを見る必要があります。

> 完全な白は使わないように注意して書いています。(明度トレーニング中、背景白との比較で)

## 個人的な所感 / 残った問い

- 「描写を増やさず対比再配分で完成度を上げる」というデモは、初心者の「描き込めば完成度が上がる」思い込みへの効果的な反証
- レイヤー効果「カラー」で実明度を確認する Tip は他講座でもよく聞くが、明度対比の事前検証として常用したい
- モノクロ推測スタディは時間対効果が高いと講師は言うが、頻度の推奨値は明示されていない → 自分の練習頻度ルールに落とす必要あり

## 補助資料

### `c02_要約ノート.pdf`(全 3 ページ)

講師制作の章まとめスライド。本文の内容を視覚的に再構成しており、以下の構造が明確化されている。

- **メリハリ = 強弱**: 強 = 対比強/密度高/立体的/情報量多 → **視線誘導**、弱 = 反対 → **視線分散**
- **「強を表現するためには、必ず弱を描写する必要がある」** という命題が明示化(本文では暗黙だった)
- **明度対比の定義**(色塗りにおける): 「明度に差がある二色が隣接していると、明るい色はさらに明るく、暗い色はさらに暗く見え、お互いが分離して見えること」
- **デジタル数値の明度 vs 実際の色の明るさ** の差を CSP 機能と紐づけ:
  - `Ctrl+U`(彩度ダウン) → デジタル数値の確認
  - レイヤーカラー → 実際の色の明るさの確認
- **彩度対比/補色対比/暖寒対比** を色相環図とサンプル(赤/オレンジ/青/緑配置)で図解
- **「明度は脈絡(=視線の流れ)に最も大きな影響を与える」** という結論を強調
