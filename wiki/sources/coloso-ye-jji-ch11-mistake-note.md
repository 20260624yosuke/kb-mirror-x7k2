# ye_jji_11. 間違いノートの作成

## 要旨

Section 4 の締めくくり。**ここまで学んだ全理論を 1 枚のセルフチェックリストに圧縮** し、自分の絵を ○ / △ / ✕ で診断 → 間違いノートに整理 → 修正実演する反復学習プロトコル。講師自身の昔の絵を題材に、すべての修正項目を順に実装するライブデモが 2 部に渡って続く。「学んだ理論をどう自己フィードバックループに組み込むか」の操作的回答を示す。

### 自己診断 → 間違いノート → 修正の 3 ステップ

1. **モノクロ化して明度退避を確認** → 修正項目を ✕ / △ / ○ で記録
2. **間違いノート作成**: ✕ と △ 項目を 1 枚にまとめる
3. **順番に修正実演**: 学んだ手法を 1 つずつ適用

### 第 11 章の対象イラスト(古い絵のリタッチ)

- 主題部=逆光のキャラ + 背景=海・砂浜・鳥
- 診断結果: ✕ キャラと背景の明度分離不足 / △ 暖寒対比弱 / ○ シルエット繰返し / ✕ 全体的に強で休む区間なし / ✕ フォームの中にキャストシャドウ / ○ 中間トーン適切 / ✕ 明暗境界がぼやけている / △ 靴の反射率不足・マフラーのデコボコ不足 / ✕ 環境色・補助光不足 / **+ 透過光ゼロ** / ○ 背景描写量はキャラより少なめ / ✕ 形が崩れている(ラフ仕上げになっている)

### デモで実演された主な修正(操作レベル)

- **明度退避**: スクリーンレイヤーで背景を明るく抜く + 青み寄りに → カラーバランスで影を青に / ハイライトを赤に振って暖寒も同時強化
- **暖寒退避**: 主光(赤)の彩度を上げて肌・マフラーに赤、暗部はすべて青み寄りに塗り替え
- **シルエット強弱**: 不必要に複雑だった服のシワを整理 → 主題部(顔・脇・縫い目近く)だけにシワを集中
- **影の重複削除**: フォームシャドウ内のキャストシャドウを消し、**オクルージョンシャドウ** として境界を緩める
- **フォーム vs キャスト境界の区別**: フォームは溶かす(柔らかいエッジ)、キャストは硬く保つ
- **質感**: 靴の反射率を上げる(ハイライトを鮮明にして影は気にせず反射を描く) + マフラーの境界にデコボコのタッチ追加 + 線画なしで境界が見えない場所に線追加
- **照明補完**: 補助光=砂の黄色を下向き面に / 環境光=空の青を上向き面に / 主光=赤を全体に薄く / 反射光は同系色なら彩度を上げる
- **透過光**: 髪・耳・鳥の翼の薄い部分に高彩度オレンジを追加(物体固有色の高彩度版)
- **背景**: 雲のエッジを整理して階調を統一、波の境界を泡(白)で表現、遠くの山はシルエットのみ

### ビフォー / アフターでの効果

- 主題部への視線誘導が改善
- 背景の硬いタッチや色味が整理
- 完成度が上がり、背景とキャラが情報量の段差で分離

### 反復学習の効率

- カラーラフを横に置く運用(ch10 のコツ 1)と同じ感覚でチェックリストを横に置きながら作業
- ✕ / △ 項目だけに集中することで「次に学ぶこと」が自動的に明確化

- **チェックリスト + 自己診断 + 修正実演** は本講座のメタ学習装置。Sections 2〜3 の全コンテンツを操作的に統合する役割を持つ
