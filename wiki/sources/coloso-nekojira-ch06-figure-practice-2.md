# Nekojira 06. 人体練習パート 2

## 要旨

[[nekojira]] のパート 2。ch05 が「**伝統的順序**(ジェスチャー → 細部)」だったのに対し、本章は「**ミックス&マッチ手法**(参考から各パーツを独立に抽象化 → パズルのように再配置)」を実演する **対照的アプローチ**。同じ参考資料(横向き女性)を使って 2 通りの結果を比較。

## キーポイント

- **体の傾き観察**: 「肩のような部分」「頭の中心線(三角カードで一方カード化)」「足のシルエット(円柱化)」を観察してから描画開始
- **比率の重要観察**: 上半身と下半身が **1 対 1 比率**、腰と臀部の位置は半分、手の先端と特定部位がほぼ同じ高さ など
- **パーツ別の抽象化と幾何学化**:
  - 太もも → **円柱**(傾きと遠近感のため)
  - 硬い(脛) → **グラス(コップ)型**(細い円柱が逆さに見える形)
  - 足 → **三角系(少し上に伸ばす)**
  - 上半身 → **長方形 + 曲線で曲がり角**
  - 腕 → **6 ストロークでの単純化**
  - 前腕 → **円柱**
  - 手 → **四角形**
  - 頭 → **箱の形**
- **パズルアプローチ**: 各パーツを別レイヤーに切り出し、ジェスチャーガイドの上に配置 → Ctrl+T で回転調整 → ジェスチャーガイドを非表示 → 細部清書
- **2 種類の結果比較**: ミックス&マッチで配置した骨格 + パーツ → そのまま清書(配置を変えず、同じ場所に直接描き込む 2 番目のバージョン)
- **ネガティブシェイプの実適用**: 「腕の輪郭が難しい場合は **ネガティブスペースを観察**してください」「青い線を見てから確認」(8:12) → [[negative-shape]] の人体ドローイングへの直接実装
- **「お尻が少し大きすぎますね。申し訳ありません。大きめのお尻を描きは私の悪いです」**(7:50) — 自己の癖を率直に開示する教授スタイル
