# Nekojira 15. 最終ドローイングスケッチとプラン (パート 1)

## 要旨

[[nekojira]] **最終ドローイング工程の開始**。テーマは「**長い髪の少女、指を組んだポーズ、クラシックなドレス、強い風**」。**マスク&キューブ法**(ch09 由来)で顔比率を、**ミックス&マッチ**(ch04/06 由来)で体パーツを個別に組み立ててから配置する。「**記号的な形だから修正コストが最小限**」という低コスト実験フェーズの哲学が中心。手・袖・スカートの個別パーツを **別キャンバスで研究 → 貼り付け** する技法も実演。ch15_02 は空(動画依存の live drawing)。

## キーポイント

### コンセプト

- 長い髪の少女、両手の指を組んだポーズ、強い風で髪とドレスがダイナミックに流れる
- クラシックなドレス
- **45° の顔角度**
- **マスク&キューブ法**(ch09)で顔の比率を捉える
- **ミックス&マッチ手法**(ch04)で体パーツを個別に書いて組み合わせ

### パーツ別記号化(超単純化)

| パーツ | 表現 |
|---|---|
| 胴体 | 45° の単純な四角 |
| 骨盤 | 小さな四角 |
| 上腕 | 単純な円柱 |
| 前腕 | (短縮法のため)意図的に短い円柱 |
| 頭部 | 顔は単純な四角、頭の向きは三角形 |

- **四角を半分に分けて目の上部の位置を示す**
- **三角形から構造を伸ばし、頭蓋の向きと形を表現**

### 「記号的だから修正コストが最小限」哲学

- 「これは私のお気に入りのポーズスケッチと実験方法の 1 つです。**間違いに対する許容範囲が大きいからです**。全て記号的な形で書かれているので細部を気にせず簡単に調整できます」(ch15_01 4:25)
- 「**詳細を加えてイラストに時間をかければかけるほど修正のコストが高くなります**」「**今は全て記号的な形なので修正コストは最小限です。そのためストレスなく大胆に実験することができます**」(ch15_01 4:43)

### 別キャンバスでの「パーツ研究 → 貼り付け」技法

- 「**手や足の特定の角度やポーズが必要な時は別々に書いてイラストに貼り付けます**」(ch15_03 1:19)
- 「**全身を毎回書く必要はありません**。体の特定の部分にふれな場合はまずその部分だけを切り離して形を研究することをお勧めします」(ch15_03 0:55)
- 「**解剖学は常に最も大きな課題ですが、別々に書いて貼り付けるこの技法は課題解決の良い方法です**」(ch15_03 3:15)
- → これは **CPU 節約**(ch07)の具体的な実装

### 袖・スカート研究のミニ実演

- 参考画像から **大きなシルエット → ジグザグ抽象化 → 三角形+直線で再構築**
- 「**最も重要な部分だけを捉えます**。全てを捉える必要はありません」(ch15_03 4:55)
- 厚みのある袖は **腕の解剖学的な特徴を残しつつ厚みを加える**

### スカートのリボン視点(ch08 から発展)

- 「**紙を書く時のリボンテクニックと似ていることに気づきませんか?**」(ch15_03 13:46)
- スカートの **流れと回転** を「リボン」として捉える([[ribbon-technique-hair]] の発展系)
- スカートの重なりに **密度集中**(角度関係で距離が縮まる部分)

### 「形 → 構造 → 解剖学 → ひ」の階層

- 「形の概念を理解すれば **携帯(形態)、構造、解剖額(解剖学)、ひ** などの基礎知識を組み合わせてより面白い形を作り出すことができます」(ch15_03 16:36)
- これは **形最優先のフレームワーク**(ch07 CPU 比喩)を最終ドローイングで実装する宣言

### 「難しい部分は小さく分解 → 1 つずつ解決」哲学(再掲)

- 「**作業を小さな部分に分けて 1 つずつ解決することでより気楽で柔軟に進められる**」(ch15_03 18:25)
- ch15 の最終メッセージとして **「形態に関する結論」全体の方法論を凝縮**

### 別キャンバスへの書き直し

- ラフを別キャンバスに **より洗練されたバージョンで書き直す**(ch15_01 5:23)
- 元のキャンバスでパーツを完成度高く配置していれば不要、が一般的には書き直しが効率的
