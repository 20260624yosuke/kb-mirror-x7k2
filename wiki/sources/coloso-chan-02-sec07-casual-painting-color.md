# 第 07 項 カジュアル画における色彩とは?(Section 2 開幕)

## 要旨

Section 2 の開幕章。**「色塗りの上手さ」は主観的だが、商業性を持たせるなら「他人が見て上手」も必要** という二条件を提示。3 つの軸でカジュアルイラストを分類する: ① **テーマ軸**(キャラクター中心 vs 雰囲気重視)② **スタイル軸**(ドロー中心 vs 色塗り中心)③ **特性軸**(平面中心 vs 立体中心)。各軸の用途・長所・短所を比較し、自分が目指す方向を **意識的に選ぶ** ことが勉強効率を上げる根拠と説く。後半ではドロー中心と色塗り中心の同一キャラ実例を **線の強弱 / タッチ / 全体コントラスト / 個性表現の置き場所** で比較。ch08–10 はこの分類軸を 1 つずつ実演する予告。

## キーポイント

- **上手な色塗り = 自分が好き + 他人も好き(商業性) + 基本テクニック**
- **必要な 3 条件**:
  1. 他人の好を知る(普遍的・大衆的な絵の分析能力)
  2. 自分の好を言語化できる(感覚レベルでは説得力が出ない)
  3. 基本テクニック(明暗 / 描写 / 質感 / 配色 / 強弱 / 構成)
- **3 つの分類軸**(本章の中核):
  - **テーマ軸**: キャラクター中心(ファンアート、ゲームポートレート向き)vs 雰囲気重視(ローディングイラスト、作家性)
  - **スタイル軸**: ドロー中心(線が主、平面、軽快、日本人気)vs 色塗り中心(色が主、立体、中国・台湾的)
  - **特性軸**: 平面中心(絵柄強調)vs 立体中心(リアリティ + 共感、背景あり)
- **どの絵描きになりたいか**(目的地設定の重要性):
  - 依頼制作 / ゲーム会社 / アニメ → 個性は不利、トレンド適応必須
  - 同人活動 / ファンボックス / 支援サイト → トレンドに敏感だと不利
  - 趣味絵 → 自由
- **ドロー中心の構造**(右側の例):
  - 線の強弱を極端に → 線自体が魅力源
  - 色塗りは控えめ(エアブラシ等)→ 線の主張を消さない
  - 配色のコントラストを大きく → 書き込みで稼げない明暗を補う
  - テクスチャを追加 → 質感が分かりにくいデメリットを補う
- **色塗り中心の構造**(左側の例):
  - 線は控えめ・補助的 → 色に注目させる
  - 書き込みで明暗を細かく表現 → 線の不足を補う
  - 個性は **使う色 / ライティング表現 / 境界色** で出す
- **エゴ = 個性の材料**: 自分が「いい」と思う要素を意識的に取り入れる。曖昧では魅力にならない
- **「100% 以上の実力を発揮できる」プロ条件**(sec06 と接続): エゴを言語化し工程を整えれば達成可能
