# coloso ひづるめ ch06 ― 基本的なイラストの描き方の種類

> Section 02。塗りの種類(アニメ / イラスト・ブラシ / 厚塗り・グリザイユ)のメリ・デメと、本人独自の「力場起点」ワークフロー。

## 要約

代表的な塗りを長所短所で比較し、最後に本人の描き方を示す。本人は **グリザイユ寄りの厚塗り** をルーツ(アナログ油彩)に持ち、**絵の力場が強い場所から塗り始めて密度を拡散させる** 独自ワークフローを採る(完成イメージ + 色知識 + [[shi-sen-yu-dou|視線誘導]]の理解が前提)。

## ソース内の主要主張(塗り別)

- **アニメ塗り**: 生産性が高く速い、線が大事、光と影をくっきり分ける。**イラストの基礎**でデメリットがほぼない。カジュアルキャラ志望は最初にこれから。
- **イラスト塗り / ブラシ塗り**(両者の区別は小): リアルっぽい、キャラクターイラストの主流、工程管理しやすい、安定。日本の主流。
- **厚塗り**: リアル・質感表現しやすい・レイヤーに縛られない・速い・**玄人向け**・線画をほぼ描かない。基礎がないと失敗しやすく「何回失敗したか」が鍵。
- **グリザイユ**: 厚塗り起源。バストアップ人物が描きやすい。**グレー(白黒)から描くので陰影が崩れない**、高速。
- **(独自)本人の描き方**([[rikiba-kiten-painting]]): ラフ → 初期感覚の色 → 力場が強い場所の周辺(まず上半身)→ その周辺背景 → 密度を上げて拡散 → 視線誘導ポイント作成 → 調整。クオリティ UP + 速度爆速。
