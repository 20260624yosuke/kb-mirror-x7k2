# coloso ひづるめ ch04 ― SNS 戦略と仕事をもらうために

> Section 01 の SNS 戦略章。バズの原理・NG 行動・流行の掴み方・0→2 万人手順・8 万いいねのコツ。本人の経験則中心(confidence: medium)。[[takeda-yohsuke]](X 主戦場)に直結する章。

## 要約

「質は客を呼び、それは信用となる」。画像は **1 秒未満 / 動画は最初の 3 秒** で勝負が決まるため、ファーストインプレッションと差別化が必須。バズは **運ではなく仕組み(構造)で再現** できて初めて成功。信用と期待値を守り、流行絵柄を研究し、フォロワー 2 万人を目指すと企業案件が来る。

## ソース内の主要主張

- **バズの原理**([[buzz-first-impression-and-structure]]): 客は忙しく飽きやすい。目につくものしか見ない(お菓子の成分表の比喩)。差別化は必須。偶然バズは危険で、2〜3 回再現できなければ成功でなく、**運を計算に入れない**。
- **SNS 運用 NG 行動**([[sns-ng-actions]]): 二次創作絵師の自分語り / 長文投稿(広告に見え無意識に避けられる)/ タグは 3 つまで / 日常投稿(絵師は期待値を失う)。アクティブユーザーこそ大事。例外 = フォロワー 50 万超のトップ絵師は無条件で信用が立つ(同じ運用を真似ると逆効果)。
- **SNS の厳しさ**(絵師レベル↑ + AI↑ で埋もれる)を越える = 自分を信じて描き続ける信念。楽な方法を探さない。
- **絵柄の流行の掴み方**([[egara-ryuukou]]): 5 万いいね以上のイラストが流行絵柄。集めて研究し自分の絵へ落とし込む。流行が染み付くと新流行を即察知できる。乗り遅れると人気絵師でもいいねが取れない。レジェンド(絵柄を築いた人)は変えなくてよい。漫画・文字入りは例外。
- **仕事を受ける条件**: 信用と期待値を保ち、火力を上げてフォロワー 2 万人。これで企業案件が舞い込む(本人は到達に約 2 年)。
- **0→2 万人フォロワー手順**([[zero-to-2man-followers]]): 人気キャラの別絵 3 枚(資料あり・公式級)→ タグ付け投稿、2 日は反応待ち(投稿・コメント返信もしない)→ FF 比(フォロー数 > フォロワー数は NG)→ 最低 200 いいね条件 → 成長しながら 500 人ずつ → 3,000 いいねの壁(最大の壁)→ 高いいね作をプロフ固定し信用利用 → 2 万人。ベストは 4 日に 1 枚。本人は 100 日チャレンジで 1 回目 +1,400 人。
- **8 万いいね以上のコツ**(おまけ)([[8man-iine-recipe]]): 流行絵柄(10 万いいね作 20 枚研究)+ 画力 + 信用 + 期待値 + 人気度 + 少しのセンシティブ(絶対領域・ふとした肌、下品な直接表現は NG)+ ドラマチックで **異質な絵**(フック: なぜ階段にグラス?)+ 少し大人の絵(14〜28 歳、幼すぎは伸びない)+ **勢いのない静かな絵**(流れのある絵は飽きられた)。
