# Nekojira 17. 講師の作業工程に関する簡単な説明

## 要旨

[[nekojira]] **Section 05(色彩明度)の開幕章**。最終ドローイング本体に入る前に、**別のキャラクター(3D モデル参考の男性)を題材に Nekojira のレンダリング・ワークフロー全体を 1 動画で凝縮実演**。**5 段階フレームワーク**(1. 影の形 → 2. 塔の値 → 3. 光と雰囲気 → 4. 反射と素材 + ベース色)を確立し、ch18 以降の各工程章への目次として機能する。「**難しい作業を段階に分け、1 度に 1 つの問題解決に集中**」する CPU 節約戦略の最も洗練された宣言。

## キーポイント

### Nekojira 5 段階レンダリング・ワークフロー

| 工程 | 内容 |
|---|---|
| 0(下準備) | **3D モデルでライティング構成を決定** + ベースカラーをパーツ分け |
| **1. 影の形** | コントラスト(明暗・密度)を考慮した影のシェイプデザイン(ハードブラシで素早く) |
| **2. トン(塔)の値** | 暗めの色から始めて徐々に明るく、グラディエントマップを試す |
| **3. 光と雰囲気** | セカンダリーライト追加 + 露出オーバー + アンビエント色変化 |
| **4. 反射と素材** | 目・髪の艶・服素材・SSS(サブサーフェススキャタリング)・ターミネーター |

「**まず光原の位置を決め、影の形をデザインし、塔の値、光と雰囲気、最後に反射と素材**」(ch17_01 0:41)

### ベース色の選択原則

- **最も明るい色をベースカラーに**(マルチプライで暗くしていくため)
- **明るすぎない 95% 程度** で明るい色を加える余地を残す
- 暗いベースから始めると **マルチプライで暗すぎ / 鮮やかすぎ** になりやすい

### CSP 特有の Tips

- **消しゴムを使わず「透明色」ツール**(ショートカット 1 を割り当て)で切り替え
- **透明ピクセルロック**(Alt+ ピクセル選択)で形を保持
- **Ctrl+ レイヤーで形を即座に取り戻せる**(後の調整余地)
- **線画レイヤーをオフ → 線なしでも形・構造が分かるか確認**(出来チェック)

### 影の色選択コツ

- **グレーから始める**(色感の半分 → サイドを上げる)
- 「**最初から明るすぎる影 / サイドの高い色は調整余地が狭い**」(ch17_01 13:02)
- **塔の値の関係を維持** したまま **彩度を変化** させる

### 純白光ストロークの原則

- 「**純粋な白色のみを使用、点圧をコントロールして後の上山時に邪魔になる中間ドンを作らない**」(ch17_01 14:00)
- 灰色や薄いグレーを使うと **冗談効果が弱くなる**

### グラディエントマップ多用

- 「**この段階ではグラディエントマップを試すことをお勧めします。光の効果を演出するのに最適なツール**」(ch17_01 14:53)
- 講師が **複数章で繰り返し** 推奨する個人的お気に入りツール

### サブサーフェススキャタリング(SSS)技法

- 「**影の縁に高サイドの色を使う**」「**強い光が皮膚を投化して散乱し、影の縁に赤みを作り出す**」(ch17_02 11:57)
- ターミネーター(影の境界部分)も「**輝かしい青色 → 影の境界**」と命名
- これは ye_jji の [[saido-no-3-points]] の SSS と同じ現象

### 目の描き方ワークフロー(ch17_02 9:00)

| 段階 | 内容 |
|---|---|
| 1 | グラデーションカラーで影の塔を捉える |
| 2 | ベースカラー(青)を徐々にサイド上げ |
| 3 | **目の大部分はサイドの低い灰色、交際(虹彩)の部分だけが高サイド** |
| 4 | オーバーレイレイヤーで柔らかいグラデーション |

- 「**この小さな部分だけで目を鮮やかに際立たせるのに十分**」 = **グレー基調 + 局所高彩度** という Nekojira の色味哲学

### グレー + 局所高彩度の哲学

- 「**鮮やかな色を大量に使うのではなく逆。グレーと少量の高サイド色を組み合わせ、グレーとサイドの退避(対比)を作り出す**」(ch17_02 10:15)
- 「**何かを輝かせるには比較対象が必要**」 = [[tai-hi]](対比の親概念)に直結

### 髪 → 衣装 → 全体調整の順序

- ch17_02 終盤〜ch17_03: 髪の影 → オクルージョン → 衣装の色変化 → 線画の色変更 → 目のハイライト
- **線画は黒のままにせず高サイド色に変更** = ye_jji の [[line-as-shadow-deformation]] と同じ運用

### 「個人の主観で進む」最終調整(ch17_04)

- 「**ここからは個人の主観的な好みに関わる部分なので自分の好きなように良いと思うように進める**」(ch17_04 6:02)
- これは [[intent-first-correction]](ye_jji ch22)と同じ哲学

## 引用に値する一節

> まず光原の位置を決め、その光の方向に基づいて影の形をデザインし、その形をより魅力的にする方法を考える必要があります。影の形が決まったら塔の値を考慮し、光と雰囲気作りも検討し、最後に反射と素材の質感について考えます。(ch17_01 0:41)

> 私の手順では難しい作業を段階に分け、1 度に 1 つの問題解決に集中します。手順は以下の通りです。影の形をデザインし、光と影を使い、式張とカラーモードを追加し、最後に素材や反射を考慮します。(ch17_03 6:59)

> 私の色のつけ方は単に鮮やかな色を大量に使うのではなく、むしろ逆です。グレーと少量の高サイド色を組み合わせ、グレーとサイドの退避を作り出します。(ch17_02 10:15)

> 影の縁に高サイドの色を使う...強い光が皮膚を投化して散乱し、影の縁に赤みを作り出す。個人的にこの効果を多様して色に変化をつけ、全体的な結果をより魅力的にしています。(ch17_02 11:57)

## 文字起こしノイズの注記

- 「カに 2 を当てて」→ **カに 2 次光を当てて**(secondary light)
- 「マルチプライヤー」→ **マルチプライ**(Multiply モード)
- 「サブサーフェイスキャタリング」→ **サブサーフェススキャタリング(SSS)**
- 「ターミネーター」→ 同(終端、影の境界)
- 「塔の値」/「東の値」/「ドン」/「トン」→ **トーン(tone)の値**(明度)
- 「式張」→ **彩度 / 色調**(文脈で判断)
- 「ピーピクセルロック」→ **透明ピクセルロック**(transparent pixel lock)
- 「アイドルトーン」→ **ハイライト・トーン / mid tone**(?要再確認)
- 「来店」→ **オーバーレイ / レイヤー効果**(?要再確認、文脈)
- 「謝って」→ **誤って**
- 「商点」→ **焦点**(focal point)
- 「カラーどっち」→ **カラーホイール**
- 「強膜」→ **(目の白目部分)強膜**(sclera、訳語そのまま)

## 個人的な所感 / 残った問い

- 本章は **Nekojira 色塗りワークフロー全体の目次** として機能。ch18(オクルージョンシャドウ/線画)、ch20(光と影)、ch21(色彩明度)、ch22(ライティングと雰囲気)、ch24(仕上げ)はすべて **本章の 5 段階のどれかを深掘り** する関係にある
- ye_jji の **色塗り 6 工程**(c14 PDF)と比較すると、Nekojira は **5 段階に整理 + ベース色を 0 段階に独立** という違い。両者は同じ問題を異なる粒度で分解しているが、**「形 → 値 → 光 → 素材」の順序は完全に一致**。これは `ye-jji-vs-nekojira-rendering-workflow-comparison` という analysis 候補
- **3D モデルを参考に強い影を作る** は ch22 でも繰り返される(ch17 では男性 3D、ch22 では女性 3D)→ Nekojira の **3D 補助ワークフロー** は概念化可能
- **「グレー基調 + 局所高彩度」** は Nekojira の最も特徴的な色味哲学 → ye_jji の [[saido-no-3-points]] と接続するが、Nekojira はより **広範囲をグレーに保つ**(局所性が強い)
