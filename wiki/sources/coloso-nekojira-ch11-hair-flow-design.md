# Nekojira 11. 練習 2：髪の毛の流れをデザインする

## 要旨

[[nekojira]] の Section 03 の **髪の毛実習**。**3 シーン**(ポニーテール = 風で揺れる / ストレートロング = 自然落ち着き / ロングダイナミック = 強風 + リボン)を順に描き、**リボン技法**(ch08)を全面適用。**「3 回の繰り返しを避ける」「斜めに切る」「ネガティブシェイプを使う」**の原則を実装する。後半は **レイヤーのプロパティ → エッジ硬化** という CSP のシルエット支援機能を使う小技も紹介。

## キーポイント

### 3 シーン構成

| シーン | 紙のタイプ | キーワード | リボン適用度 |
|---|---|---|---|
| 1 | ポニーテール | 風で揺れる、ダイナミック | 中(リボン少なめ) |
| 2 | ストレートロング | 自然・落ち着き・エレガント | 低(リボン回転は乱雑感を生むので避ける) |
| 3 | ダイナミックロング | 強風 + リボン技法フル | 高(回転効果・重なり多数) |

→ シーンごとに **適切なツールを選択**:「**リボンを揺らすのはダイナミックな形に効果的だが、今回は自然なストレートヘアを目指している**」「**回転効果を加えると少し乱雑に見える**」(12:57)

### 髪のデザイン原則(ch08/10 から実装)

- **3 回の繰り返しセグメントは避ける**: 「**123 とると少しるかもしれません**」 = 同じ方向 3 連続は単調 → 「**サイクルを破るために違う方向を使う**」(1:41)
- **斜めに切る**: 真ん中で対称的に切るのではなく斜めの位置
- **大小・密集と空間・曲線と直線**(コントラスト 3)を常に意識
- **ネガティブシェイプの読みやすさ**: 「**ネガティブスペースを見てください。尖がりすぎているので切り取りたい**」「**今の方が読みやすくなりました**」(7:01) — 鋭角を切る修正
- **太さの変化**(リボンの太さ変化)を意識
- **「変化点については大きな変更を避けて簡単なものにしましょう**」(11:51)
- **対称の禁止再強調**: 「**頭蓋骨の輪郭を表現するために土的に線を止めます**」(19:22)

### CSP の小技 — レイヤープロパティでシルエット強化

- **レイヤーのプロパティ → エッジの太さを黒 + 硬いブラシ**(5:16〜)
- 簡単に **面白いシルエット** を作るのに役立つ
- 一度作ったら **ラスタライズ** して内部の詳細を加えていく

### リボン技法の応用展開

- リボン = 折り返し + ねじれ + 太さ変化
- **C カーブから始める** → 面白そうな曲線 → ジグザグしたリボン
- 「**Cカーブから始めましょう。面白そうだから試してみましょう。このカーブがあると面白そうです。リボンのような形を表現できそうですから**」(8:58)
- **重なり(オーバーラップ)** を意図的に多用 → 髪の層の細部を表現
- **頭蓋骨の輪郭を表現するため髪の側面に三角形を使う**(13:45)

### 実験的姿勢の正当化

- 「**実験や思考錯誤を重ねてみましょう**」(10:30)
- 「**勇気を持って描画を楽しんでください**」(16:31)
- 「**時には少しルールを破ってもっと面白い結果を試してみることもあります**」(16:26)
