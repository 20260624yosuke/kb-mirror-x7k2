# ye_jji_07. 多彩な色味の活用(基礎編)

## 要旨

色味パート前半。**光 = 色** の物理的紐づけ(RGB 加法混色)から始まり、立体感を保ったまま多彩さを出すための **「高彩度を許される 3 ポイント」**(透過光・明暗境界・同系色光)を理論として提示。さらに **錯視を抑える色彩トレーニング**(スポイトではなく目分量 → 写真と比較しながら調整)で「自分の癖」を発見する自学プロトコルを実演。SD イラスト + 写真模写の 2 つの実習で完結する。

## キーポイント

### 光と色の物理(RGB 加法混色)

- 光の三原色 R/G/B、すべて混ぜると白
- **彩度 = RGB の値の差**。3 値が同じ → 無彩色、1 値だけ突出 → 高彩度
- 類似色を混ぜると彩度が上がる、補色を混ぜると彩度が下がる(クリスタの加算レイヤーで検証可)
- 絵が単調な人は「光を考慮していない」可能性が高い

### 高彩度が許される 3 ポイント

立体感のあるイラストでは中間トーンに低彩度色が混ざる宿命 → 多彩さを出すには **理論上高彩度が成立する 3 箇所** を狙う:

1. **[[touka-hikari|透過光(SSS = サブサーフェススキャタリング)]]**
   - 薄い物体(耳・髪・布のエッジ・葉)を通過する光が物体内で散乱 → 別地点から出る
   - 出てくる光は **物体の固有色で高彩度** になる
   - 写真観察: 耳が赤く、髪先がオレンジ色に
2. **[[mei-an-kyoukai-saido|明暗境界(中間トーン)]] の彩度**
   - 強い光で明部が **白飛び**(色相飽和)し彩度が下がる → 中間トーンで本来の彩度を取り戻す
   - 白飛びした明部の隣に **高彩度の中間トーン** が必要
3. **同系色の光を受ける部分**
   - 物体が反射する波長と同系色の光が当たると、吸収が少なく多くの光が反射 → **高明度 + 高彩度**

### よくある間違い

- **中間トーン全体ではなく境界ラインだけを高彩度にする** → 細い高彩度線が浮いて立体感を壊す
- **高彩度部分の明度を下げ忘れ** → 高彩度は低彩度より明度が低く描かれるべき(同じ明度数値なら彩度が高い方が暗く見える)。中間トーンの明度が暗部より低くなるケースが頻発
  - 検証法: レイヤー効果カラーで実際の明度を確認

### 多彩さの拡張テクニック

- **固有色 + 類似色** = 滑らかに溶け合い、自然に多彩
- **固有色 + 補色** = 強いコントラストで情報量増、主題部用
- 高彩度部分は基本的に固有色を使う → そこから類似 / 補色へ広げる

### 色彩トレーニング(写真模写)

- 目標: 周囲の色による錯視を抑え、見える色を正確に捉える
- 手順:
  1. **目分量で下地を塗る**(スポイトは使わない)
  2. 写真と比較して「より明るい/暗い/彩度高い/低い/色相がどっち寄り」を **順番に反映**
  3. 最終的にスポイトで誤差を比較 → 自分の癖を発見
- **アンチパターン**: スポイトで一発抽出 → 比較プロセスがなく上達しない、時間ばかりかかる
- 講師自身の癖: 「明度が下がる(彩度を上げる癖の副作用)」「暖色寄りに傾く」

### 錯視について

- 同じモノクロでも、暖色の隣 → 寒色寄りに、寒色の隣 → 暖色寄りに見える
- 周囲の明度・彩度・色相が見え方を歪める → 定期的な色彩模写で癖を矯正

## 引用に値する一節

> 絵の式調が単調な方は光を考慮していない可能性が高いです。光を適用するだけで多彩な光と敷張を演出できます。

> 中間トーンは名部と安部の中間程度のトーンを持つべきです。中間トーンが暗くなってはいけません。

> 1 度でこの色を出そうとするのではありません。下地の色と比較してどう違うかを反映していくのです。

## 個人的な所感 / 残った問い

- **SSS の説明** が初心者向けに最小化されているのが見事(「光が薄い物体を通過し、内部で散乱して別地点から出る」)
- 「中間トーン全体が高彩度」原則は、サブカル系の典型ミス(教会だけハイライト)を明確に否定。論理的根拠(光理論)と合わせて記憶
- 写真模写の **「目分量 → 比較調整」プロトコル** は応用範囲が広い(写実・色設計全般)
- ch08 で扱う「思考・補助・環境」の概念がここで先行登場 → ch07/08 は連続教材として捉えるべき

- **p3 高彩度のポイント 1: 透過光 (SSS)**:
  - **★ 新規追加情報**: **「SSS は、ある程度密度の低い物質で見られる現象で、密度の高い金属や石ではほとんど見られない」** — 本文では言及されていない適用範囲の限定

  - 球体 3 体の図(低彩度の中間 / 強い光で過反射した左 / 中間トーンで本来の彩度を取り戻した右)

- **p5 高彩度のポイント 3: 同じ系列の光を受けた地点**:
  - 赤い球体が赤い面に置かれている図解

- **p7 錯視の種類と注意点**:
