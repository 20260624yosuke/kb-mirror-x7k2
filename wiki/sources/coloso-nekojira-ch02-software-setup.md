# Nekojira 02. ソフトウェアセットアップ

## 要旨

[[nekojira]] が **Clip Studio Paint(クリスタ)** を使う前提で、講座で多用する **ブラシのダウンロード方法 / 環境設定 / ショートカット設定 / 5 つのお気に入りブラシ紹介 / レイヤー効果の使い方** を解説する完全に実用的なセットアップ章。

## キーポイント

- **ブラシ DL**: 講座資料に添付されたブラシをダウンロード、複製を作成して新しいグループに整理することを推奨
- **筆圧設定**: ファイル → 環境設定 → **目を閉じて普段の描き方で何か描く** → システムが自動的に最適な筆圧を調整(タブレットや描き癖で変わるので各自やる必要あり)
- **カーソル設定**: デフォルトの「ブラシサイズ(丸)」ではなく **「ブラシの形」+「ツールのカーソル」** に変更 → 四角ブラシでも四角カーソル、ハッチングは点線 → 方向確認が容易
- **重要ショートカット 4 つ**(全部好きなキーに割当):
  1. **描画と透明色の切り替え** = ブラシの先端のまま透明ピクセルで消しゴム化(本人は **「地」キー**)
  2. **水平方向に反転**(本人は **Ctrl+F**)— 正面顔や対象的なもののチェック時
  3. **選択範囲の枠線の表示/非表示**(本人は **Ctrl+H**)— 点線が邪魔な時
  4. **定規にスナップ + 特殊定規にスナップ**(本人は **Ctrl+2**)— パース定規切替
- **Ctrl + クリック**(レイヤー上)= レイヤー内の要素を選択 → 範囲外にはみ出さず混色できる
- **新規補正レイヤー**(色調補正レイヤー): 上のレイヤーには影響せず下のレイヤーにのみ影響 → 局所色調整に便利(Ctrl+B ではなくこれを使う)

## お気に入りブラシ 5 つ

| ブラシ | 用途 | 備考 |
|---|---|---|
| **G ペン** | スケッチ + 線画 | 丸い基本ブラシ、筆圧で線幅変化、「スケッチ作業の全工程」これで完結 |
| **ブラシ番号 394 / 400** | 補助 | (具体的内容不明、講座配布ブラシ) |
| **ソフト 7** | グラデーション系 | 柔らかい輪郭・色をブレンド |
| **濃い鉛筆** | レンダリング | 実際の鉛筆のような感じ、**レンダリング作業の 80% はこれ**、肌色を入れて筆圧で輪郭を強くする |
| **平筆系(兵質ブラシ)** | テクスチャ / 面白い形 | 丸では難しい鋭いエッジや有機的な形を作る、オーガニックなヒットに利用 |

→ メインで使うのは「フィールド」(= 上記 5 つ)。他のブラシは時々のみ使用。

## パース定規スナップのデモ

- レイヤー → パース定規作成 → 3 点法でセットアップ
- **Ctrl+2** で「特殊定規にスナップ ON/OFF」をトグル
- スナップ ON: パースに沿った直線が引ける → 背景・テクスチャをパースに従って配置できる
- 平筆をスナップさせれば「面白いテクスチャエフェクト」が簡単に作れる

## 引用に値する一節

> クリップスタジオの消しゴムの種類は比較的少ないです。消しゴムの代わりに色の透明度を使って消しゴムのように扱います。そうすると簡単になりブラシの先端を作り直すことができます。(1:43)

> 必圧で線の太さを変えられる感覚が大好きで、その表現方法がとても気に入っています。デフォルトのペンだけど既にで強力な機能を持っています。(6:30)
