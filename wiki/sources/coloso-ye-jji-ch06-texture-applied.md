# ye_jji_06. 多様なテクスチャー描写(応用編)

## 要旨

ch05 の続編。**混合反射** という新カテゴリを導入し、**小物 4 種**(ポーション瓶 + 靴(混合反射) + ぬいぐるみ(拡散反射) + ハンバーガー(自然物の多彩色))を 30〜60 分の実習で順に描く。各小物で「写真観察 → 反射特性の特定 → 描写順序」のループを反復し、テクスチャー描写の **判別力** を養うことが目的。最重要 Tip は **「明暗境界のシルエットにテクスチャー(でこぼこ)を仕込めば、絵全体がその質感に見える(錯覚)」** という効率原則。

## キーポイント

### 反射の 3 分類(本章で整理される)

- [[sei-han-sha|正反射]] = 鏡面、表面滑らか、像をはっきり反射
- [[ran-han-sha|乱反射(拡散反射)]] = 表面でこぼこ、像を散乱、反射形状なし、ハイライトのみ
- [[kon-gou-han-sha|混合反射]] = 拡散反射 + 弱い正反射。靴・革・くすんだ金属などの中間素材
  - 表面の **荒さ** によって描写方法が変わる:
    - 荒さ低い → 正反射に近い(鮮明な反射)
    - 荒さ高い → 拡散反射に近い(ハイライトのみ、境界ぼやけ)
  - ハイライトの境界はぼやかして溶け込ませる

### 反射率の高い物体に情報量を盛る Tip

「周りに何かたくさんあると仮定して書く」: ハイライト数を増やす、空・床・装飾の反射色を追加、補色を入れて彩度コントラストを作る。**情報量が物足りなければ仮想の反射ソースを足せばよい**

### ぬいぐるみ(拡散反射の応用)

- 表面全体にでこぼこ質感を描くのは大変 → **明暗境界線にだけでこぼこテクスチャーを集中** させると、人の目が錯覚で全体をでこぼこと認識する
- 中間トーンは「毛の塊と塊の間に影ができる」と捉えて描写
- 反射光は「下に芝生があると想定」など仮想ソースで色味を作る
- ステッチ・縫い目を追加 → 縫い目に沿ったでこぼこ → 反射形状をその縫い目で再分割

### ハンバーガー(自然物の多彩色)

- 自然物は **下地が単色だと人工的に見える** → ブラシタッチで多彩な色を仕込む
- 下地のレイヤーと明暗のレイヤーを分け、不透明度を調整できるブラシ(濃い鉛筆)で重ねる
- 各部位ごとに反射率が違う: パン(弱い艶=薄いハイライト)、レタス(混合反射)、トマト(弱反射)、チーズ(混合反射・荒め)、パティ(コーティング=肉汁で高反射、ハイライト点々)
- 「単調に見えたら色を足す → 影を入れ直す」のループ

### ワークフロー Tips

- **レイヤー戦略**: 下地・明暗・反射・ハイライトを別レイヤーで運用するが、講師は基本的に **ノーマルレイヤーで描き、スポイトで色を取り直す** スタイル。レイヤー効果はソフトライト・スクリーンを限定的に使用
- **ステッチ・縫い目ブラシ**: 曲線定規 + ブラシで線を引き、ピクセル流動化で整える。素材を使った後は必ずリタッチで馴染ませる
- **補正の最終工程**: ソフトライトレイヤーで主題部のコントラストを上げ、副題部のコントラストを下げる(視線誘導の補強)
