# 第 17 項 現実的な描写練習 = 表現法の派生(練習 3/3)

## 要旨

Section 3 の最後の練習法 = **書き込み訓練**。だが単に描写を増やす練習ではなく、**ベースとなる自分の塗り方から「派生スタイル」を作り出す体系的メソッド**。

**最重要メソッド = 「情報の総量一定 + ペア操作」**: 4 情報軸(色相/彩度/明度差/密度)のうち、**片方を増やしたら片方を減らす** ことで情報総量を維持しつつスタイルを派生させる。これにより自分の塗り方を元に **4 派生スタイル** が作れる:
1. **雰囲気重視風**(色相増 + 彩度減 + 明度差減 + 密度増)
2. **メンヘラ風**(色相増 + 彩度極大 + 密度減 + 明度差減)
3. **Web トゥーン風**(明度差増 + 彩度増 + 色相減 + 密度減)
4. **青白系のリアル風**(密度極大 + 色相減 + 明度差減 + 彩度減)

基本描写の前提として **グリッド線法**(縦/横/筋肉に沿ったグリッドを引いて立体把握 → 数学的明度配点)。**光の方向は X/Y/Z 3 軸必須**(右上だけだと不完全)。**色塗り詰まり時のドロー側 vs 色塗り側診断フレーム**(明暗の入れ方が分からない = ドロー側、コントラスト調整が分からない = 色塗り側)。

## キーポイント

- **情報総量一定 + ペア操作**(本講座最重要メソッド): 4 情報軸の片方 ↑ なら片方 ↓ で総量維持
- **ベースから 4 派生スタイル**(本章実演):
  - 雰囲気重視(色相 + 密度 ↑、彩度 + 明度 ↓)
  - メンヘラ風(色相極大 + 明度 ↓)
  - Web トゥーン風(明度差 + 彩度 ↑、色相 + 密度 ↓)
  - 青白リアル風(密度極大、他全 ↓)
- **書き込みは顔/肌(ボディ)/衣服の 3 パーツ中心**で勉強する(chan の Coloso Plus 講座と接続)
- **基本描写の前提 = グリッド線法**: 直線 → 曲線で物体上にメッシュを引いて立体把握
- **光の方向は X/Y/Z 3 軸必須**: 右上・左上だけだと不完全、前後方向(Z 軸)も指定
- **明暗を数学的に配点**: グリッドの各面に +1/+2/0/-1/-2 と数値を付けて色を塗る
- **物体間影 = キャストシャドウも計算する**: フォームシャドウだけでなく
- **色塗り詰まり時の診断フレーム**:
  - 明暗をどこに入ればいいか分からない = **ドローイング(立体把握)が弱い**
  - コントラストをどれくらい強くすればいいか分からない = **色塗り側が弱い**
- **「ドローイングが嫌いだから色塗りに逃げる」罠**: 色塗りが弱いのに色塗りばかり勉強する非合理
- **パーツ間 vs パーツ内 のコントラスト**両方を意識: 髪と肌の差 + 髪内部の影の差を独立に設計
- **色相変えてもトーンは安定維持**: 派生スタイルでも白黒予測したトーンは崩さない

## 引用に値する一節

> 「すぐに実践で使えるような塗り方を自分で作り出せるように、今回の方法を準備した」
> 「色塗りが難しいと感じる方の中には、どの色を使えばいいのか分からない方がいます。他には明暗をどこに入ればいいのか分からない方。立体的な内容を把握することが最優先になります」
