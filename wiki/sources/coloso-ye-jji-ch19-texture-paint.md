# ye_jji_19. 色塗り 05:テクスチャー描写

## 要旨

色塗り 7 工程の **工程 5(質感描写、髪以外の素材)**。ch05/ch06 で確立した **テクスチャー 5 区分(正反射 / 拡散 / 混合 / 透明 / 半透明 / 異方性)** をライブで適用しつつ、**「曲面の角に情報量を上げる」「仮想の反射源を増やす」** など密度コントロールの実用テクが詰まる。素材を順に描写:**パフェ(透明 + 拡散 + 半透明 + 異方性のミックス)→ 金属装飾(異方性正反射)→ 缶コーラ(異方性正反射の単純例)→ 水濡れ表現(乗算 + 反射の 2 段プロセス)→ 透ける水着**。後半は **濡れ表現** が独立技法として詳細に展開され、布と肌の透過関係も実装される。

## キーポイント

### パフェの 4 素材を分けて描く

| 素材 | 質感 | 描写法 |
|---|---|---|
| **ホイップクリーム** | 拡散反射 + 黄色がかった白 | くぼみのオクルージョン + 高さ高め。**最も明るく** 保つ |
| **アイスクリーム** | 拡散反射 | 表面のでこぼこをブラシでポンポン、割れの陰影 |
| **イチゴ** | 反射率高め拡散 + 異方性 | シードを点で配置 + シード位置に明暗(空向き面 = 青、下向き = 砂のオレンジ)+ フレネル反射でサイド明るく、パラソルからのハイライト |
| **ガラスコップ** | 透明 + コーティング | 内面を乱反射として描く + 上にスクリーンレイヤーで透明体描写を重ねる(ch05 透明実習の応用) |

**ホイップが最も明るい** が全体配色のルール。イチゴ内側の白がホイップを超えないように注意。

### パフェのガラス透明体の二層構造

- 下層:**反射する物体として内面の明暗** を描く(中央暗、ブルーベリーとの接触オクルージョン)
- 上層:**スクリーンレイヤーで反射物** を重ねる(肌/指/水着/髪/ヤシ/空/イチゴ/砂)
- 上層に **太陽の円形ハイライト** + スクリーンレイヤーで日陰時のパラソル反射光

### 金属装飾の手順(ch05 異方性反射の実装)

1. **ハイライト先行** + ハイライト以外を 1 段暗く(正反射のセオリー)
2. 反射: 砂(同系色 → 高彩度)、空(寒色 → 低彩度)、肌(同系色 → 高彩度)、髪反射
3. **異方性に沿って木目方向にハイライト分割**
4. オクルージョン部分は黒に近く(物体同士の接触で暗化)
5. ハイライト隣に **クライトンを追加** して金属の輝きを強調
6. 真珠 = **ハイライト / 暗 / 反射** の島模様で簡略化(細かい点描写は省略、島模様用の形だけ)

### 曲面の角に情報量を集中

- 角部分のハイライトを **多重化** + 色を 2 種類以上
- 翼の装飾など曲がりの強い箇所に集中(情報量増は曲面で行う)

### 「キラキラ反射」テクニック(仮想反射源)

- 何かが反射していると **仮定** → 情報量が物足りない時の鉄板技
- 水のキラキラ・雲・他物体の反射を **架空で入れて** 密度を上げる
- 「ここには砂だけである必要はない、水のようなキラキラしたものが反射する可能性もある」

### 缶(コーラ)

- 異方性正反射 → ハイライトが縦か横に伸びる(円柱なら縦)
- **四角形ブラシ** でハイライトを描く効率テク
- 床の反射を軽く
- ラフ運用(前景で歯に隠れる部分が多いため)

### 水濡れ表現の 2 段プロセス

1. **乗算レイヤー** で水が付いた部分を暗く設定(光遮断のため明度低下)
2. その上に **反射ハイライト** を追加(水の薄膜が反射体になる)

#### 水濡れの描き方

- 体のグリッドに沿って **薄い水 / 厚い水溜まり** を分ける
- **Y 字の繰り返しに注意** → 太ももの片方は逆向きに(左右対称を回避)
- 顔・腕・胸のラインに沿って水が落ちる
- フレネル反射で **傾いた部分が明るくなる**
- 水のオクルージョンシャドウも入れる

### 透ける水着

- 上山レイヤー(乗算)で **肌の色を布に塗る** ことで透け感
- **布と肌が接している部分だけ** 透ける(骨盤や腹部の出っ張り、福部の辺り)
- 空気の溜まる **丸い気胞部分は透けない** → 消す
- シワで出っ張る部分も透けない
- **濡れている = 水が一層コーティングされている** → 布の上に反射ハイライトを追加(キラキラに)

## 個人的な所感 / 残った問い

- 「**ホイップが最高明度**」のルールは食べ物イラスト全般に応用可能(ホイップ含むカクテル類、生クリーム入りデザートなど)
- 「**仮想の反射源**」は ch06 で出た原則の再強調 — 質感描写の核
- 水濡れの 2 段プロセス(乗算 → 反射)は観察ベースで導出されており、再現性が高い実用フレームワーク
- 「透ける布」の **接触部のみ透ける / 気胞は透けない / シワは透けない** という 3 ルールは観察を体系化した稀少な技法
- 「**完璧な仕上げは ch20-22 で行う**」と複数回明示 — 工程設計の予告が明示的
