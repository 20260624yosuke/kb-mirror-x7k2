# coloso ひづるめ ch08 ― 人体を軽く学ぶ

> Section 02。人体は暗記、効率的学習は「少しの練習と多くの実践」、絵の中盤での人体確認法。

## 要約

人体は暗記であり、**実際に描いて初めて身につく**。書き始めはクロッキー不要(吸収が少なく非効率)。レベルに応じて **質 → 量 → 質** と力点を切り替える。キャラの比率は現実と違うので好きなキャラの等身を測って覚える。キャラを描きながら学ぶと SNS 投稿と学習を両立できる。人体理解は約 1,000 時間。

## ソース内の主要主張

- **質 → 量 → 質の道のり**([[shitsu-ryou-shitsu]]): 初期はじっくり質、中間は量(速く描く力)、終着点はまた質。一般の勉強は反復(量)が効率的だが、**絵はじっくり学ぶ方がよい**。
- **人体は暗記 + 比率**([[jintai-anki]]): 比率を外すと後から狂う。キャラの比率は現実と異なるので **好きなキャラの等身を測って覚える**。
- **描きながら学ぶ**([[kyara-egakinagara-gakushu]]): キャラに寄せた人体を写真から起こすと、SNS 投稿イラストと学習を両立できる。もう一つは写真を最初からデッサン(練習、ch10 で実演)。
- 必ず資料を見る(ソッカの美術解剖学ノートを辞書的に)。資料サイト: Unsplash / Shotdeck / Texels(要確認)/ Pinterest。
