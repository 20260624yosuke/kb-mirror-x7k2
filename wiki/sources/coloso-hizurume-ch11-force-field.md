# coloso ひづるめ ch11 ― 絵の力場

> Section 03「目の錯覚と視線誘導」の第 1 章。視線誘導([[coloso-hizurume-ch12-gaze-guidance|ch12]])の前提となる「絵の力場」を導入する。元 md は Whisper 逐語(誤変換多数)。本要約は明らかな誤認識を補正している(例: 「円 / N の力場」→絵の力場、「迷路 / メール管理」→明度管理、「焦点コトロール」→焦点コントロール)。

## 要約

「絵の力場」とは、画面内で **焦点(視線が集まる場所)をコントロールする力** が働く場所の分布。ひづるめはこれをサーモグラフィ風に **黄(強)/ 赤(中)/ 青(弱)** で可視化する。**力場を理解してから視線誘導が発生する**(順序は力場が先で不可分)。脳は無意識に「物の中心」から見始め、「物と物との境界線周辺」と「画面端」を認識しづらい。ゆえに青(弱)の領域は **情報を抜いてよい**(ぼかし・テクスチャのアレンジが目立たない)。強い場所ほどあらゆる対比を上げ、端へ向かうほど対比を下げる。

## ソース内の主要主張

- **絵の力場 = 焦点コントロールの力の分布**。黄 = 強(視線が集まる)/ 赤 = 中 / 青 = 弱(画面端・物と物の境界)。**力場が視線誘導の前提**(切り離せない)。
- **脳の認知傾向**: 無意識に物の中心から見始め、境界線周辺・画面端を認識しづらい。→ 端や境界は情報を抜いても気づかれず、一体感が出る。ぼかしても物体は認識できる。
- **3 分割法が効く理由**は「端 = 境界 = 認識されにくい場所を避け、中心寄りに主役を置く」から。だが **仕組みを理解せず比率式(3 分割法・レイルマン)に頼ると縛られる**。ひづるめは現在ほぼ使わない。
- **境界そのものは明暗・色相でしっかり分けて認識できること**が必須(線だけ・コントラスト無しは NG)。これにより「遠目はきっちり / 拡大はラフ」の絵が成立。
- **強い場所ほど対比を高く、端ほど対比を低く**(明度・色・シェイプ・曖昧×シャープ)。
- **「線でごまかしていないか」**: 線画を抜いて物体が判別できるかが自己テスト。抜いて崩れる = 明度(可読性)管理が未熟。線は細く、サムネ / 縮小で潰れる → 色・明度で境界を分ける。後ろに「嘘でも」コントラスト源を置く。
- **焦点コントロールの光側優先 / 影側優先(ライトサイド / ダークサイド)**: 光部分と影部分のどちらを目立たせるか明確に決める。判断は「全体的に見て顔が明るいか暗いか」。優先側を高密度に、反対側の情報を抜く。アニメは光側優先が多い。フード内を描くかどうかも光 / 影優先で操作。
- **優先順位が決まれば資料収集が効率化**(視線が集まる場所の資料を厚く集める)。
