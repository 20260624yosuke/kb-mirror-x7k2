# 第 06 項 マウスでも可能なカラーラフを描くこと(Section 1.5 彩色法)

## 要旨

Section 1 と Section 2 の橋渡しとして配置された **「実習用彩色法」** の章。chan の厚塗りワークフローを **筆圧解除ハードブラシ + 投げ縄ツール + スポイト** だけで実行する方法を提示する。タッチを意図的に排除することで **「色塗り」と「タッチ表現」を工程分離** し、色塗りの正確性と補正容易性を上げる。工程は **サムネ → 第 1 次スケッチ → (第 2 次スケッチ) → 第 1 カラーラフ(配色 + 雰囲気) → 第 2 カラーラフ(ライティング・大きな明暗) → 第 3 カラーラフ(オクルージョン + ハイライト)** の最大 5–6 段階に分解。**苦手な工程ほど分解段階を増やす** ことが熟達の鍵。「マウスでもかける = 必圧依存をなくす」が最大の主張。

## キーポイント

- **工程分解の原則**: 苦手なパートほど工程を増やす。同じものを 1 回より 2 回、2 回より 3 回繰り返すことで熟練度が上がる(リズムゲーム比喩)
- **カラーラフ 3 段階**:
  1. **第 1 カラーラフ**: 全体の配色と画面の雰囲気
  2. **第 2 カラーラフ**: ライティング・大きな明暗・領域設定
  3. **第 3 カラーラフ**: オクルージョン + ハイライト = 完成直前まで仕上げ
- **「遠くから見て完成したように見えるか」が基準**: ラフの完成条件 = 細部を抜きに全体のシルエットと明暗構造で完成感
- **必圧解除ハードブラシ + 投げ縄ツール主体**:
  - タッチが残らない = 情報量が減って脳のリソースを「観察」に回せる
  - 領域選択で補正が極めて楽 = 後工程で色相を全面変えるのも簡単
  - ごまかせない = 自分の弱点がドローイングか配色か明暗かが明確に出る
  - 個性は最後にタッチで足せる(必圧解除は色ラフ工程だけのルール)
- **トーンは 6 段階を上限とした分類**: 最も明るい部分を 1、暗くなるほど 2/3/4… 多すぎるとコントロールできない(Coloso Plus 既存課程ではより少数に圧縮済み)
- **厚塗りを好む理由**: 人は線ではなく面で物を認識するため、面で組まれたラフは完成形を予測しやすい(線顔のラフでは塗ったときの違和感が出やすい)
- **配色のコツ**: 似合う色のほとんどは高彩度。スポイトより **カラーピッカーで意図的に色を指定** することで色の感覚も身につく
- **業務適性**: 会社・外注の依頼では工期が短く、本手法の作業速度 + シンプル仕上げが効く(講師の外勤務時の実体験)
- **境界色(教会色 = 明暗の境目の高彩度ポイント)**: カジュアル絵は実写より明暗差が少ないため、明暗境界の彩度ピークを強調すると視線が集まる
- **逆光のサイドを下げる**: メイン光より逆光の彩度を低くすると視線が中央に行く
- **プロの定義**: 「常に 100% 以上の実力を発揮できること」。コンディション差を工程分解と最適化で吸収する

## 個人的な所感 / 残った問い

- **苦手な工程ほど分解** という学習論は ye_jji ch23「興味駆動学習」([[interest-driven-learning]])と Nekojira ch26「70:30 配分」([[seventy-thirty-comfort-challenge]])と思想接続。3 講師の学習論を横串する analysis 候補
- **本手法は ye_jji ch12 カラーラフ 4 工程 + ch15 工程 1(暗部設定)を凝縮したもの** に近い。ye_jji は完成イラストの工程、chan はラフ段階の工程に焦点 — 粒度が異なるため両立可能
- 「マウスでもかける」というタイトルは初心者向けの謙遜だが、本質は **「液タブの筆圧依存をなくす = 自分の絵の構造を理論で把握する」** という診断ツールでもある
- 6 段階トーン制限は実装が簡単で、すぐ自分のワークフローに導入可能なルール
- 「会社の外注では本手法が役立った」という具体実例は、chan の業務経験に基づく信頼性の高い証言
