# coloso ひづるめ ch13 ― 錯覚と嘘

> Section 03 中核(動画 2 本)。講座の看板テーマ「嘘というスパイス」。連想錯覚・心理的な質感・色の感情・画角まで。誤変換を補正(例: 「断食」→暖色、「波長遠近法」は本人造語のまま、「ミイサンラ」→ミー散乱)。

## 要約

**絵の嘘** = 目的に応じて陰影・質感のニュアンスをその都度変える描き方で、**理論より見やすさに依存**する。脳は色・質感・形で **連想錯覚** する。重い絵 / 軽い絵は心理的な重さで、その適用場所は **絵の力場の分布と一致**(重い = 黄 / 軽い = 青)。色には感情と波長(赤は前進・青は後退 = 波長遠近法)がある。**明暗さえ合っていれば何を嘘で描いても違和感がない**。

## ソース内の主要主張

### 絵の嘘([[e-no-uso]])
- 目的に応じてニュアンスを変える。**理論より見やすさ優先**。例: パースに 2 つのアイレベルを交差させる「嘘」で窮屈さを減らす。
- **明暗さえ合っていれば嘘 OK**(まつ毛の上に肌色、背景の色を拾う)。光と影さえあれば立体感は成立 → 光・影を交互(光影光影…)で奥行きと立体感を同時表現(服のシワ)。
- **たくさんの嘘を混ぜてクオリティアップ**。当たらない場所に光を足して存在感を作る。

### 連想錯覚([[rensou-sakkaku]])
- 脳が無意識に **色・質感・形** で連想・錯覚する。判断基準は「シンプルな状態で相手に伝わるか」。
- 日常物・生き物は連想しやすく、専門的なもの(鉄鋼ヤスリ等)は連想しにくい → 情報を集めて差別化。シミュラクラ現象(目・顔)も連想錯覚の一種。
- 例: 赤+白+ファー = サンタ。何の手段でも **連想させれば勝ち**(色がなければ形、形がなければ質感)。

### 重い表現 / 軽い表現([[shinri-tai-hi]])
- 適用場所は **絵の力場の分布と同じ**(重い = 黄 = 焦点強 / 軽い = 青 / 中間 = 赤)。
- **重くする**: 現実の明暗に沿わせる / 明暗境界線の立体感 / 階調を増やす / シェイプで重力 / 反射光を少なく / 質感を金属寄り / 暖色寄り(前進色)/ 油彩画のようにべっとり。
- **軽くする**: 空気遠近(白・青白)/ 反射現象多用(透明感)/ 階調を減らしてアニメ調化 / ミー散乱。**白基調にすると問答無用で透明感**。軽い表現はほぼ失敗しない。

### 色の感情([[iro-no-kanjou]])
- **波長遠近法**: 赤は認識しやすく前進、青は後退。色の組み合わせで印象(冬 / アンティーク / 大人の女性)。連想させれば OK。
- 伝えたい色を写真・絵から観察して自分に取り入れる → 個性に。「**描く人が見た人にどう思わせたいか**」からスタート。

### 画角(キャンバス比率)
- 横長 = 壮大 / 落ち着き、四角 = 人物、縦長 = 高さ・煽り俯瞰。比率は自由でよい。

## 不確実・要確認

- 「絵の嘘」「連想錯覚」は言語化困難と本人も明言。練習法はなく SNS でトライ&エラー・直感。
