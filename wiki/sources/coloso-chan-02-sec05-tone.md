# 第 05 項 絵を見るもう一つの目「トーン」について

## 要旨

第 04 項「強弱」を補強する **「トーン(白黒で見た時のメ度バランス)」** の目を養う章。トーンは色相・彩度・固有明度のすべてに影響を受け、絵の **安定感と完成度の基盤** になる。トーンの観察にも錯視がある(高彩度の黄色は思ったより暗く、赤は予想外に暗く出る)ため、**自分が予想した白黒を塗ってから Ctrl+Y で実物と比較する練習**が必須。応用として **同じトーンを維持しながら色相を自由に入れ替える**(肌に青を塗っても破綻しない)技法が確立する。Section 01 の総括: 第 1 項「情報」+ 第 2 項「色の落とし穴」+ 第 3 項「色のイメージ」+ 第 4 項「強弱」+ 第 5 項「トーン」 = **「正確に見る目」が完成**。番外編で **色塗りが美しくない原因はデザインやドローイングにある場合もある** ことを明示。

## キーポイント

- **トーンの定義**: 絵を白黒で見た時の結果。明度差の影響を最も受けるが、彩度と色相の固有明度も影響する
  - 彩度↑ → トーン↓(暗くなる)
  - 明度↓ → トーン↓
  - 色相: 赤・青・紫 = トーン低い、黄・緑・水色 = トーン高い
- **トーンの利点と欠点**:
  - 差を大きく → 視認性高い、強烈な雰囲気だが負担感も大
  - 差を小さく → 軽くてアプローチしやすいが、視認性低下
- **色相の情報が多い時のテクニック**: 全体トーン差を抑えて安定性を確保 → その上に色相を追加する
- **白黒視差錯視の典型**:
  - **赤は色で見ると明るく感じるが、白黒では予想外に暗い**
  - **黄色は彩度が高いほど白黒で思ったより暗い**
  - 周辺色の影響で実際より明暗が違って見える(同時対比のトーン版)
- **練習法 = 予想と検証**: 自分が想像した白黒トーンを塗る → Ctrl+Y で実物と比較 → ズレを修正
- **Photoshop の Ctrl+Y 設定**: 編集 > プルーフセットアップ > カスタム > CMYK → グレースケール変更後、Ctrl+Y で白黒プレビュー切替できる
- **2 画面ワークフロー**: Window > アレンジで同じファイルを 2 タブ開き、片方を白黒プレビュー固定 → 作業しながらリアルタイム確認
- **同トーン維持で色相を自由に入れる**: 肌に青を塗っても、白黒で同トーンなら破綻しない(極端な例)
- **逆利用**: 明るく見せたい部分にあえて低トーンの明るい色 / 暗く見せたい部分に高トーン暗色 = トーンを保ちつつイメージを強調
- **色塗りが美しくない 4 原因**:
  1. 色塗り自体
  2. **ドローイング**(立体把握不足、明暗位置が分からない)
  3. **デザイン**(衣装デザインの明暗配置が美しいトーン構成と合わない)
  4. 絵柄との相性(リアル × カジュアル のミスマッチ)
- 「**目に見えるものだけが全てではない**」= デザイン・ドローイングを変える必要がある時もある
- 台湾のイラストレーターは高彩度多色相 × 安定トーンの好例 → 検索推奨

## 個人的な所感 / 残った問い

- **トーン = 絵の OS** という思想は ye_jji ch01「完成度 = 視線誘導 + ディテール」([[wan-sei-do]])の OS 層 / アプリ層比喩と思想的に同型。chan は「トーン = OS、色相 = アプリ」とより明示的にレイヤー化

- **「色塗りが下手なのではなく、ドローイング / デザインが原因」** という診断フレームは chan の主張は[[takeda-yohsuke]] が共感するパターン。Nekojira の「立ち(形態)」優位思想と直接接続するため、analyses 候補
- 台湾イラストレーター(高彩度 × 同トーン)は X / Pixiv で検索する具体的アクション可能。フォロー候補リスト化価値あり
- 「サブカル系の色塗り = OS = トーン」という講師の主張は、本講座が「色塗り講座」のタイトルで実は **観察力訓練講座** として設計されていることを再確認させる

- 「トン / 党 / 等 / 塔 / 単 / 度 / 同 / 銅」→ 全て「トーン」(本章で最も誤変換が激しい語)

- 「サイド / 再度」→ 「彩度」
- 「式層 / 色走 / 色想」→ 「色相」
- 「死人性 / 死認性 / 死性」→ 「視認性」
- 「教会」→ 「強弱」または「境界」
- 「リュ」→ 「メニュー(View)」(Ctrl+Y 設定説明部)
- 「龍 / 流」→ 「View(英語メニュー名)」(同上)
- 「Sグレイ」→ 「グレースケール(Gray)」
- 「リ廻」→ 「輪廻(りんね)」(比喩語)
- 「白眼」→ 「白眼(はくがん)」(物事の本質を見抜く目の比喩)
- 「断食」→ 「暖色」、「感触 / 観触」→ 「寒色」
