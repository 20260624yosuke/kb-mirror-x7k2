# 第 13 項 立体中心(特性軸の第 2 章 = 深み)+ Section 2 まとめ

## 要旨

特性軸の後半 = sec12 の対。**立体中心 = 空間色を積極反映し、距離感(遠景/中景/近景/極近)を分けて配置することで現実感・没入感を最大化する** 方針。投資(透視)を生むのは **人の 2 眼の交差点 + 作死現象(歪み)**(chan 独自定義の理論枠)。長所は **空間感 = 実感 + 没入感、外中・会社で必須、多くの情報を収納できる**。欠点は **個性が出にくい(人の認識方法は皆同じ)、情報を多く入れる必要があるため要求スキルが高い**。本章で特に強調されるのは **空気遠近法は意図的デフォルメ** という思想(現実より誇張する)。**近景の歪み + 黒化 + ガウシアンブラ** で前後距離を演出する具体技も実演。Section 2 のまとめとして、3 軸(キャラ vs 雰囲気 / ドロー vs 色塗り / 平面 vs 立体) の二分割が「正解はない、適量を選んで自分のスタイルを見つける」枠組みであることが再確認される。

## キーポイント

- **立体感を作る理論基盤 = 作死現象**: 人の 2 眼が交差して視点を結ぶ生理 + 近景の物体が歪んで大きく見える歪み現象
- **長所**: 空間感 = 実感 = 没入感、商業外注で必須、多くの情報をコンパクトに圧縮できる
- **欠点**: 個性が出にくい(人の認識方法は普遍的)、必要なスキル要求が高い、ワンパターンに陥りやすい
- **空間色を必須化**: 雰囲気重視と最相性 = sec09 の彩色法に立体が乗る
- **距離層 3〜5 段階**: 遠景(星/雲) / 中景(構造物・テラス) / 近景(キャラ) / 極近(柱・前景髪)
- **空気遠近法 = 意図的デフォルメ**: 厳密には大物体(山)にしか適用されないが、イラストでは平面化のマイナスを補うため極限まで誇張する
- **近景の演出 3 ステップ**: ①歪み(作死現象を模倣)②黒化(目の前にある物体は暗く感じる)③ガウシアンブラ(焦点が合わない表現)
- **キャラクターを完全に背景に溶け込ませる極端な例** も存在(コントラスト下げ + 周囲ライティング中心)
- **視線処理が立体中心で見落とされがち**: 立体的な絵ばかり描く人は視線誘導をないがしろにする(平面中心の練習が補完になる)
- **Section 2 全体のメタテーゼ**: 「正解は存在しない、皆さんが自分で分類する基準を見つけて欲しい」
- **本章まで = 観察 + 理解パートの終わり**: 次の sec14 から Section 3 = 練習パート開始の予告

## 個人的な所感 / 残った問い

- **作死現象という用語**はchan 独自定義 = 「2 眼の歪み」の名称。光学的には「両眼視差 + 焦点ぼけ」だが、chan 定義は記録の価値あり
- **空気遠近法 = デフォルメ宣言**は本講座の独自主張 = 美術的「現実主義」へのカウンター。他講師の遠近論との比較 analysis 候補
- **近景の指の真っ黒化**は実写映画/アニメで頻出する演出技だが、イラスト解説として明示的に教える講師は珍しい
- **「立体中心は個性が出にくい」**主張は ye_jji の [[wan-sei-do]] や Nekojira の「個性は副産物」と並列。3 講師横串で「個性論」テーマ可
