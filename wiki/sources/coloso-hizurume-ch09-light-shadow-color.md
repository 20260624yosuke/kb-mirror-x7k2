# coloso ひづるめ ch09 ― 光と影と色

> Section 02 で最も理論密度が高い章(動画 2 本)。光の物理現象をイラスト向けに抜粋。誤変換を補正(例: 「サイド」→彩度、「メイド」→明度、「電動体 / 不動体」→伝導体 / 不導体、「ミニサラン / ミサラ」→ミー散乱、「レイリーサラ」→レイリー散乱、「後期現象」→光彩/ブルーム、「色周差」→色収差、「逆さ富士」フレネル)。

## 要約

影の 4 分類から始め、陰影の明度差(**バリュー値で 25 以上**)、拡散反射 / 鏡面反射、2 つの塗り方向(光から影 / 影から光)、フレネル反射、SSS と表面下散乱、ミー散乱 / レイリー散乱、ブルーム、色収差までを物理ベースで解説。

## ソース内の主要主張

- **影の 4 分類**: 明暗境界線([[ta-mi-na-ta|ターミネーター]])/ 影(光が当たらない面)/ 落ち影 / **オクルージョンシャドウ(本影)**([[occlusion-shadow]])。
- **陰影の明度差 = バリュー値で 25 以上**([[value-25-rule]]): 答えはないが指標。**彩度 0 は明度依存で色の重みを省くので不可**、レイヤープロパティ or レイヤーカラーの「バリュー値(グレースケール)」で測る。影の色相は光の色相と被らないようずらす。
- **拡散反射 / 鏡面反射**([[kakusan-kyoumen-hansha]]): 拡散反射 = マット(岩・布・アニメ塗りの基礎)、鏡面反射 = 光沢金属・鏡(応用)。鏡面は **伝導体(色が映る)/ 不導体(固有色になり明度だけ映る)** に分かれ、両者は地続き(錆びで変化)。
- **2 つの塗り方向**([[hikari-kage-2-direction]]): ①光から影(固有色 → 影、アニメ・カジュアル、速い)②影から光(暗 → 光を抽出、現実的、視線誘導向き、情報量を上げやすい)。
- **フレネル反射**([[fresnel-reflection]]): 見る面が水平になるほど反射率↑(逆さ富士・水たまり・円柱の縁)。エッジに光が凝縮 → 高確率でエッジが光る → エッジ光は理にかなう。
- **SSS と表面下散乱**([[sss-and-surface-scattering]]): SSS = ぼかしフィルター越しに光が溶け広がる(半透明の膜で発生、透明感・柔らかさ)。表面下散乱 = 明暗境界線に高彩度の色(肌は半透明で血の赤が散乱)。**明暗境界線に入れるだけでクオリティ UP**(SSS が起きない場所でも「嘘」で OK)。
- **ミー散乱 / レイリー散乱**([[mie-rayleigh-scattering]]): ミー = チリ・埃・水蒸気・雲で光路が見える(ドラマチック)。レイリー = 空の青 / 夕焼けの赤(波長依存)。
- **ブルーム(光彩)**: 強い光で温められ発光して見える。クオリティ UP だが使いすぎで輪郭がぼける。ハロー / レンズフレア(メイン + ゴースト)も。
- **色収差**([[shikishuusa-chromatic]]): RGB レイヤーをスクリーン合成してずらす。明るい元気な絵は赤ずらし、暗いマット / ポストアポは緑ずらし(緑とピンク)。先端だけずらして拡大すると、目立たせたい側を薄く・逆側を濃くできる。レイヤーマスクで部分制御。
