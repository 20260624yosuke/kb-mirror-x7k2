# 第 16 項 色構成の練習 = 分析練習(練習 2/3)

## 要旨

Section 3 の 2 つ目 = **分析練習**。AI と人間が絵を上達させる原理は同じ = **観察 → 分析 → 表現** の 3 段階。本章は「分析」に焦点。chan の中核メタファー = **国語の教科書方式**(死を文法・糸から分析するように、絵も理由を付けて言語化する)。**分析は数値化と理由付けがすべて、間違っても問題ない**(後で再分析するときに「5 等の」= 間違った答え案として比較基準になる)。実演としてchan の落書きに 1 枚の自作完成イラストの強みを抽出して適用する過程を見せる。

抽出される観察項目: **メインの視線 / サブの流れ / 視線交差 / 色相パターン(カラーパレット化) / 退避 / 同調 vs 暖色の遠近 / 髪と肌の密度差 / トーン低い赤(白黒で見ると低トーン)のポイント色 / 緩い雰囲気 / 横方向のライティングで視線速度を遅くする補助 / 等**。最終的にchan の落書きに「夕焼け空間色 + 緩い雰囲気 + 密度差ポイント + 横ライティング + キラキラ効果」を移植して別物の完成度に達する demo。

**マネズム vs 分析練習の境界**: 同人/アップロード時は **「参考にしました」と元作品と一緒に明示** することがマナー。

## キーポイント

- **絵が上手の 3 段階**: ①綺麗な絵を見つける ②なぜ綺麗かを説明できる ③自分の絵に取り入れられる
- **3 段階それぞれの失敗原因**: ①観察力不足 ②分析力不足 ③表現力不足
- **AI と人間の絵生成原理は同じ**: AI はデータベースのパターン抽出、人間も同じ
- **国語の教科書方式**(chan 中核メタファー): 死の文法と糸を分析するように絵も数値化して理由を付ける
- **分析は理系的行為**: 「色相 高/低、密度 高/低」と数値化することで感覚から逃げる
- **間違っても問題ない**: 後で再分析(再評価)するときの比較基準 = 「5 等の(誤答)」になる
- **再分析習慣 = 成長の最良の可視化**: 1 ヶ月前の分析と今の分析を比較
- **分析実演項目**(chan の絵に対する):
  - メイン視線(背骨に沿って右下へ)
  - サブ視線の X 交差 → 中央集中 → 上方向集約 = 顔への誘導
  - 色相パレット化(肌領域・衣服領域に分解)
  - 同調/暖色の遠近(冷たい色を奥に、暖色を近に)
  - 髪と肌の密度差(髪 = 高密度、肌 = 低密度で分離)
  - 赤色の白黒トーンが低いことを利用したポイント設計
  - 横方向ライティング = 視線速度を遅くする補助線
  - キラキラ + プリズム効果 = 点的密度ポイント
- **マネズム議論回避**: アップロード時は元作品と「参考にしました」を明示

## 引用に値する一節

> 「絵を分析する過程はイラストにある内容とそれを書いた人がなぜそうしたかを引き出す時間」
> 「分析の理由が間違っていても問題ありません。文章化していく過程で 5 等の(誤答)が作られ、後でその誤答を採点することが同じ絵をもう 1 度分析することになる」
> 「分析だけを何度も繰り返すと一定以上から効率が大幅に落ちる。分析と実践を並行することが重要」
