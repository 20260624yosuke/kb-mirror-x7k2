# coloso ひづるめ ch14 ― シンプルとは洗練の極み

> Section 03 締め。Section 03 全体(力場・視線誘導・錯覚と嘘)の **復習クイズ章**。

## 要約

「**シンプルとは洗練の極み**」= どれだけシンプルに他人の心を掴み錯覚させるかが最強だが、そこに至るには「どこまで伝わるか」を理解する長い道のりが要る。本章はクイズ形式で S03 の概念(ミー散乱 / 影から光 / 軽い絵分類 / 流れのあるポーズ / 軽くする塗り / 形の対比 / 重い表現のブラシ)を復習する。

## ソース内の主要主張

- **シンプル化 = 洗練の極み**([[simple-is-refinement]]): 最小ラインで連想を成立させる境地。到達には「どこまでが良くてどこから伝わらないか」の理解が必要。
- **流れのあるポーズ = リズム**([[nagare-rhythm]]): 手がカクカクすると視線が止まる(テンションがかかる)。スラスラ流すとリズム・脈動感が出る(止まった絵でも動いて見える)。
- 復習クイズの要点:
  - 軽くする塗り: **白基調 = 軽い**、固有色でべったり = 重い、暗い = 重い、反射光 1 割でも全体が暗ければ重い。
  - 形の対比: 整然(調和)の中に角張りが混じると対比が生まれる([[chouwa-tai-hi]] と接続)。
  - 明度は色相より見やすい(白黒で見ると判別しやすい)。
  - **ブラシ**: テクスチャブラシ / 描き込み = 重い、**かすれるブラシ = 軽い**(外側に使う)。
