# Nekojira 09. ボックスを利用した比率の把握

## 要旨

[[nekojira]] の Section 03 第 2 章。**顔の描き方** の中核章で、**ボックス(長方形・正方形)を頭蓋骨の上のマスクとして配置** → **3 分割 + 中心線**で比率を測る方法を確立。**目を 6 セグメント** に分割するフレームワークも導入。最後にローアングル(下からのアングル)の難しさと、Nekojira 流の解決策(顎を平らに / 鼻と口を近づける / 形を意図的に変形)を提示。

## キーポイント

### ボックス法

- まず **長方形か正方形** から始める。高さと幅が年齢・性格を決める
  - **若い・可愛い** = 幅広い長方形(横長)
  - **大人っぽい** = 幅狭・高さあり(縦長)
- ボックスを **頭蓋骨の上のマスクとして配置** する
- **3 分割の重要比率**:
  1. 額体 → 目の上(額)
  2. 目の下 → 鼻
  3. 鼻 → 顎
- **鼻と顎が長くなるほど大人っぽい**
- **眉毛は基準にしない**(可愛い顔は眉毛が高い・動きで位置が変わる)→ 一貫性のため **上まぶたの上** を基準にする

### 目の 6 セグメント分割

- 目を **6 つの線** に分解。それぞれを 1 つの比較として扱う
- セグメントごとに **長さ・カーブ・方向** を変えるだけで **異なる性格・年齢の目** が作れる
- 実演:
  - **大人クール**: 直線寄りで上向き、短く
  - **生き生き優しい**: 緑色(下まつ毛)で下向きカーブ
  - **子供丸**: 全体的に丸く、小さく
- 「**最初は性格差が必要でそれには多くの経験が必要です。物事を小さな部分に分解してから 1 つずつ捉えてください**」(7:56) — 「**複雑なものを単純な工程に分解する**」哲学の再強調

### 角度別の頭部構築

- **角度ごとに使う 3D 表現を変える**:
  - **正面・横向き** = 純粋な輪郭観察(自由度高い)
  - **少し傾き / ハイアングル** = ボックス + 中心線(立法体で構築)
  - **ローアングル** = ボックス + 立法体 + 円柱(首)。CSP の 3D アニメモデルも参考
- **目の傾きや髪の位置** で頭の向きを示す

### ローアングルの難しさと Nekojira 流解決

- 3D ソフトに従いすぎると **顔が丸すぎて「エイリアンのように見える」**(5:07) → 16-17 歳のキャラには不適切
- 解決策:
  1. **耳を下げる**(通常 → 下げる、口の辺り)
  2. **鼻を上げる**
  3. **目・鼻・口を近づける**(距離を離すと不自然)
  4. **顎ラインを意図的に明確化**(3D の丸みを破る)
- 「正面から描いた絵とほぼ同じように見えることに気づくかもしれません。**ただし耳の位置を調整して口と鼻をより近づけることで下から見ているような錯覚を作れます**」(8:54)
- 「**より成熟した表現や写実的な表現、男性キャラクターを描く場合は適していないかもしれません。これはデフォルメされた可愛いアニメの女の子の特徴を保つための方法**」(11:27) — 適用範囲の明示

### 髪の毛と遠近表現

- 髪の毛は **構造線** として使える → 「**髪の毛を構造線のように使って構造がどこにあって繋がっているかを表現**」(11:47)
- 実生活の参考資料が必要(特定角度での髪の見え方を観察)

## 引用に値する一節

> 四角く形は頭蓋骨の上に置くマスクとして扱います。それを貼り付けて中心線や構造線を加えていきます。そうすれば簡単に頭部を捉えることができます。(2:01)

> 物事を小さな部分に分解してから 1 つずつ捉えていってください。時間が経って技術が向上すれば 1 度で描けるようになります。リラックスしながらも正確さに注意を払うことがスケッチ段階で最も重要です。(7:56)

> 個人的にこの 2 つの選択肢の間では形を重視する方向に必ず進みます。良い形を作るためにルールを破ることもありますが、それが私にとって最優先事項です。(6:50)

> アニメスタイルで下アングルを描く際の難しい点は、3D モデルを使用しても顎のラインが丸すぎることです。うまく説明できませんがエリアンのように見えます。(4:55)

## 文字起こしノイズの注記

- 「ま、価値」「ま、方形」→ **正方形 / 長方形**(まず、〜 を使って)
- 「重大 / 大重大 / 異重大」→ **重大** = キャラクター種別(おそらく「大人」と「子供」の中間で、**ティーン**)。または「**正太**」(ショタ・若い男性)? 文脈で「中学生〜ティーン」と推定
- 「ロポーション」→ **プロポーション**
- 「マ方形 / た方形」→ **正方形 / 長方形**
- 「マロの線 / マロ」→ **目の(英語の brow から?)**(?要再確認)
- 「価値 / 立法体」→ **立方体**(複数箇所)
- 「俯瞰アングル / 400 度」→ おそらく **3/4(four-fifth)アングル**(英語の "four o'clock" や 3/4 view の聞き取り誤り)
- 「下アングル / ローアングル」→ **アオリ / 下からのアングル**
- 「エリアン」→ **エイリアン**
- 「ハース / パース / パーペスティブ / パーセクティブ」→ **パース / パースペクティブ**(複数表記揺れ)
- 「松毛 / ま毛 / 軒毛 / 軽毛」→ **まつ毛 / まぶた**(文脈別)
- 「相 / 鼻」→ **鼻 / 頬**
- 「身」→ **耳**(複数箇所)
- 「貧し形」→ **菱形 / 紡錘形**(?要再確認)
