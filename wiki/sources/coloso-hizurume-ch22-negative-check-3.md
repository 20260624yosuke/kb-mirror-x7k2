# coloso ひづるめ ch22 ― 【実技2-3】ネガティブチェック

> Section 05 実技 2(動画 2 本)。明るい絵の描き込みと「ネガティブチェック」。

## 要約

描き込みを進めつつ、見えにくい・黒つぶれ・単調などの「ネガティブな部分」を洗い出して直す。透明感の作り方、絵の嘘、フェチポイントの扱いを実演。

## ソース内の主要主張(実演メモ)

- **ネガティブチェック**([[jiko-tensaku]]): 指と重なって見えにくい部分・黒すぎるシャドウ・一定すぎる単調さを洗い出してコントラストで直す。黒いシャドウは明るめ・彩度高めの色で。**1 日置いてから投稿**(コントラスト不足等が見える)。
- **明るい色は顔と目が大事**。透明感 = 空気の層(青空反射)+ 影 + 補色強調([[ho-shoku-kyouchou]])。
- **絵の嘘でなんでもいい**([[e-no-uso]]):カジュアルイラストは絵の嘘でできている。ただし「綺麗に嘘をつく」とレベルが上がる(汚い嘘はダメ)。
- 自動選択 + 選択範囲の縁取りで情報量を簡単に上げる(イラスト絵との親和性が高い)。
- **フェチポイント(谷間等)は描き込みすぎると BAN される** → イラストっぽくぼかす([[8man-iine-recipe]] のセンシティブ運用と一致)。
- 調和対比: シワが一定だと、一定でない部分に視線を奪われる([[chouwa-tai-hi]])。線を描くと時間がかかるが企業案件では要求される。
