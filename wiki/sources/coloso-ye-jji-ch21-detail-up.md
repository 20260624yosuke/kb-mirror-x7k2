# ye_jji_21. 色塗り 07:ディテールアップ

## 要旨

色塗り 7 工程の **工程 7(最終ディテール描写)**。色分けレイヤーを **全て統合** し、**省略していたレース・ネイル** を追加 → **メイドコントラスト**(ミドルコントラスト)を主題部に集中 → **線画は「影のデフォルメ」として再導入** → **リムライト** を多彩色で入れる、という流れ。レイヤー統合の利点(**形を自由に変えられる**)を生かし、髪の毛の分割追加・シルエット修正を行う。「**整える**」= **はみ出した部分を整理して外側を綺麗に仕上げる作業**、と用語定義も入る。**モノクロ変換でバリュー確認** を繰り返しながら、主題部の情報量を上げ、副題部のコントラストを抑える調整に時間をかける(個人作品ではこの段階に **時間をかけることを推奨**)。

## キーポイント

### レイヤー統合 → 形の自由

- キャラクター・前景アイスボックス・パラソル・サンベッドのフォルダーを統合
- 「**全額が生きている時にはできなかった形の修正**」が可能に
- 髪の毛を **後から分割追加** / シルエットに穴を開ける / 形そのものを変形 / 線前を超える細かい髪追加
- 透明ピクセルロックで **色だけ変える**

### 省略していたレース・ネイルの追加

- レース:CLIP STUDIO 素材から適当な素材 + **曲線定規** で描き、不要部分を消す
- 短い範囲は手で描く
- レースに **下地より少し濃い色** を使う(線画がないため形が見えにくい補完)
- ネイル:**手が主題部に近いため情報量を盛る**(条件付き戦略)
- ピンク色グラデーション + 先端ピンク / 内側白 + キラキラハイライト

### メイドコントラスト(ミドルコントラスト)の実践原則

- **モノクロ変換** でバリュー確認(パラソルが不必要に高コントラスト / 主題部が足りない、を発見)
- **近接物体**: 後ろを **暗く** する → 「オクルージョンシャドウを強く見せる印象」
- **離れている物体**: 後ろを **明るく** する → ミドルコントラストで分離
- グラデーションで処理(明暗の教界がはっきり残ってはいけない)
- 「決まった正解はない、自分が綺麗だと思う方向」(講師の経験則)

→ [[me-do-tai-hi]] / [[occlusion-shadow-as-mid-contrast]]

#### 具体実装例

| ペア | 処理 |
|---|---|
| 帽子 ↔ 髪 | 帽子を暗く、髪を明るく(離れているので) |
| 帽子の上部 | キャラに対して暗く抑える(オクルージョン的) |
| パラソル後ろ | 主題部から離れているので明るく(青色) |
| フリル内側 ↔ 外側 | 自動選択 + グラデーションで内側を暗く |
| 上下フリル | 下を暗く、関係性整理 |
| 髪 ↔ 肌 | 接触部はグラデーションで肌を暗く |

「**関係整理**」とも表現され、平面化を回避する重要工程。

### 線画は「影のデフォルメ」

- 「**この線画は影のデフォルメです**。影をこれ以上追加したくない部分、デフォルメされた部分に線画を追加する形」
- **物体と物体が完全に分離している箇所** に線を入れる
- **柔らかい部分にある線は消す** → ぼかして溶かす
- 髪と背景の分離に外角ラインだけ濃い色の線画
- 首と顔の間、肩、リボンなど分離していない部分にも線画
- 口・鼻にも濃い色の線

→ [[line-as-shadow-deformation]]

### リムライトは多彩色で

- 色は **1 色だけにしない** → ミント / 黄 / 複数色を混ぜる(植物が多いのでミント基調)
- 光の方向(上から)を考えて、**上向き面に多く、他向き面に少なく**
- リムライトを入れた色は、**目のハイライトや顔のハイライトに繰り返し使う** → 統一感
- 「単に線をなぞる」のは NG(平面化) → 面積を調整して入れる

### 主題部の情報量を上げる小技集

- **フリル**: 内側を選択して暗く + 上下のフリルを分けて層を作る
- **リボン**: 質感に沿った **ハッチング** で布の厚みを表現
- **ゴム**: シワ + **縫い目のライン**(上下に)
- **胸元の布**: 厚みの表現 + 縫い目のライン
- **髪**: 大きな塊の間に暗いトーン + 細かい毛を線前を超えて追加 + 流れる髪の分割
- **手のひら**: シワ + 指間のオクルージョン + メイドコントラスト
- **ネイル**: ピンクのグラデーション + キラキラハイライト(主題部に手がある条件付き)
- **水滴**: 結露の水滴(冷たいパフェ)、果物の水滴(生き生き)、髪の毛の水滴(水着シーンの統一感)
- **肋骨**: 脇腹が平坦に感じたら追加
- **水で肌の境界線が膨らむ表現**

### 砂・テクスチャの追加描写

- 砂のでこぼこを **暗い影をもう 1 度押す**
- **人手のようなオブジェクト** を追加(左側に配置、右側に既でにオブジェクトが多いため)
- パラソル布の厚みのハッチング、傷の描写
- 後ろの足にも反射と決めの描写

### 「整える」の定義

- **はみ出した部分を整理する** こと
- 外側を綺麗に仕上げる作業
- 線画が必要な箇所に線画を追加、不要な箇所の線画を消す
- 「**整える**」という言葉を講師が繰り返し使うため、本回で明示的に定義された

### ディテールに時間をかける

- 「時踊り細かい部分を全て省略して書く方は手が早いのが利点だが、**長時間をかけてディテールを上げていくのも絵に非常に役立つ**」
- 個人作品や案件では時間をかける、実演では沈黙が長くなりすぎないよう短縮
- **どこまで完成度を上げればいいか分からない時は、参考資料(東案 = 答案の役割)を見ながら進める**
- メイド退避の度合いも同じく **参考資料を回答用紙の役割** として確認しながら

> 大体物体が近接している場合は後ろを暗くした方が見が良くなりました。離れている場合は後ろを明るくするのが一般的によく見えました。

## 個人的な所感 / 残った問い

- 「**線画 = 影のデフォルメ**」は本講座の核心アイデアの一つ — 線画と陰影を別物として考えるのでなく、デフォルメ度の連続スペクトラムとして扱う
- メイドコントラストとオクルージョンシャドウの統一は気持ち良い再フレーミング(個別技術が同じ原理の現れと見える)
- 「整える」は曖昧な用語だが、**定義が明示されている** のが講座として誠実
- ネイルにこだわる戦略は「**主題部に手がある時の情報量増し**」という条件付き — 構図によって判断
- 「**参考資料 = 東案(答案用紙)**」というメタファーは ch12 の参考収集論を深化させた表現
