# 第 04 項 料理の甘辛、音楽のテンポ、絵の強弱

## 要旨

chan 哲学の中核「**強弱(きょうじゃく)= 料理の味付け = 音楽のテンポ = 映画の起承転結**」を提示する章。強弱は **「絵の情報量の道(凹凸)」** であり、視線という名前の水を左上から右下に流したときに、深い穴(高情報)に視線が長く溜まり、浅い穴(低情報)で次へ繋ぐ。**全体強または全体弱は分散か散漫を生む**。情報量に応じて差の大小を調整、**強弱は重複できる(強の中に中弱、その中にまた強)**、**順番に並べず入れ替えると良いテンポになる**。実演分析では一枚絵に対して ① **主題(強)** → ② **メインの視線**(0.3 秒で形成、左上→右下、大きく曲がらない)→ ③ **サブの視線**(再度見たときの流れ、有機的に繋がっていること)を 3 段階で観察する。

## キーポイント

- **強弱 = 料理の味付け / 音楽のテンポ / 映画の起承転結 / テンション**。最後まで集中を切らさない設計
- **情報の構成要素**: 彩度 / 明度 / 色相 / 密度 が多いほど強(深い穴)、少ないほど弱(浅い穴)
- **視線水流モデル**: 視線を「左上から右下に流れる水」と捉え、強弱の凹凸が水の流れる道を作る
  - 全体が強い → 水が乱流して散る(視線分散)
  - 全体が弱い → 水が留まらず流れ落ちる(視線素通り)
  - 適切な凹凸 → 主題に長く溜まり、副題で次へ繋ぐ
- **情報量と強弱の差の関係**(本講座の独自原則):
  - 情報量が **多い**(複雑な絵)→ 強弱の差を **大きく**して視線を強く引きつける
  - 情報量が **少ない**(シンプルな絵)→ 強弱の差を **小さく**して長時間止める
- **強弱の重複**: 強の中に中・弱、その中にまた強。中央に視線を確実に集中させるネスト構造。キャラの顔の周りに高密度を重ねると自動的に顔を見る
- **入れ替え配置**: 強中弱を順番(強→中→弱)に並べると下を見なくなる。入れ替えてテンポを切らさない
- **観察の 3 段階フレーム**(本章の中核ツール):
  1. **主題(しゅだい、強)**: 最重要部分。丸で囲んで特定
  2. **副題(ふくだい、中)**: 主題に次ぐ。サブと少し重なる
  3. **サブ(弱)**: 細部・つなぎ役。複数あってよい
- **メインの視線**: 第 1 印象 0.3 秒の流れ。左上→右下が基本軸、大きく曲がらない、ジグザグはない
- **サブの視線**: 再度見たときの流れ。**有機的に互いに繋がっていなければならない**。メインを補助・派生する形で構築
- **視線エラー診断**:
  - 集中できる部分がない → 主題が形成されていない(背景イラストで頻発、同じ大きさの山が 3 つでは美しくない)
  - 第 1 印象が微妙 → メインの視線が破綻
  - 印象が硬い → サブの流れが切れている
- **観察ワークフロー**: 遠くから(目を細める)→ 主題と視線を把握 → 近くで(拡大)→ 重複と密度差を観察
- **本講座の Section 1(観察)が完成**: 第 1 項 = 情報という基準 / 第 2 項 = 色の落とし穴 / 第 3 項 = 色のイメージ / 第 4 項 = 強弱(良し悪しを判定する基準)。次回第 5 項からは「トーン」の視点を追加する

## 個人的な所感 / 残った問い

- 本章はchan 講座の **構造の中心**。第 1–3 項で養った「観察の目」を「価値判断の目」に変換する転換点
- ye_jji の「視線誘導 + ディテール = 完成度」([[wan-sei-do]])と思想は完全に同型だが、chan は **「水流」「凹凸」「料理」というメタファー** で同じ内容をより明示的に体系化
- Nekojira の「コントラスト 3 種(直線×曲線 / 大小 / 密度)」([[form-rhythm-3-contrasts]])は形の側の話、chan の強弱は情報量の話 — 両者を横串する analysis 候補
- **「メインの視線 0.3 秒」「サブの視線は有機的に繋ぐ」**という具体ルールは本講座の独自貢献。ye_jji も Nekojira も視線については抽象的にしか語っていない
- 「主題 / 副題 / サブ」の 3 段階分け + 順番でなく入れ替え配置 = 強弱の典型エラーを診断できる作業フローとして再利用価値が高い
