# Nekojira 25. 最終ドローイング：最終修正

## 要旨

[[nekojira]] 最終ドローイングの **最終修正章**。ch24 で主要パーツを完了 → 本章で **袖の影改善、リボン/ベルトの細部、紙(髪)の重なりとレイヤー感、線画の太さ強調、空気感(アトモスフィア)追加、グラディエントマップ最終調整** を実装。「**90%が完成、残りはシャープにする最終調整**」と講師が宣言。**金属(ベルト)** の **クライ色の反射 + 白点ハイライト** で素材を表現する Nekojira 流の金属簡略化手法も実演。

## キーポイント

### 本章での作業内容(講師宣言、ch25_01 17:00)

1. **線画を太く/暗くする**(キャラ全体をより際立たせる)
2. **影の形の改善余地** を探る
3. **紙(髪)の重なりを増やしてレイヤー感**

### 袖の影改善

- 「**小さな影を 1 つの大きな形にまとめる**」(ch25_01 0:39)
- 雫型の影を加えて **柔らかさを表現**(布の素材感)
- 「**布は柔らかい素材なので柔らかいエッジ**」「**エッジが鋭すぎると硬い質感に見える**」(ch25_01 2:40)

### ベルト(金属素材)の Nekojira 流表現

- 「**反射した暗い色を捉えることで金属素材を表現**」(ch25_01 15:05)
- **ハイライト = 白い点を加える** → 金属らしく見える
- **平筆ストロークでテクスチャを追加**
- **青色を隠して繊細な表現**

### リボンの細部 + 天空光

- **上向きの面に青色を加えて天空光を表現** = ch24 と同じ
- 「**影のグループにも同様に色の変化を加えます**」(ch25_01 14:03)
- これは **影内のグラデーション** 追加

### 紙(髪)の細部過剰部の平滑化

- 「**過剰で乱雑に見える部分を少し平らに**」「**細部をもう少し減らします**」(ch25_02 0:18)
- 「**目を引きすぎないよう情報を減らす**」 = **顔(商点)を保護** する戦略

### 紙の輪郭線(高彩度青)

- 「**高サイドの青を使って頭部の輪郭を強調**」(ch25_02 5:24)
- 「**手の線画も灰色っぽいので、より赤みが勝ったサイドの高い色に**」(ch25_02 6:23)
- → 線画は **色変化で光感を表現**(ch21/24 と一致)

### 後ろ髪に追加レイヤー(奥行き)

- 「**キャラクターの後ろに髪の毛のレイヤーをもう 1 枚追加して奥行きを出す**」(ch25_02 8:46)
- **エッチカラーを鮮やかな青、明るい青で塗る** = レイヤープロパティ機能
- **自由にストロークを描いて後ろの紙のシルエットを作り、レイヤー感と奥行きを出す**

### グラディエントマップで全体ムードを変える

- ch25_02 で **グラディエントマップで遊ぶ** → 面白い効果を発見 → 採用
- 「**サイドを上げるエフェクトを作成しました**」(ch25_02 15:50)
- **コントラスト/明るさを少し調整**(微差)

### 空気感(アトモスフィア)追加

- 「**ドット模様のブラシ + スクリーンレイヤー**」(ch25_02 17:36)
- これは ye_jji の [[photo-finish-3-set]](ノイズ + クロマティックアベレーション + レンズフレア)と同等の **写真的仕上げ**

### 完成宣言(ch25_02 18:34)

- 「**最終的な仕上げに満足しています**」 → ch26 の Q&A 章へ
