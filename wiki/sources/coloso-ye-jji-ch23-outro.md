# ye_jji_23. 終わりに

## 要旨

最終回(Section 08 Outro)。**独学の進め方** と **フリーランス準備(ポートフォリオ戦略)** を講師の経験ベースで語る。学習法は **「基礎から積み上げない — やりたい気持ちが続くこと、必要を感じた時に必要な分野を学ぶ」** を原則に、**色遣い・ドローイング・比例感(携帯力)・観察力** の 4 サブスキルそれぞれに具体的トレーニング法を提示。ポートフォリオは「**目標を明確に → そこに合致する作品を積む**」「フォロワー数より目標会社」「ニッチジャンルは反応は少ないが案件は取りやすい」を要点とする。講師自身の Web 小説好き → ファンタジー系投稿 → ネイバーカフェ経由初受注、という実例も提示。

## キーポイント

### 学習の原則:興味の持続最優先

- 「**基礎から着実に積み上げる**」は理想的だが **習得に長い時間** → 興味を失いやすい
- **多くのイラストレーターは** その時々で必要に応じて勉強してきた
- 色感が足りないと感じたら色、人体が不足なら人体、と分野ごとに **必要駆動学習**
- **オリジナルイラストやファンアートを書くことも勉強の途中で必須**(目に見えないものが習得される)

### 4 サブスキルとトレーニング法

#### 1. 色遣い

- **観察中心**:綺麗だと思う写真・イラストを集めて観察
- スポイトで **色の変化** を見る
- 色を覚えてイラストに使う
- 落角を減らすために **色遣いの模写**

#### 2. ドローイング(線を引く感覚)

- 「30 秒・1 分クロッキー」だけでは不十分
- **曲線を丁寧に処理する練習** が肝(直線より難しい)
- 時間がかかってもいい / 線が遅くてもいい / 曲がり具合・極率の変化を **1 つ 1 つ数える**
- 例: **膝の曲線が何回極率変化しているかチェック** / シワが何回入っているか数える / 靴底の構造を正確な比率で
- **大きく描く**: キャンバスいっぱい / ノート 1 杯 / マーカーや太いペンで(シャープペンは NG)
- **速描き派 vs 丁寧派 → 互いに逆方向の訓練** を入れる(速派は時間制限なしで丁寧、丁寧派は時間制限で速く)

#### 3. 比例感(携帯力)

- 写真模写 + **角度を変えて様々な方向から描く**(平面図を別投資背景で描く)
- マスターすれば大抵のスケッチは難しくなくなる
- 講師自身も平面図を見て角度を変えて描く練習を実行

#### 4. 観察力(細部)

- **写真と同じクオリティで写真の模写** をする
- 高クオリティ模写を 1〜2 度やるだけで観察力が伸びる(時間がかかるので頻度は低くて良い)

→ [[four-sub-skills]]

### ポートフォリオ戦略

#### 「フォロワーを増やす」だけでは仕事は来ない

- まず **どんな仕事を受けたいか目標を設定** する
- キャラクターイラストの案件種別: **インゲーム CG / ゲームお祝いイラスト / キャラクターデザイン / ライトノベル差し絵 / Web 小説表紙 / グッズ作業**

#### ターゲット別の戦略

| 目標 | 戦略 | SNS 反応 |
|---|---|---|
| 特定ゲーム会社のインゲーム CG | そのゲームのキャラクター / 似た雰囲気を多数描く | 不要 |
| VTuber 関連 | **ファンアートタグ**を活用。**ファンの少ない VTuber** のファンアートで名前を売る | 必要 |
| 服ブランド・産業(コラボ) | **オリジナルキャラ** でアカウント運営(ファンアートは版権が自分にないので NG) | 必要 |
| 広告イラスト | 流行りジャンルを素早く描いてフォロワー増 | 必要 |

#### ジャンル選択

- **ニッチジャンル** は SNS 反応は少ないが、その分野での認知は得やすい → 案件が入りやすい
- VTuber 界でもホロライブ・2 次 3 時のような有名どころ vs **ファンアート供給が少ない比較的小規模な会社** がある → 後者の校者のファンアートを書くのも良い戦略
- 講師自身の例: **Web 小説好き → ファンタジー系を投稿 → ネイバーカフェ経由で初受注**(Twitter / Pixiv ではなく)

#### 露出戦略

- **できるだけ多くの場所** にポートフォリオを掲載
- 名前が露出するほど企業からのコンタクト確率が上がる

### ファンアートに関する補足

- 流行りジャンルを書くのも良いが、**本当に自分の好きなジャンル** の絵を書く方が良い
- 比較的人気のないジャンルは SNS 反応少 → でも **名前を知られるのはメジャージャンルより簡単** → 比較的仕事も入りやすい

### 結びの言葉

- リバードがオープンしてから多くの関心 → 撮影中ずっと緊張、再撮影も多かった
- 「この講座が皆様の絵画生活のお役に立てることを心から願っております」
- 受講生に感謝、お疲れ様

## 引用に値する一節

> 基本的に勉強はやりたい気持ちになった時にするのが 1 番良いと思います。多くのことがそうであるように絵も長く書き続ける人が照者だと思います。

> その過程で絵に興味を失いやすいため良くないと思います。

> 単にフォロワーを増やすだけでは仕事は簡単には来ません。自分がどんな仕事を受けたいのか目標を設定すること。

> 比較的人気のないジャンルは SNS での反応が少ないのは確かでしょう。しかしその分野で名前を知られるのはメジャージャンルより簡単です。そのため比較的仕事も入りやすいです。

> 速く書くことだけをする人がいます。反対に性格が控えめで貴重面なため雑に書くことができず小さく丁寧に書く人もいますが、この場合は時間制限を設けて素早く書くドローイングの練習をしてみるといいでしょう。

## 個人的な所感 / 残った問い

- 「**基礎から積まない**」は色彩・人体の伝統的な体系学習主義へのアンチテーゼ。**興味の持続** という心理的継続性を最上位の制約に置くスタンス
- 4 サブスキル分解は本講座の前段(対比・量感・テクスチャ・色味 = 描写力)とは **異なる軸** — 講座は「描写の理論」、ここは「練習法」と層が違う
- 「ニッチで名前を売る」は実務戦略として強力だが、ニッチ過多なら市場自体が小さい問題は残る
- 「**VTuber 関連はファンアートタグ / 服ブランドはオリジナル**」と **版権の所在** で戦略が分かれるのは普遍的な原理
- 「**速派 vs 丁寧派は逆方向の訓練**」は学習論として普遍 — 自分の癖を見極めることが前提
- ネイバーカフェ経由初受注 = 韓国市場特有のチャネル発見の事例として記憶 → 日本市場では別チャネル(Pixiv リクエスト・SKEB・コミティア等)に置き換えて考える必要
