# Nekojira 26. まとめ＆今後のアドバイス

## 要旨

[[nekojira]] **講座最終 Q&A 章**(4 ファイル)。視聴者からの幅広い質問に回答: 初心者へのアドバイス、スランプ対処、絵のスタイル発見、キャラデザインのアイデア、構図とフォーカルポイント、目の角度ごとの一貫性、オンラインリソース推薦、キャリアの始まり、SNS のフォロワー戦略、淡い色と高彩度の使い分け、色選びの実演など。**「アートはマラソン、100m 走ではない」「完璧を目指す前に完成を目指す」** という最終メッセージで締めくくる。

### 初心者へのアドバイス(ch26_01)

- **観察力 = 形とシルエット** から始める
- **CSI ストロークで線をかけるようになる** = 最優先
- **興味駆動学習** = 「**好きなものを書く**」「**観察を続ける**」(ye_jji の [[interest-driven-learning]] と一致)
- 「**始める時には金法(遠近法)があることを知っておけばいい**」「**全てを急いで極める必要はない**」(ch26_01 3:21)
- 「**スキルを身につけるには焦らずにゆっくりと水を注ぐように**」(ch26_01 3:50)

### スランプ 3 タイプの対処

1. **オーバーワーク疲労** → **休憩**(作業場所から離れる、好きなゲーム)
2. **テーマが難しすぎる** → **練習で経験を積む**、**スキルレベルが現状不足**
3. **センスがスキルを上回る**(最も多い) → 「**実はとても良いこと**」「**まだ改善の余地がある**」 → 練習を続ければ追いつく
- 「**スランプは強力なボスと戦う緊急クエストのようなもの。それを倒せば相応の報酬が得られる**」(ch26_01 10:14)

### クリエイティブブロックの対処

- 「**特定の大材への理解が不足**」 → **参考資料を探す**
- 木の例: 「**ミキが太くてバジ型のパターン、枝があちこちに広がり**」を **知っているか/いないか** で生き生きとした絵になる
- **足が苦手だった時期 → 足/靴の練習だけ集中** = **小さなテーマに分割して 1 つずつ習得**

### 70% 快適 + 30% 挑戦の練習配分

- 「**現在の実力を把握し、人体を簡単にかけて全身に不安がないなら次は広大な環境**」(ch26_01 12:58)
- 「**題材の 70%は快適ゾーン、30%は挑戦的な要素**」(ch26_01 13:17)
- → これは [[interest-driven-learning]] の量的な実装ガイド

### スタイルの発見

- 「**自分の好きなものをみんなの好きなものになるまで捜索し続ける**」(ch26_01 1:11)
- 「**他者に影響を与え、自分の好きなものを共感してもらえる**」 = 制作の長期目標

### キャラデザインのアイデア生成法

- **ランダムワード生成**: サメ、悪魔、天使、箱 など + 職業: バリスタ、科学者、宇宙飛行士 など
- **箱に入れて 1 枚無作為抽選** → アイデアの組み合わせ
- 「**80 年代の宇宙飛行士のサメ**」のような **意外な組み合わせ**
- 「**新しく独特なものを作りたいならまず古典から始めるべき**」(ch26_02 2:58)

### オンラインリソース推薦

- **YouTube が最も価値**
- **解剖学**: 秀先生、Proko(プロコ)
- **色彩**: 魔ブ(?)、Aaron Blaise(Becoming a Better Painter シリーズ)
- **配信**: Imaging Direct、ED058(スケッチ/線画作業を見る価値)
- **中国語**: クレンツ(Krenz Cushart)が **メンター、Nekojira の知識の主な出所**

### 様々な角度から一貫した目を描く

- **6 セグメント分割**(ch09 から継承)を **45° で 1,2,3** → 反対側で **4,5,6**
- 「**完全に平らにせずこの部分に立体感を持たせる**」(ch26_03 7:17)
- **まつ毛の形を角度に応じて変える**:
  - 真正面/真横: **少し外側に向けて**
  - 45°: **異なる方向で書く**、目が閉じかけている状態は逆方向

### 淡い色から高彩度へ、そして再び淡い色へ

- 「**淡い色から鮮やかな色へ。そしてまた淡い色に戻る組み合わせ**」(ch26_02 7:32)
- 例: 肌色 = **淡い色基調 → サイドの高い色を加える → サイドの高い色の中で再び淡い色**
- これは [[grey-plus-local-high-saturation]] の **時間軸版**(リズム)

### 構図のヒント

- **シルエット + ネガティブスペース** が綺麗である
- **キャラポーズはシンプル + 複雑の組み合わせ**(片側シンプル、片側複雑) = ch20 の原則
- 「**シンプルな 1 本の線で読みやすく、ここには奇的な形が存在**」(ch26_03 16:43)

### アイデア → 完成までの 3 段階長期プロジェクト

- ティアのドレスデザインの例: 数年かけて **A → B → C → D → 完成版**
- 「**1 日 2 日で完成させようとは思わない**」「**アイデアは常に進化し続ける**」(ch26_03 14:25)
- **構図ストレスは普通のこと**(自分の作品に満足していない健全な徴)

### SNS 戦略について

- 「**この部分については私は単に運が良かっただけ、戦略的なアドバイスは何もできない**」(ch26_04 4:02)
- 「**いいねや再生数にこだわるよりスキルを磨く**」
- **ジャンル特化**(モダンファッション + 悪魔の組み合わせなど)で **企業からのアプローチを受ける**
- 「**長年かけて作り上げた 1 つのジャンルに特化したポートフォリオがあるので求められる仕事ができることを証明**」(ch26_04 5:23)

### 最終メッセージ(ch26_04 6:51)

- 「**アートは 100m 走ではなくマラソン。途中で休憩を取ることも大切**」
- 「**完璧を目指す前に完成を目指してください**」
- 「**前進し続け探求すればいつか必ず目標に到達できます**」

### Nekojira の弱点開示

- **パースペクティブ**: 「**レベル 2 つ程度**」「**1 人しか書かないので極端なパースで 4 人を書くのは挑戦的**」(ch26_01 6:39)
- **英語**: 「**第 2 言語、得意ではない、録画は緊張**」(ch26_01 13:42)
- → **講師でも弱点がある** という Nekojira の特徴的な誠実さ(ch13 のローアングルと同じパターン)
