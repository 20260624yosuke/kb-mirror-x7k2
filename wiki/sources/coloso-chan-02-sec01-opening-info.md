# 第 01 項 オープニング、そして「情報」とは？

## 要旨

Coloso 3 作目(色とカラリング系列)の冒頭。講座全体の構成(Section 1〜4 + 1.5、観察 → 理解 → 練習 → 実践)を提示し、本講座の核心となる **「情報」** という基準概念を導入する。「色塗りは感覚ではない」という講師の信念を明示し、彩度・明度・色相・密度の **4 つの情報** を以降の全章で参照する観察フレームとして確立する。

## キーポイント

- **本講座の位置づけ**: コロソ 3 作目。基本 20 講 → プラス 10 講(ドローイング中心) → 本講座(色塗り)の流れ。**理論は最小限に圧縮、自分の絵にすぐ適用する実用ノウハウ重視**
- **イラストの第一印象を決める 2 要素**: シルエット と カラー
- **カラー(色)の定義**: 色相・彩度・明度 の 3 要素 + 白黒(光)で構成
- **色塗り = 配色 → ライティング(明暗) → 描写(質感) → 補正(CG 特有)** の 4 段階
- **上手な色塗りの 2 条件**: ① 自分が好きなものを知ること ② その理由を説明できる根拠を持つこと
- **講座 4 セクション**: Section 1 = 観察 / Section 2 = 理解(カジュアル画の分類) / Section 3 = 練習法 / Section 4 = 実践(スピードドローイング動画) + 中間 Section 1.5(実習用彩色法)
- **情報 (information)**: 「差を生み出すすべての内容」。視線を集める力の基準
- **4 つの基本情報**: **彩度 / 明度 / 色相 / 密度**。以降全章の観察軸
- **密度の定義**: 「描写が小さく密集している度合い」=「描写がどれだけ重なっているか」。学生がよく誤用する語の再定義
- **「色感(色彩感覚)」は存在しない**: 多すぎる情報を脳が処理しきれず感覚に任せた結果のラベル。感覚に依存すると安定したクオリティが出ず、運任せになる
- **目の例**: 同じ目に彩度 → 明度 → 色相 → 密度を順に追加して情報の差を可視化する実演

## 個人的な所感 / 残った問い

- 本講座は **ye_jji の「対比 4 種」+ Nekojira の「形態(立ち)」とは独立の観察フレーム** を提示。chan 流は **「情報」一元論** で、対比も密度もすべて「情報の差」として統一して説明する点が独自
- 「色感は存在しない、すべて情報の集積」という強い主張は、Nekojira の「センスとスキルのギャップ」([[skill-vs-taste-gap]])と微妙に立場が異なる(Nekojira は taste 自体の存在を認めつつ語彙化を促す)。比較分析の余地
- 「色塗り = 配色 → ライティング → 描写 → 補正」の 4 工程定義は **ye_jji の「色塗り 6 工程」** と粒度が異なる。両者を横串する analysis 候補
- chanが「情報」という観察軸を講座で定式化していた事実を Wiki が明示的に記録できた点で、bookkeeping 価値が高い
