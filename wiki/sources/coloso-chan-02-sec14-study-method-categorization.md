# 第 14 項 彩色で必要な勉強とは?(Section 3 開幕・勉強法の分類)

## 要旨

**Section 3 の開幕章 + 勉強法のフレームワーク提示**。Section 2 で見た 6 つのスタイル(キャラ中心 / 雰囲気 / ドロー / 色塗り / 平面 / 立体)それぞれに **強み・弱点・勉強すべきこと** を分類して提示する設計図。chan の中核学習哲学 = **「絵を上手に書くことよりも実力が上がることの方が重要」**(これから何十年も描き続けるため、成長速度こそ最優先)。**強み 先 → 一定レベルに達したら弱点を埋める** の順序を強調。各スタイルの代表的弱点を診断:
- **キャラ中心** → 構成の幅、空間色、設定的魅力
- **雰囲気中心** → 顔の描写、可読性、ディープすぎる罠
- **ドロー中心** → タッチ感、ライティングのリアリティ、シャープに偏る
- **色塗り中心** → 形(人体)、ドローイングの安定性
- **平面中心** → 背景構成、立体感
- **立体中心** → 視線処理、構成

模写は **観察 / 形 / 色相パターン / ライティング / 書き込み** の 5 分類で進める。次の sec15-17 で 3 つの練習法(目の鍛錬 / 色構成 / 描写)を実演する予告。

## キーポイント

- **「絵が上手」 = 自分の基準で絵を描けること**(他人の評価より自己満足が条件)
- **学習哲学の最深層**: 「**今すぐ上手より 1 年後上手の方が重要**」=「**成長速度の引き上げ**」が本講座の真の目的
- **強み先 → 弱点後 の勉強順序**: 強みが実践レベルに達してから弱点へ。両方の能力は有機的に繋がっているため
- **各スタイルの典型弱点(chan の生徒データベースから derived)**:
  - キャラ中心 → 構成多様性 / 空間色 / 設定的魅力(意外な見落とし、ディテール軽視)
  - 雰囲気中心 → 顔の描写(後回しにする癖)/ 可読性 / ディープに走る罠(「お宅会」)
  - ドロー中心 → タッチ感の練習不足 / ライティングリアリティ / 鋭すぎてフリル描けない
  - 色塗り中心 → **人体ドローイングが弱い**(色で隠れて気づかない、最大の落とし穴)
  - 平面中心 → 背景構成 / 立体感
  - 立体中心 → 視線処理 / 平面構成
- **AI と人間の絵が上手くなる原理は同じ**: 観察 → 分析 → 表現の 3 段階
- **塾は効率的だが必須ではない**(後の sec16 で再展開)
- **両能力均等向上の論理**: A だけ極端に上げると効率が落ちる(ゲームのレベル曲線比喩 + 能力同士の相互接続)
- **トレンディな内容に多く触れる**(ゲーム / 映画 / ドラマ / ステッカー収集)=平面中心スタイルに特に重要
