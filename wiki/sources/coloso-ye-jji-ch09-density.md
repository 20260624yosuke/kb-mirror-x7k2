# ye_jji_09. 密度を下げる

## 要旨

Section 4 開始回。**背景や副題部の描写省略** を体系化する。「ただラフに済ます」は未完成感を生む典型ミス。「コントラストだけ下げる」も主題と同じ描写量で色濁りを招く。**正しい省略 = 階調を減らす + 空気遠近法 + コントラスト低下** の 3 段階を組み合わせる。カップ写真の階調実習(8 階調 → 5 階調 → 3 階調)で「明度をまとめる」感覚を養い、複雑な山岳背景を前景〜遠景で **階調数を変えながら描く** デモを実演する。

## キーポイント

### 描写省略 = 階調を減らすこと

- **階調** = 明度の高いトーンから暗いトーンまでの段階数
- 低コントラストの中間段階トーンを **省略してまとめる** ことで丸みのある形状感を保ちつつ密度を下げられる
- 練習プロトコル: 写真を 5 階調で描く → 3 階調で描く。明るいトーンを「これより明るいか/暗いか」で 1 段階上のトーンにまとめていく
- **8 → 5 → 3 → 1 階調** と段階的に圧縮する流れがデモで示される

### 描写省略のやり方 3 段(まとめ)

1. **階調を下げる**(中間トーンを上下どちらかに吸収する)
2. **色彩に空気遠近法を適用**(大気色寄りに振る)
3. **コントラストを下げる**(明度差を縮める)

この 3 つを **同時に** 行うのが正しい省略。1 つでも欠けると「ラフ仕上げ = 未完成」か「色濁り」になる。

### 距離別の階調数(目安)

- 前景: 5〜8 階調
- 中景: 3〜5 階調
- 遠景: 1〜2 階調(シルエットのみ)

「正確に階調数を分ける」ことに焦点を当てず、**奥に行くほど徐々に減らす** ことに集中する。色彩固有の明度があるため厳密な階調数の制御は不可能と講師も明言。

### 空気遠近法

- 遠くなるほど **大気の色(空の色)** が反映される
- よくある間違い: 「ぼかして遠ざける」と勘違いして彩度を下げる → 色が濁る
- 実際は遠くの色も **高彩度を持ち得る**(大気色そのものが鮮やかな場合があるため)
- 結論として「遠くなるほど大気色が反映される」を覚える(彩度の上下とは独立した話)

### 自然物 vs 人工物

- **自然物**: 色不規則・形多彩 → **階調を下げるのが難しい**。講師は厚塗りで処理し、境界線がラフでも大きな問題はない
- **人工物**: 物体同士のシルエットが明確 → **境界線をはっきりさせる** ことが重要。線画ベースで描く

この二分法は ch13(線画の活用)とも整合する。

### 山岳背景の実演ワークフロー

1. 似たトーンの低コントラスト部分を 1 つの塊にまとめる
2. 大きな影と光を受ける明部だけ区別
3. 奥に行くほど階調を 5 → 3 → 1 と減らす
4. 完全な遠景は「岩壁と木の区別」程度 → さらに奥は 1 トーンのシルエットのみ
5. 雲も同様: 手前は中間トーンを足し、遠くはシルエットのみ
6. 空は近い上部分が濃く、遠い下部分が大気色寄り
7. 湖は **目立つ明 / 暗の 2 トーン** だけで処理し、細かい色変化は省略

### リタッチ実演(旧自作の古い背景)

- 古い作品の背景(青屋根 + 白壁 + 影で 6 トーン)を 4 トーンに整理
- 「自然物は境界ラフでも OK / 人工物は境界線をはっきり」原則を適用
- 暖色が強すぎる時は寒色側で覆って調和を取る
- スポイトで既存色だけ吸い上げて使い、新色を増やさず階調を増やさない

## 引用に値する一節

> 仕上げをラフに描写するのですが、これは背景を書くことに慣れていない方々がよくする間違いです。このようなラフな仕上げは未完成の印象を与えてしまいます。

> 自然物は境界ラインがラフでも大きな問題はありません。人工物は物体同士の境界線がはっきりしているのが重要です。

> 背景のように視線を誘導してはいけない部分を書く時は描写を単にラフに済ませるのではありません。階調を下げ、色彩に空気遠近法を適用し、コントラストを下げてください。これら 3 段階を活用して描写してください。

## 個人的な所感 / 残った問い

- 「描写省略 = ラフ仕上げ」と「描写省略 = 階調削減」の違いは目から鱗。前者は単に **未完成** で、後者は **完成度** を上げる行為
- 階調数の数値(5 / 3 / 1)はあくまで目安。色彩固有の明度があるので厳密には測れない、と講師も明言
- 「自然物は厚塗り、人工物は線画」というワークフロー二分は ch13(線画の活用)で再強化される
- 「空気遠近 ≠ 彩度低下」は重要な反直観原則。`[[atmospheric-perspective]]` の核心
