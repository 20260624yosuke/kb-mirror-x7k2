# ye_jji_10. 余白を埋める

## 要旨

「描き終わったのに何故か空いて見える」キャンバスを埋める **3 つの簡易テクニック**。(1) **構成段階で色塗りを考慮する** = カラーラフ段階で色塗りまで試して問題を先取り、(2) 広い単色面積に **グラデーション** を入れる、(3) **点要素**(花・葉・水滴・小物・鳥・鬼火など)を **3 つ以上 + 前/中/遠の距離差** で配置。短い章だが講師が「非常によく使うノウハウ」と強調する密度設計の実用集。

## キーポイント

### コツ 1: 構成段階で色塗りを考慮する

線画段階では問題なかったのに色塗りで物足りなく感じる原因 3 段階:

1. **同じ色が隣接**(緑と緑)
2. **異なる色でも明度が似ている色が隣接**(配色段階で彩度と明度を考慮しても起こり得る)
3. **影を入れた時に明度が重なってコントラスト低下が露見**

解決: **カラーラフ段階で配色 + 影 + 補正まで全部試す**。明度や色味が重なる部分がないか検証してから本イラストに進む。

講師の運用: カラーラフを **用紙のように横に置いて** 本番イラストを描く(ch11 / ch12 でも同じ運用が再登場)。

### コツ 2: グラデーションを積極的に活用

- 広い単色面積は **思った以上に目を引く** → 主題への視線誘導を妨げる
- 髪・服・空・地面・髪の毛など、広い面積に色相 / 明度のグラデーションを入れるだけで多彩さが出る
- 細かいタッチを入れにくい部分(髪のトーン変化なしの面、傘の上面など)に特に有効

### コツ 3: 点の要素を活用

- 面積が小さく **シルエットを自由に設計しやすい** → どこにでも配置できる
- 候補: 花・葉・水滴・埃・レンズフレア・小物(紙・ペン・文具)・雲のシルエット・鳥・鬼火
- **必ず 3 つ以上配置**:
  - 1 つだけ → 重要オブジェクトに見え、視線を引きすぎる
  - 3 つ以上 → 「重要でない装飾」と認識される
- **距離感を 3 段階** で(ch03 の繰り返し回避と同じロジック):
  - 前景(キャラの手前)
  - 中景(キャラと同じ深度)
  - 遠景(キャラの後ろ)
- 繰り返し(同じサイズ・同じ間隔・同じ方向)を避ける
- 片側に偏らず、キャンバス全体にバランスよく散らす

### 実演例

- **自然背景イラスト** → 鳥を 3 種類のサイズで分散配置(右、左、上に振り分け、近 / 中 / 遠で大きさを変える)
- **東洋風和風キャラ** → 鬼火を 3 つ + サイズと間隔と長さを変える + 内側に明るい色を入れて燃焼感を出す + 遠は空気遠近で明度を上げる

## 引用に値する一節

> このようなポイント要素は 1 つだけ入れないでください。最低 3 つ以上入れることが重要です。1 つだけ配置すると、とても重要なオブジェクトのように見えて目を引いてしまいます。

> 私の場合はこのカラーラフ段階で配色と影だけでなく補正まで全て試してから本イラストに進みます。

## 個人的な所感 / 残った問い

- 「カラーラフで影 + 補正まで試す」は最大の収穫。**カラーラフ = 単なる配色テスト** という多くの初心者の理解を更新する
- 「点要素 1 つだけ NG」は説得力がある(重要性の認識ルール)。ジャンルを問わず使える普遍原則
