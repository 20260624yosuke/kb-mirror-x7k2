# ye_jji_15. 色塗り 01:暗部領域の設定

## 要旨

ch14 で示された **色塗りプロセスの工程 1**(暗部の領域と色の設定)のライブ実演。海辺キャラクター全身を題材に、線画 + 下塗りからスタートし、**透明ピクセルロック + 自動選択ツール** を駆使して影領域を一気に設定するワークフローを示す。「カラーラフから色を取って塗る」(スポイト中心)、「キャラと背景を同時進行 + キャラ優先」など、ch14 で予告された原則を実装する回。後半は **色味の反映**(環境光・補助光・主光)と **透過光の追加**(物体固有色の高彩度版)まで進む。

## キーポイント

### 開始前の整理(補正レイヤーの除去)

- カラーラフの上にあった補正レイヤーは色塗り作業の邪魔になる(スポイトで純色を取れなくなる)
- 解決法: 補正レイヤーを **コピーして整理済みレイヤーに 1 つずつクリッピングで貼り付ける**
- 講師は専用の **コピペオートアクション**(ボタン 1 つで実行)を作成

### レイヤー設計の原則

- **色** ではなく **パーツ** でレイヤーを分ける(パフェ・サンベッド・水着 + 髪・金属 など)
- 金属は同レイヤーにまとめる
- 髪と水着は色は同じだが別オブジェクトなので分ける
- 影描写では **明暗ごとにレイヤーを分けない**(レイヤーを増やすとブラシのタッチが消極的になり、立体的なボリュームが失われる)
- 暗部は **透明ピクセルロック** で直接乗せる

### 暗部領域の取り順序

1. **大きなブラシでラフに** 暗部領域を設定(キャラの体・水着・髪・パフェ・サンベッド・小物)
2. パラソルのキャストシャドウラインで顔・体・腕全体に大きな影
3. 服のフリル・骨盤に沿った折れジワでフォームシャドウを足す
4. **足の装飾のキャストシャドウは距離感を反映**(キャストシャドウは光の方向と物体間距離で決まる:近い部分は近く、遠い部分は遠くに離れる)
5. **金属(正反射体)には影を作らず** 周囲を反射させるだけ(パラソルのキャストシャドウで金属を暗くしない)
6. **3D セット(サンベッド/パラソル)由来の不要な明暗ライン** は自動選択で除去 → アウトラインのデコボコを流動化で整理
7. 線画の不透明度を全体的に下げる + クリッピングレイヤーで線の色を絵全体の色味(ピンクトーン)に寄せる

### 色相の設定(色味の反映)

- カラーラフから **スポイトで暗部の色を取って** 適用(c14 PDF p2 の原則を実装)
- 環境(青)・補助(砂のオレンジ)・主光(赤味)を全パーツに反映
- **無彩色(白い髪・白いシャツなど)は光源色を強く反映** → 髪に高彩度の青を入れる
- **同系色の反射** は彩度を上げて適用(胸の合わせ目など、ピンク同士・肌同士)
- 「青い光を受けるから青を塗る」NG ルール(ch12 で既出)を再強調 → **カラーホイールを回して彩度・明度を調整**

#### 色味の反映マップ(本講座キャラの実例)

| 部位 | 反射光 | 色味 |
|---|---|---|
| 顔下部 | 自身の肌の反射 | 高彩度の暖色 |
| 髪の上部 | 麦わ帽子の反射 | 暖色系 |
| 髪・水着の暗部 | パラソル + スカイライト | 青み |
| 顎・水着の下向き面 | 砂 + 肌の反射 | 暖色寄り |
| 上向き面 | パラソル + スカイライト | 青み |
| 水着・髪 ↔ タオル接触面 | タオルのピンク | ピンクの彩度を上げる |
| 胸の合わせ目 | 互いの反射 | 高彩度・くっきり |

### 中間トーン(明部)の暫定タッチ

工程 1 の終盤で、中間トーンの **高彩度の色を明部領域に軽くタッチ** していく(本格的な明部描写は ch16 へ送り)。仕上げではなく「色合いだけ表示している」段階。

### 透過光の追加

- 髪・耳・指先の薄い部分に **物体固有色の高彩度** で透過光を入れる
- 強調したい場合は **光源色の高彩度** で描写してもよい(デフォルメ領域)
- 例: 髪の毛は本来初の毛の色に従って鮮やかな空色で描写 → 後ろからの黄色い光を強調したい場合は黄色く描写

### 背景の進行

- カラーラフで設定済みの色相を維持
- ヤシの木のシルエットを「**幹を基準に葉が放射状**」と捉え整理
- 葉の繰り返し(尖った形のシルエット)が単調にならないよう、広がった部分と密集した部分を分ける
- 後ろのパラソル・サンベッド・浮輪などを追加
- 海・空・山は資料を見ながら **空気遠近法** で大気色寄りに

## 引用に値する一節

> 影と影にレイヤーを分けることはお勧めしません。レイヤーが細かく分かれると絵は綺麗になるかもしれません。しかしそれだけブラシのタッチが消極的になる可能性があります。

> 麦わ帽子が青い光を受けるからと言ってこのように青を入れるのはよくありません。カラーホイールを回して彩度・明度を調整して反映させてください。

> 足のキャストシャドウの場合、中央部分は足にくっついています。上に行くほど足から離れていきます。そのためその距離感に注意してください。

- **3D セット由来のノイズ除去** は他講師では言及されにくい実務 Tip。サンベッド・パラソルなどの 3D 素材を多用する作家に有用
