# ye_jji_12. カラーラフの描き方

## 要旨

Section 5 の実践開始回。カラーラフ作成を **「参考資料の収集 → 配色 → 明暗 → 全体バリューチェック」** の 4 工程に分解。資料収集は **「細部参考」と「絵の模範回答」** の 2 系統で目的化することが重要。リファレンスの量より「目的を持って集めたか」が応用力を左右する。実演ではビーチで水着 + 麦わ帽子 + パフェ + ヤシの木の構成キャラを 22 分でカラーラフ完成までもっていく。

## キーポイント

### なぜ資料が必要か

- 視覚情報は脳が単純化して記憶する → 「頭の中の絵」は実物より情報量が少ない
- 高完成度には必ず情報豊富な資料が要る
- 「資料を見る = 実力ではない」は誤解 → 分析して身につければ本当の実力になる
- 「1 枚の絵に 1 セットの参考資料」が基本

### 資料の 2 分類

1. **細部参考資料**(描く対象の構造)
   - 服のシワ、筋肉、髪の流れ、小物の構造、植物の生え方など
   - **アングルやデザインが違っても OK**(背面の参考資料からヤシの構造を学ぶなど)
   - 実演で集めた例: パフェの中身 / 麦わ帽子のテクスチャ / ヤシの構造 / サンベッドの構造 / 金属アクセサリーの色

2. **絵の模範回答資料**(自分が迷う部分の正解例)
   - 自分はうまくできているか迷いやすい部分: 絵柄、コントラスト、完成度、密度、デフォルメ、空気遠近法、配色、各照明の色彩設定、最も暗い色/明るい色の明度水準
   - 中心は **他作家のイラスト**

### 「明確な目的を持って資料を集める」原則

- 「綺麗だな」だけで集めると、いざ使う時に思い出せず参考にならない
- 「髪の毛の色塗り時に見る用」のように **目的を紐づけて保管** → 実際に作業時に開く
- 講師は **PureRef** に分類して保管(本文中「QRF」と書かれているのは PureRef のこと、[[pureref]] 参照)
- 主な収集先: **Pinterest / X(Twitter)/ pixiv** + 不足は Google 画像検索 + 自撮影

### 資料はラフ前から集める

- ラフ後に「合う構図」を探すのは非常に難しい
- **白紙の段階から資料を見てインスピレーションを得る** のが効率的
- 「この資料で今度描こう」とメモするフローも有効

### カラーラフ実演の手順(8 工程)

1. **配色(下塗り)**: 物体の本来色だけで塗る。光源色はまだ反映しない。大きなブラシでざっくり、はみ出しは気にしない
2. **デザインの分離チェック**: 同色 / 同明度が隣接していないか確認。問題があれば色を変える or 明度だけ変える(リボン↔タオルなど、似色を使う場合は明度差で逃げる)
3. **背景の配色 + 雲のシルエット**: 主題への視線誘導を狙ったライン:
   - **集中線型** = 主題に向かって集まる線
   - **包み込み型** = 主題を基準に囲む線
4. **明暗のラフ**: 乗算レイヤーで雑に陰影を入れ、明度の重なりを確認。パラソルの大きなキャストシャドウ → フリル等の小キャストシャドウの順
5. **照明色を反映**: 思考(直射)・補助(砂の反射)・環境(空)を全パーツに適用。**上向き面に環境色、下向き面に補助色**
6. **暖寒コントラストの強調**: 上向き面に寒色、下向き面に暖色を強引に振って暖寒対比を最大化
7. **リムライト + 透過光 + 反射光**: 主題部周辺だけ情報量を盛る(キャラと背景の分離)
8. **補正(カラーバランス + ソフトライト)**: 中間トーンに赤み、シャドウに青み / ソフトライトで主題外の輪郭ラインを暗く抑える / 水に濡れた表現を最後に少しだけ追加

### 同色重複の解決法

- 髪・水着・サンベッドが似色 → サンベッドに **タオル / クッション** を追加して色を差し込む
- リボンと同色のタオルなら **明度だけ少し変える**
- ヤシ ↔ モンステラなら **葉の色味を少し青寄りに** して種別を出す

### 照明色の反映で **やってはいけない描き方**

- 「青い光を受けるから単に青を塗る」は **NG** → 彩度が濁って加算混合の表現にならない
- 正しい: ch07 / ch08 で学んだ **カラーホイールを回して彩度・明度を調整** してから反映

### カラーラフは丁寧すぎなくてよい

- ラフ段階でキャンバスを拡大して整える人がいるが NG → **ブラシを大きく、キャンバスを縮小して描く**
- 全体の明暗バランスに集中。モノクロ表示で随時確認
- 別モニターに全体ショットを表示しながらやる

## 引用に値する一節

> ただ綺麗だなと思ってどう使うか考えずに無作為に資料を集める方がいます。そういう方々は大体たくさん集めた資料集を私に見せてくださいます。そして「先生、こんなに参考にしても適用できません」と言われます。

> ラフは丁寧に整える必要のない工程なんです。だから整えるのは後回しにしても大丈夫です。

> 麦わ帽子が青い光を受けるからと言ってこのように青を入れるのはよくありません。学んだようにカラーホイールを回して彩度・明度を調整して反映させてください。
