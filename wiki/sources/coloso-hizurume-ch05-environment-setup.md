# coloso ひづるめ ch05 ― 環境のセットアップ

> Section 02。作業環境・キャンバス設定・レイヤー効果・ショートカット効率化。CLIP STUDIO PAINT 前提。

## 要約

本人の機材とキャンバス設定、CSP のワークスペース構築、レイヤー効果(特に **カラーレイヤー**)の使い分け、ショートカット中心の効率化を紹介。

## ソース内の主要主張

- **作業環境**: Mac / メモリ 64GB / Wacom Cintiq 24 インチ液タブ / BenQ カラーマネジメントモニター。左手デバイスは 60 個以上試し、**回転デバイス(XP-PEN、旧 Rev-o-mate)+ キーボード** が最強(回転デバイスは親指の近く)。
- **キャンバスサイズ**([[large-canvas-7000px]]): 長辺 7000px 以上 / 350dpi。**大きく描いて縮小**する方が精度・クオリティが上(投稿時は 3000×4000 に)。プリセット保存。
- **ワークスペース**: パレットドックを利き手側に配置しシンプルに。
- **レイヤー効果の使用順**(本人): カラー → 乗算 → オーバーレイ → 比較(明)→ 色相 → 輝度 → 彩度/スクリーン → 加算発光 → 焼き込み発光 → 乗算/ソフトライト。
  - **カラー**([[layer-color-value-preserve]]): バリュー値(明度)を保ったまま彩度を変える。**情報の入り抜き**が簡単(最重要)。
  - 乗算 = 影、オーバーレイ = 色味/光、比較(明)= 黒を明るく、色相 = 色相変更、比較(暗)= 明るい色を暗く/光の色変更。
- **ショートカット効率化**([[shortcut-efficiency]]): 1 枚を速く描く人の最重要事項。ペンを速く動かしても品質は落ちるだけ → 描いていない工程を省く。覚えるまでやる。筆圧検知レベルの一括調整、クイックアクセス/コマンドバー編集。
