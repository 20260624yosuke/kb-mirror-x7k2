# Nekojira 05. 人体練習パート 1

## 要旨

[[nekojira]] が参考資料(美しい S カーブを持つ女性ポーズ)を使い、**ジェスチャー観察 → CSI で大きな流れ → パーツ抽象化 → 細部清書** の **伝統的な順序**で全身を描き上げる実演章。ch04 で導入した [[csi-stroke]] と [[abstract-mix-and-match]] の応用 1 セット目。**顔(目・口の単純線)・髪の毛・手・足の指**まで一気通貫で実演。

## キーポイント

- **観察フェーズ**: 参考資料を見て **S カーブ(美しいビットフロー)**・**骨盤の傾き**・**腕の方向**・**頭の向き** を素早く把握 → メモ的に大きな流れだけを掴む
- **ジェスチャー描画**: 大きな S カーブ → 骨盤(円柱)→ 足の直線 → ランドマーク。「ジェスチャーの流れを捉えたら体の形を綺麗にする」順序
- **CSI を 3 ストロークに制限**: 「**ストロークを複雑にしないように心がけています**」「C カーブと S カーブだけを調整して流れを改善」(9:36, 9:40)
- **顔のシンプル線**: 「**目を表現するのにシンプルな線だけを使っています**」「比率と位置を決めているだけで細部は後回し」(12:47)
- **手と指**: 大きなシルエットを最初に描いて、その後に指を追加。「**正しい形を取れば全て簡単に調整できる**」(10:29)
- **手の指の単純化**: 1, 2, 3, 4, 5 と数える単純な比率分解。「結合部分のほとんどはすでに測定済みだということが分かります。必要なのは正しい輪郭を加えること」(11:16)
- **修正ループ**: 描いて気に入らなければリクイファイで調整、また線を引く、また調整 — を繰り返すことを正当化(「ミスに対して許容範囲が広い」13:24)
- **練習後は必ず自分のスタイルで描き直す**: 「人物観察の練習後は必ず自分のスタイルで描き直して次のステップに行かせるか確認することをお勧めします」(11:43)

## 個人的な所感 / 残った問い

- 本章は **CSI ストロークを通常のドローイングフロー(伝統的順序)に適用する** 実演で、ch04 が「ジェスチャー前提の理論」、ch05 が「ジェスチャーから清書までの一気通貫実演」という構造
- ch06 では「**ジェスチャーではなく、参考から各パーツを抽象化 → ミックス&マッチで再配置**」という非伝統的順序を提示する(対照実験的構造)
- 「**目はシンプル線で寸法だけ。細部は後回し**」は [[ye-jji]] ch18 の「目: 暗さを集中させる + ハイライトは暗部に」とは別レイヤーの議論(Nekojira = 構造段階 / Ye Jji = 着色段階)
- 顔・髪・手・足の **構築寸法そのものが繰り返し練習素材** として開示されている(指の数・足の指 3 分割・親指 1/3 など)→ 別途 `hand-drawing-simplification` / `foot-drawing-simplification` の concept 候補(本 batch では深追いせず、CSI 一般化に統合)
