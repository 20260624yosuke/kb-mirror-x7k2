# ye_jji_05. 多様なテクスチャー描写(基礎編)

## 要旨

Section 3 の質感パート前半。**素材ごとの反射特性** を 4 カテゴリで整理: 正反射(鏡・金属)、透明(ガラス・水)、半透明(ゼリー・飲み物)、違法性反射(木目方向にハイライトが伸びる金属)。各素材の **物理原理(フレネル反射・屈折・コサイン)** を 1〜2 行で示し、すぐ実習に移る形式。**ハイライトはセンターライトの位置ではない**(光が目に届く反射経路上)、**透明物体の反射はスクリーンレイヤーで描写**、など実装直結のテクニックを多数提示。

## キーポイント

### 正反射(鏡・金属)

- 表面が滑らかで周囲の像をはっきり反射する → 反対は [[ran-han-sha|乱反射]]
- **量感描写が生じない**(キャストシャドウ・フォームシャドウなし)。鏡が手のひらに影を作らない事実で確認できる
- 描写手順:
  1. **反射を描く**: 物体のグリッドに合わせて歪ませる。床方向の面 → 床の色、壁方向 → 壁の色
  2. **ハイライトを描く**: 光源の形・色をそのまま反射(光源が白なら白、四角なら四角)
  3. **ハイライト以外を 1 段暗く** 抑える(反射光は跳ね返りで吸収されて弱まる)。これがないと「白髪のキラキラ」が出ない
  4. **明・暗・明の縞模様**: 周囲計算が困難な箇所(背景の小金属など)はこのパターンで省略
  5. **曲面で情報量増**: 平面より曲面の方が反射範囲が広い → ハイライト数増・色味増で違和感なく密度を上げられる
- **ハイライトの位置は [[center-light|センターライト]] ではない**: 光線が物体表面で反射し **目に届く位置**。光源側面側に寄りすぎると間違い。**ハイライトはやや内側** にできる
- ハイライトは複数生じうる(同じ角度を持つ面全てに発生)
- 物体同士が接する部分は **互いを反射し合い** メ度が低下 → [[occlusion-shadow|オクルージョンシャドウ]] のように暗く描写

### 透明(ガラス・水)

- 特徴: 後ろの像が透ける + 屈折 + 周囲の反射
- **屈折描写**: 物体のグリッドに合わせて歪ませる(正反射と同じ流れ)。**凸レンズ形状(球体)では上下左右反転**
- **反射の描写は 3 段階の強度**:
  1. **ハイライト** = 不透明
  2. **エッジ(フレネル反射)** = 不透明(斜めから見る角度ほど反射率高)
  3. **明るい色の反射** = 不透明、暗い色の反射 = 透明 → クリスタの **スクリーンレイヤー** がそのまま使える(明色を残し暗色を透過)
- **厚みが増すほど不透明** に描写。色味は物体の固有色に従う(青なら厚部を青く)
- **背景明度で描写が変わる**: 背景明るい → 厚部を暗く / 背景暗い → 厚部を明るく
- ハイライトはグレー化させない(常に最高明度)。グレー化すると反射率が低く見え透明感が消える

### 半透明(ゼリー・飲み物のような不透明体)

- 固有色以外を吸収するため **色表現が弱まり、ほぼ明度のみで後ろの像を描く**
- **キャストシャドウに固有色が反映**(光が物体内で吸収・反射して固有色のみ通過)
- **光源の反対側が高彩度で明るい**(凸レンズ効果で光が内側に集まる)
- 表面のマット化で反射が消える → 滑らか:鮮明な反射 / マット:反射ほぼなし

### 異方性反射(Anisotropy / 加工金属・髪の毛)

> [!note] 訂正済み (re-ingest 2026-05-17)
> 旧 wiki では「**違法性反射**」と表記していたが、PDF (`c05_要約ノート.pdf` p8) では正式に **「異方性反射(Anisotropy)」** と明記。YouTube 自動文字起こしの「いほうせい」を旧 ingest で「違法性」と誤変換していたことが判明。**正しくは「異方性」**。リンク slug は移行コスト上 `i-hou-sei-byou-sha` のまま据え置くが、表示名と概念ページ本文は「異方性」に統一する。

- **異方性 (Anisotropy)** = 加工された金属の表面や髪の毛など、**テクスチャがある表面でハイライトが伸びる現象**
- 反射率は **正反射より低い**(表面に模様があるため)
- ハイライトと反射が **木目に沿って伸びる**(明暗の縞模様が方向性を持つ)
- 描写: 模様と反対方向にハイライトを伸ばす + 模様方向にハイライトを分割
- 髪の毛のハイライトも同じ原理(天使の輪が木目方向に伸びる)
- PDF の例: 加工金属(ハイライトが上下方向に伸びる)/長い黒髪(ハイライトが左右方向に伸びる)

### 実習構成

- ポーション(透明な瓶) + B 玉(凸レンズ・厚いガラス球) + 靴(違法性反射)を、明背景 と 暗背景の 2 ケースで描写
- スクリーンレイヤーで反射を一気に表現するワークフロー

## 個人的な所感 / 残った問い

## 補助資料

### `c05_要約ノート.pdf`(全 8 ページ)

講師制作のスライド集。テクスチャー描写を **5 区分(正反射 / 透明 / 半透明 / 混合反射 / 異方性反射)** で整理しており、本文の構成より体系的。

> [!note] 訂正済み (re-ingest 2026-05-17)
> 旧 wiki の「混合反射は ch06 で初出、ch05 では明示されない」という記述は誤り。PDF (`c05_要約ノート.pdf` p7) では ch05 の章資料として混合反射が明示されている。**混合反射の起点は ch05 PDF にあり、ch06 で実習として深掘りされる**、と整理し直すべき。

- **p1 正反射とは**:
  - 「表面が滑らかで、周囲の像を鮮明に反射すること」と定義(=鏡面反射とも)。対義語は乱反射
  - 材質の特徴: 周囲の像を鮮明に反射 / **量感が生じない → 影が現れない**
  - 描写方法: ハイライト位置(目に届く位置に生成)/ ハイライトの数(複数あり得る)
- **p2 正反射(続き)**:
  - **反射する物体が白色の場合**: 白い物体でも光は何度か反射しながら吸収されるため、**明度を少し下げてハイライトより暗く描写**
  - **固有色が白色の場合**: 同じ理由で「ハイライトより暗く描写」(白髪のキラキラ問題の解)
  - **比較的重要度の低い部分**: 背景や小金具など → ストライプ状模様でシンプルに表現
- **p3 正反射(続き)**: 曲面では反射による情報量が増える(平面比) → 周りの色を多く取り込んで反射、タッチやハイライトの数を増やす
- **p4 透明な材質の特徴**:
  - 後ろが透ける / 厚みで屈折 / 反射が中心(立体感より反射優先)
  - **屈折の描写**: 物体のグリッドに沿って行う。雫のような球形は **凸レンズ効果で上下左右に反転**
  - **描写方法 — 強い反射は不透明に**: ハイライト / エッジ(フレネル反射) / 明るい色
- **p5 透明 — 光の遮断**: 100% 透明は存在しない → 重なりや厚み部分は不透明に。**背景の明度による描写の変化**: 背景明度低 → 厚みを明るく / 背景明度高 → 厚みを暗く
- **p6 半透明な材質の特徴**:
  - 固有色以外を吸収 → 他の色が目立たない / キャストシャドウに固有色が反映
  - **光の散乱**: 膨らんでいる立体形状では凸レンズ効果で光が下に集まり散乱、**光源の反対側が明るくなる**
  - 表面がマットになるほど、後ろの像や反射がぼやける
- **p7 混合反射とは(★ch06 と被るが ch05 PDF で初出★)**:
  - 「正反射と乱反射の両方の特徴を持つ反射」「最も一般的に見られる材質」
  - **コーティング**(乱反射物体に透明材質がコーティングされた場合): 量感描写と反射描写を分けて表現、レイヤー分離推奨
  - **表面の粗さ**: 正反射物体の表面が粗くなると乱反射の性質を帯びる。**反射された像の境界をぼかして表現**。粗さが大きくなるとハイライトのみ強調される形に
- **p8 異方性反射 (Anisotropy)**:
  - 「加工された金属の表面や髪の毛など、テクスチャがある表面でハイライトが伸びる現象」
  - 金属が異方性反射を持つことが多い理由: 加工時に表面にテクスチャが生成されるため
  - 例画像 2 点: ハイライトが上下方向に伸びる(加工金属パイプ群) / 左右方向に伸びる(長い黒髪)
