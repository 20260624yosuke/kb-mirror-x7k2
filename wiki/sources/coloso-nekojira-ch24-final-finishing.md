# Nekojira 24. 最終ドローイング：仕上げ

## 要旨

[[nekojira]] 最終ドローイングの **5 段階フェーズ 4(細部+反射素材)**(5 ファイル)。ch17/ch21/ch23 で確立した原則を **長髪少女キャラに実装** する集大成。中核技法: (1) **影の縁にサイドの高い色を加える**(SSS の応用)(2) **パーツ間の細部密度を均等化**(顔/髪/服)(3) **目を商点化** = 目に集中的に細部を加える(4) **空からの青光を上向き面に隠す** = 天空光モデル(5) **線画は他のパーツも合わせて太く** = 完成度の同時性。ch24_05 は **transcript 空**(live drawing)。

## キーポイント

### 5 つのフェーズで考える(復習)

| 工程 | 考慮事項 | 本章での扱い |
|---|---|---|
| 1. 影の形 | コントラスト | カラースケッチで完了 |
| 2. 塔の値 | グラディエントマップ | 微調整 |
| 3. 光と雰囲気 | 露出オーバー | 紙の明るい部分 |
| 4. **反射と素材** | テクスチャ + SSS | **本章の中核** |

### 影の縁に高彩度色を「隠す」

- 「**シャドウの縁にサイドの高い色を使うのが好き**」「**洗顔やシャドウの縁に使って情報量やディテールを増やしつつ光の存在感も強調**」(ch24_01 7:07)
- 「**普段から線画に高サイドの色を使用していますが、線の色を変えることで光の表現がより強くなる**」(ch24_01 6:52)
- これは **SSS(影の縁の赤み)** の応用。Nekojira スタイルの **微差ディテール** の数値的核

### パーツ密度の均等化(完成度の同時性)

- 「**各パーツの細部の密度を揃えていきます。特定パーツに時間をかけすぎて他のパーツの仕上げに影響が出ないようにします**」(ch24_01 13:28)
- これは ch21 の「**エッジ追加の連動原則**」の実装版

### 顔の細部追加手順

1. **ソフトブラシでサイドの高い赤** を頬に
2. **目の周りにも赤み**(構造の変化点 = 敷張変化)
3. **強膜**(白目)は **完触系(青みグレー)** で(純白は避ける)
4. **アイライナーは濃い赤色**(肌色と馴染ませる)
5. **目のベースカラーはグレーから始める**(高彩度から始めない)

### 「強い光部分はフラットに保つ」哲学

- 「**光の当たる部分はあまりトンに変化をつけずフラットにしげる**」(ch24_01 2:44)
- 「**強い光が当たると細部が消える錯覚**」
- → これが Nekojira スタイル(劇的な光 + フラットな明部)の鍵
- 自然光重視ならハイライト多め、劇的光なら **影に詳細・明部はフラット**

### 跳ね返り光で色を追加

- 「**暗い部分を使って明るいスカートに情報を加える**」(ch24_01 3:16)
- バウンスライトは **暗い影を多色化** する手段

### 「肌色を目に溶け込ませる」

- 「**目は水晶のように反射する素材なので肌の色を目に溶け込ませるのが好き**」(ch24_03 15:25)
- 肌の色が反射 → **目に多様な色変化**

### 目の細部とその先(ch24_03/04)

- 目の **影 +1 層のキャストシャドウ**(暗いトーン追加)
- 交際の周りに **利こい影**(細い線)
- グレー基調 → **高サイド青のアクセント**(影に隠す)
- **アイライナー近くに色を隠す** で微妙な変化
- **目とまつ毛の間** は **最も強いコントラスト**(商点 = focal point)

### コントラストの統一(目を商点にする際の注意)

- 「**ハイコントラストやリアル表現のスタイルなら目は機能するかもしれないが、今回はフラットなため違和感**」(ch24_03 11:38)
- 「**全体の雰囲気やト関係、カラーパレットは制御を保つ必要**」(ch24_03 11:44)

### 線画の太さで完成度を保つ

- 「**目の線画は他の部分と比べて太め → 他の部分を細くて柔らかい線にすると目が目立ちすぎる**」(ch24_04 15:02)
- → **他の部分の線も不(太く)** して全体的に見たスタイルに

### 上向き面に青を「隠す」(天空光モデル)

- 「**上向き面に青色を加えると肌の敷張より明るく見える**」(ch24_01 17:08)
- 空からの光は青 → **微妙な感触(寒色)を加える**
- これは **温と寒の間に隠れた感触で色変化を興味深く**(ch24_01 17:08)

### 「カラーパレットの関係性を保つ」最終調整哲学

- 「**カラーパレットは待ったので微調整を重ねます。個人的な好みに基づく調整で大きな変更は不要**」(ch24_04 7:44)
- これは [[intent-first-correction]] と同じ

## 引用に値する一節

> 光の当たる部分はあまりトンに変化をつけずフラットにしげることが多いに気づいたかもしれません...影の縁あたりにサイドの高い色を使うのが好きなんです...影の部分では塔の変化をあまりつけません。形に集中するため平坦に保ち、最も暗い塔も 1 つだけ加えます。(ch24_01 2:44)

> 私の絵のスタイルはフラットでシンプルですが、人々が気づかない微妙な細部の変化を加えています。これは私がよく使うテクニックです。(ch24_01 17:31)

> 作業を進める前に各パーツの細部の密度を揃えていきます。特定パーツに時間をかけすぎて他のパーツの仕上げに影響が出ないようにします。(ch24_01 13:28)

> ハイコントラストやリアルな表現のスタイルなら目は機能するかもしれません。しかし今回は比較的フラットで明確なトン変化が少ないため異なる風になってしまいます。コントラストは重要ですが全体の雰囲気やト関係、カラーパレットは制御を保つ必要があります。(ch24_03 11:38)

> 目の線画は他の部分と比べて太めになっているので、他の部分を細くて柔らかい線にすると目が目立ちすぎてしまいます。それを避けるため他の部分の線も不して全体的に見たスタイルに仕上げています。(ch24_04 15:02)
