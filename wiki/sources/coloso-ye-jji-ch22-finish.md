# ye_jji_22. 加工と仕上げ

## 要旨

色塗り 7 工程外の **補正・仕上げ章**(ポストプロセス)。**よく使うレイヤー効果**(ソフトライト・オーバーレイ・ハードライト・カラーバーン・スクリーン・カラー・発光ドッジ)と **補正レイヤー**(カラーバランス・カーブ)の役割と使い分けを定義し、実ファイルに **3 面ビネット → 主題部にカラーバーン → 背景にガウシアンぼかし → 発光ドッジで光の滲み → カラーバランスで青みシャドウ + 赤み中間 → カラーレイヤーで局所色味 → スクリーンで透過光 → 結合 → ノイズ + クロマティックアベレーション + レンズフレア + 埃** の順で適用する流れを実演。**「意図した色味を最優先に。運任せの補正(適当なグラデーションマップ等)は感覚を磨かない」** を強く釘付けする学習論の章でもある。

## キーポイント

### よく使うレイヤー効果(強度順)

| 効果 | 用途 | 講師の強度ランキング |
|---|---|---|
| **ハードライト** | 微妙な明暗を強く調整 | **強(最も色が反映される)** |
| **オーバーレイ** | 同上、中程度 | 中 |
| **ソフトライト** | 同上、弱く | 弱 |
| **カラーバーン** | 主題部の影を強調 | コントラスト UP(別レベル) |
| **スクリーン** | 背景明るくする / 透過光に色味を乗せる | 加算系 |
| **カラー** | 色相変更(明暗を保ったまま色味だけ変える) | 色相のみ |
| **発光ドッジ** | 光の滲み | 金属・水滴・足先のハイライト誇張 |

ハードライト > オーバーレイ > ソフトライト の **強度ランキング** は本講座の実用的なメンタルモデル。

### 補正レイヤーの使い分け

- **カラーバランス** — ハイライト / 中間トーン / シャドウ別に色相シフト(青みシャドウ・赤み中間など)
- **カーブ** — より明確に領域を指定して色相変更(例: 中間明度の色相を赤に)
- カラーバランスで足りない時にカーブを使う

### 補正の原則:意図ファースト

- 「青い色張を強調したいのか、補色を強調したいのか、断食の色張を強調したいのか、これを明確に決める」
- **NG**: 適当な色を重ねる / 適当なグラデーションマップを当てる「**運任せ補正**」
- **理由**: 綺麗な結果は得られるが、**色彩感覚のスキル向上には繋がらない**
- 「補正の感覚は磨かれるかもしれませんが、色彩感覚自体は育たない」

→ [[intent-first-correction]] / [[interest-driven-learning]] の補正領域における実装

### ビネット(外側暗化)の 3 面ルール

- 外側を暗くすると視線がキャンバスの外に逃げにくくなる
- **4 面全部を暗くするのは NG**(窮屈に見える)
- **3 面だけ暗く、1 面を開ける** → [[vignette-3-side-rule]]
- ソフトライトで実装

### 主題部のコントラスト追加

- **カラーバーン** で影の領域にエアブラシでポンポン
- キャンバスを遠くに置いて確認
- 光が当たっている面に **光の滲み**(発光ドッジ)を追加
- キャラクター後ろに **スクリーンレイヤー** で背景明るく → キャラを浮かせる
- 帽子からパラソルへの流れを切る

### 背景ぼかしで空間感

- 背景レイヤー統合 → 領域選択 → **フェザー 50px** → ガウシアンぼかし
- Photoshop 持ちは **レンズぼかし効果** がより現実的
- 主題部に接している部分を特に強くぼかす → 帽子からパラソルへの流れを切る
- 前景のアイスボックスや円形にもぼかしを入れる

### 発光ドッジで光の滲み

- 強い日差し感を出すため、明部に滲みを描写
- 金属・水滴・足先の反射に効く

### カラーバランスで色味調整

- 個人的に **青い観の色味** を強調 → ブルーを上げる
- **シャドウ部分に青みのトーン**
- **中間トーンは肌を考慮して赤み**
- マスクレイヤーで不要な効果を消す(外側のサイドを下げる)

### カラーレイヤーで局所色味

- 明暗はそのままで **色相だけ変更**
- 環境光を受けている部分はより青み
- 砂からの反射光をより強く描写

### スクリーンで透過光強調

- 青を持ってきて遠価光に色味を乗せる
- 紫色の透過光は別レイヤーで
- 光の滲みをさらに強調(雲の白色にも光の滲み)

### 最終レタッチ

- 補正をすると **新しく見えてくる** ハイライトの強化
- リムライトの色味を左側に持っていく(パラソルと麦わ帽子の分離にも使う)
- 主題部のパフェにもリムライトを追加
- 「単に線をなぞるのは NG(平面化)」(ch21 と同じ原則の再強調)

### 仕上げの「写真っぽさ」3 点セット + 埃

- **ノイズ** — 統一感を与える、写真の感じ。ただし **顔の部分はマスクで消す**(描いた顔が潰れるため)
- **クロマティックアベレーション** — 顔をフォーカスに、離れた部分だけにかける
- **レンズフレア** — CLIP STUDIO 素材 + スクリーンレイヤー。光の方向と一致させる
- **埃の散らし** — ラストブラシで開いた部分を埋め + 近くの埃はブラで曖昧に → 屋外の空間感

### 統合 → ノイズ → クロマティックの順

- ノイズとクロマティックは **全レイヤー結合後** にかける(その上で顔をマスクで保護)

## 引用に値する一節

> 受行生の皆さんがこのイラストでどこを強調したいのかが重要です。…これを明確に決めていただくと良いと思います。

> 適当な色を重ねてレイヤー効果を試してみたり…運任せで補正をするケースを見かけましたが…色彩感覚のスキル向上には繋がりにくいと思います。

> 4 面全てが暗いとで塞がれてしまうのはよくありません。…3 面程度だけ暗く保ってください。残りの 1 面は開けておくことをお勧めします。

> せっかく描いた顔の部分が潰れてしまうのは少し悲しいです。だから顔の部分はノイズを消していきます。

## 個人的な所感 / 残った問い

- 「**補正で色彩感覚を磨く / 運任せだと育たない**」は学習論として強い主張 — 通常の補正チュートリアルとは逆の立場
- ビネット 3 面ルールは画面構造の話で、構図上どの面を開けるかは別問題(本講座では「主題部側に視線を逃がす方向」の説明が薄い)
- レイヤー効果の強度ランキング(ハード > オーバー > ソフト)は **実用的なメンタルモデル** として優秀
- 「**ノイズとクロマティックは顔をマスクで除外**」は描いた顔を守る配慮 — プロセス設計として丁寧
- 「補正後に新しく見えてくる要素」を **再レタッチで強化** する反復は ch11 のセルフフィードバックループとも構造が似る
