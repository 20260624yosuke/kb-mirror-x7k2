# ye_jji_18. 色塗り 04:髪の毛と目の描写

## 要旨

色塗り 7 工程の **工程 4(髪と目のディテール描写)**。本講座で最もキャラの印象を決める章。前半「ディテール 01:髪の毛」では **髪はデフォルメで質感が大きく変わる** ことを最初に整理し、**3 つの考慮事項**(質感のデフォルメ依存 / ハイライトの工程差・途切れ / 厚みの現代トレンド)を明示。後半「ディテール 02:目」では「**コントラストと透明感を出す配置**」(暗部に暗さ集中 / 固有色クリア / ハイライトは暗部に)を講師の好みとして実演。**資料は目指す質感に合致するものだけ参照する**という講師の運用哲学が貫かれる。本章には 5 枚の講座教材スライド画像が付属(髪 3 + 目 1 + 実演完了状態 1)。

## キーポイント

### 髪の質感はデフォルメ依存(教材スライド 1: マテリアル)

- **拡散反射寄り**: ハイライト弱、量感描写中心、塊感が出る
- **正反射寄り**: ハイライト鮮明、反射描写中心、コントラスト強、キラキラ華やか
- 講師は **正反射寄り + 少し量感** を好む(主題部への視線集中)
- ライティング方向が重要な時は **量感描写の割合を増やす** という調整も
- **目指す質感に合った資料だけ参考にする** → 違う質感の資料が混ざると明暗判断で混乱する

### ハイライトの 2 軸(教材スライド 2: ハイライトの形)

- **工程差(上下の変動)**: 大きい → ダイナミック、小さい → 整った大人しい印象
- **途切れ**: 多い → 髪のでこぼこ感増、厚みあり / 少ない → 滑らかな髪
- 「ダイナミックなイラストに違和感のあるハイライト」が出るのは **工程差不足** が原因
- 「ベタつき過ぎる髪」は **途切れ過剰** が原因

書きたい印象に応じてこの 2 軸を組み合わせる。

### 薄い髪の現代トレンド(教材スライド 3: 明暗描写)

- **厚みのある髪は古く見える** → 薄い髪・軽い描写が現代的
- フォームシャドウは **大きな明暗だけ** で描く
- 密度を上げるなら、フォームシャドウを増やすのではなく **明暗境界のシルエット + 反射 + キャストシャドウ** を中心に描写を追加する

### 髪の描写順序(実演)

1. **オクルージョン中心** で暗部を取る(髪と髪の隙間、塊と塊の境界、リボン・帽子・体への接触)
2. **ハイライトのラフ配置**: 真ん中にメインハイライト(光は影内なので反射ハイライト寄り)
3. **2 系統のハイライト** を入れる(本実演):
   - パラソルからの **青い反射光**(主ハイライト) — 上下に変動するラインで描く
   - 砂からの **オレンジの反射光**(下方の副ハイライト) — 上ハイラインより細く弱く
4. **フレネル反射**を意識してサイド面で反射率を上げる
5. **透過光**を空色 + ピンクで前髪に(顔色をスポイトで前髪に塗る = 透ける表現)
6. **異方性反射** の原則に沿ってハイライト分割(髪の繊維方向)
7. ハイライト周りを 1 段暗く抑えて反射を強調
8. **ハイライトの太さ・面積** にも変化をつける(島模様化回避)

### 髪の Tip 集

- 「同じトーンで塗り続けない」(ch17 と同じ原則)を髪でも徹底 — 自動選択 + エアブラシで色味追加
- **画面反転を頻繁に** 行い、手首が楽な曲線で描く
- 長い髪はキャンバスを縮小して **遠くから明暗を確認**(バリュー崩壊回避)
- 主題部の情報量を上げる:ハイライト周りに **暗い帯** + コントラスト UP

### キャラ固有のツートン処理

- ピンクの内側の **蝶模様**(キャラデザ要素)→ レイヤー分離して塗り、後で結合
- ツートンの境界は **明暗とは別のデザイン要素** として処理
- 「蝶をテーマにデザインしたキャラクター」と講師が明言(本キャラの設定)
- レイヤー結合後にオクルージョンで塊を分離

### 目の描写戦略(教材スライド 4: 目のデフォルメ)

- 目は **デフォルメによって質感・形・色味すべてが変わる** 最もセンサ別なパーツ
- 種類が多すぎるため講師の好む形だけを説明
- 講師の好み: **高コントラスト + 透明感のある固有色** + **立体的な形**(情報量が増え視線誘導が容易)
- **暗いトーン(まつ毛・瞳)に暗さを集中** → 残りは固有色をクリアに(逆に固有色を暗くするとクリアさが失われる)
- **ハイライトは暗い部分に配置** してコントラストを最大化
- **眉毛のグリッド** を意識して立体的に描く(平面で書かない)
- 「正解はない、私の好みに合う目を描くにはこう」と明示

### 目の描写順序(下のレイヤーで瞳 / 上のレイヤーで眉毛)

1. **上部を暗く、下部を明るく** のグラデーション(下が上を向くため光を多く受ける、器のような形)
2. 株は青み(環境光)、下は床/肌のオレンジ反射
3. **同行(瞳孔)を最も暗く** → 視線が合う感じ(薄くすると神秘的・虚空を見つめる印象)
4. 同行の周りに **筋肉ラインのような放射状の影**(ドーナツ形のデフォルメ)
5. **コントラストを上げる**: 同行をさらに暗く、まつ毛上下を暗く
6. まつ毛: 単色ではなくブラシタッチで **毛束感**、上下両方向に
7. 白目と黒目の境界は **少し柔らかく**(濃すぎると不自然) — 色味のあるトーンで境界をぼかす
8. **ハイライト位置**:**下に置くと落ち着いた印象 / 上だと活発**(本キャラは下に配置)
9. ハイライト周りに暗いトーンを配置してコントラスト強調
10. ハイライト色 = **白ではなく** 周囲反射の **空色 / オレンジ / 紫(補色)**

### 目の補強要素

- アイメイク・アイシャドウを上山レイヤーで追加
- 前髪が目を隠す部分 = **髪色を薄く乗せる**(透ける表現)
- 中間に明るいトーンを入れて目の縦の比率を広く見せる
- 紫の補色は **意図的に捕食を使う** → 補色対比で情報量を上げる

## 引用に値する一節

> 反射率の高い質感を意識して色塗りしています。

> 厚みを感じさせる髪の毛を描くと絵が古く見える可能性があります。

> 私はこのように書きます。ハイライトは暗く押えた部分に打ちます。そうすることでコントラストを強調できます。

> 正解はないということを覚えておいてください。そして目に陰営影をつける時は基本的に上部を暗く抑え株を明るく抜きます。これは黒目の形が内側にくぼんでいるからです。

> 本来は明暗や色味について悩んで時間をかけますが、悩む家庭が退屈に感じられるため短縮しました。受行生の皆さんは十分な時間をかけてどんな色味が綺麗か試してみてください。
