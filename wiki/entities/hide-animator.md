# hide(フリーアニメーター)

## 現在の統合見解

[[coloso]]「描いて覚える人体ドローイング基本講座」の講師。フリーアニメーター兼 YouTuber として紹介され、YouTube チャンネル「hide channel 顔と体の描き方講座」で絵の描き方を配信している。講座紹介ページでは、アニメーターとして多数の人気作品の原画・作画監督などに関わった経験を、線・比率・パース・立体化・人体解剖の単純化へ落とし込む立場として説明されている。

### 公式商品ページからの補足(2026-08-22 取り込み)

- **Clip Studio の頭部 3D モデルを監修**している(商品ページ「その他」欄に明記)。
- 使用ツールは **Clip Studio EX Ver.3.0.4**。
- インタビュー要旨: ①自分の絵の安定性欠如の原因は感覚で描くことで、基礎を学んで解決した → その経験が本講座の由来。②制作で一番力を入れるのは「キャラクターが生きているか」で、素体が安定して描けることが必須。③初心者ほど瞳の綺麗さ等の表面的な部分に目が行くが、仕上げを魅せるには土台の安定性が欠かせない。
- 受講特典: ジェスチャー / ボックス / ブロック / パース別人物 / 骨格・筋肉の単純化(頭部〜足まで部位別)などの実演例題資料。

## 根拠

- 講座紹介ページでは、キャラクターイラスト全工程ではなく、人体ドローイングの基礎力強化に講座範囲を絞っている。
- 経歴として、ONE PIECE、プリキュアシリーズ、ポケットモンスターシリーズ、NARUTO -ナルト- 疾風伝、アイドルマスター シンデレラガールズ、進撃の巨人、僕のヒーローアカデミア、転生したらスライムだった件などへの参加が列挙されている。
- ch02-06 では、長い線、人体比率、男女差、頭身別描き分けを扱う。
- ch11 では、人物の立体感を **稜線・ラッピングライン・短縮法・オーバーラップ** の 4 点で教える。
- ch12-14 では、頭・胸郭・骨盤、四肢、複数人物のパース配置を扱う。
- ch15-25 では、解剖学を名称暗記ではなく、キャラクターを自由に描くための道具として扱い、頭部から足までを単純化する。
- ch26 では、線のリズム、オーバーラップ、重心と軸で自然なポーズを整理する。
