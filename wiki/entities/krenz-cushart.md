# Krenz Cushart(クレンツ クシャート)

## 概要

[[nekojira]] の師(メンター)であり、Nekojira の理論・方法論の大部分の源泉とされる高名なイラスト指導者。Nekojira は講座中で繰り返し「自分の知識の大部分は Krenz から学んだものを、自分なりに消化・解釈したもの」と明言している。本ページには **Nekojira 講座を通して言及される範囲** の情報のみを記載する(Krenz 本人の一次資料は未取り込み)。

## 詳細(Nekojira 講座由来)

- **Nekojira との関係**: Nekojira は 2018 年に Krenz のオンラインコースを受講し、2019–2021 年に Krenz の **教育アシスタント** を務めた(ch26 キャリア年表)。Nekojira の理論的バックボーンの源泉。
- **由来する技法・概念**(いずれも Nekojira が Krenz 由来と明示):
  - [[csi-stroke]] — CSI ストローク(C/S/I の 3 線に自己制限)。ch04 6:52「クレンツクシャートから学んだこの技術」と明言
  - [[observation-via-abstraction]] / [[abstract-mix-and-match]] — 観察 → 抽象化 → ミックス&マッチの 3 段階
  - 形態最優先・観察力・参考資料集めといった方法論全般
  - 「**直線回避チャレンジ**」— Krenz の講座の課題として ch12 で明示
- **言語・地域**: ch26 で Nekojira は中国語コースとして Krenz を推薦。中華圏で活動。
