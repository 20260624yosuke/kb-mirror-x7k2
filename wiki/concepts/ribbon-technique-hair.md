# リボン技法(髪の毛)

## 定義

[[nekojira]] が ch08 で導入する **髪の毛の構造を「リボン(ねじれて幅が変化する帯)」として考える** デザイン手法。リボンは折り返し・ねじれ・幅の変化を持ち、髪の毛の自然な流れを **抽象化して表現** する。

「**リボンが曲がったりねじれたりする時、幅が変化することに注目してください**」「**これこそが髪の毛を自然に見せるために表現したいポイント**」(ch08 2:43)

## リボンの構成要素

| 要素 | 効果 |
|---|---|
| **折り返し** | 表/裏の切り替え。ターニングポイント |
| **ねじれ** | 幅が細くなる位置(遠近 + リボンの回転) |
| **幅の変化** | 太い ↔ 細いのリズム |
| **重なり(オーバーラップ)** | 髪の層・密度感 |

## 適用手順

1. **大きなリボンから始める** = 髪の流れを 1 本の帯として描く
2. **C カーブで開始**(ch11 8:58)= [[csi-stroke]] 適用
3. **真ん中で分けない** = 7:3 / 8:2 比率
4. **斜めに切る** = 対称回避、三角形を作る
5. **太さを変化させる** = リボンの幅変動
6. **テクスチャ(細い線)を追加** = 髪の質感
7. **重なりを多用** = 髪の層

## 適用度の判断(ch11)

- **動きのあるシーン** = リボン回転を強く適用(ダイナミック)
- **自然・落ち着き** = リボン回転は乱雑感を生むので **避ける**(ストレートロングはリボン控えめ)
- 「**リボンを揺らすのはダイナミックな形に効果的だが、適切な状況で使用する必要がある**」(ch11 13:03)

→ **万能ツールではなく、適用先を選ぶ**

## デザインルール(ch08/11 から)

| ルール | 説明 |
|---|---|
| **3 回の繰り返しを避ける** | 同じ方向の 3 連続 = 単調。「サイクルを破る」 |
| **三角形を意識** | 対称的にならないよう |
| **斜めに切る** | 真ん中分けは硬く見える |
| **大償(大小)を出す** | 大きな塊と小さな毛束のコントラスト |
| **ネガティブスペースの読みやすさ** | 鋭角が尖りすぎたら切り取る(ch11 7:01) |

## CSP の小技(ch11 5:16)

- **レイヤーのプロパティ → エッジの太さを黒 + 硬いブラシ**
- 簡単に **シルエットだけ** を作って実験
- ラスタライズ → 内部詳細を加える
- → 線が不安な時の補助ツール

## 「外輪に 100% は従わない」(ch08 6:43)

- 「**実は外輪に 100% 従っているわけではありません。後で形の変化を強調するために自分なりの考えでファインメントしていきます**」
- 参考資料を **意図的に脚色** することを明示

## Nekojira 視点 — [[hair-painting-workflow]] への拡張

[[hair-painting-workflow]](Ye Jji ch18 起点)は **着色段階** の髪を扱うが、Nekojira ch08/11 は **線画段階** の髪を扱う。両者は **同じ「髪」の異なる時相**:

1. **線画段階(Nekojira)**: リボン化 + 3 コントラスト + ネガティブシェイプ
2. **着色段階(Ye Jji)**: 質感デフォルメ + ハイライト 2 軸 + 薄い髪トレンド
3. **両者は順序的に連続**: Nekojira リボン → Ye Jji 着色 の組み合わせで完成
