# 暗部はオクルージョン + 反射光で描く

## 定義

`c14_要約ノート.pdf` p4 で [[ye-jji]] が明示した暗部描写の代替原則:

> 暗部の領域ではミッドトーンやキャストシャドウ、フォームシャドウなどの描写が難しいため、**反射光やオクルージョンシャドウで描写する**。

明部領域で使う中間トーン・キャストシャドウ・フォームシャドウは、すでに暗くなった領域では明度差が出にくく機能しない。代わりに **接触面でさらに暗くする(オクルージョン)** と **反対側を持ち上げる(反射光)** だけで暗部の形態を描き分ける。

## 構成要素 / 主要な論点

### なぜ明部用ツールが暗部で機能しないか

- 中間トーンは「明部の中で微妙な角度差を表現」するもの → 暗部にはそもそも光が入っていないので角度差が見えにくい
- キャストシャドウは「光が遮られて落ちる影」だが、すでに暗部にあるものはどこから影が来ても全体が暗い → 識別不能
- フォームシャドウも同様、暗部の中の角度差は人の目で区別しにくい

### 代替ツール

| ツール | 役割 | 暗部での効き方 |
|---|---|---|
| [[occlusion-shadow]] | 物体同士の接触で生まれる極端な暗さ | 暗部の中でも **さらに暗くなる** 接触点が見え、形が読める |
| [[reflected-light]] | 周辺物体の反射が暗部下端を持ち上げる | 暗部の中で **明るく抜ける線** が形を浮かび上がらせる |

### 工程順での位置付け

c14 PDF の色塗りプロセスでは:

1. 暗部の領域 + 色の設定(ch15)
2. ミッドトーン = 明部の描写(ch16)
3. **オクルージョン + 反射光 = 暗部の描写**(ch17)
4. 質感描写(ch18 / ch19)
5. 仕上げ(ch22)

つまり **「明部はミッド」「暗部はオクルージョン + 反射光」が役割分担として独立工程化** されている。

## 解釈の揺れ / 異論

- 一部の作家は暗部内にもキャストシャドウやフォームシャドウの明度差を描き込む(ペインタリー寄り、写実派)。本講座は **サブカル絵での効率重視のルール** として明示
- 暗部の中の「微妙な中間トーン」を完全に省略するのは、結果として塗りが平面的に見えるリスクがある → ch17 で実演を見て補完が必要

## 出典追加 (2026-05-17): ch17 の本格適用 / ch19 の素材横展開

- **ch17(暗部詳細描写の本実装回)**: オクルージョンの **5 原則**(隙間ならどこでも生じる / 柔らかい境界 / 黒まで下げてよい / 近づくほど濃く / 三角形を意識)を体系化。同時に反射光は「**主光より弱く**」「上向き面は反射光も届かない = **コアシャドウ** で 1 段暗く」という補助原則も明示。**安部領域が大きいキャラ絵で特に有効** という適用条件も認識される
- **ch19(質感描写での横展開)**: パフェ・金属・コーラ・水濡れ など多様な素材描写でも、暗部側ではオクルージョン中心の運用を継続(イチゴのオクルージョン、缶コーラの接触暗、パフェガラスとブルーベリーのオクルージョン)。**オクルージョン主導は質感描写工程でも有効** という汎用性の確認
