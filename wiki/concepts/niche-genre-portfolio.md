# ニッチジャンル戦略(認知獲得 > SNS 反応)

## 定義

[[ye-jji]] が ch23 で示す **ポートフォリオのジャンル選択戦略**。**ニッチジャンル** は SNS 反応(いいね・フォロワー)は少ないが、その分野での **名前認知** は得やすい → **案件が入りやすい**。フォロワー数とは別の評価軸で動く。

## 構成要素

### 原則

- 比較的人気のないジャンルは **SNS 反応が少ない**(確かに)
- **しかし** その分野で名前を知られるのは **メジャージャンルより簡単**
- → 比較的 **仕事が入りやすい**

### 講師自身の例

- Web 小説好き(ニッチ) → ファンタジー系を投稿
- **ネイバーカフェ(韓国 SNS のニッチコミュニティ)経由で初受注**
- Twitter / Pixiv ではなくニッチコミュニティから

### VTuber 業界での応用

- ホロライブ・2 次 3 時(2 次元・3 次元)のような有名どころ vs **ファンアート供給が少ない比較的小規模な会社**
- 後者の校者のファンアートを書くのが良い戦略
- 「ファンの少ない VTuber」=ニッチ = 名前を売りやすい

### 「本当に自分の好きなジャンル」を優先

- 流行りジャンルを書くのも良いが、**継続性** を考えると好きなジャンルが優位
- [[interest-driven-learning]] とも整合

## 解釈の揺れ

- 「ニッチ過多なら市場自体が小さい」問題は残る
- 「ニッチで名前を売る」→ メジャー側に流れる時の評価軸は別問題
- 講師は **「最初の足がかり」としてニッチを推奨** していると読むのが妥当
