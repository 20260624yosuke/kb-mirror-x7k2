# ボックス比率法

## 定義

[[nekojira]] が ch09 で導入する **顔・頭部構築の中核フレームワーク**。**長方形(または正方形)を頭蓋骨の上のマスクとして配置** し、中心線 + 3 分割で **目・鼻・口・顎・眉** の比率を決める方法。

## ボックス形状でキャラクター差

| 形状 | キャラクター | 例 |
|---|---|---|
| **幅広い長方形(横長)** | 若い・可愛い | 子供、ロリ |
| **正方形** | 重大(ティーン) | 中学生〜高校生 |
| **幅狭・縦長** | 大人っぽい | お姉さん、大人女性 |

## 3 分割

ボックスを以下の 3 セグメントに分ける(中心線で 4 領域ともいえる):

1. **額体** → 目の上(額)
2. **目の下** → 鼻
3. **鼻** → 顎

**鼻と顎が長くなるほど大人っぽい** → ボックス自体の縦比に直結

## 重要な配置ルール

- **基準は上まぶたの上**(眉毛ではない、と明示):
  - 眉毛は動きや感情で位置が変わる
  - 可愛いキャラは眉毛が高い
  - 「**一貫性を保つため、個人的には眉毛より上を捉えることを好みます**」(ch09 4:03)
- **目は中心線の近くに配置**
- **耳は眉毛と鼻の間** (通常アングル)

## 角度別の構築

| 角度 | 推奨構築法 |
|---|---|
| **正面・横向き** | 純粋な輪郭観察 |
| **少し傾き / 4/5 アングル** | ボックス + 中心線(立方体) |
| **ハイアングル(見下ろし)** | ボックス + 中心線、目位置を上に |
| **ローアングル(見上げ)** | ボックス + 立方体 + 円柱(首) |
| **横顔(プロファイル)** | **特殊測定法**(中央線が耳/顎の端) |

## ローアングルの特殊技法(ch09 / ch13)

- 3D ソフトに従いすぎると **顔が丸すぎてエイリアン化** → 16-17 歳キャラに不適
- 解決策:
  1. **耳を下げる**(口の辺り)
  2. **鼻を上げる**
  3. **目・鼻・口を近づける**(遠近で短縮)
  4. **顎ラインを明確化**(丸みを破る)
- **適用範囲限定**: 「デフォルメされた可愛いアニメ女子のみ」(写実・男性キャラには不適切と Nekojira 自身が明言、ch09 11:27)
- → [[low-angle-deformation]] として詳細化

## 解釈の揺れ / 異論

- Nekojira は **3 つの代替法を並列で紹介**(ch13 10:15):
  1. **ルーミス法**(Andrew Loomis): 球 + 顎の伝統的構築
  2. **円から始める方法**
  3. **ボックス法**(本概念) — Nekojira が選択
- → 「**自分にあった方法を見つけよ**」がメタ的メッセージ。ボックス法 = **Nekojira 個人の好み**(絶対的正解ではない)
