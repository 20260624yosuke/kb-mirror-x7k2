# 髪の流れデザイン

## 定義

[[nekojira]] の髪の毛の総合デザイン論。**3 セクション分け** + **リボン技法** + **3 コントラスト適用** + **シーン別の適用度判断** の 4 つを組み合わせる。

## 3 セクション分け(ch10)

髪を以下の 3 つに分解して構築:

1. **前髪(forehead)**
2. **横紙 / サイド**
3. **後ろ紙**

「**できるだけ詳細にではなく明確に部分を分ける**」(ch10 6:10)

## ステップワークフロー

1. **3 セクション分けで大きな形** を作る
2. **リボン技法**([[ribbon-technique-hair]])で各セクションをデザイン
3. **3 コントラスト**([[form-rhythm-3-contrasts]])を適用
4. **ネガティブシェイプ**([[negative-shape]])で読みやすさを調整
5. **オクルージョンシャドウ**(線の太さ変化)で髪の層を示す

## 髪型バリエーション 3 種(ch10)

| 顔タイプ | 髪型 | 設計意図 |
|---|---|---|
| **若い** | ツインテール | 大きな前髪 + 横サイド + 大きな後ろ髪。顔を小さく見せて可愛く |
| **重大(ティーン)** | Nekojira オリジナルキャラスタイル | 前髪 + 横サイド + 後ろ髪 |
| **大人っぽい(お姉さん)** | 短紙(肩より上) | 額をあまり見せず、横顔として考える。3 つのレイヤー構造 |

## 3 シーン構成(ch11)

| シーン | 紙のタイプ | リボン適用度 |
|---|---|---|
| 1 | ポニーテール、風で揺れる | 中 |
| 2 | ストレートロング、自然・落ち着き | **低**(リボン回転 → 乱雑になるので避ける) |
| 3 | ダイナミックロング、強風 + リボン | **高**(回転 + 重なり多数) |

→ **「**リボンは万能ではなく適用先を選ぶ」**

## 髪を「構造線」として使う(ch09 11:47)

- 髪の毛は **構造線として使える** → 構造がどこにあって繋がっているかを表現
- 特定角度では髪のシルエットが頭蓋骨の形を補強する
- 実生活の参考資料が必要(特定角度での髪の見え方)
