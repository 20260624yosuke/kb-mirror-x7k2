# スクリーン(加算)レイヤーでの照明色反映

## 定義

ye_jji が ch08 の照明色反映と ch22 の補正で多用する **加算系レイヤー効果** の使い分け技法。**スクリーン / 加算 / 加算(発光)** などの加法ブレンドモードで、**主光源色や環境光色を物体全体に乗せる** ことで [[shoumei-iro-tekiyou-3-steps|3 ステップ手順]] を素早く実装する。ただし **レイヤー効果のみに依存すると名部の色合いに環境光が侵入する間違いが起こる** ことが ch08 最終で警告される。

> ch08_03 のセリフは OCR で「ザ山レイヤー」と表記されているが、これは **「加算レイヤー」** の音認識ミス(zあ-san → 加算)。実物は CSP/Photoshop の **加算 / スクリーン** ブレンド。

## 使用場面(ch08 中の登場)

- ch08_03 8:44 「思考は黄色です。黄色がよく反映されています。ただし **加算レイヤー** をこのように塗っただけです。そのため名部の領域なのに完触の色合いを持つ部分が所々ある」
- 加算レイヤーで **環境光(青系)** を全体に乗せ、その上から名部に **主光源色(黄)** を加算 → 簡易的に 3 ライトの色相を反映できる

## レイヤー効果による反映の限界(ch08_03 18:32-18:58)

ye_jji が自ら **失敗例 → レタッチで修正** という形で明示している NG パターン:

1. **環境光がレイヤー効果で名部に侵入** = 全体に青を加算すると、本来主光源色(黄)が支配すべき名部にも青みが乗る
2. **比較的単調な色合い** = レイヤー効果に依存しすぎると、結果として **色彩のメリハリが死ぬ**
3. **修正の方針**: ① 名部のレイヤー効果をマスクで切る ② [[reflected-light|反射光]] を直接ブラシで追加 ③ ハイライトに [[ho-shoku-tai-hi|補色]] を直塗りで追加

→ **「レイヤー効果は下地、ブラシ直塗りで仕上げ」** という二段構えが本講座のメッセージ。

## ye_jji 流の扱い方

- **スクリーン / 加算は高速プロトタイピング用**: 4 シーン実習で「屋外昼/夜/ネオン/室内」の色味を切り替える際、固有色レイヤーを保ったまま加算で照明色だけ差し替えると効率的
- **マスク併用が必須**: 名部 / 安部 / 反射光のレイヤー分けを保ったまま加算を効かせ、領域外侵入を防ぐ
- **最後はブラシで直塗り** = レイヤー効果の限界を補い、[[intent-first-correction|意図ファースト]] の調整を加える

## ch22 との接続

ch22(補正章)では加算系も含めた **レイヤー効果の強度ランキング** が体系化される(本概念は ch08 で初登場 → ch22 で全レイヤー効果の中に位置付けられる):

- [[layer-effects-by-intensity|ハード > オーバー > ソフト]] とは別系統の **加算系**(スクリーン/加算/カラードッジ)
- ch22 では「スクリーン = 加算系。背景明るくする / 透過光の色味」と整理
