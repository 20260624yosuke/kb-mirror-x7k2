# 多色リムライト

## 定義

[[ye-jji]] が ch21 で示す **リムライトの色設計**。**1 色だけ** でなく **ミント / 黄 / 複数色** を混ぜて入れる。光の方向(上から)を意識して **上向き面に多く、他向き面に少なく** 配置。リムライト色は **目のハイライトや顔のハイライトに繰り返し使う** → 統一感。

## 構成要素

### 色選び

- 周囲の環境を考慮(本キャラは植物が多いのでミント基調)
- 1 色だけは平面的 → 必ず複数色を混ぜる
- 派生色:ミント / 黄 / 他に意食(類似色)

### 配置原則

- 光の方向(本キャラは上から)を意識
- **上向き面に多く、他向き面に少なく**
- 面積を意識的に調整 → 「単に線をなぞる」のは平面化につながる

### 統一感の作り方

- リムライトと同じ色を **目のハイライト** に再利用
- **顔のハイライト** にも同じミント系
- → 絵全体で **色のエコー** が生まれる

### ch22(補正章)での再強調

- 補正後に **リムライトの色味を左側に持っていく**
- パラソルと麦わ帽子の分離にも使える
- 主題部のパフェにもリムライト追加

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch22-lighting-mood]] / [[coloso-nekojira-ch24-final-finishing]]

- Nekojira は **多色リムライトを「バックライト戦略」** として ch22 で扱う
- バックライトは **使える光の範囲が非常に限られている**(キャラクター輪郭部分にしか現れない) → **強い露出 + 影に高サイドの色** で補強
- 「**写真家が別の光や温かい光を当ててこの強い弾色を全体的に出した**」(ch22_05) → ye_jji の多色リムライトと **物理現象が一致**
- Nekojira は **影の縁に高サイドの色を加える**([[shadow-edge-high-saturation]])を全章で反復 → これは **多色リムライトを影の縁にも拡張した運用** と読める
- ch24 で **「上向き面に青を加える」**(天空光モデル)→ ye_jji の「**上向き面に多く**」と同じ配置原則
