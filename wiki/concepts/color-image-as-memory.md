# 色のイメージ(記憶側の色とデフォルメ)

## 定義

[[chan]] が sec03 で扱う概念。人は場所や情景の **最も強烈な色を一色に統一して強く記憶し、他の色を捨てる**(映画館=赤、コンサートホール=金、水族館=青)。この「記憶側の色」が色のイメージ。イラストでは実際の色より**記憶側の色を再現する方が共感を呼ぶ**ため、色をデフォルメ(省略 + 強調)して描く。

## 主要な論点

- イメージの 2 種類: ① 色自体の文化的連想(暖色=温かい等)② 記憶過程で生じる思い出補正(本概念)
- 根拠: ありのままの色は「観察したことのある色」止まりで感情を動かしにくい。デフォルメで「自分が感じた印象」を見る側に追体験させる
- 強度の個人差: カジュアル系はイメージを極端に強調(子供向けアニメは高彩度)、シリアス/ホラー系は弱める(現実色強調が逆に効く)
- 実装は [[background-character-deformation]] の 2 段階ワークフローへ
