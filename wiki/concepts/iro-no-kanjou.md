# 色の感情(色の真理 + 波長遠近法)

## 定義

[[hizurume]] による色の心理効果論。固有色や組み合わせで感じ方が変わる。波長による前後感を **波長遠近法**(本人造語)と呼ぶ。

## 構成要素 / 主要な論点

- **波長遠近法**: 赤は認識しやすく **前進**、青(短波長)は認識しにくく **後退**。空気遠近の心理的裏付け。
- 色の組み合わせで印象を操作(冬 / アンティーク / 大人の女性 等)。連想させれば OK。
- 伝えたい色を写真・絵から **自分で観察して取り入れる** → 個性に(他人に言われずに考えることが重要)。
- 出発点は「描く人が見た人に **どう思わせたいか**」。

## 関連

- [[dan-kan-tai-hi]] — 暖寒対比(前進色 / 後退色の一般概念)
- [[rensou-sakkaku]] — 色からの連想
- [[mie-rayleigh-scattering]] — レイリー散乱(波長の物理)
- [[atmospheric-perspective]] — 空気遠近(波長遠近法が心理基盤)

## 解釈の揺れ / 異論

- 「波長遠近法」は本人命名。色の感情は文化差あり(本人も連想は環境依存と明言)。
