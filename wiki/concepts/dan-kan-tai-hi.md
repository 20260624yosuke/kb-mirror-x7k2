# 暖寒対比

## 定義

[[tai-hi|対比]] の 4 種のうち **色温度** の対比。暖色(赤・橙・黄)/ 寒色(青・青緑・紫青)/ 中性色(緑・紫)の組み合わせで描く。

## 構成要素 / 主要な論点

- **明部寒色 → 暗部暖色** / 逆に明部暖色 → 暗部寒色という構造で立体感が出る
- 環境光の **空 = 寒色 / 地面 = 暖色** の対比は屋外シーンの定番([[coloso-ye-jji-ch20-background]] で実演)
- 同じ画面に **暖系統と寒系統が共存** することで多彩な色味([[shi-kan-no-katsuyou]])が成立する
