# CSP 3 大補正ツールセット

## 定義

[[chan]] が sec03 で常用セットとして提示する CLIP STUDIO PAINT の色調補正ツール群。色のデフォルメ・空間色適用を実装する実務ツール。

## 構成

- **Ctrl+U**(色相・彩度・明度)— 3 要素を同時調整
- **Ctrl+B**(カラーバランス)— 色相に特化した補正
- **Ctrl+M / Ctrl+N**(レベル / カーブ)— 明暗 + RGB チャンネル別調整

## 補助: 選択範囲のセット

- スポイト + 自動選択(W キー、許容範囲調整)
- メニュー Select > カラーレンジ(進化形の自動選択)
