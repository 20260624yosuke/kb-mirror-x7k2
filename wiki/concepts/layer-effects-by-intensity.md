# レイヤー効果の強度ランキング(ハード > オーバー > ソフト)

## 定義

[[ye-jji]] が ch22 で提示する **微妙な明暗調整用レイヤー効果の使い分けメンタルモデル**。**ハードライト・オーバーレイ・ソフトライト** の 3 つは「明るい色 → 明るく / 暗い色 → 暗く」の同じ作用を持つが、**色がどれだけ反映されるか** の強度が違う。

## 構成要素

### 強度ランキング

| 効果 | 強度 | 用途 |
|---|---|---|
| **ハードライト** | 強(最大) | 微妙な明暗を強く調整 |
| **オーバーレイ** | 中 | 同上、中程度 |
| **ソフトライト** | 弱(最小) | 同上、弱く |

### 他のレイヤー効果との関係

- **カラーバーン**:上記 3 つとは別レベルの **コントラスト UP**(影を強調)
- **スクリーン**:加算系。背景明るくする / 透過光の色味
- **カラー**:明暗を保ったまま色相のみ変更
- **発光ドッジ**:光の滲み(金属・水滴のハイライト誇張)

### なぜ強度差を覚えるべきか

- 「**レイヤーを複数使用しなくても明暗調整が容易**」(同じ効果で強度違い)
- 実際塗ってみて感覚を掴むのが基本
- 「微妙にしたい時はソフト、強くしたい時はハード」と即決できる
