# ランバート余弦則(Lambert's Cosine Law)

## 定義

**拡散反射面の見かけの明度は、入射光線と面の法線がなす角 θ の余弦(cosθ)に比例する** という物理法則。c04 PDF p2 で量感描写の物理的根拠として導入される。ye_jji 流の一文表現は、**「面の明度は、傾きが変わることで徐々に暗くなるのではなく、急激に暗くなり、対比が高くなる区間が生じる」**。すなわち暗化はリニアではなく **後半で急激** に進み、これが [[silhouette-of-light-edge|明暗境界線]](ターミネーター)として現れる。

## 構成要素 / 主要な論点

### 角度 → 明度% の対応表(c04 PDF p2 一次資料)

| 入射角と面の傾きが成す角度 | 明度 |
|---|---|
| 90° | 100% |
| 100° | 99% |
| 110° | 97% |
| 120° | 94% |
| 130° | 89% |
| 140° | 82%(PDF 表記は「82°」だが文脈的に 82%) |
| 150° | 73% |
| 160° | 62% |
| 170° | 45% |
| 180° | 0% |

- **暗化の非線形性**: 90°→130° までは明度が 11% しか落ちないが、160°→180° の最後 20° で 62%→0% と崩落する
- この **後半の急激な暗化区間** がコアシャドウ・明暗境界線として知覚される
- **明暗境界線(ターミネーター)= 入射角と面の傾きが 180° を成す地点**(c04 PDF p2)

### 描写への含意

- 明暗を均等なグラデーションで描くのは物理的に誤り。**明部寄りは緩やか、暗部寄りは急峻** な遷移
- 「急激に暗くなる区間」を意識的に残すことが量感の鍵
- ぼかしツールで全体を均等にぼかすと、この急峻区間が消えて平面化する

## ye_jji 流の扱い方

- c04 PDF で物理法則を絵に直結させる「角度→明度%」表を提示。実装の参考値として直接使える
- 「面の傾きを読む = [[keitai-ryoku|形態力]] が必要」と、物理法則の応用には **ドローイングの基礎能力が前提** であると明示
- 実際の描写では、表通りに数値を当てはめるのではなく **周りの形状と比較しながら調整** する(c04 PDF p4)
- ch16(明部回)・ch17(暗部回)で、横軸 → 縦軸の中間トーン構造、反射光の階層など、この法則を絵に落とし込む工程が実演される

## 解釈の揺れ / 異論

- ランバート余弦則は **完全拡散面(Lambertian surface)** を仮定する理想モデル。実際の物体は鏡面反射成分や [[texture-types|異方性反射]] を含むため、ハイライトや反射光は別途モデル化が必要
- 3DCG/PBR では「N·L」(法線と光ベクトルの内積)として実装される。本法則はその基礎
- c04 PDF の角度表記は「入射角と面の傾きが成す角」で 90° がピークだが、より一般的な物理表記では「法線と光線のなす角」で 0° がピーク。**90 度の差** に注意
