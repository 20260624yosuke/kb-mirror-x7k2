# キャストシャドウ(Cast Shadow)

## 定義

**主光源の光が物体に遮られて、他の面(地面・壁・別物体)に投影される影**(c04 PDF p3「主光源の光が物体に当たらず、地面に形成される影」)。物体表面そのものに出る [[form-shadow|フォームシャドウ]] とは別個の影として扱う。

## 構成要素 / 主要な論点

- **基本はハードエッジ**(c04 PDF p5): 物体との接触部に近いほど境界はシャープ。遠ざかるにつれて境界はわずかに薄くなるが、**遠い影でない限り基本は硬く描く** ことが推奨される
- **境界を薄く描き過ぎる弊害**: フォームシャドウと混同され、物体の形が歪んで見える可能性がある(c04 PDF p5)
- **影同士は重ならない**(→ [[shadow-do-not-overlap]]): キャストシャドウやフォームシャドウの暗部内ではキャストシャドウは消滅する。「同じ照明による影が重なっても光量が減ることはない」ため(c04 PDF p5)
- **位置計算**: 光の **角度線** と **方向線** の交点で求められる(円柱・立方体・球体で実演)。実際は目分量で描き、おかしいと感じたときに引いて確認する

## ye_jji 流の扱い方

- **逆光時の暗部にキャストシャドウを足してしまう** のは典型的な間違い。「物足りない暗部を埋めたい」心理が原因で発生
- **地面と物体の距離感に注意**: 習慣的に物体の後ろを一直線に塗りつぶしてしまうと、空間感がすべて失われ平面的になる(c04 PDF p5)
- **様々なエッジを描く意義**: キャストシャドウの硬い境界は情報量を増やす役目も持つ
- フォームシャドウの描写に集中するあまり、**キャストシャドウを見落としがち** であることに留意

## 解釈の揺れ / 異論

- 「キャストシャドウの境界は遠くなるほどぼやける」という一般原則と「**基本は硬く描く**」という ye_jji 流は一見矛盾するが、ye_jji は「絵としての情報量・形の維持」を優先しているため。物理シミュレーションの忠実度より **描写上の役割** を重視する立場
