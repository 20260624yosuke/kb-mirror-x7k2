# グレー基調 + 局所高彩度(Nekojira 色味哲学)

## 定義

[[nekojira]] の **代表的な色味哲学**(ch17 で初出、複数章で繰り返し)。「**鮮やかな色を大量に使うのではなく逆。グレーと少量の高サイド色を組み合わせ、グレーとサイドの退避(対比)を作り出す**」(ch17_02 10:15)という戦略。「**何かを輝かせるには比較対象が必要**」という対比論理に基づく。

## 構成要素 / 主要な論点

### コア原則

- **絵の大部分はグレー(低彩度)**
- **小さな部分だけが高彩度**(影の縁、交際、目のハイライト等)
- **高彩度がより鮮やかに見える** = グレーの対比効果

### 適用領域(章別の実装)

| 章 | 対象 | 実装 |
|---|---|---|
| ch17 | 目 | グレー基調 + 交際(虹彩)だけ高彩度 |
| ch17/24 | 影の縁 | グレー影 + 縁に高彩度(SSS) |
| ch21 | 全体 | 微差(2-3%)で情報、エッジで形 |
| ch23 | カラースケッチ | 青基調 + 影に温色を隠す |
| ch24 | 仕上げ | 上向き面に青、影の縁に高彩度赤 |
| ch26 | 淡 → 高彩度 → 淡 | 時間軸のリズム |

### 「淡 → 高彩度 → 淡」のリズム(ch26 で総括)

- 「**淡い色から鮮やかな色へ、そしてまた淡い色に戻る**」(ch26_02 7:32)
- 肌色の例: **薄いベース → 影に高彩度赤 → 影縁に冷たい色**
- 「**鮮やかな色を加えるのは主に影の縁**」(ch26_02 8:36)

### 数値的特徴(ch21 から)

- **3 つ以下のトーン** で完了
- **2-3% の微差調整** で情報量
- → 「**フラットに見えるが情報量が多い**」スタイルの核

## 解釈の揺れ / 異論

- ye_jji の [[saido-no-3-points]](高彩度 3 ポイント: SSS / 明暗境界 / 同系色光)と **機構は同じ** だが、ye_jji は **物理現象として** 説明、Nekojira は **絵画戦略として** 説明 → 補完関係
- ye_jji ch07 では **シルエットレッドなど色彩を派手に** することもあるが、Nekojira は **大部分を抑える方向に一貫**
- ch23 の **青基調** は、グレーの代わりに **完触系(クール)を基調にする** バリエーション → 「**グレー = 純粋に無彩色** ではなく **彩度を抑えた色全般**」と読むべき
