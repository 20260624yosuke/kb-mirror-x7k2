# ドロー中心 vs 色塗り中心(スタイル軸)

## 定義

[[chan]] の [[casual-illustration-3-axes|分類 3 軸]]のスタイル軸。

- **ドロー中心**: 線が主役。平面的・軽快、日本で人気。線の強弱を極端に / 色塗りは控えめ / 配色コントラスト大 / テクスチャで質感を補う
- **色塗り中心**: 色が主役。立体的、中国・台湾的。線は控えめ・補助 / 書き込みで明暗を細かく / 個性は使う色・ライティング・境界色で出す
