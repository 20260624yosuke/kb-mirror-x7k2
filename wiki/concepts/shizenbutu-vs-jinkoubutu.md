# 自然物 vs 人工物の描き分け

## 定義

[[ye-jji]] 講座を貫く描き分け原則。**自然物は色不規則・形多彩で輪郭が曖昧 → 厚塗りで処理**、**人工物は色規則的・形固定で輪郭明確 → 線画 + フラット塗りで処理**。1 枚の絵で両者が混在する場合、別ワークフローを並行して使い分ける。

## 構成要素 / 主要な論点

### 自然物の特性と扱い

- 色が非常に不規則(山・木・雲・水・岩などは多彩なグラデーション)
- 形も多彩で **境界がもともと曖昧**
- → **階調を下げるのが難しい**(ch09 で講師が認める)
- → **線画は付けず、面だけで形を作る厚塗り**(ch13)
- 結果:境界ラフでも違和感が少ない

### 人工物の特性と扱い

- 物体同士のシルエットが固く明確(建物・服のボタン・金属・帽子のリボン・3D セット)
- 形が固定されている
- → **境界線をはっきりさせる** ことが重要(ch09)
- → **線画でトレース + 内部のフラットな塗り**(ch13)
- 結果:線がぼやけると人工物らしさが失われる

### ch09(密度を下げる)での示唆

- 古い作品のリタッチで、青屋根 + 白壁(人工物)の境界を整理しつつ、自然物の山はトーンを統一する例
- 人工物は階調を下げても **形が読める** 必要がある → 境界線を明確に
- 自然物は階調を下げ過ぎても境界の曖昧さで救われる

### ch13(線画の活用)での示唆

- **人物 + 人工物 → 線をトレース**
- **自然物 → 線なし、面だけ**(厚塗り)
- 自然物の代表である背景の植物・雲・水は ch20 でほぼ線なしで描かれる

### 混在シーン(本講座のキャラ実演)

- 海辺キャラ: キャラ(人物 = 線あり)+ 水着・帽子(人工物 = 線あり)+ ヤシ・モンステラ・砂・雲(自然物 = 線なし)
- ch15 でこの方針が実装される — 自然物の植物のシルエットを面だけで形作る

## 解釈の揺れ / 異論

- 漫画系の作家は自然物にもしっかり線を入れる(背景の岩や雲にもインク線)。本講座は **サブカル系のキャラ絵中心** の前提に立つ
- 「自然物 = 厚塗り、人工物 = 線画」の二分はあくまで **デフォルト**。プロは混合する(自然物にも整理線、人工物にも厚塗りタッチ)
