# センスとスキルのギャップ(Nekojira)

## 定義

[[nekojira]] の **ch26** で説明されるスランプの **正常型**。「**完成が向上しているのに技術が追いつかない**」状態を「**実はとても良いこと**」「**まだ改善の余地がある**」と再定義し、ネガティブを成長の徴と読み替えるメンタル・モデル。

## 構成要素 / 主要な論点

### 基本構造

- **センス**(taste、美しさを見分ける能力)が **先に向上**
- **スキル**(実装能力)が **後から追いつく**
- 両者のギャップ期間 = **不満・スランプ感**

### 講師自身の例

- **3-4 年前: 自分の書く顔に満足できない時期**
- **何度も何度も顔を書き続ける**(毎日)
- **2 年前: マスク法**([[box-proportion-method]])に到達 → スランプを抜ける
- 「**それまでは丸縁を書いて十字を入れるだけで不安だった**」(ch26_01 8:25)

### 「妥協は」(駄目)

- 「**そう、妥協はです。顔が下手だという事実を受け入れないということです**」(ch26_01 9:05)
- **センスが優れているならその利点を生かす** = 目標を下げない

### 解決パターン

1. **発見の段階**: スランプ感のある期間(辛い)
2. **練習対象を特定**: 何を磨くべきか明確化
3. **手順を繰り返す**: 反復で上達(楽になる)
4. **早くなっていく**: スキルがセンスに追いつく

## 解釈の揺れ / 異論

- ye_jji 講座にも **「目指す高さによって苦しさが続く」** という類似の認識はあるが、**「センスがスキルを上回る = 良いこと」** という明示的なリフレーミングは Nekojira 独自
- これは **Ira Glass の有名な「The Gap」エッセイ** と同型の構造(センス先行、スキル後追、ギャップ期間が才能ある人ほど長い)
