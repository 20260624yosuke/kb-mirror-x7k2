# 髪の描写ワークフロー(Ye Jji 流)

## 定義

[[ye-jji]] が ch18 で示す **髪の毛の色塗りの全体ワークフロー**。「**髪はデフォルメで質感が大きく変わる**」という前提のもと、**3 つの考慮事項**(質感のデフォルメ依存 / ハイライトの 2 軸 / 薄い髪の現代トレンド)を確認した上で実装する。

## 構成要素

### 3 つの考慮事項(教材スライド 1-3)

1. **質感のデフォルメ依存**:**拡散反射寄り**(マット、量感中心、塊感)↔ **正反射寄り**(キラキラ、コントラスト強)のスペクトラム。**目指す質感に合った資料だけ参考にする**(混在で混乱)
2. **ハイライトの 2 軸**:
   - **工程差(上下の変動)** 大 → ダイナミック / 小 → 整った印象
   - **途切れ** 多 → でこぼこ感 + 厚み / 少 → 滑らかな髪
3. **薄い髪の現代トレンド**:厚みのある髪は古く見える。フォームシャドウは大きな明暗だけ、密度を上げるなら **明暗境界のシルエット + 反射 + キャストシャドウ** を中心に

### 描写順序(本キャラ実演)

1. **オクルージョン中心で暗部** を取る(髪と髪の隙間、塊と塊、リボン・帽子・体への接触)
2. **ハイライトのラフ配置**(主ハイライト + 副ハイライト 2 系統)
3. **異方性反射**(髪繊維方向のハイライト分割)
4. **フレネル反射**でサイド面を明るく
5. **透過光**(空色 + ピンク)を前髪に
6. ハイライト周りに **暗い帯** を入れて反射強調
7. **ハイライトの太さ・面積に変化**(島模様化回避)

### 運用 Tip

- 同じトーンで塗り続けない → 自動選択 + エアブラシで色味追加
- **画面反転を頻繁** に行い、手首が楽な曲線で描く
- キャンバス縮小で **遠くからバリュー確認**
