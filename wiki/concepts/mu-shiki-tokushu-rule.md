# 無彩色特殊ルール(光源色をそのまま反映)

## 定義

ye_jji が ch08 で確立する **無彩色物体(白・黒・グレー)に対する特別な照明色適用ルール**。**[[shoumei-iro-tekiyou-3-steps|3 ステップ手順]] の例外** として、無彩色物体は **光源色をほぼそのまま反映** する → カラーホイールを **光源位置に大きく動かしてそのまま塗る** だけで OK。色相・彩度・明度の細かい調整は不要。

## 物理的根拠

無彩色物体は固有色を持たない → 入射光の波長を **吸収せず・選択せず** 反射 → **光源色がそのまま見える**。
有彩色物体のように「自身の波長は強反射 / 補色は吸収」という選択がないため、3 ステップ手順の **彩度・明度補正分岐が消える**。

## ye_jji 流の扱い方

### 適用対象

- **白シャツ / 白い髪 / 白いドレス**
- **グレーの金属(つや消し)**
- **黒い髪 / 黒いコート**(暗いがやはり光源色がそのまま乗る = 暗い光源色になる)

### ワークフロー

1. 物体が無彩色か判定(固有色がほぼ R=G=B、[[saido-calc-rgb|RGB 差による彩度計算]] で確認)
2. **3 ステップを省略** し、カラーホイールを光源色位置へ大きく移動
3. そのまま塗る(他の有彩色物体と同じ思考プロセスを通さない)

### 4 シーン実習での適用

- 屋外昼: 白シャツ → 太陽の白 + 地面オレンジの反射光 + 空の青(環境) → 3 光がそのまま乗る
- 夜の街灯: 白シャツ → 黄(主光源)+ 青(反射光地面)+ 青(夜空)
- ネオン: 白シャツ → 赤一色に染まる
- 室内: 白シャツ → 青(窓)+ 黄(床)+ オレンジ(壁)が直接乗る

→ **無彩色物体は照明の "サンプル" になる**。シーンの色構成を読み取るためのキャンバスとして機能する。

## ch15 / ch18 での再強調

- ch15(暗部設定): 白い髪に **光源色の高彩度** を強く反映(7-color 原則と統合)
- ch18(髪と目): 髪先 SSS の透過光に空色 + ピンク → 無彩色ベースだからこそ強い色が乗る

## 解釈の揺れ / 異論

- 厳密には「完全な無彩色」は実写には存在しない(白には微弱な固有色がある)
- 講座スタンスは **実用上の近似ルール** として「無彩色なら 3 ステップ省略 OK」を提示。
- 厳密派は「白でも固有色を仮定して 3 ステップを適用」する → 結果はほぼ同じだが思考過程が複雑化
