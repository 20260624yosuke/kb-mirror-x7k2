# フォームシャドウ(Form Shadow)

## 定義

**物体自身の形状によって光が当たらなくなる領域**(c04 PDF p3 「物体の形状によって生じるすべての影」)。物体が他面に投影する [[cast-shadow|キャストシャドウ]] とは区別される、**物体表面そのものに生じる暗部**。広義には [[mid-tone|ミドルトーン]]・[[core-shadow|コアシャドウ]]・[[reflected-light|反射光]] を含む暗部全体の総称としても扱われる(c04 PDF p3 注記)。

## 構成要素 / 主要な論点

- **生成原理**: [[lambert-cosine-law|ランバート余弦則]] に従い、光の入射角と面の傾きが 90° から離れるほど暗くなる
- **境界の柔らかさ**: 面の曲率に応じて境界の遷移幅が変わる
  - 角張った形状 → ミドルトーンの範囲が狭い → 境界がシャープ
  - 柔らかい形状 → ミドルトーンの範囲が広い → 境界がぼやける(c04 PDF p4)
- **キャストシャドウとの違い**: フォームシャドウは「物体自身に出る影」、キャストシャドウは「他面に落ちる影」。両者を視覚的に混同しないこと(→ [[shadow-do-not-overlap]])
- **明暗境界線(ターミネーター)**: フォームシャドウの最外縁。入射角と面の傾きが 180° を成す地点で、急激に暗化する区間が生じる

## ye_jji 流の扱い方

- 「ぼかしの度合い = ミドルトーンの範囲」というフレームで描写スペクトラムを 3 段階(角張った / 中間 / 柔らかい)に整理(c04 PDF p4)
- **ぼかしツールで全体を均等にぼかすのは平面化の元凶**。表現したい明暗に応じて部位ごとにぼかし強度を変える(→ [[bokashi-control]])
- **指先ツールでゴシゴシ擦るのも不適切**。境界の物理的意味(=形状の角度遷移)を失う
- ランバート余弦則で正確に計算できるが、**実際には周りの形状と比較しながら調整** することが多い(c04 PDF p4)

## 解釈の揺れ / 異論

- **広義 vs 狭義**: c04 PDF p3 では「物体の形状によって生じるすべての影」と広く定義しているが、本文では「センターライト・ミドルトーン・コアシャドウ・反射光」と並列に列挙されることも多い。狭義では「ターミネーターからコアシャドウまでの面そのものの暗部」を指す
- 翻訳上の揺れ:韓国語原文の「携帯の影」(形態の影)が日本語訳で「フォームシャドウ」として定着
