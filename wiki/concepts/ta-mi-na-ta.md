# ターミネーター(明暗境界線)

## 定義

物体表面で **明部と暗部を分けるライン** の正式名称 = **ターミネーター (Terminator)**(天文・写真・絵画分野の共通用語)。光の入射角と面の法線がなす角が 90° に近づく(= 面の傾きが急変する)地点で発生する。ye_jji 流では「明暗の境界 / 明暗境界」と日本語化して扱われる。

## スラッグ由来の注記

`ta-mi-na-ta` は **「ターミネーター」を kebab-case で表記** した実用スラッグ。
本概念は元々 ch04 [[lambert-cosine-law|ランバート余弦則]] の説明文中で「ターミネーター = 光の入射角と面の傾きが 180° をなす地点」と命名された([[coloso-ye-jji-ch04-volume]] line 25-26)。Group A / B 作業時に意味未確定の broken link として残されていたが、PDF / 本文照合の結果、**「ターミネーター = 明暗境界線」の音写スラッグ** と確定。

`タミナ多` などの OCR/転記揺れの可能性も検討したが、ch04 ソースの文脈とリンクから **ターミネーターで確定** と判断。

## 物理的根拠(ch04 / ランバート余弦則)

- 拡散反射面の明度は cosθ に比例
- θ が 90° に近づく区間で明度が **急激に** 落ちる → 連続的でなく対比が高い遷移帯が発生
- この遷移帯のラインが **ターミネーター**
- ch04 PDF p2 に「角度→明度%」の表があり、急激な暗化の数値根拠を提示

## 視覚的特徴 / 描写ポイント

- 球体・円柱では帯状(円弧)、平面の折れでは線状
- [[core-shadow|コアシャドウ]] が乗る位置(暗部の最暗帯)
- [[mei-an-kyoukai-saido|彩度ピーク]] が乗る位置(中間トーン帯)
- [[silhouette-of-light-edge|光のシルエット]] と空間的に同一

## ye_jji 流の扱い方

- ch04 量感の最重要ランドマーク
- ch06 で **質感はこの線に集中** させて全体を支配
- ch07 で **彩度はこの線(中間トーン帯)で最大化**
- 横軸 + 縦軸の 2 軸構成 = 形態に沿ったターミネーターの走り方を意識([[mid-tone]] と連動)
