# 形態力(keitai-ryoku)

## 定義

[[ye-jji]] が `c04_要約ノート.pdf` p2 で明示的に名付けた概念。**「明暗境界線(入射角と面の傾きが 180° になる地点)を見つけて描写するためには、物体の形状を理解し明確に表現する能力が必要」** = この能力を **形態力** と呼ぶ。色彩感覚とは独立した、ドローイングに属する基礎能力。

## 構成要素 / 主要な論点

- 色塗りで立体感を表現するためにも形態力が **重要前提**
- 色彩感覚が優れていても、量感の描写が難しいと感じる場合は **ドローイングを学ぶことで実力を向上させることができる**(=色彩スキルだけ磨いても上限がある)
- 「ある面がいつ暗くなり、いつ明るくなるか」を把握する = 面の角度を立体的に読み取る = 形態力

## 関連

- [[ryou-kan]] — 量感描写の前提として位置付けられる
- [[lambert-cosine-law]] — 形態力を背後で支える物理法則
- [[four-sub-skills]] — 講師が示す 4 サブスキル(色遣い / **ドローイング** / 比例感 / 観察力)の「ドローイング」と重なる
- [[de-te-ru]] — ディテール表現の土台

## 解釈の揺れ / 異論

- 「形態力 = drawing skill」と素直に英訳できる。3DCG では「フォームの理解」「面取りの把握」と呼ばれる近い概念。**色塗り講座でこの概念が独立して名付けられること自体が ye-jji 講座の特徴**
- 本講座は形態力をどう養うかには深入りせず、「ドローイングを別途学んでほしい」と外部化している
