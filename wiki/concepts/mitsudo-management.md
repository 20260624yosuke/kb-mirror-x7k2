# 密度コントロール

## 定義

画面内の **情報量の濃淡** をコントロールして、主題に視線を集める設計。「描き込み量」と「余白」は対の概念で、**密度を下げる**(整理)と **余白を埋める**(空きに情報を流す)を行き来する。

## 構成要素 / 主要な論点

### 密度を下げる(ch09)

- 主題部の情報量を **相対的に高く** するため、副題部を整理する
- **[[mitsudo-management|密度差]]** が大きいほど主題が際立つ
- 似た形・似た明度の繰り返しを **シルエットの穴開け**([[silhouette-hole-trick]])で破る

### 余白を埋める(ch10)

- 「描かない」ではなく **意図的な空白** を残す
- 余白部分には **小さな点要素**([[point-elements-on-subflow|点要素]])や **流れの線**([[nagare-rhythm|流れを作る]])で誘導を作る
- 全体が均一に詰まると平面的になる

### 仕上げ段階での操作

- 背景にガウシアンぼかし([[background-blur-focus]])で主題と分離
- ノイズ・[[photo-finish-3-set|レンズ効果セット]]は **顔以外** にかけて主題を保護

## 出典追加 (2026-05-17): ch09 / ch10 / ch11 の再取り込み

- **描写省略 = ラフ仕上げ ではない**:ch09 で講師が最初に否定する典型ミス。**正しい省略は「階調を減らす + 空気遠近 + コントラスト低下」の 3 段階を同時に行う**(`ye_jji_09._01` 0:35 〜)。「ただラフに済ますと未完成感が出る」を踏まえると、密度コントロール = 密度を下げる作業も **能動的な操作** であることが明示される
- **階調圧縮の数値目安**(ch09): 前景 5〜8 / 中景 3〜5 / 遠景 1〜2 階調(目安、固有明度のため厳密ではない)
- **自然物 vs 人工物の二分**(ch09): 自然物は階調を下げにくく境界もラフでよい / 人工物はシルエットを明確に。これは [[shizenbutu-vs-jinkoubutu]] の起点
- **余白を埋める 3 コツ**(ch10):
  1. 構成段階で色塗りまで考慮(同色・同明度の隣接を防ぐ、影を入れた後の明度重なりまでカラーラフで検証)
  2. 広い単色面積にグラデーション
  3. 点要素 3 つ以上 + 前 / 中 / 遠の距離差で配置(1 つだけだと重要に見えてしまう)
- **チェックリストでの密度監査**(ch11 セルフチェックリスト 6-1 / 6-2): 「過度に描写されていないか」「形がぼやけすぎていないか」 — 密度コントロールの自己診断項目として明文化

## 出典追加 (2026-05-17, Batch 3): ch17 / ch19 / ch21 での実装

- **ch17(暗部詳細)**: 「主題部だけ密度を上げる」原則を **麦わ帽子のテクスチャ密度** で実装(顔に近い部分のみ密度集中、残りは「でこぼこがある」程度のラフ)。麦わ帽子の密度判断は **「主題部への視線誘導を妨げない」** という条件付き
- **ch19(質感描写)**: 「曲面の角に情報量を集中」=曲面の角に **多重ハイライト + 複数色** を入れる。**「仮想反射源」** で密度を増やす(何かが反射していると仮定する架空描写) → 質感描写における密度コントロール手段
- **ch21(ディテールアップ)**: 主題部の情報量を上げる小技集が **ネイル・フリル・リボン・ゴム・髪・手・水滴・肋骨** で連続実装。**「関係整理」** = 近接物体と離れている物体を **明度で分離** = ミドルコントラストと密度差の融合
