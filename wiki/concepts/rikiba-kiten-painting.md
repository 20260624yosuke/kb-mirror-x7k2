# 力場起点の描き方(本人ワークフロー)

## 定義

[[hizurume]] 独自の塗り進行。**[[e-no-chikara-ba|絵の力場]]が強い場所から塗り始め、密度を周囲へ拡散** させる。グリザイユ寄りの厚塗りで運用(ルーツはアナログ油彩)。

## 構成要素 / 主要な論点

1. ラフ → 初期感覚の色を決める。
2. 力場が強い場所の周辺(まず上半身)を塗る。
3. 次にその周辺背景を塗る。
4. その場所の密度を上げ、周囲へ拡散させていく。
5. [[shi-sen-yu-dou|視線誘導]]ポイントを作成 → 調整して密度を上げる。
- 完成イメージ + 色知識 + 視線誘導の理解が前提で難度は高いが、**クオリティ UP + 速度爆速**。
