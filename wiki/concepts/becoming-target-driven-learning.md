# どの絵描きになりたいかが学習方向を決める

## 定義

[[chan]] が sec07 で説く目的地設定。**目指す絵描き像によって、個性とトレンドのどちらに寄せるべきかが変わる**ため、学習方向を意識的に選ぶ。

## 用途別の方向

- 依頼制作 / ゲーム会社 / アニメ → 個性は不利、トレンド適応が必須
- 同人活動 / ファンボックス / 支援サイト → トレンドに敏感すぎると不利
- 趣味絵 → 自由
