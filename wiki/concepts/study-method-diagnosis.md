# スタイル別の弱点診断フレーム

## 定義

[[chan]] が chan 02 講座 sec14(Section 3 開幕)で示す勉強法の設計図。[[casual-illustration-3-axes|6 スタイル]]それぞれに**強み・弱点・勉強すべきこと**を割り当てる。chan は生徒データベースから derived と講座で述べている。

## スタイル別の典型弱点(講座での提示)

- [[character-focus-coloring-method|キャラ中心]] → 構成の幅 / 空間色 / 設定的魅力
- [[mood-centered-illustration|雰囲気中心]] → 顔の描写 / 可読性 / ディープすぎる罠
- [[drawing-focused-illustration|ドロー中心]] → タッチ感 / ライティングのリアリティ / シャープ偏重
- [[coloring-focused-illustration|色塗り中心]] → 人体ドローイング(色で隠れて気づかない最大の落とし穴)
- [[plane-focused-illustration|平面中心]] → 背景構成 / 立体感
- [[3d-focused-illustration|立体中心]] → 視線処理 / 平面構成
