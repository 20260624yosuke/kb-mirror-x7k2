# 暖寒系統の維持(オリジナルカラー設定の制約)

## 定義

ye_jji が ch08 終盤で提示する **オリジナルカラー設定の原則**。**既存の暖寒系統(時間帯・照明の雰囲気を支える色温度の枠組み)を維持** すれば、彩度・色相・明度の細部を変えても **最初に意図した時間帯や雰囲気は失われない**。逆に暖寒系統を崩すと、絵が表現したい「夕暮れ感」「青い朝感」「室内オレンジ感」が消失する。

## なぜ重要か(本文の引用)

> 既存の暖触系、断色系を維持すれば色調を調整しても雰囲気は維持されます。
> (ye_jji 本人発言、_03.md より)

> 1 つのパーツに思考補助校環境の 3 つ以上の色感が生まれると見ていいでしょう。
> ([[shi-kou-hojo-kankyou|3 ライト]] が揃った状態を前提に系統を維持)

「最初に意図した時間帯や照明の雰囲気」が画家の意図そのもの。これを崩す調整は本末転倒というメンタルモデル。

## 維持しながら可能な調整 4 種

ch08 で「好みを加える」ために許容される操作:

1. **補色対比の強調**: 環境を「主の補色側」に動かす(主=赤なら環境=緑系へ)
2. **彩度対比の強調**: 名部だけ彩度を上げて安部の彩度を下げる(講師の好み = **名部のサイドが好み**)
3. **明度対比の強調**: コントラスト UP
4. **柔らかさの強調(コントラスト消去)**: 安部の色相を主の方向へ少し寄せる(紫経由など)
5. **(追加技)ハイライトに補色を仕込む**: 主題部限定で情報量を増やす

これらすべて **「暖寒系統 = 全体の色温度の主従関係」を崩さない範囲で操作する**。

## ye_jji 流の扱い方

- ch08 の巨匠 2 点分析を踏まえた応用パートでは、青いヌ側の春に対し **赤を強調 / 青を強調 / 色相対比を下げて柔らかく** の 3 バリエーションを実演 → 3 つとも夕暮れ感は保たれている
- **NG パターン**: 補正で「青の色味」「赤の色味」を闇雲に乗せて系統が反転すると、夕暮れが昼間に / 夜が朝になる
- 補正レイヤーでも本原則は適用 → [[intent-first-correction|意図ファースト補正]] の判定基準として機能(「この補正は系統を維持しているか」が自己チェック項目)
