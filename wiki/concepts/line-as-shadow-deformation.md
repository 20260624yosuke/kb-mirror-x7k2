# 線画は「影のデフォルメ」

## 定義

[[ye-jji]] の **線画観**。線画は陰影と別物ではなく、**影をデフォルメして線にしたもの**。つまり「これ以上影を追加したくないが、コントラストが欲しい部分」に **デフォルメ済みの影** として線を入れる。

## 構成要素 / 主要な論点

- **線画を入れる条件**: 物体と物体が完全に分離している箇所
- **線画を消す条件**: 柔らかく繋がっている部分 / 立体感を壊している線
- 髪と背景を分離するときは **外角ラインだけ濃い色の線画** を入れる
- リボン・帽子・髪・3 ベッドなどで「形が完全に終わった時に線を入れる」「ラフな曲がりの中にある線は消す」を使い分ける
- 結果として **デフォルメ強度のグラデーション** ができる — 完全リアル(線なし)から強デフォルメ(線で表現)まで

## 解釈の揺れ / 異論

- 多くのキャラクターイラストで「線画 → 塗り」と分けるワークフローが一般的だが、本講座は **塗り → 必要な部分にだけ線** という逆方向のスタンス。これは「ペインタリー寄り」のキャラ絵作法
- 「デフォルメ強度の連続スペクトラム」として陰影と線を統一視するのは強い再フレーミング

## 出典追加 (2026-05-17, Batch 3): ch21 で「影のデフォルメ」が直接的言明として明示

- **ch21(ディテールアップ実装)**: 講師自身の口から「**この線画は影のデフォルメです。影をこれ以上追加したくない部分、デフォルメされた部分に線画を追加する形だと考えてください。**」と直接的に言明される(本概念の名前の出典そのもの)
- ch21 の実装例:
  - **柔らかい部分の線は消す、ぼかして溶かす**(明示的なルール)
  - **髪と背景の分離 = 外角ラインだけ濃い色の線画**
  - **首と顔の間、肩、リボン** など分離していない部分にも線画追加
  - **口・鼻にも濃い色の線**(増作 = 造作のはっきりさを出す)
- ch20 の **アウトライン機能を手前のヤシだけにかける** という運用も、**線 = デフォルメ強度の表現** として読める([[outline-function-foreground]] との接続)

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch18-lineart-occlusion]] / [[coloso-nekojira-ch24-final-finishing]]

- Nekojira の **線画 3 原則**([[lineart-3-principles-nekojira]])は本概念と **本質的に同じ哲学**(線画は塗りの先取り)
- 違いは:
  - ye_jji: **影との連続性** 強調(線は影をデフォルメしたもの)
  - Nekojira: **オクルージョン優先** で運用(2 物体近接部の暗さを表現)
- Nekojira は ch22-25 で **線画の色を高彩度に変更**(赤・青)→ ye_jji の ch22 補正で **線画に高サイド色** と同じ運用
- 「**強い光部分はフラットに保ち、線画も色変化で表現**」 = 両者ともペインタリーレンダリングに線画を共存させる戦略

## ひづるめ視点 (2026-06-11): 線画抜きテストと「明度管理」(ch11 映像つき)

- ひづるめは ch11 で **「線でごまかしていないか」の自己テスト**を提示: 線画を抜いて物体が
  判別できるかを確認し、抜いて崩れるなら「**明度管理**ができていない」と判定する
  (「明度管理」はスライド表記。映像観測 [09:20] で画面確認済み。文字起こしの
  「迷路管理/メール管理」は Whisper 誤認識)。
- 実演ペア(失敗例として提示):
  - 線画あり [08:40] — 獣耳キャラのパステル調イラスト(本人の昔の絵)
    ![[wiki/assets/frames/coloso-hizurume-ch11-force-field/hizurume-ch11-08m40s.png]]
  - 線画を抜くと境界が消える [09:20] — 「肩や腕や髪の毛の境界がわからなくなりました。
    こうなってしまうと失敗です」+境界に赤線を live 加筆
    ![[wiki/assets/frames/coloso-hizurume-ch11-force-field/hizurume-ch11-09m20s.png]]
- 理由づけ: 線は細く、サムネイル縮小で潰れる。色・明度で境界を分けてあれば縮小でも成立する。
  「後ろに『嘘でも』コントラスト源を置く」ことも許容。
- ye_jji(線=影のデフォルメ、塗り→必要部だけ線)・Nekojira(オクルージョン優先)と並ぶ
  **第3の講師視点**: ひづるめは「線に頼らず明度で境界を作れているか」を品質テストとして使う。
  3者とも「線画を塗り/明度の従属物として扱う」点で整合する(整合の指摘は AI の整理)。
