# レイヤー数を一桁に

## 定義

[[hizurume]] のワークフロー制約。**レイヤー数を一桁(用紙レイヤー除く)に抑える**。レイヤーに縛られると自由に描けない。

## 構成要素 / 主要な論点

- 本人は線 → シルエット → 色 → 補正 → 影 → ハイライト…と細かく分けて、逆に成長を妨げていた(失敗談)。
- 不透明度の活用は可。レイヤー数だけを一桁に。
- 自分が今できない塗り方(厚塗り等)に変えると新しいレベルが見える([[egara-change-for-kosei]] と一対)。
