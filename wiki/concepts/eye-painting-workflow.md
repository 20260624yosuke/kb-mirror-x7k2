# 目の描写ワークフロー(Ye Jji 流)

## 定義

[[ye-jji]] が ch18 で示す **目の色塗りの講師流ワークフロー**。「目はデフォルメで質感・形・色味すべてが変わる最もセンサ別なパーツ」「**正解はない**」を前提に、講師の好みである **「高コントラスト + 透明感のあるクリアな固有色」** を実装する手順。

## 構成要素

### 講師の好み(教材スライド 4)

- **暗いトーン(まつ毛・瞳)に暗さを集中** → 残りは **固有色をクリアに保つ**
- **ハイライトは暗い部分に配置** してコントラスト最大化
- **眉毛のグリッド** を意識して立体的に描く(平面で書かない)
- 「ある人は固有色を暗くするが、それだとクリアさが失われる」 → 講師は **明暗集中型** を選択

### レイヤー戦略

- 瞳の描写は **線画の下** のレイヤー
- 眉毛(まつ毛)の描写は **線画の上** のレイヤー
- レイヤーは 2 つ使用

### 描写順序

1. **上を暗く、下を明るく** のグラデーション(下が上を向くため光多)
2. 株は青み(環境光)、下は床/肌のオレンジ反射
3. **瞳孔(同行)を最も暗く**(視線が合う印象。薄くすると神秘的)
4. 瞳孔周りに **筋肉ラインの放射状影**(ドーナツのデフォルメ)
5. コントラスト UP:瞳孔さらに暗く、まつ毛上下を暗く
6. まつ毛 = 単色でなくブラシタッチで **毛束感**
7. 白目と黒目の境界は **少し柔らかく**(濃すぎは不自然)
8. **ハイライト位置**:**下 = 落ち着いた印象 / 上 = 活発**(本キャラは下)
9. ハイライト周りに暗いトーン
10. ハイライト色 = **白ではなく** 周囲反射の **空色 / オレンジ / 紫(補色)**

### 補強要素

- アイメイク・アイシャドウを上山レイヤーで
- 前髪が目を隠す部分 = 髪色を薄く乗せて透ける表現
- 中間に明るいトーンで目の縦比率を広く見せる

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch17-instructor-workflow]] / [[coloso-nekojira-ch24-final-finishing]]

- Nekojira の目 workflow も **「グレー基調 + 局所高彩度」** の哲学([[grey-plus-local-high-saturation]])に従う:
  - 最初に **グレーカー青** で影の形を作る(高彩度から始めない)
  - **目の大部分はサイドの低い灰色、交際(虹彩)の部分だけが高サイド**
  - オーバーレイレイヤーで柔らかいグラデーション
- ch24 では **「目は水晶のように反射する素材なので肌の色を目に溶け込ませる」** → ye_jji の **「ハイライトは白ではなく周囲反射色」** と同じ哲学
- 目のシェイプ自体は ch09/26 の **6 セグメント分割**([[eye-6-segment]])を基盤に角度ごとに変化
- ye_jji の **「暗さ集中 / ハイライトは暗部に」** vs Nekojira の **「グレー基調 + 局所高彩度」** は別角度から同じ目の **商点化** を実装
