# 抽象化による観察

## 定義

[[nekojira]] が講座全体で繰り返し提示する **メタスキル**: 「**ごとを形として見る目を養い、観察する**」(ch07 8:30)。**複雑な対象を単純な幾何学形(○ □ △ + 円柱)に分解して見る習慣** を身につけることで、あらゆる描写が容易になるとする。

→ 「**観察 ≠ ただ見る**」「**観察 = 抽象化された形を読み取る能力**」

## 哲学的根拠

### CPU 使用率の比喩(ch07 9:19)

> スキルとは頭内の CPU 使用率を下げるようなものです。複雑なものを単純化することで難しい問題解決により多くの脳細胞を使えるようになります。

- 対象を「単純な形」として認知することで、認知負荷が下がる
- 残った脳の余裕で「**より高度な判断**」(構図・配色・性格表現)に集中できる

### 形 → 解剖 → 遠近 → 構造 の優先順位(ch07 8:59)

> 解剖学・遠近法・構造、これらの高度な知識は確かに重要ですが、結局それらは全て形になるのです。より信頼性のある現実的な形を作るためにそれらを理解しているのです。

- **形が最優先**。解剖学・パースは形を補強する手段
- 形が正確であれば、解剖学的詳細は後で追加できる
- 形が不正確だと、後で何を足しても破綻する

### 視覚ライブラリ構築(ch07 9:31)

> 形として観察してから、特定の角を描く時は視覚的な記憶から呼び出すだけです。形がどう見えるかを知っていれば、高度な知識を取り入れる時にずっと簡単になります。

- 観察 = **形のライブラリへの登録**
- 描画 = **ライブラリからの呼び出し**

## 練習法

### 初心者向け(ch12 から)

1. **シンプルな対象を選ぶ** — 複雑なものを最初に選ばない
2. **大きな形を抽象化** — ダイヤモンド・三角・円柱に
3. **CSI でクリーンに描く** — 細部より輪郭精度
4. **慣れたら徐々に複雑化**

### 観察対象の選び方

- 実生活 + コスプレ写真 + 動画 + 写真集
- 「**実際に観察してみる**」(ch04 8:22)
- 同じ対象を別の角度から複数描く

## Nekojira 視点 vs Ye Jji 視点

- **Ye Jji**: 「観察力」を 4 サブスキルの 1 つとして列挙([[four-sub-skills]])、観察 = **高クオリティ写真模写**([[high-quality-photo-tracing]])
- **Nekojira**: 「観察力」= **抽象化能力**。模写ではなく **形に分解する** 訓練
- → **同じスキル名でアプローチが異なる**。両方を組み合わせれば「**模写しながら CSI で抽象化する**」という複合練習が成立
