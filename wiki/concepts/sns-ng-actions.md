# SNS 運用 NG 行動(信用と期待値)

## 定義

[[hizurume]] が挙げる、絵師アカウントが **信用と期待値** を失う運用パターン。SNS では信用が最重要という前提。

## 構成要素 / 主要な論点

- **二次創作絵師の自分語り**: アクティブユーザーほど「うるさい」と感じ、ミュート/解除/ブロックに至る。アクティブユーザーこそ大事にする。
- **長文投稿(+絵文字・矢印)**: 広告・宣伝に見え、無意識に避けられる。まず見てもらうことが第一。
- **タグは 3 つまで**: 多いと長文扱い。初心者向けの「つながりタグ」は使わない。
- **日常投稿**: 絵師は「次の絵が見たい」期待値を失う。一次創作絵師は例外余地あり。
- **例外**: フォロワー 50 万超のトップ絵師は無条件で信用が立つため、同じ運用を真似ると逆効果(本人の失敗談)。
