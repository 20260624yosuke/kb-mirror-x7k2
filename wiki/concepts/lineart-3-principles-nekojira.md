# 線画 3 原則(Nekojira)

## 定義

[[nekojira]] の **ch18(オクルージョンシャドウ / 線画)** で確立される、線画の **3 つの方向性**。線の太さを意図的に変えることで **情報量と立体感を線だけで表現** する手法。

## 構成要素 / 主要な論点

### 3 原則

1. **シルエット強調**: 重要なシルエットの外側は太く、内側細部は細く
2. **構造の変化点**: 平面が変わる転換点で線を太く
3. **影**(特にオクルージョン): 2 物体の近接部、影の濃い部分で線を太く

### 線太の 3 つの制御方法

| 方法 | 内容 |
|---|---|
| 1 | **シルエット(外輪郭)→ 太く** |
| 2 | **光原方向性**: 光に近い部分は細く、影の部分は太く |
| 3 | **オクルージョンシャドウ**: 近接物体の隙間で最も太く / 点を打つ |

### 「点を線として読む知覚」を利用

- 「**1 つの点には多くの情報がありませんが、点の横に線があると私たちの目はそれを 1 本の線として認識**」(ch18 9:41)
- 線を **完全につなげない** → **隙間 + 点** で柔らかさを表現
- 適用箇所: 胸の谷間、指と指の間、髪の重なり

### CSI ストロークとの組み合わせ

- 線画でも **CSI ストロークに自己制限**(C / S / I 線のみ)
- 「**綺麗な線画のため 3 種類のストロークに制限**」(ch18 2:28)

## 解釈の揺れ / 異論

- ye_jji の [[line-as-shadow-deformation]] と **本質的に同じ哲学**(線画は塗りの先取りとしての影表現)。違いは:
  - ye_jji: **影との連続性** 強調(線は影をデフォルメしたもの)
  - Nekojira: **オクルージョン優先** で運用(2 物体近接部の暗さを表現)
- 「**外側を太く、内側を細く**」は古典的な漫画/イラスト技法だが、Nekojira は **オクルージョン + 形態学** で根拠付ける点が独自
