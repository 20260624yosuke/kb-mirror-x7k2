# コアシャドウ(Core Shadow)

## 定義

**主光源の光も反射光も届かず、最も暗くなる部分**。主に **明暗境界(=フォームシャドウが始まる位置)** に現れる帯状の最暗部(c04 PDF p3)。フォームシャドウ内部の他の場所より暗く、反射光がまだ届いていない区間として定義される。

## 構成要素 / 主要な論点

- **位置**: ターミネーター(明暗境界線)のすぐ暗部側。明部と暗部の遷移が完了した直後で、反射光が回り込む手前
- **発生原理**: 主光源の cosθ がゼロに近づく + 反射光がまだ届かない、という二重の暗化条件が重なる
- **見落とされやすい**: 多くの学習者は「明暗境界 = グラデーションの中間値」と捉え、最暗部の帯としては描かない
- **反射光とのセット**: コアシャドウは **反射光の副産物として立ち上がる**。コアシャドウだけ単独で暗く描こうとするのではなく、**反射光側を明るく保つことで結果的に最暗部として浮かぶ**
- **重要な注意点**(c04 PDF p3): 「コアシャドウの部分(明暗境界)を暗くせず、反射光の部分を暗くすると、コアシャドウと反射光の描写がはっきり区別できなくなる」

## ye_jji 流の扱い方

- ch04 では陰影 7 要素の 1 つとして位置付けられ、ch17 で **暗部寄り 3 要素(オクルージョン / コアシャドウ / 反射光)** の 1 つとして集中実装される
- **上向き面 = 反射光も届かない = コアシャドウで 1 段暗くする** という補助原則を ch17 で実演
- ch17 で「コアシャドウを描き間違えること」がよくあるミスとして指摘されている
