# 高彩度が許される 3 ポイント

## 定義

立体感のあるイラストでは中間トーンに低彩度色が混ざる宿命だが、**理論上 3 箇所でだけ高彩度が成立する**。多彩な色味を出すには、この 3 箇所を逃さず使うべし。

## 構成要素

1. **[[touka-hikari|透過光(サブサーフェススキャタリング, SSS)]]**
   - 薄い物体(耳・髪・布のエッジ・葉)を光が通過 → 物体内で散乱 → 別地点から出る
   - 出てくる光は **物体固有色で高彩度** に
   - 観察例: 逆光時の耳が赤、髪先がオレンジ

2. **[[mei-an-kyoukai-saido|明暗境界(中間トーン)の彩度]]**
   - 強い光で明部が **白飛び**(色相飽和)→ 中間トーンで本来の彩度を取り戻す
   - **中間トーン全体が高彩度** になる(境界ラインだけではない、よくある間違い)

3. **同系色の光を受ける部分**
   - 物体が反射する波長と同系色の光 → 吸収が少なく多くの光を反射 → **高明度 + 高彩度**

## 出典追加 (2026-05-17): `c07_要約ノート.pdf` の補強

- **透過光 (SSS) の適用範囲限定**(PDF p3):「SSS は、ある程度密度の低い物質で見られる現象で、密度の高い金属や石ではほとんど見られない」 — 本文では言及されていない新規情報。**SSS は薄い半透明物質に固有の現象** と整理可能(肌・葉・布のエッジ・髪先など)。
- **錯視 3 種類への整理**(PDF p7):色彩トレーニングの目的を **明度 / 彩度 / 色調** の 3 種類の錯視を見抜く力、と整理(本文では暖寒対比の錯視のみ)。

## 出典追加 (2026-05-17, Batch 3): ch17 / ch18 での実装事例

- **ch17(暗部詳細描写)**: **耳の透過光**(SSS の代表例) — 厚みのある部分はピンクの高彩度で明るく、厚みが大きい部分は暗いまま残す。これは「**SSS は薄い半透明物質に固有**」(PDF 補強)の原則そのものの実装
- **ch18(髪と目)**: **髪先の透過光**(空色 + ピンクの SSS)、目のハイライトに **空色 / オレンジ / 紫(補色)** を使う = 「ハイライト色は単なる白ではなく周囲反射 + 補色」 → これは 3 ポイントのうち **同系色光と補色対比** の組み合わせ運用

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch17-instructor-workflow]] / [[coloso-nekojira-ch22-lighting-mood]] / [[coloso-nekojira-ch24-final-finishing]]

- Nekojira は **同じ SSS 現象を「影の縁に高彩度を隠す」** という単一テクニックに集約([[shadow-edge-high-saturation]])。ye_jji の **3 箇所整理** に対し、Nekojira は **影の縁 1 箇所への反復実装** で習得しやすくしている
- ch17_02 で **「ターミネーター(影の境界部)」** と命名 → 「**強い光が皮膚を投化して散乱し、影の縁に赤みを作り出す**」 = SSS の原理を絵画戦略として再述
- ch22 では **5 環境(緑/温/冷/緑深/バックライト)で SSS を反復実装** → 環境によらず影の縁の赤みは保持
- Nekojira 色味哲学([[grey-plus-local-high-saturation]])との接続: 「**グレー大部分 + 影の縁だけ高彩度**」 = ye_jji の **「立体感維持 + 3 箇所で彩度回復」** と同じ機構
