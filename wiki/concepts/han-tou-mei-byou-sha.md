# 半透明描写

## 定義

光が物体内部に部分的に入って散乱・吸収され、**固有色のみが透過光として出てくる** 物体の描写。
ゼリー・飲み物・蝋・牛乳・紙・玉(翡翠)・**肌** などが該当。物理的には Subsurface Scattering (SSS) の領域。
[[tou-mei-byou-sha|透明]] のように背景の像はそのまま見えず、代わりに色味(固有色)が滲み出る。

## 視覚的特徴 / 描写ポイント

- **固有色以外を吸収**:色表現が弱まり、ほぼ **明度のみで後ろの像を描く**(`c05_要約ノート.pdf` p6)
- **キャストシャドウに固有色が反映**:光が物体内で吸収・反射して固有色のみ通過 → 影に色が出る
- **光源の反対側が高彩度で明るい**:凸レンズ効果で光が内側に集まり、反対側でピークを作る(p6 「光の散乱」)
- **表面のマット化で反射が消える**:滑らか → 鮮明な反射 / マット → 反射ほぼなし、後ろの像もぼやける
- **エッジ・薄い部分が暖色で輝く**:SSS の典型(耳・鼻・指先・花弁の縁が光に透ける現象)
- **厚みで不透明化**:厚い部分は固有色だけが残り、薄い部分はほぼ透明 → レース・布・水着の透けに応用

## ye_jji 流の扱い方

- **ch07 高彩度 3 ポイントの 1 つ**:SSS は [[saido-no-3-points]] のうち最重要要素。明暗境界・同系色光と並ぶ「彩度を上げてよい場所」
- **ch17 レース**:半透明 + 厚みで不透明化、という ch05 原則をそのまま適用
- **ch19 透ける水着**:
  - 乗算レイヤーで肌色を布に塗る = 透け感
  - **布と肌が接している部分だけ** 透ける(骨盤・腹部の出っ張り)
  - **空気の溜まる丸い気胞部分は透けない**
  - シワで出っ張る部分も透けない
  - 濡れている = 水コーティング → 反射ハイライト追加(→ [[wet-skin-2-step]])
- **肌の SSS 表現**:耳の縁・指先・鼻の薄い部分など、ライトが裏から透ける箇所で温色を仕込む

## 解釈の揺れ / 異論

- 「半透明」と「拡散反射 + マット」の境界は連続的(物理的には吸収・散乱係数の組み合わせ)。本講座は **背景の像が薄く残るか/固有色が前に出るか** で実用的に区別
- 肌を「半透明」とだけ扱うのは ye_jji 流では不十分:肌 = 混合反射ベース + 一部 SSS(耳・指先など)。「肌 = SSS」と単純化しない方が良い
- 3DCG では SSS はシェーダー専用の処理だが、2D 絵では「縁を暖色で塗る」「キャストシャドウに固有色を入れる」など局所的に手で実装する
