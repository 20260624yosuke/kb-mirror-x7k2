# 混合反射

## 定義

[[sei-han-sha|正反射]] と [[ran-han-sha|乱反射]] の両方の特徴を同時に持つ反射。
拡散ベースの上に弱い正反射成分が乗るタイプで、**現実世界で最も一般的な反射特性**
(`c05_要約ノート.pdf` p7 で「最も一般的に見られる材質」と明記)。半艶塗装・革・くすんだ金属・
コーティングされた物体・**肌**などが該当する。サブカルキャラ絵における「デフォルト」の質感。

## 視覚的特徴 / 描写ポイント

- **2 成分の同時運用**:量感描写(拡散ベース)と反射描写(弱い正反射)を別レイヤーで扱うのが推奨(`c05_要約ノート.pdf` p7)
- **表面の荒さで描写トーンが変わる**:
  - 荒さ低 → **正反射寄り**(鮮明な反射、ハイライトくっきり)
  - 荒さ高 → **拡散反射寄り**(ハイライトのみ強調、反射像の境界はぼかす)
- **反射像の境界をぼかして表現**:鏡のような鮮鋭さは出さず、ふんわりした反射として置く
- **コーティングされた物体**(透明材質が乱反射物体にコーティング):量感描写と反射描写をレイヤー分離して別管理
- **ハイライトの境界はぼやかして溶け込ませる**(ch06 靴実習)

## ye_jji 流の扱い方

- **ch05 PDF p7 が起点**(本文文字起こしには明示されないが PDF に独立スライドあり)。ch06 はその実習編という構造
- **ch06 で実習中核として展開**:
  - **靴**:混合反射の代表例。革の弱い艶
  - **ハンバーガーのパティ**:コーティング(肉汁)で高反射、ハイライト点々
  - **ハンバーガーのチーズ**:混合反射・荒め
- **ch16 肌**:肌は **「完全マットではなく少し艶あり」= 表面の荒さ高めの混合反射** と明示。ハンバーガー回(ch06)の混合反射原則を肌に転用する形
- **ch19 イチゴ**:反射率高めの拡散 + 異方性混合。サイドにフレネル反射、パラソルからのハイライト
- **「現実物体の大半は混合反射」** → 純粋な正反射/乱反射として描いてしまうとリアルさが失われる、というデフォルト警告として機能
