# ポートフォリオは目標会社・案件種別ファースト

## 定義

[[ye-jji]] が ch23 で示す **ポートフォリオ戦略の核心原則**。「**単にフォロワーを増やすだけでは仕事は簡単には来ない**」。まず **どんな仕事を受けたいか目標を設定** し、その目標に合致する作品を積み重ねる。

## 構成要素

### キャラクターイラストの案件種別

- **インゲーム CG イラスト**
- **ゲームのお祝いイラスト**
- **キャラクターデザイン**
- **ライトノベル差し絵**
- **Web 小説の表紙**
- **グッズ作業**

### ターゲット別の戦略

| 目標 | 戦略 | SNS 反応 |
|---|---|---|
| 特定ゲーム会社のインゲーム CG | そのゲームのキャラクター / 似た雰囲気を多数描く | **不要** |
| VTuber 関連 | ファンアートタグを活用。ファンの少ない VTuber のファンアートで名前を売る | 必要 |
| 服ブランド・産業(コラボ) | **オリジナルキャラ** で運営(ファンアートは版権が自分にない) | 必要 |
| 広告イラスト | 流行りジャンルを素早く描いてフォロワー増 | 必要 |

### 露出戦略

- ポートフォリオは **できるだけ多くの場所** に掲載
- 名前が露出するほど企業からのコンタクト確率が上がる

### 講師自身の例

- Web 小説好き → ファンタジー系イラストを多く投稿
- 結果:Twitter / Pixiv ではなく **ネイバーカフェ** で初受注

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch26-summary-advice]]

- Nekojira も ch26 で **本概念とほぼ同じ戦略** を提示:
  - 「**いいねや再生数にこだわるよりスキルを磨く**」
  - 「**ジャンル特化(モダンファッション + 悪魔)で企業からのアプローチを受ける**」
  - 「**長年かけて作り上げた 1 つのジャンルに特化したポートフォリオがあるので求められる仕事ができることを証明**」
- Nekojira の **キャリアの 4 段階**(2018 Krenz → 2019 アシスタント → 2021 Yostar 初依頼 → 2022 Mihoyo 正式)は、本概念の **長期戦略の実例**
- 「**この部分については私は単に運が良かっただけ、戦略的なアドバイスは何もできない**」と謙遜しつつ、結果的に **ジャンル特化** が両講師とも採用 = 業界標準のベストプラクティス
