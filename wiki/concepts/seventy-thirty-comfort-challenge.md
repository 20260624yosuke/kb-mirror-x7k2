# 70%快適 + 30%挑戦の練習配分(Nekojira)

## 定義

[[nekojira]] の **ch26(まとめ&アドバイス)** で提唱される **学習計画の量的ガイド**。「**題材の 70%は快適ゾーン、30%は挑戦的な要素**」(ch26_01 13:17)に配分することで、**ストレスを抑えながら確実に成長する** バランスを取る。

## 構成要素 / 主要な論点

### 構成比

- **70%快適**: 既にできることで楽しさを維持
- **30%挑戦**: 新しい要素(レンダリング、難ポーズ、新ジャンル、新環境)

### 効果

- **70% で余裕** → エネルギーを 30% の新課題に集中投入
- **30% の経験を積み重ね** → 視覚的ライブラリが少しずつ広がる
- **疲労なく長期継続** が可能

### 用例

- 人体を簡単に書ける → 30% は **広大な環境のキャラクター** に投資
- 普段 1 人 → 30% は **2 人以上の構図** に投資
- 顔/服が得意 → 30% は **パース** に投資

### 「題材の難易度ガイド」

- 「**現在の実力を把握することが大切**」(ch26_01 12:58)
- **挑戦的すぎる**(100% 挑戦)= ブレインフォグ
- **快適すぎる**(100% 快適)= 成長停滞

## 解釈の揺れ / 異論

- ye_jji 講座には **明示的な数値配分** はない。Nekojira の **数値ガイド** は実装可能性の点で独自貢献
- 「**70:30**」は厳密な数値ではなく **目安**(80:20 / 60:40 でも本質は同じ)
