# ソフトライト補正(最弱の明暗調整)

## 定義

CSP/Photoshop の **ソフトライト** ブレンドモードを用いた色味・明暗の **微調整補正**。「明るい色 → 明るく / 暗い色 → 暗く」の作用を **最も弱く** 出す方法で、[[layer-effects-by-intensity|レイヤー効果の強度ランキング]] における **最弱** に位置付けられる(ハード > オーバー > **ソフト**)。

## 使用場面

- ch08 で **照明色の微反映**: 加算レイヤーが強すぎる場合の代替
- ch22 で **最終仕上げの繊細な色調補正**: 既に整った絵に最後の一押しを加える
- **やり過ぎ NG な場面の保険**: 「もう少しだけ明るく / 暗く / 暖かく」を **後戻り可能** に試せる

## 強度ランキングでの位置(ch22 整理)

| 効果 | 強度 | 用途 |
|---|---|---|
| ハードライト | 強(最大) | 微妙な明暗を強く調整 |
| オーバーレイ | 中 | 同上、中程度 |
| **ソフトライト** | **弱(最小)** | **同上、弱く** |

3 つは **同じ作用** を持つが **強度だけが違う**。意図ファースト補正の文脈では「最初はソフトライトで試し、足りなければオーバーレイ → ハードライト」とエスカレーションする運用が合理的。

## ye_jji 流の扱い方

- **意図が定まっていない時の探索ツール**: ハードだと変化が大きすぎて意図がブレる → ソフトで微変化を試す
- **顔・主題部での使用**: 大きな変化を避けたい主題部はソフト一択
- **[[face-mask-during-finish|顔だけマスクで保護]]** との組み合わせ: 顔以外にハードを当て、顔だけソフトに切り替える運用

## ch08 ↔ ch22 の連続性

- ch08 では本概念は **暗黙の使用**(加算レイヤー失敗例の修正でブラシ直塗りと併用)
- ch22 で **3 効果の強度ランキング** として明示体系化 → ソフトライトに「最弱の意味」が定義される
- → ch08 で実演 → ch22 で言語化、という Coloso 講座の伝統的構造
