# 色の訓練法(ye_jji 推奨ドリル)

## 定義

ye_jji が ch07-08 で繰り返し推奨する **色彩感覚を鍛えるための訓練法群**。中核は **写真模写 → 自分の癖の発見 → 巨匠絵画分析** の 3 段階で、[[me-do-training|明度トレーニング法]] と並ぶ Coloso 講座の重要練習論。

## 推奨ドリル一覧

### 1. 色模写(写真模写)

- ch07_02 で実演される **基本ドリル**: 写真をスポイトせず目で観察 → 同じ色を作って塗る → 写真と並べてスポイトで比較 → **自分の癖を発見**
- 観察対象は **明度 / 彩度 / 色相 / 暖寒系統** の 4 軸
- ye_jji 本人の発見例: 「**メイドが低くなる癖** = 鮮やかな色を多用するため明度が下がる」([[bowtie-mei-do-otoshi-wasure|蝶ネクタイ型明度落とし忘れ]] の起源)

### 2. 限定パレット(色制限の練習)

- 既存ベースを **少数の色相** に絞って描き、構造を維持できるかをチェック
- ch12 カラーラフでも応用される(ベース色数を絞って明度のみで形を出す)

### 3. 配色チャレンジ

- 同じ絵を **4 つの照明設定** で塗り分ける(ch08 屋外昼/夜/ネオン/室内)
- 同じ絵を **巨匠絵画の照明** に置き換える(ch08 フラゴナール/青いヌ側の春)
- → **1 イラスト多照明** で「光が色味に与える影響」を体感

### 4. オリジナル照明設定(応用)

- 既存の照明設定に **暖寒系統を維持したまま** 好みを加える([[dan-kan-keitou-iji]] に基づく)
- 補色対比 / 彩度対比 / 明度対比 / 柔らかさのいずれかを強める

### 5. 巨匠絵画分析(本格)

- [[meiga-bunseki|名画分析]] として独立扱い → 別ページ参照

## ye_jji 流の扱い方

- **「スポイトで比較する」を恥じない**: 自分の色と写真の色を直接スポイトして数値で比較 → 感覚と数値のギャップを埋める
- **癖は弱点ではなく個性の出発点**: 発見した癖は意図的にコントロールするか、強みとして活かす
- **PDF p7(c07)の整理**: 色彩トレーニングの目的は **明度 / 彩度 / 色調 の 3 種類の錯視を見抜く力**(本文より広い)
- **chan 視点との対照**: [[me-do-training]](chan の明度模写)が **目の鍛錬法** として明度に特化するのに対し、ye_jji の色訓練は **3 軸 + 暖寒系統** を同時に鍛える

## 訓練の順序(推奨)

1. **明度模写**(chan の [[me-do-training]] と統合) — 白黒で写真模写、トーンバランスを訓練
2. **色模写**(本概念) — 色付きで写真模写、4 軸を訓練
3. **配色チャレンジ**(本概念) — 1 イラスト多照明
4. **巨匠分析**([[meiga-bunseki]]) — 完成度の高い作品で照明解釈の幅を広げる
5. **オリジナル設定**(本概念) — 自由設定で系統維持の判断力を養う
