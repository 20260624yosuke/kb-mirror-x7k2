# 4 サブスキル(色遣い・ドローイング・比例感・観察力)

## 定義

[[ye-jji]] が独学者に提示する **イラストの基礎を分解した 4 つのサブスキル**。それぞれに別の練習法が必要とされる。

## 構成要素

| サブスキル | 練習法 |
|---|---|
| **色遣い** | 観察中心。綺麗な写真・イラストを集めて見る / スポイトで色変化を分析 / 色遣い模写 |
| **ドローイング** | **曲線を丁寧に**(クロッキーだけでは不十分)/ 極率の変化を数える / 大きく太く描く |
| **比例感(携帯力)** | 写真模写 + **角度を変えて様々な方向から** 描く |
| **観察力(細部)** | **写真と同じクオリティ** での写真模写を 1〜2 度 |

## 学習論との結合

- **「基礎から積まない」**([[interest-driven-learning]])を前提に、必要を感じたサブスキルだけ取り出して練習する
- 速描き派と丁寧描き派で **逆方向の訓練** を入れる(速派は時間制限なし、丁寧派は時間制限あり)
- デジタルでも手書きでも **キャンバスいっぱいに大きく** 描く
