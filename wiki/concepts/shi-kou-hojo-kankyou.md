# 思考・補助・環境(3 ライト構成)

## 定義

1 枚の絵で使う基本ライト 3 種の役割分担。3DCG のキー/フィル/アンビエントと同じ枠組み。**1 つのパーツに 3 つ以上の色感を仕込む** ことで多彩さを担保する手法。

## 構成要素

- **思考(キー)**: メイン光、通常は **直射光**、名部領域を支配。立体感の主担当
- **補助(フィル)**: 反対側を救う光、通常は **反射光**、思考より弱い
- **環境(アンビエント)**: 周辺散乱光、通常は **拡散光**、安部領域を支配し背景と溶け込ませる
- **リムライト(任意)**: キャラ輪郭を後ろから照らし、背景分離を行う

## 適用順序

固有色に光源色を反映させる際は [[shoumei-iro-tekiyou-3-steps|3 ステップ]] を踏む(色相 → 彩度 → 明度)。

- 名部 = 思考の色味
- 安部 = 環境(主)+ 補助(部分的に反射光位置)

## 既存設定例(屋外昼)

- 思考 = 白(太陽)
- 補助 = オレンジ(地面)
- 環境 = 青(スカイライト)

## 出典追加 (2026-05-17): `c08_要約ノート.pdf` の整理

PDF p4 で、3 ライトと **明部 / 暗部 / 反射光 領域** の対応関係が明示的に表で整理されている(本文では暗黙だった):

| 領域 | 描写する色 | 対応する光 |
|---|---|---|
| **明部** | 主光源の色 | 主光源(=思考)の直射光 |
| **暗部** | 環境光の色 | 環境(アンビエント)の拡散光 |
| **反射光** | 補助光の色 | 主光源の反射が補助光の役割を果たす |

また、各光の「どの種類で設定するか」の **デフォルト推奨** が PDF p3 で対応表として明示:

- 主光源 → **直射光** で設定(形態明確化のため)
- 補助光 → **主光源の反射光** として設定するのが一般的(量感を損なわず、主光源より目立たないため)
- 環境光 → **拡散光** で設定(散乱した光が弱く照らすため)
- リムライト → 別枠、明度コントラスト + キャラ/背景分離

## 出典追加 (2026-05-17, Batch 2): 実装回での適用例

- **ch11 セルフチェックリスト 5-1**:「主光源・副光源・環境光の色をすべて反映しているか」が公式チェック項目として明示。**3 ライトが全て反映されているかの自己診断** を 1 ライン化
- **ch12 カラーラフ実装**:カラーラフの工程 5「照明色を反映」で 3 ライトを **上向き面 = 環境光(青)/ 下向き面 = 補助光(暖色)/ 全体に主光源** という空間配置として実装
- **ch12 / ch15 で再強調された NG パターン**:「青い光を受けるから単に青を塗る」は彩度が濁って加算混合の表現にならない。**カラーホイールを回して彩度・明度を調整** してから反映が必須
- **ch15 のキャラ実演**:無彩色(白い髪)に **光源色の高彩度を強く反映**(7-color 原則の再確認)
- **ch15 の同系色反射のコツ**:胸の合わせ目など同じ色相同士が反射し合う部分は **彩度を上げてくっきりと** 描写
- **ch07 / ch08 + ch11 / ch12 / ch15 の通史**:理論 →自己診断 →実装 →ライブ実演、と段階的に再現された(Coloso 講座全体の中で最も繰り返し参照される概念の 1 つ)
