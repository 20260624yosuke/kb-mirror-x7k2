# RGB 差による彩度計算

## 定義

ye_jji が **彩度を数値的に判定** するために使う実用ルール。
**R, G, B の 3 値に差が生じると彩度が高くなり、3 値が同じ値になると彩度が低くなる**(PDF p1)。
1 値だけが突出 = 純粋色 = 高彩度、3 値が均等 = 無彩色。

## 物理的根拠(PDF p1)

光の三原色(赤・緑・青)を錐体細胞が感知することで色が成立。物体は特定の波長を吸収し、残りを反射 → 反射光の R/G/B 構成で色が決まる。

- 例: R 255% / G 0% / B 0% → 純粋な赤、最大彩度
- 例: R 50% / G 50% / B 50% → 灰色、彩度ゼロ
- 「R, G, B の値に差が生じると彩度が高くなり、同じ値になると彩度が低くなる」(PDF p1 ハイライト)

## 視覚的特徴 / 描写ポイント

- **2 色の合成検証**: 加算レイヤーは光の加法混色と同じ → 合成結果の RGB を確認することで類似色 / 補色の効果を実証可能
- 本文の実演: R200/G50/B50 + R0/G150/B150 = R200/G200/B200(灰色 = 補色対比)
- 「カラーピッカーで RGB を見ると 150 です」のように **カラーピッカーの数値で彩度感覚を補強**

## ye_jji 流の扱い方

- **「なんとなく彩度が低い」感覚を数値で裏付け** するためのチェック手法
- 高彩度 3 ポイントを塗るとき、自分で塗った色の RGB を見て **本当に 1 値が突出しているか** を確認
- 補色を選ぶときは「加算で灰色になる組み合わせ = 補色」を逆算するのに使える
- カラーレイヤー併用で **実明度** も同時にチェック([[bowtie-mei-do-otoshi-wasure]] の予防)
