# ポスタリゼーション(階調化)による影観察補助

## 定義

[[nekojira]] が **ch14・ch20・ch22 で 3 回繰り返し推奨** する、写真参考資料の **影の形を抽出するためのデジタルハック**。参考画像を **ポスタリゼーション(階調化)** で **漫画のような数階調の影** に変換し、そこから **大きな形のリズム** を観察する。

## 構成要素 / 主要な論点

### 手順(CSP の場合)

1. 参考画像のレイヤーを **コピー**
2. **編集 → トーン補正 → ポスタリゼーション** (階調化、binarization)
3. **トーン値 = 7〜8 程度** に設定
4. これで **漫画のような明確な影区分** が得られる

### 目的

- 「**写真の細部に気を取られすぎる場合**」(ch14 5:52)に有効
- **影の形を観察** するだけでよくなる
- **大中小の形のデザイン** を抽出しやすい(ch20 の 4 原則と接続)

### ch14 → ch20 → ch22 の繰り返し言及

- ch14: シの観察補助として **初出**
- ch20: 影の形のインスピレーション補助として再強調
- ch22: 「**観察が難しい対象はポスタリゼーションを使う**」と **習慣化**

### ch22 では更に植物の表現にも応用

- 「**この植物は色張変化が多く書くのが難しそう → ポスタリゼーション → 簡単に形を抽出**」(ch22_01 11:39)
- 1 枚 1 枚の刃を書く必要なく、**漫画化された影の形だけ書けば植物に見える**

- ye_jji 講座には **明示的にポスタリゼーション推奨** はない(類似機能は **ぼかし** で代替している可能性)
- → これは Nekojira の **個人的なお気に入りハック** であり、**1 つの講座で 3 章で繰り返される独自貢献**
- Photoshop / Procreate でも同等機能あり(「Posterize」)
