# 色構成の練習(分析 → 適用)

## 定義

[[chan]] が sec16 で実演する[[training-method-3-categorization|3 練習法]]の「分析」。**綺麗な絵を分析して強みを抽出し、自分の絵に適用する**ワークフロー。[[ai-and-human-painting-3-stages|3 段階]]の「分析」と「表現」を繋ぐ。

## 実演の抽出項目(chan の絵に対し)

- メイン視線 / サブ視線の交差 / 色相パレット化 / 寒暖の遠近 / 髪と肌の密度差 / トーン低い赤のポイント色 / 横方向ライティングで視線速度を遅くする
