# ぼかしのコントロール(選択的ぼかし原則)

## 定義

ye_jji の描写・補正における **ぼかしツールやソフトブラシの使い分け原則**。「**ぼかしを均等にかけるのは NG**」「**色合いをぼかしで吸うと濁る**」が中核の警告。ぼかしは目的的・部分的に使うべきで、全体に均等適用してはいけない。c04 PDF p4 でも NG テクニックとして同種の警告がある。

## 中核原則

### NG: 均等ぼかし

- 全パーツを均等にぼかすと **コントラストが死に、形態が消える**
- 「明るい名部と既存の安部をぼかしで吸ってみましょうか。色合いがかなり濁ってきているのが見えます」(ch08_03 10:14)→ デモで意図的に失敗例を見せる

### OK: 選択的ぼかし

- **反射光の境界をぼかす**: 直射光よりコントラストが弱い反射光は意図的に明暗境界をぼかす(c08 _01.md 反射光説明)
- **拡散光時の境界の柔らかさ**: 拡散光下では明暗境界が消える → 全体的に柔らかいぼかしが正しい(PDF p2)
- **遠景・空気遠近**: 距離があるパーツほどエッジをぼかして空気感を出す([[atmospheric-perspective]])
- **ハードエッジ保持**: 明暗境界の高彩度サイドや形態の主軸はぼかさない

## ye_jji 流の扱い方

- **ぼかし → 「色を混ぜる」装置と捉えない**: ぼかすと **色相が中間値に倒れて低彩度化** する(高彩度を入れた中間トーンが消滅する)
- **「ぼかしで色を吸う」のは応急処置**: 描き間違えた領域をぼかしで誤魔化すと色彩情報が抜ける → 描き直しの方が結果が良い
- **使うべき場面の明確化**: 反射光の境界 / 拡散光下の全体 / 遠景の遷移 / セミ・グロス質感の混合反射部 のみ
- ぼかしの強度を **領域ごとに変える** = エッジ階層を作る(Nekojira の [[edge-4-levels]] と同根)
