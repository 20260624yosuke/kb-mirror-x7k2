# ベース塗り方から 4 派生スタイル

## 定義

[[chan]] が sec17 で実演する、[[information-balance-pair-operation|情報総量一定 + ペア操作]]で自分のベースから生成する 4 つの派生スタイル。

## 4 派生(情報軸の増減)

1. 雰囲気重視風(色相 + 密度 ↑ / 彩度 + 明度差 ↓)
2. メンヘラ風(色相極大 + 明度差 ↓)
3. Web トゥーン風(明度差 + 彩度 ↑ / 色相 + 密度 ↓)
4. 青白リアル風(密度極大 / 他全 ↓)
