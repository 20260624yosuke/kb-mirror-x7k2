# 透明描写

## 定義

ガラス・水・宝石など、**光が物体内部を通過して背景が透ける** 物体の描写。
固有色はほぼ持たず、見えるものは(1)背景の透過像 + (2)屈折で歪んだ像 + (3)表面反射(ハイライト+
エッジ+明色反射)の重ね合わせ。**立体感(量感描写)より反射と屈折が描写の中心**(`c05_要約ノート.pdf` p4)。

## 視覚的特徴 / 描写ポイント

- **3 段階の反射強度**(`c05_要約ノート.pdf` p4):
  1. **ハイライト** = 完全に不透明(光源の形そのまま)
  2. **エッジ([[fresnel-reflection|フレネル反射]])** = 不透明(斜めから見るほど反射率が高い)
  3. **明るい色の反射** = 不透明、**暗い色の反射** = 透明 → クリスタの **スクリーンレイヤー** がそのまま使える(明色を残し暗色を透過)
- **屈折描写**:物体のグリッドに沿って背景を歪ませる。**凸レンズ形状(球体)では上下左右反転**
- **厚みが増すほど不透明**:重なりや厚い部分は固有色寄りで描く(青なら厚部を青く)
- **背景明度で描写が変わる**(`c05_要約ノート.pdf` p5):背景明るい → 厚部を暗く / 背景暗い → 厚部を明るく
- **ハイライトはグレー化させない**(常に最高明度)— グレー化すると反射率が低く見え透明感が消える
- **100% 透明は存在しない**(p5)— 重なり・厚みで必ず不透明度が立つ

## ye_jji 流の扱い方

- **ch05 ポーション瓶 + B 玉実習**:明背景 と 暗背景の 2 ケースで描き分ける。スクリーンレイヤーで反射を一気に表現する効率ワークフロー
- **ch19 パフェのガラスコップ(二層構造)**:
  - **下層**:反射する物体として **内面の明暗** を描く(中央暗、ブルーベリーとの接触オクルージョン)
  - **上層**:**スクリーンレイヤーで反射物** を重ねる(肌/指/水着/髪/ヤシ/空/イチゴ/砂)+ 太陽の円形ハイライト
- **「スクリーンレイヤーが透明反射と同じ振る舞いをする」**:デジタル描画特有の高効率テク。レイヤー効果を物理原理に紐づけて理解する稀有な例
- 透明体の描写は **混合反射のコーティング** と原理的に近い(透明材質が乱反射物体の上に乗る = ch05 p7 のコーティング概念)

## 解釈の揺れ / 異論

- 「透明」と「半透明」の境界は連続的(物理的には吸収係数の違いに過ぎない)。本講座では **背景が見えるか/固有色が前景に出るか** で実用的に区別している
- 凸レンズによる「上下左右反転」は球形に限る挙動。雫のような半球形でも上下のみ反転など、形状依存性がある(本講座では主に球と平面で説明)
