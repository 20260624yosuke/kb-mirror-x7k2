# トーン = 絵の OS(基盤)

## 定義

[[chan]] が sec05 で導入する観察軸。**トーン = 絵を白黒で見た時の明度バランス**。絵の安定感と完成度の基盤で、chan は「トーン = OS、色相 = アプリ」とレイヤー化して捉える。

## 主要な論点

- トーンは明度差の影響を最も受けるが、彩度・色相の固有明度にも左右される
  - 彩度↑ → トーン↓(暗くなる)/ 明度↓ → トーン↓
  - 色相: 赤・青・紫 = トーン低い / 黄・緑・水色 = トーン高い
- 差を大きく → 視認性高・強烈だが負担大 / 差を小さく → 軽くアプローチしやすいが視認性低下
- 色相情報が多い時は全体トーン差を抑えて安定性を確保 → その上に色相を追加([[information-volume-vs-contrast-amount]])
