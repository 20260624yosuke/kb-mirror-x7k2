# 参考の特徴を自分の条件に翻訳する

## 定義

[[chan]] が sec16 の実演で示す適用法。分析で抽出した参考作品の特徴(夕焼け空間色 / 緩い雰囲気 / 密度差ポイント / 横ライティング等)を、**そのままコピーせず自分の絵の条件に翻訳して移植**する。chan の落書きに移植して別物の完成度に達する demo を見せる。
