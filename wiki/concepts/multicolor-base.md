# 多色のベース塗り

## 定義

固有色を **単色のフラット塗り** で下地にせず、最初の段階から **複数の色相** を仕込んで多彩性の土台を作る描写戦略。ye_jji の「立体感を保ったまま多彩な色味を出す」哲学の **入口** に位置する。ブレンディング過程で必然的に低彩度色が混ざる宿命を、下地段階で先回りして緩和する。

## 起点と接続

- 起点: ch06 ハンバーガー実習 — 自然物の拡散反射面は多彩色のタッチで下地を作る
- ch07 では理論側で「**立体描写の過程では低彩度の色が使われる**(PDF p2)」「ブレンディングで色を混ぜると彩度が低くなってしまう」と説明 → ベースを多色化することは **後段で彩度が下がる前提の対策**

## 視覚的特徴 / 描写ポイント

- **同じ色相での広い面塗りを回避**(ベタ塗り回避、[[shi-kan-no-katsuyou]] の前提条件)
- 固有色 + その類似色 2-3 種を最初の塗りで配置
- 後段で [[saido-no-3-points|高彩度 3 ポイント]] を載せる際の「ベースの多彩さ」が効いてくる
- 自然物(肌・布・葉・木材・岩など)で特に有効

## ye_jji 流の扱い方

- **下地段階で多色を仕込み、量感描写で低彩度に向かい、3 ポイントで高彩度を回復** の 3 段構成
- 単色下地に高彩度ポイントだけ載せると **「点だけ浮く」絵** になる → 下地の多色性が高彩度を馴染ませる
- ch07 本文「固有色 + 固有色の類似色を一緒に使用」「黄色やピンク色などの色を一緒に使用」(13:38) は **下地段階から類似色を混ぜる** 思想と表裏一体
