# 光の 3 種類(直射 / 反射 / 拡散)

## 定義

ye_jji が ch08 で **物体側で観察される光のあたり方** を 3 区分した枠組み。**直射光・反射光・拡散光** の 3 種で、それぞれ方向性・明暗境界の明瞭さ・フォーム/キャストシャドウの描写有無が異なる。本枠組みは [[shi-kou-hojo-kankyou|3 ライト構成(思考・補助・環境)]] の物理基盤として機能する(各ライトはこの 3 種のいずれかで設定される)。

> **注**: 光源の物理分類(太陽光 vs 人工光、PDF p1)とは別軸。これは「光源から発した光が **物体に届く形態** 」の 3 区分。

## 3 区分の整理(PDF p2)

| 種類 | 性質 | 方向性 | 明暗境界 | フォーム/キャスト |
|---|---|---|---|---|
| **直射光** | 光が物体に直接当たる | 強い | 鮮明 | 描写する |
| **反射光** | 壁/天井に一度当たってから物体に届く | あるが弱い | 薄い | 直射より弱く描写 |
| **拡散光** | 物体を通過し散乱した状態で届く | なし | 消える | フォーム/キャスト不在、オクルージョン中心 |

PDF p2 では球体図 + 矢印付き図解で 3 種を比較しており、各区分の **チェックリスト形式** が決定的に明快。

## 影響力ヒエラルキー

3 種が同時に物体に当たる場合、影響力の強さは **直射 > 反射 > 拡散** の順(PDF p2 下部に再強調)。

- 強い光が当たる部分には弱い光は影響できない(明部に拡散光の青みは乗らない)
- 直射光と反射光が当たらない領域 = 暗部 → 拡散光(= 環境光)の支配域

## ye_jji 流の扱い方

- **直射光時** = これまで学んだ [[lambert-cosine-law|ランバート則]] と [[form-shadow]] / [[cast-shadow]] / [[core-shadow]] / [[mid-tone]] / [[reflected-light]] / [[center-light]] / [[highlight-position]] の 7 要素をそのまま適用
- **反射光時** = 同じ 7 要素を描くが、**明暗境界をぼかし**、コントラストを下げて描写
- **拡散光時** = フォーム/キャストシャドウが目立たなくなり、代わりに [[occlusion-shadow|オクルージョンシャドウ]] が際立つ → **曇天の絵で必須の知識**

## 3 ライト構成との対応(PDF p3)

各ライトの **デフォルト設定** は:

- **主光源(思考)** → 直射光 で設定(形態を明確に表現するため)
- **補助光** → 主光源の **反射光** で設定するのが一般的(量感を損なわず、主光源より目立たないため)
- **環境光** → **拡散光** で設定(散乱した光が弱く照らすため)
- **リムライト** → 別枠(明度コントラスト + キャラ/背景分離)
