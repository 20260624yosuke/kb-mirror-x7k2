# 空気遠近(大気色への収束)

## 定義

距離が遠いほど物体の色が **大気の色(屋外では空の青)** に寄っていく現象。ch20 の背景描写で全面的に使われる。

## 構成要素 / 主要な論点

- 手前 = 鮮やか + 多階調 + 高コントラスト
- 遠景 = **大気色寄り** + 単階調 + 低コントラスト
- 「遠くにあるオブジェクトは波のような細かい描写は省略しても大丈夫」
- 海は **遠 = 青み / 砂浜近く = エメラルド** のグラデーション
- 遠景の山と灯台はほぼシルエットのみ、区別もつかない

## 出典追加 (2026-05-17): ch09 / ch10 / ch15 から起点を遡及

- **ch09(空気遠近の初出と核心原則)**: 概念の **講座内初出は ch20 ではなく ch09**(密度を下げる)。`ye_jji_09._01` 1:21 で「描写省略 = 階調削減 + 空気遠近 + コントラスト低下 の 3 段階」の 1 つとして導入される。**「ぼかし = 彩度を下げる」が誤解** という反直観的注意 — 大気色そのものが鮮やかな場合は高彩度のまま遠景化することもある(本講座の重要な反例ルール)
- **ch10(遠景の点要素にも適用)**: 点要素を遠景に配置する時、空気遠近で明度を上げて遠さを示す(鬼火デモ)
- **ch15(キャラ実演時の背景処理)**: 後ろの山に大気色寄りの色味を反映、というシンプルな実装例
- **ch20(背景全章での全面適用)**: 海・空・山・雲・遠景植物すべてに体系的に適用

## 出典追加 (2026-05-17, Batch 3): ch16 の雲・遠景処理

- **ch16(明部の描写)**: 雲(近 = 側面+低面の明暗 / 遠 = シルエットのみ + 大気色)、ヤシ(手前 = 多階調 / 中 = シルエット / 遠 = 色味のみ)で、**色塗りの中間トーン工程でも大気色帰結を実装** することを明示。「**薄い雲は光透過 → 影を作らない**」という光学原則も補強

## Nekojira 視点 (2026-05-18): [[coloso-nekojira-ch22-lighting-mood]]

- Nekojira は **空気遠近として独立章を割かない**(本講座は背景描写を集中扱いしない)
- ただし ch22 で **アンビエントライト(環境光)が周囲の色を物体に反射** させる原則を強調 → 「**白いシャツに緑/青/オレンジが反射**」など、**距離ではなく環境** からの色変化を扱う
- 「**空からの光は青** → 上向き面に青を加える」(ch24) = ye_jji の空気遠近の **天空光側の局所版**
- → ye_jji が **空間スケールの色変化**(遠景の大気色化)、Nekojira が **物体スケールの色変化**(環境からの反射)という分担
