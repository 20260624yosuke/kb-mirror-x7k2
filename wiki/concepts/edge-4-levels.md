# エッジ 4 段階(Sharp / Firm / Soft / Lost)

## 定義

[[nekojira]] の **ch21(色彩明度)** で確立される、影の境界(エッジ)を **4 つの硬さレベル** で分類する手法。「**繊細な式調値の制御よりエッジコントロールに注力**」する戦略を支える中核フレームワーク。

## 構成要素 / 主要な論点

| レベル | 名称 | 用途 |
|---|---|---|
| **1** | **シャープ** | シルエットの端、キャストシャドウ、近接影 |
| **2** | **ファーム** | しっかりした転換点、物体から離れた影 |
| **3** | **ソフト** | トランジション、丸い表面の転換点、胸 |
| **4** | **ロスト** | 形が消えていく部分、中間調、遠景 |

### 簡略化

- 「**覚えておくべきはシャープとロストだけで十分**」(ch21 6:45)
- 残りの 2-3 は「**わずかなスルドさしか持たない**」中間値

### 部位別の推奨レベル(ch21 実演から)

| 部位 | 推奨 | 理由 |
|---|---|---|
| お尻の丸み | 2 → 3 | 丸い変換点、離れて柔らかく |
| キャストシャドウ(脚を覆う影) | 1 | 物体間の鋭い境界 |
| 胸の柔らかい部分 | 3 | 丸い表面の柔らか |
| 胸の谷間 | 1 | 近接影 |
| 鎖骨周辺 | 2-3 | 構造の転換点 |

## 構成要素 / 主要な論点(続き)

### エッジ追加の連動原則

- 「**イラストの特定部分にエッジを適用する場合、全体スタイルを合わせるため他の部分も調整が必要**」(ch21 8:35)
- 片所だけ仕上げ度を上げると **他の部分の完成度が低く見える**
- → エッジ追加は **全体一斉で行う** べき

### ソフトエッジ追加で「仕上げ」が生まれる

- ハードブラシだけでは「**純粋な形しか作れず仕上がりが劣る**」(ch21 8:02)
- **ソフトエッジ = 完成度の核**

## 解釈の揺れ / 異論

- ye_jji は **4 段階のような明示的分類を持たない**。代わりに [[totoneru-definition]](整える) や [[bokashi-control]](ぼかし制御)で個別に扱う → Nekojira の **より体系化された貢献**
