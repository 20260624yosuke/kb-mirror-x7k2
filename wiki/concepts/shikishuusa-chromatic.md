# 色収差

## 定義

レンズの波長屈折で RGB がずれる現象を再現する仕上げ技法([[hizurume]])。RGB レイヤーをスクリーン合成してずらす。

## 構成要素 / 主要な論点

- 作り方: 統合画像を 3 枚複製 → R/G/B で塗りつぶし → 赤・緑をスクリーン合成 → ずらす。
- **色による使い分け**: 明るい元気な絵 = **赤ずらし**(赤と青)、暗いマット / ポストアポ = **緑ずらし**(緑とピンク)。
- **拡大法**: 先端だけずらして拡大すると、目立たせたい側(顔)を薄く・逆側を濃くできる。
- レイヤーマスクで部分制御(顔だけ収差を消す等)。フィルターの放射状/平行は「誰でもできる」ので使い所に注意。
