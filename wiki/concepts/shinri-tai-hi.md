# 心理対比(心理的に重い絵 / 軽い絵)

## 定義

被写体が見る人に与える **心理的な「重さ / 軽さ」の対比** で視線を誘導する考え方([[hizurume]])。本人は **キャラクターを心理的に重く / 背景を心理的に軽く** することでキャラへ視線を集める。

## 構成要素 / 主要な論点

- 「重い絵」= 塗り方が心理的に重い(くすみ・密度・陰)。「軽い絵」= 流れ・空間で非現実的に軽い。
- 背景をふわっと軽く、キャラだけを重く描く → キャラが目に入る視線誘導。
- 視線誘導の重ね掛けの一部として運用([[shi-sen-yu-dou]])。

## 重い表現 / 軽い表現の方法(ch13)

適用場所は **絵の力場の分布と同じ**(重い = 黄 / 中間 = 赤 / 軽い = 青、[[e-no-chikara-ba]])。

- **重くする**: 現実の明暗に沿わせる / 明暗境界線の立体感 / 階調を増やす / シェイプで重力 / 反射光を少なく / 質感を金属寄り / 暖色寄り(前進色)/ 油彩画のようにべっとり / テクスチャブラシ。
- **軽くする**: 空気遠近(白・青白で問答無用に透明感)/ 反射現象多用 / 階調を減らしアニメ調化 / [[mie-rayleigh-scattering|ミー散乱]] / かすれブラシ(外側に)。軽い表現はほぼ失敗しない。

## SNS 市場観察(本人の主観・要検証)

- **流れ(たなびく髪)の"軽い"絵は 2025-2026 の X で伸びにくい**(見飽き・流行飽和)。本人も最高 3.6 万いいね止まり。商業では喜ばれる。
- 最近の流行 = **「心理的に重い絵」**。重い絵は 10 万いいねを取りやすい。
- ポップで明るい絵は 10 万いいね到達しにくい。ポストアポカリプス / 廃墟のくすんだ絵は伸びやすい。
- 大きい仕事はフォロワー 2 万人以上 or 名声が前提(本人の認識)。
