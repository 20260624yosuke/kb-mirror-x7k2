# 構図は 1→2(写真の構造借用 + 連想ゲーム)

## 定義

[[hizurume]] の構図発想論。構図は **0→1(無から創造)ではなく 1→2**(既存の良い写真・映像の構造を借りて要素を入れ替える)。

## 構成要素 / 主要な論点

- 良い写真の **構造を拝借**(そのまま使うのは厳禁)→ 概念を足す → 要素を入れ替えると別構図に(花 → ラッパ → 音楽団 → 黒服…)。
- 構図が決まっているなら **連想ゲーム**(夜 → 部屋 → 扇風機 → 夏…)で発想を広げる。
- 足す要素は仕上げで画面が寂しい時に([[atodashi|後出し]])。
- 「構図は楽しんでこそ」。難しく考えない。
