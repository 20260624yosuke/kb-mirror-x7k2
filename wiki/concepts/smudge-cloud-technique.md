# 指先ツールでラフブラシ跡を雲化

## 定義

[[ye-jji]] が ch20 で示す **雲の描画テクニック**。CLIP STUDIO PAINT の **「ぼかしツールの中の指先」** で、ラフに置いたブラシ跡を **ポンポンと打って境界を崩す** → 自然な雲の外角ラインに変換する。

## 構成要素

### 手順

1. ブラシで雲の **基本シルエットをラフに** 置く(白系の色)
2. 指先ツールで **境界を崩す**(ポンポンと打つ動き)
3. 必要なら通常ブラシで補強

### 雲の種類別の使い分け

- 流れに沿って動かす → **筋雲・煙雲**
- ラインを集中させる → **集中線型雲**
- 横方向に散らす → 後ろの雲
- 完全に煙のように散らばらせる → 飛び去る雲

### 代替手段

- CLIP STUDIO 素材の **にブラシ** も活用可能
- 直接ブラシでシルエットを整える併用
