# 乱反射(拡散反射)

## 定義

表面がでこぼこ(微視的に粗い)な物体において、光がさまざまな方向に散乱して跳ね返る反射。
特定方向の鋭いハイライト(=鏡面ピーク)を持たず、明暗は **[[lambert-cosine-law|ランバート余弦則]]**
に従って面の傾きで滑らかに変化する。肌・布・紙・マット塗装など、現実の大半の物体の基礎挙動。
対義語は [[sei-han-sha|正反射]]。

## 視覚的特徴 / 描写ポイント

- **像を反射しない**:周囲の物体の形を映さず、散乱光として再放射する
- **量感描写の主舞台**:陰影 7 要素(フォームシャドウ / キャストシャドウ / コアシャドウ / 反射光 / ミッドトーン / センターライト / ハイライト)が全部立つ → [[ryou-kan]]
- **ハイライトは点状ではなく、境界がぼやけた明るい領域** として現れる(鏡面ピークがない)
- **明暗境界線にだけ質感(でこぼこ)を集中** させれば、人の目が錯覚で全体をでこぼこと認識する(ch06 ぬいぐるみ実習の核心 Tip)
- **下地は単色にしない**:自然物の拡散反射面は多彩色のタッチで仕込む(ch06 ハンバーガー実習、→ [[multicolor-base]] が未作成なら参照不要)
- **反射光は仮想ソースで色味を作る**:「下に芝生があると想定」「水のキラキラが反射する想定」など([[virtual-reflection-source]])

## ye_jji 流の扱い方

- **ch06 ぬいぐるみ実習**:乱反射の応用例。中間トーンは「毛の塊と塊の間に影ができる」と捉えて描写。ステッチに沿った縫い目で反射形状を再分割
- **ch06 ハンバーガー実習**:自然物の拡散反射 + 多彩色下地。各部位(パン/レタス/トマト/パティ)で反射率が違うことを意識
- **ch16 肌**:**完全マットではなく少し艶あり = 表面の荒さ高めの混合反射** と明示されており、純粋な乱反射ではなく [[kon-gou-han-sha|混合反射]] 寄り。「肌 = 乱反射」と単純化するのは ye_jji 流では誤り
- **ch19 ホイップクリーム/アイスクリーム**:典型的な乱反射。ホイップは画面の最高明度を取るルール

## 解釈の揺れ / 異論

- 「乱反射」と「拡散反射」は本講座では同義。物理学では Lambertian diffuse が理想化されたモデルで、現実の拡散面は若干の方向依存性を持つが、本講座は実用上同一視
- **肌を単純な乱反射として扱わない** という ye_jji の方針(ch16)は、サブカルキャラ絵全般で注意すべきポイント
