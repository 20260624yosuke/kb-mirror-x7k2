# 仕上げの「写真っぽさ」3 点セット(ノイズ + CA + レンズフレア)

## 定義

[[ye-jji]] が ch22 で示す **イラスト仕上げの最終演出セット**。**ノイズ + クロマティックアベレーション + レンズフレア + 埃** の組み合わせで「写真っぽさ」「リアル感」「統一感」を出す。**全レイヤー結合後** に適用し、**顔の部分はマスクで保護** する。

## 構成要素

### 1. ノイズ

- イラスト全体に **統一感** を与える、写真の感じ
- 完成度の高い印象
- **顔の部分はマスクで消す**(描いた顔が潰れるため)

### 2. クロマティックアベレーション

- 顔をフォーカスにする → **顔から離れた部分だけ** にかける
- 描いた顔に影響が出ないよう注意
- フォーカス感を演出

### 3. レンズフレア

- CLIP STUDIO 素材の良いものを活用
- **スクリーンレイヤー** で重ねる
- 光の方向と一致させる
- 不要な部分は削除

### 4. 埃の散らし(屋外シーン)

- ラストブラシを使って開いている部分を埋める
- 近くの埃は **ブラ(ぼかし)** で曖昧に → 空間感
- 屋外シーンの **情報量増し**

### 適用順序

- **全レイヤー結合** → ノイズ → クロマティックの順
- レンズフレアと埃はスクリーンレイヤーで個別追加
