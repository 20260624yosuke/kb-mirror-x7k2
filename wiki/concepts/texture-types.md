# テクスチャー(反射特性)6 分類

## 定義

本講座が扱う物体表面の反射特性によるテクスチャー分類。物理原理ベースで「光がどう振る舞うか」で分かれる。

## 構成要素 / 主要な論点

| 区分 | 特徴 | 描写の中心 |
|---|---|---|
| **[[sei-han-sha\|正反射]]** | 表面滑らか、像をはっきり反射 | グリッドに沿った反射 + ハイライト + 「ハイライト以外は 1 段暗く」 |
| **[[ran-han-sha\|乱反射(拡散反射)]]** | 表面でこぼこ、像散乱 | 量感描写 + ハイライト(境界ぼやけ) |
| **[[kon-gou-han-sha\|混合反射]]** | 拡散 + 弱い正反射 | 表面の荒さで描写トーンを変える(荒さ低=正反射寄り、高=拡散寄り) |
| **[[tou-mei-byou-sha\|透明]]** | 後ろが透ける + 屈折 + 反射 | 屈折 + スクリーンレイヤー反射 + 厚みで不透明化 |
| **[[han-tou-mei-byou-sha\|半透明]]** | 固有色のみ反射、他は吸収 | 明度主体 + キャストシャドウに固有色 + 反対側がハイライト |
| **[[i-hou-sei-byou-sha\|異方性反射 (Anisotropy)]]** | 木目方向にハイライト/反射が伸びる | ハイライトを木目反対方向に伸長、模様方向に分割 |

## 重要原則

- **量感描写は正反射では起こらない**(鏡が影を作らないことで検証可)
- **ハイライト位置 ≠ センターライト位置**(反射経路で目に届く点)
- **明暗境界のでこぼこで全体質感を錯覚させる**(ぬいぐるみで実践: 全表面に描かず境界に集中)
- **反射率を上げたい時は周囲に仮想の反射ソースを足す**(複数ハイライト・補色)

## 出典追加 (2026-05-17, Batch 3): ch16-19 での実キャラ実装

- **ch16(明部の描写)**: 肌は **「完全マットではなく少し艶あり」= 表面の荒さ高めの混合反射** と明示。ハンバーガー回(ch06)の混合反射原則を肌に転用
- **ch17(暗部詳細)**: リボン = **シルクのデフォルメ = 異方性反射**(折り目に沿ってハイライトが伸びる)、麦わ帽子 = 拡散反射 + 透過光、レース = 半透明 + 厚みで不透明化
- **ch18(髪)**: 髪は **デフォルメによって質感のスペクトラムが変わる** という独立節を追加。**拡散寄り(マット、量感中心、塊感)↔ 正反射寄り(キラキラ、コントラスト強)** の連続体として整理。さらに **異方性反射**(髪の繊維方向のハイライト分割)も明示
- **ch19(質感描写の本実装回)**: パフェ = 拡散(クリーム/アイス) + 透明(ガラス) + 拡散+異方性(イチゴ) の **4 素材ミックス** をライブで描き分ける。金属装飾 = 異方性正反射、缶コーラ = 異方性正反射(円柱形)、水濡れ = 透明+反射の **2 段プロセス**、透ける水着 = **半透明 + 接触部条件**(布と肌が触れる部分だけ透ける)
- **「ホイップが最高明度」「主題部の質感に集中、副題は省略」**(ch19)など、質感描写の **全体配色ルール / 視線誘導との結合** が追補される
