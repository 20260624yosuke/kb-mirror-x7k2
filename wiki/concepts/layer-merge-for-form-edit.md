# レイヤー統合 → 形の自由

## 定義

[[ye-jji]] が ch21 で示す **ディテールアップ工程のレイヤー戦略**。色分けレイヤーを **全て統合** することで、「全額が生きている時にはできなかった形の修正」が可能になる。**透明ピクセルロック** で色だけ変えながら、髪・シルエットを自由に編集する。

## 構成要素

### 統合タイミング

- 工程 7(ディテールアップ)の冒頭
- キャラクター / 前景アイスボックス / パラソル / サンベッド の各フォルダを統合

### 統合後に可能になる操作

- **髪の毛を後から分割追加**(線を超えて細かい髪を足す)
- **シルエットに穴を開ける**
- **形そのものを変形**(歪み・縮小・拡大)
- **透明ピクセルロックで色だけ変える**

### トレードオフ

- 統合前 = レイヤー分離で色変更・修正は容易、ただし形修正は範囲が限定される
- 統合後 = 形修正は自由、ただし色だけの修正は透明ピクセルロックを介す
- 「**ある段階で覚悟して統合する**」のがディテールアップの前提
