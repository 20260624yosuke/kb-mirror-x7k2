# 14枚のフレーム観測記録

全フレーム共通の事実: **CLIP STUDIO PAINT EX** の画面。タイトルバーは `5강 다양한 재질 묘사 01* (4001 x 2251px 72dpi 71.8%)`。上部タブは `1. 정반사 / 2. 투명 / 3. 반투명 / 4. 흔합 반사(혼합 반사) / 5. 비등방성` の5枚で、常に「**5. 비등방성**」がアクティブ。キャンバスには灰色背景上に傾いた350ml缶と、赤ピン留めされたスパイラルメモ(ハングル手書き「비등방성」「빛나의 형태가 각진 여자 느낌인…」)、黒インク壺アイコン。右側レイヤーパネルには「비등방성」フォルダ配下に Layer 118 / Layer 117 / Layer 93 (Multiply) 等が並ぶ。

---

00m00s.png
確信度： medium
観測： 正位置(回転なし)のキャンバス。缶は線画+フラットな灰色で、ハイライトはまだ描かれていない。Tool Property に Brush Size 24.4。カラーウィールは赤系選択。レイヤーパネルで Layer 93(Multiply)が選択中。字幕「まず、これはハイライトが生じる 正反射物体で現れる現象ですね。」が表示。

00m20s.png
確信度： medium
観測： 正位置キャンバス。Brush Size 24.4。Layer 93(Multiply)選択。字幕「まず、これはハイライトが生じる正反射物体で現れる現象ですね。」缶はまだ無地状態。

00m40s.png
確信度： high
観測： 正位置キャンバス。白色選択(S 0% / V 100%)。Brush Size 116.3。Layer 93(Multiply)選択。字幕「缶の上面は天井を反射するでしょう。」缶はまだハイライト無し。

01m00s.png
確信度： high
観測： 正位置キャンパス。白色選択。Brush Size 58.8。Layer 117 選択。字幕「ハイライトは今回は蛍光灯のように 少し長く続けて描いてみましょうか?」

01m20s.png
確信度： medium
観測： 正位置キャンバス。Brush Size 50.0。字幕なし。缶中央に白い小さなドット数個(ハイライトの打ち始め)が出現。Layer 117 選択。

01m40s.png
確信度： low
観測： 正位置キャンバス。Brush Size 50.0前後。字幕なし。缶上に小さな白ドットが複数確認できる状態。

01m56s.png
確信度： medium
観測： 正位置キャンバス。Brush Size 50.0。字幕なし。缶上部に白いマーク群+中央にドット。Layer 118 選択。

02m00s.png
確信度： medium
観測： 正位置キャンバス。Brush Size 50.0。Layer 118 選択。字幕「ここで異方性を持たせると、模様に沿ってこの反射の形が伸びていくことになりますね。」

02m20s.png
確信度： high
観測： 正位置キャンバス。サブツールが「square texture brush」に切り替わり、Tool Property が Brush Size 29.3 / Opacity 100 / Angle 0.0 表示に変化。Layer 118 選択。字幕なし。缶下部付近にブラシカーソル。

02m40s.png
確信度： high
観測： キャンバスが反時計回りに大きく回転(約30°)。ズームも上がり缶が拡大表示。square texture brush のまま Brush Size 72.3 / Opacity 100。V値 66%。缶下面付近にブラシカーソル。Layer 118 選択。字幕なし。

03m00s.png
確信度： high
観測: 回転したキャンバスのまま。Brush Size 72.3 / Opacity 100 / Angle 0.0。V値 49%。Layer 118 選択。字幕なし。Navigator パネルのサムネイルも回転を反映。

03m20s.png
確信度： high
観測： 回転・拡大表示。square texture brush、Brush Size 56.9 / Opacity 100。S 1% / V 36%。缶下部にブラシカーソル。字幕なし。

03m21s.png
確信度： high
観測： 回転キャンバス。Brush Size 56.9 / Opacity 100。S 0% / V 65%。字幕「基本的に異方性があるということは、表面に模様があるということですよね。」が表示。

03m40s.png
確信度： high
観測： キャンバス回転が解除され正位置に戻る。square texture brush、Brush Size 56.9 / Opacity 100。V値 49%。Layer 118 選択。字幕なし。

---

補足(観測上の注意): 
- 進行の流れとして「赤→白→グレー系」と描画色が変わり、標準ブラシ→`square texture brush` への切替(02m20s以降)、缶への白ハイライトの追加、途中でのキャンバス回転(02m40s〜03m21s)と復帰(03m40s)が確認できた。
- ただし各フレームの割り当てはツール結果の添付順に依存しているため、類似した隣接フレーム間(例： 00m00s/00m20s、01m40s/02m00s)の細部の対応については確信度を medium〜low としている。
- 字幕は日本語で、韓国語講座動画に日本語字幕が重畳した状態で撮影されている。
