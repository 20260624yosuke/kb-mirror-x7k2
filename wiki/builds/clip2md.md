# clip2md（クリップボード長文の .md 化）

## 現在の統合見解

長文を LLM に渡すとき、チャット欄へ直接貼ると UI が重くなる。これを避け、コピー済みの
長文を **`.md` ファイル化して LLM に渡す**ための自作ツール。2026-06-07 実装。

設計の軸は、武田さんが今使う **Claude Code / Codex がローカルファイルを直接読める**こと。
ドラッグ添付せず、**ファイルのパスを伝えるだけ**で中身を渡せる。そのためスクリプトは
保存後にファイルの絶対パスをクリップボードへ戻し、エージェントへ貼り付け一発で渡せる
ようにしている。Web 版 Claude/ChatGPT 用には Finder で表示してドラッグ添付できる。

コピペ用 `.md` は「運搬手段」であり知識ではない、という方針。**Wiki には自動で残さない。**
使い捨てスクラッチ `~/llm-uploads` に保存し、Wiki に残したい時だけ手動で `raw/` に置いて
ingest する（運搬と知識化を分離）。

## 現行の運用（2026-06-07 時点）

- スクリプト本体を **Apple ショートカット「md変換」**でラップ（`$HOME/.local/bin/clip2md`
  を「シェルスクリプトを実行」で呼ぶ）。
- そのショートカットを **Raycast から呼び出して起動**する運用にした（直接のグローバル
  ホットキー割り当てではなく、Raycast 経由）。
- 起動 → コピー済み長文が `.md` 化 → パスがクリップボードへ → Finder 表示。
  Claude Code / Codex にはパスを貼って「このファイル読んで」、Web 版は Finder からドラッグ。

## 実装

- 本体: `~/.local/bin/clip2md`（実行権限付き）
- 保存先: `${CLIP2MD_DIR:-$HOME/llm-uploads}`
- ファイル名: `<YYYYMMDD-HHMMSS>-<先頭行スラッグ>.md`
- 動作: `pbpaste` 取得（空なら終了）→ 書き出し → `pbcopy` でパスを戻す → `open -R` で
  Finder 表示 → パスを標準出力。

## 重要保証・既知の注意

- **UTF-8 固定**: ロケール未設定（`LANG` 空＝C ロケール）の環境では pbcopy/pbpaste が
  日本語（マルチバイト）を落とす。スクリプト冒頭で `export LC_CTYPE=UTF-8` を固定して
  回避済み。Apple ショートカット経由など最小環境で実行されても安全。
- 先頭行スラッグは日本語を含み得る（macOS のファイル名としては可。可読性優先）。
