# E-Hentai to Notion Clipper

## 現在の統合見解

`tools/e-hentai-notion-clipper/` は、E-Hentai の作品詳細ページを、既存 Notion データベース `イラスト　how-to` へ保存する Chrome 拡張機能 + Mac ローカル補助処理。

v0.1.1 時点では、タイトル、URL、表紙、既存タグ、新規タグを保存できる。既存 URL のページがある場合は新規作成せず、既存ページを非破壊で補強する。

## 根拠

- 保存先 Notion データベースは API で接続確認済み。確認済みプロパティは `名前`、`URL`、`タグ`、`作成日時`、`プロパティ`。
- Notion 認証情報は `/Users/takedayousuke/.notion-ehentai-clipper-env` に保存し、Wiki・log・README には秘密値を書かない。
- 補助処理は `127.0.0.1:41885` で待ち受ける。`LaunchAgent` として `com.takedayousuke.e-hentai-notion-clipper` をインストール済み。
- ユーザー実機確認で、タグ一覧表示、保存、タグ反映、ページ内画像由来のサムネイル表示が動作 OK と確認された。

## 実装仕様

- Chrome 拡張機能:
  - `manifest.json` は v0.1.1。
  - ポップアップに拡張機能バージョンと補助処理バージョンを表示する。
  - E-Hentai 作品詳細ページから、タイトル、URL、表紙 URL、ページ上タグを抽出する。
- ローカル補助処理:
  - Notion API 2026-03-11 を使う。
  - Notion File Upload API で表紙を Notion 側へアップロードする。
  - 既存ページが無い場合は、ページを新規作成し、カバーと本文画像を設定する。
  - 既存ページがある場合は、既存本文・既存タグ・手動メモを消さず、カバー、本文サムネイル用画像、タグだけを補強する。
- タグ:
  - 既存タグは `着彩 / キャラクター / コミッション / 画集 / how-to / 服 / 構図/背景 / 雑誌`。
  - 新規タグはポップアップから追加できる。
  - カンマは Notion の `multi_select` タグ名に使えないため拒否する。

## 変遷

- 2026-06-25: 初回方針は公式 Notion Web Clipper 代替。公式クリッパーでは `hath.network` の一時 URL が 404 になり、Notion サムネイルが壊れる問題を回避するため、専用拡張 + ローカル補助処理を採用。
- 2026-06-25: v0.1.0 を実装。Notion 接続、タグ一覧取得、新規ページ作成、表紙アップロード、重複 URL 検出を確認。
- 2026-06-25: ユーザー検証で補助処理未起動によりタグ 0 件・保存失敗。`LaunchAgent` 常駐、未起動時の保存ボタン無効化、再確認ボタンを追加。
- 2026-06-25: 同じ URL で既存ページがある場合、スキップではなく既存ページ補強へ変更。カバー更新、タグマージ、必要時のタイトル補正、更新ログ追記を実装。
- 2026-06-25: ユーザー検証で Notion ギャラリーがページ内画像をサムネイルに使っていると判明。既存ページ補強時にも本文サムネイル用画像を追加・更新する仕様へ修正し、動作 OK。
- 2026-06-25: ユーザー要望により、マイナーな変更でも確認しやすいよう `manifest.json` のバージョンを更新する運用へ変更。v0.1.1 でポップアップにもバージョン表示を追加。

## 矛盾・未確定

- Notion ギャラリー側のカードプレビュー設定は API から直接確認していない。実機挙動として、ページ内画像がサムネイルに使われる前提で対応済み。
- `exhentai.org` は対象外。現行実装は `e-hentai.org/g/<id>/<token>/` の作品詳細ページだけを対象とする。
