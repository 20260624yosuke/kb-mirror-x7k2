# Helen 水着化 — 適合手順と合否の物差し（実装計画）

> [!warning] 未承認
> 本書は 2026-08-29 のブレスト（[[brainstorm-gf2-dusevnyj-bikini-to-helen]]）の結果をまとめた計画であり、
> **武田さんの承認を受けていない。** 成果物（Blend）は作っていない。

## 1. 目的と非対象

### 目的

ドルフロ2から抽出したキャラクターを Blender 上のオブジェクトとして扱う既存の導線を使い、
**ヘレンの体型のキャラが水着を着た作画資料**を作る。原作再現ではない。原作に該当スキンは存在しない。

ドナーは Dusevnyj SSR0101 の P3 衣装のビキニ上衣。受け手は Helen SSR0101。

### 目的でないもの

- 原作の見た目の完全再現。
- ハーネス（判定の仕組み）を作ること自体。ハーネスは成果物へ到達するための手段。
- 質感・材質・透過・照明・色。優先しない。ただし透過が輪郭や布面積を変える場合は形状問題として扱う。
- モーション。立ち絵に近い1状態でよい。姿勢の選定を工程の柱にしない。

### 非対象（今回やらない）

- Dusevnyj の白い透けブラウス。
- Dusevnyj の P3 下衣。下半身は Helen 自身の布を使う。
- 全モーション検査。

### 成果物の形

**Helen 全身1体。** 下半身は Helen 自身の既存の布。編集は上半身のみ。トルソーのみは禁止。

## 2. 確定した事実（2026-08-29 実測・画像は不使用）

すべて `intermediate/*/meshes/*.npz` を読み取り専用で測った。原本は変更していない。

### 2.1 Helen の体の構造

| 事実 | 数値 |
|---|---|
| 脚の肌 `P1_body_lod0#0` | Y 0.162〜0.957 |
| 上半身の肌 `cloth2_lod0_Flat#0` | Y 1.167〜1.478、1907頂点、3468面 |
| **腰・下腹部（Y 0.957〜1.167）** | **どの衣装構成でも肌の面が存在しない** |

**布を剥がして下の肌を出すことは原理的に不可能。腰は布で覆うしかない。**

### 2.2 腰の被覆に必要な submesh

高さ 0.95〜1.20m を 2cm 刻みで切り、中心軸から72方向の被覆率を測った。

| 残す布 | 最小被覆 |
|---|---|
| 肌だけ | 0.00 |
| P3 #0 だけ | 0.08 |
| P3 #1 だけ | 0.50 |
| P3 #3 だけ | 0.78 |
| **P3 #1 + #3** | **1.00** |

**残すべきは `P3_cloth_lod0` の #1 と #3。#0 は腰の被覆に寄与しない。**
（引き継ぎ資料 revision 3 の「#0/#1 がパンツ候補」という記述は、この実測で否定された）

`P3_cloth_lod0` の submesh 間で共有する開いた辺は **#0↔#3 の190本のみ**。
#3 を非表示にすると #0 の縁が190本開き、Y1.041〜1.059 に 197×184×196mm ほかの穴が生じる。

### 2.3 その他

- Helen の全 lod0 メッシュは `material: null` / `source: no_smr`。**材質名では肌と布を判別できない。**
- Sabrina の水着スキンの体は全身1 submesh（20043面/11315頂点・開いた縁367本）。
  着衣キャラの Helen とは体の作りが根本的に違い、手本にそのまま使えない。
- Helen 胴体半径の中央値 111.2mm / ドナー胴体 89.6mm。**スケール比 1.241。**
- 大きさを合わせた後も形の違いが残る（絶対値の中央値 29.3mm、95% 75.0mm）。
  一様拡縮では届かない。

## 3. 物差し（10項目）

**すべての距離は同じ測り方で測る。** 近い8点の逆距離重みで足元と法線を作り、法線方向へ射影する
（`make_field` / k=8 / eps=1e-4）。**制作側と判定側で測り方が違うと見かけの合格が出る**
（2026-08-29 に実際に発生し、合格を1度撤回した）。

| 記号 | 測るもの | 合格線 | 出どころ |
|---|---|---|---|
| G1 | 腰帯の角度被覆率 | 腰帯 1.00 | 原本の既知良好部位から較正 |
| G2 | 未許可の開口 | 0個 | 原本にもある切り口（首・肩・腕・足首・太腿）を許可リスト化 |
| G3b | 衣装の面積のうち体が20mm以内にある割合 | 69.05〜100% | 原作10組 |
| G4a | 体からの距離の中央値 | +2.66〜+5.41mm | 原作10組 |
| G4b | 1mm より深くめり込んだ頂点の割合 | 0〜5.3% | 原作10組 |
| G4c | 最も深い頂点 | −14.14〜−0.40mm | 原作10組 |
| G5 | 使用meshの SHA-256・面数・頂点数 | source-lock と一致 | 自明 |
| G6 | 各面の来歴タグ（donor / helen / fitted / created） | created が0 | 自明 |
| G7 | 辺の長さが10倍を超えた本数 | 0本 | 自明 |
| G8 | 面の裏返り・潰れ | どちらも0面 | 自明 |
| G9a | 部品ごとの厚み比の変化 | 0.95〜1.05倍 | 同じ衣装の別状態（Dorm/Fight）1組 |
| G9b | 隣り合う面の折れ角の中央値の変化 | 0.95〜1.05倍 | 同上 |
| G10 | ドナーの上衣をドナー自身へ着せ直す | 全頂点の移動 0mm | 自明（恒等写像） |

**G4a と G4b と G7 は必ず同時に見る。** 片方だけでは、もう片方を壊す方法が合格する
（距離だけで判定して上衣を引き裂く方法を合格させた事例あり）。

### 3.1 G3a を使わない理由

「体の面積のうち衣装が近くにある割合」（G3a）は、原作の中だけで 6.6%〜58.3% と振れる。
衣装の種類（ビキニか体を覆うブラウスか）で決まり、合否の線にできない。**G3b で置き換える。**

### 3.2 G4b を「0mm未満の割合」で測らない理由

表面に載っている状態（0〜0.6mm）と突き刺さっている状態を区別できない。
実例: ある設定は「0mm未満 24.0%」だが「1mm超 0.0%・最小 −0.59mm」で、原作のどれよりも浅かった。
**深さ1mm を基準にする。**

## 5. 適合手順（案N）

正本は `tools/helen_swimsuit_fit.py`。

1. **一様拡縮** 1.241（Helen 胴体半径の中央値 ÷ ドナー胴体半径の中央値）。
   上端（首の切り口）を Y1.387 → Y1.478 に合わせ、Z 中心を各体の中央値へ移す。
2. **目標距離** = ドナー原着装で各頂点が持っていた体からの距離（同じ測り方で取得）× 拡縮率。
3. **交互に解く**（80周 × 内部5回）
   - 局所: 各頂点の一円環について、元の辺ベクトルと現在の辺ベクトルの共分散を特異値分解し最適回転を得る。
     行列式が負なら最終列を反転して鏡映を排除する。
   - 大域: `(ラプラシアン + diag(バネ)) P = B + diag(バネ) 目標位置` を解く。
     **バネは場所ごとに変える。** 全体 1e-4、**意図より深く入っている頂点だけ 2e-3（20倍）**。
     バネが毎周変わるので毎周ごとに行列を作り直す。

### 5.1 なぜこの形なのか（採用しなかった方式と理由）

| 方式 | 落ちた理由 |
|---|---|
| 一様拡縮のみ | めり込み52.7%。体に沿わない |
| 高さ別拡縮 | めり込み49%。角度ごとの形が合わない |
| 半径表による対応づけ移送 | 辺が最大73倍に伸び、68辺が10倍超。半径表が遠くの面を掴む |
| 体表面どうしの直接対応づけ | 辺が最大61倍。距離指標が循環して評価不能 |
| 拡縮＋法線押出 | 42面が裏返る |
| 変位の大きさだけをならす | 裏返り490〜758面。向きをならしていない |
| 変位をベクトルでならす | 裏返りは消せるが被覆が届かない |
| 体をなめらかな場として扱う | 立体比は改善するが二面角2.3倍のまま |
| 差分座標だけを保つ交互法 | 面積比が0.31〜2.34と不均一。皺になる |
| 硬い押し戻し | 形が潰れる（立体比0.807・裏返り178面） |

### 5.2 現在の結果（拡縮1.241・バネ1e-4/2e-3・80周）

| 項目 | 値 | 判定 |
|---|---|---|
| G3b | 80.610 | ○ |
| G4a 中央 | **+8.330** | **✕（範囲 +2.66〜+5.41）** |
| G4b 1mm超 | 2.264% | ○ |
| G4c 最小 | −4.276mm | ○ |
| G9a 立体比 | 0.964倍 | ○ |
| G9b 二面角 | 0.998倍 | ○ |
| G7 辺10倍超 | 0本 | ○ |
| G8 裏返り / 潰れ | 0面 / 0面 | ○ |
| G10 自己試験 | 移動 0.0000mm | ○ |

**不合格は G4a の1項目のみ。全体に約3mm浮いている。**

手順は G10（答えの分かっている試験）に誤差ゼロで合格するので、これは手順の誤りではなく、
**形を保ったままこの上衣を Helen に着せると、自分の体に着るときより3mm多く浮く**という
体型差の帰結。もっと密着させるには、もっと変形させるしかない。

## 6. 絶対にやってはいけないこと

1. **合格線と成果を別の測り方で測らない。** 2026-08-29 に実際に起き、合格を1度撤回した。
2. **合格させるための調整値を入れない。** `bias+0.8mm` と `目標0.5倍` を入れて2度合格を作り、
   2度とも撤回した。後者は G10 に落ちた（原作を中央値3.64mm・最大14.41mm 壊す）。
3. **距離だけで判定しない。** 形（G7・G8・G9）を同時に見ないと、上衣を引き裂く方法が合格する。
4. **LLM がレンダー画像を見て判断しない。**（[[llm-vision-review-suspension-policy]]）
5. **原本を書き換えない。** `intermediate/` と原本 Blend は読み取り専用。
6. **層A（コード由来の事実）と層B（適合）を混ぜない。** 各面に来歴タグを付ける（G6）。
7. **却下済みの方向を再提出しない。** 提示前に
   `python3 tools/rejected_approaches_check.py <計画ファイル>` を通す。

## 8. 実装の段取り（未承認）

**Phase 1** 上下の構成を固定する。`P3_cloth_lod0` の #1・#3 を採用し、G1（腰帯の被覆1.00）と
G2（未許可の開口0）を全身で測る。ここまでは既存データの選択のみで、新しい面を作らない。

**Phase 2** 上半身へ案N を適用し、G3b〜G10 を測る。G4a が範囲外のまま出るはずなので、
その扱い（線を見直すか、より密着させるか）を武田さんの判断へ返す。

**Phase 3** 上衣の下端と腰の布の上端（Y1.120）を繋ぐ。ここで新しい面を作る場合は
G6 の `created` が 0 でなくなるため、`approximation` として別に承認を取る。

各 Phase の完了条件は「`helen_swimsuit_fit.py` が該当項目で ○ を返し、その出力が保存されていること」。
`tools/rejected_approaches_check.py` と G10 自己試験を通していない成果は完了扱いにしない。

- **一様拡縮だけで着せる案を落とした。** 手元でどう変わるか: 上衣が体に沈み、頂点の半分以上が
  体の中に入った状態になる。未確認: 見た目は確認していない（画像封印中）。戻せるか: 拡縮率を指定すれば再現できる。
- **「目標0.5倍」で合格させた版を落とした。** 手元でどう変わるか: その版はドナー自身の再現を
  中央値3.64mm・最大14.41mm 壊すので、原作の形が保証されない。戻せるか: 計画書に数値を残してある。
- **LLM の画像判読を工程から外した。** 手元でどう変わるか: 部品の視覚的な名前（どれがカップか等）が
  確定しないまま進む。判定は数値のみ。戻せるか: 方針は [[llm-vision-review-suspension-policy]]、恒久ではない。
