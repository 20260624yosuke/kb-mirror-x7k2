# X→Eagle保存観測 初回パイロット

## 問い

Eagle に保存された X 由来画像のメタデータ(投稿 URL・作者・反応数・保存日時・保存理由などの付随情報)を使い、武田さんが求めている「X で伸びる絵の傾向を読み、制作判断へつなげる」流れの初回プロトタイプ(試作品として小さく試す版)を作る。

消えた Codex セッションの文脈では、目的は単なる Eagle 整理ではなく、以下だった。

- X の傾向(今、何が伸びているかの流れ)を追う。
- 伸びた画像の共通点を見つける。
- 作者・キャラ・季節・構図・題材・投稿文などを単独順位ではなく組み合わせとして見る。
- 最終的には、自分の投稿が伸びる再現性を上げる判断材料にする。
- Eagle と wiki を相互作用的にし、Eagle は現物置き場、wiki は意味置き場として使う。

## 修正版計画

今回の対象は「X 全体」ではなく、**武田さんが直近で Eagle に保存した X 由来画像**である。母集団(今回見ている対象の集まり)が武田さんの保存行動で偏るため、X 全体の流行とは断定しない。

初回条件:

- Eagle ローカル API(Mac 内で動く Eagle の読み取り口)を使う。
- `x-...` 形式または注釈に `投稿URL:` を持つ Eagle 項目を抽出する。
- 1万いいね以上に絞る。
- 画像単位ではなく投稿単位で数える。同じ投稿の複数画像は 1 件にまとめる。
- 直近30投稿を上限にする。
- 画像は全件を軽く確認し、重要そうなものだけ深く見る。
- Eagle 側には書き込まない。タグ追加・注釈変更・フォルダ変更はしない。
- 初回は `wiki/analyses/` に観測として残す。2回使って形式が安定したら `wiki/builds/` 化やスキル化(毎回同じ手順で実行するための専用手順化)を検討する。

見る観測枠:

- 高反応で保存したもの。
- 低反応だが保存理由・資料価値があるもの。
- 保存理由と数字が噛み合うもの。
- 保存理由と数字がズレるもの。
- 資料として保存したもの。
- 5万いいね以上の強い例。
- 2.5万いいね以上の研究対象。
- 1万いいね以上だが、X 全体表示は強くても画像としての反応は弱い例。

## 伸び方の型

### 1. 絵として刺さる高反応型

`@wonbin_lee_`、`@6Yaoyue`、`@doeun_o_o` などは 5万いいね以上で、表示数に対するいいね比率も比較的高い。画像として見たとき、キャラ単体の強さ、肌・質感、顔まわり、画面中央の見せ場が強い。

この型は、武田さんの「バストアップ構図で 2.5万いくのは、肌感など何かが秀でているはず」という仮説に近い。今回の直近30件では、全身・半身・バストアップが混ざるが、露出や水着だけでなく、顔・目線・体型シルエット・色の抜けが一体で働いている。

### 2. 夏・水着・肌質感型

`@Exiadoon`、`@Furaidounko`、`@akitahika44`、`@suigetu26` など、水着・夏・肌を中心にした保存が複数ある。いいねは 2.2万〜3.8万台が多く、今回の「2.5万以上を研究対象にする」基準と噛み合う。

この型は、武田さんが会話中に言った「夏の水着イラストが多くなってきた」「季節やコンテンツの新衣装で盛り上がっているのでは」という観測を支える。X 全体の断定ではないが、武田さんの保存分では明確に水着・夏・肌質感が目立つ。

### 3. SNSバズ型

`@3124km2apmxa`、`@AzaraShibainu`、`@kitanniy`、`@football_gpt` などは、表示数が非常に高い一方で、表示数に対するいいね比率は低い。たとえば `@football_gpt` は 9.8万いいねだが表示は 2100万超で、比率としては低い。

これは「X のアルゴリズムに乗った」投稿の観測として有用だが、絵作りの参考とは分ける必要がある。制作判断へ直接返すより、投稿文・ネタ性・引用されやすさ・社会的共有の型として扱う方がよい。

### 4. 保存理由と数字のズレ型

`05_服装_コスプレ_01` の実写・コスプレ系や、画像未表示の一部項目は、いいね数だけで見ると 1万〜2万台だが、表示数が多いものがある。これは「見られているが、画像として強く反応されているとは限らない」候補である。

一方で、資料価値は別である。メイド服・水着・ポーズ・衣装構造の参考として保存したものは、数字が低くても制作資料として意味がある。ここを混ぜると「伸びる絵の分析」と「資料集め」が混線する。

## 数字から見える補助仮説

武田さんは「いいね数の十分の一くらいがリポスト数になりがちな気がする」と言っていた。今回の30投稿では、リポスト数 / いいね数は多くが 5〜12% 台に収まり、肌感としてはおおむね支持される。

ただし、投稿の種類でかなり変わる。

- 絵・キャラ系: だいたい 5〜12% 台が多い。
- 水着・構図が強い絵: 8〜12% 台のものがある。
- ゲーム制作・ネタ共有型: 16% 台の例もある。
- テキストミーム・実写系: 低いものもある。

したがって、リポスト比率は主役ではなく、**拡散されやすさを見る補助指標**として使うのがよい。

表示数に対するいいね比率は、今回かなり有用だった。

- 絵として刺さっていそうな投稿: 10〜18% 台のものがある。
- 大きく表示されたネタ・実写・話題投稿: 0.5〜1% 台のものがある。

これは「表示されたから伸びた」と「見た人に強く刺さった」を分ける手がかりになる。X の画面表示由来の丸め数値なので厳密な統計ではないが、観測には十分使える。

## 制作への短い含意

今回の初回観測では、制作判断に近いのは以下。

- 水着・夏・肌質感は、武田さんの保存分では明確に複数回出ている。
- 1万いいね以上だけだと対象が広すぎるため、制作向けには「2.5万以上 + 画像として反応率が高い + 保存先が肌/水着/構図/キャラ系」を見る方がよい。
- `04_snsバズり_01` は重要だが、制作資料ではなく「X 上で広がる形式」の観測に分ける。
- 次に制作レシピ化するなら、`@suigetu26`、`@wonbin_lee_`、`@6Yaoyue`、`@doeun_o_o`、水着系 3件を中心に、顔・肌・水着・画面中央の見せ場を比較するのがよい。

## 未確定・注意

- 数値は X 画面表示由来の丸め表示であり、厳密な統計ではない。
- 今回は武田さんの Eagle 保存分だけなので、X 全体の流行とは断定しない。
- 画像未表示の2件は、Eagle の項目 `url` が投稿 URL になっており、画像 URL として読めなかった。
- 作者・キャラ・作品の確定は今回していない。必要なら別途、X 投稿本文や既存 wiki source に戻って確認する。
- NSFW 系フォルダ名があるが、今回の観測では露骨な描写の詳細分析はせず、構図・肌・水着・反応傾向に留めた。

## 次回の改善

2回目を行うなら、同じ形式で以下を追加する。

- 「イラスト/漫画/コスプレ/実写/ネタ画像」を先に分ける。
- 制作向け対象は、`04_snsバズり_01` と分けて集計する。
- 画像として刺さった投稿は、いいね/表示比率を補助指標にする。
- `llmwiki__trend__summer-swimsuit` のような Eagle 返却タグは、まだ付けない。2回目も同じ傾向が出てから判断する。

## ユーザーレビュー(2026-06-23)

武田さんは成果物を確認し、「有益な発見はなかった」「ピンとこない」と評価した。

この時点での反省は以下。

- 初回成果物は「読んだ記録」としては成立したが、「次の絵に効く発見」には届かなかった。
- `1万いいね以上` という条件は、絵・漫画・実写・ネタ・コスプレ・SNSバズを混ぜるには広すぎた。
- 数字・保存先・画像印象を並べたが、武田さんが保存した理由そのものを中心にできていなかった。
- 「水着・夏・肌質感が多い」「SNSバズ型と絵として刺さる型を分ける」程度では、武田さんにとって新しい判断材料にならなかった。
- Codex 側の次案として「水着絵だけ10件比較」を出したが、それも武田さんにはピンと来なかった。

したがって、このパイロットの次段階では、単に条件を狭めるだけではなく、問いの立て方自体を見直す必要がある。特に「何を見れば武田さんの制作判断が変わるのか」「保存時点の違和感・興味・仮説をどう取り出すのか」「X の数字を主役にするのか、武田さんの保存意図を主役にするのか」を再検討する。
