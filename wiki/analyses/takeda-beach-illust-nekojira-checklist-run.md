# 1.9 万いいね作の Nekojira ch03 チェックリスト試運転

> 試運転の目的: [[nekojira-feedback-checklist]] が実用に耐えるか、既存分析 [[takeda-beach-illust-contrast-analysis]] で対象が言語化済みの 1 枚に対して走らせて検証する。

## 検証条件(精度の前提)

- **対象画像本体は `raw/` 未配置**。[[takeda-beach-illust-contrast-analysis]] のテキスト記述から像を再構成して判定している。ピクセル単位の検証(実黒塗りシルエットテストなど)は原理的に不可
- **Layer 0(意図宣言)は遡及推測**。本来 user 本人の宣言が必要。判定文中で「[推測]」と明示
- 描画工程・線画段階の情報なし → Layer 3.4 は判定不能でスキップ

## キャラ絵フィードバック(Nekojira ch03 ベース)

### Layer 0: 意図確認(遡及推測)

- 宣言された性格: **[推測] 明るく健康的で親しみやすい(○ 寄り)**。Blue Archive ファンアート + ピンナップという文脈から、攻撃性 / 知性側ではなく「近づきたくなる」軸
- 主題: **[推測] 身体(胸〜胴の局所コントラストが最強)、第 2 ゾーンが顔**。意図的選択かは不明 — [[takeda-beach-illust-contrast-analysis]] では「水着の色がたまたま最強コントラストになった」疑い指摘済
- 鑑賞サイズ: **X タイムライン(スマホ縦)前提**で機能。サムネで暖寒対比が刺さるのが第一インパクト

⚠️ **本来この段階を user が宣言していないこと自体が、後続全項目の判定信頼度を下げる**。次回からは描き始める前に Layer 0 を紙に書いて欲しい。

---

### Layer 1: 形態(Shape language)

- **1.1 形要素の方向一致 [✅]**:
  - 髪(長い曲線)/ 体(ピンナップ姿勢の柔らかな曲線)/ 水着(体に沿う曲線)/ Blue Archive ヘイロー(円) — **キャラ本体の主要形要素は ○ で一貫**。「親しみやすさ + 健康的」の宣言(推測)と整合
  - 環境側のヤシ葉・幹は △(鋭い葉先・直線的な幹) — これは背景なので主役の形メッセージを破壊しない、むしろ環境=△、キャラ=○ で**対比構造を形態言語でも作っている**
  - 出典: [[shape-personality-map]] ○ = Cute / Softness / Friendly のマッピング、章 03 0:22

- **1.2 形の反復警告 [⚠️]**:
  - 形態言語レベル(円要素の反復)は「ピンナップ = 曲線美」のジャンル要請として意図的、問題なし
  - ただし **左右に垂れる長髪のマスが似た形で繰り返し** — これは形態より [[silhouette-check]] の「繰り返し回避」原則違反。Nekojira 章 03 の警告(3:28)とも整合する弱点
  - [[takeda-beach-illust-contrast-analysis]] でも同じ箇所が指摘済 → 2 つの分析レンズが同じ弱点を捕まえた = **両軸で一致する真の弱点**

- **1.3 目の形 [✅]**:
  - Blue Archive 系は丸い大きな瞳孔が定番 = ○ 寄り、親しみメッセージと整合
  - シアンの瞳ハイライトが強調点として効く
  - 章 03 2:21「目を四角く形に変えるだけで本をたくさん読むような静かで考え深い印象」の逆 — 目が ○ のままだから「活発・親しみ」が維持されている

- **1.4 装飾品の整合 [✅]**:
  - シュシュ(髪留め)= 円、水着 = 曲線、ヘイロー = 円。**キャラ周りの小物が全部 ○ で固められている**
  - これは無自覚なら奇跡的、意図的なら超優秀。**user 本人に確認したい**: シュシュの形は意識して選んだか?

---

### Layer 2: シルエット可読性

- **2.1 黒塗り 30 秒テスト [✅ ただし条件付き]**:
  - 実テスト不可だが推定: 全身を黒塗りしても「水着の女性」までは伝わる(腕を上げた姿勢 + 長髪 + 腰のくびれ)
  - **「Blue Archive のキャラ X」までは伝わらない** — これはキャラ識別性の問題で、Nekojira ch03 の射程外(キャラデザのアイデンティティ問題)。章 03 では「猫とわかる」「鳥とわかる」までで OK
  - 章 03 4:09 のスズメ NG 例にはなっていない

- **2.2 重要部位の重なり [⚠️]**:
  - 上半身: 上げた腕と頭の間に明確な抜き(逆三角ネガティブ)= ○、伸ばした指のジェスチャーで指先輪郭が立つ = ○ — [[takeda-beach-illust-contrast-analysis]] でも「シルエットの見せ場」と評価
  - 下半身〜脚: **あおり構図で身体が中央の縦長マスとして塊化**するリスクあり。胸・腹・腰の境界はシルエットでなく**内部明度差で見せている**(水着の中明度が肌に局所コントラストを作る、という [[takeda-beach-illust-contrast-analysis]] §3 の指摘そのもの)
  - つまり**シルエットの見せ場は上半身に集中、下半身はシルエット非依存**。これは意図的なジャンル選択なら可、無自覚なら下半身は「見せていない」状態

- **2.3 横向き検討 [✅]**:
  - ピンナップは正面〜やや斜めがジャンル要請。章 03 4:21 の「正面 = 部位重なる」リスクを承知の上で選んだ形(と仮定)なら正解
  - ただし「正面リスクを認識した上で選んだ」と user が宣言できるか?が再現性の鍵

- **2.4 付属物のシルエット [✅]**:
  - ヘイロー = キャラから浮く位置 → シルエットに溶けない
  - 髪 = 体と接続するが、ロングヘアの流れで体と髪のマスが識別可能(色が違うだけでなく形が違う)
  - 例外: 上述の左右垂れ髪の形反復(2.2 と 1.2 で既出)

---

### Layer 3: ネガティブシェイプ

- **3.1 見せたい部位の周囲の空白 [⚠️]**:
  - **上半身**: 腕-頭間の逆三角ネガティブ = 強力に機能、指先周囲もジェスチャーで空白あり → ✅
  - **胴体周囲**: 主題(推測)が「身体」なのに、胴体の周囲は環境(空・葉)と密着気味で**意図的な空白の設計はなさそう**
  - 章 03 5:07「重要な部分の周りに意図的に空白スペースを残す」基準で見ると、上半身は満点、胴体は **設計不在**

- **3.2 空白の形の魅力 [✅]**:
  - 腕-頭間の逆三角は形として強い、視線を引きつける
  - 前景植物のぼけによる空間 = 点要素として効く(これは [[mitsudo-management|余白の埋め方]] 側の話)

- **3.3 ネガティブが形メッセージを補強 [⚠️ → 発見項目]**:
  - キャラ = ○(親しみ・柔らかさ)
  - 腕-頭間のネガティブ = **逆三角 = △**(鋭さ・動き)
  - つまり **円キャラに鋭い空白が入っている** — 形メッセージとは矛盾するが、これがピンナップのセクシーアクセント / 視線吸引力として機能している可能性
  - これは [[takeda-beach-illust-contrast-analysis]] では検出されなかった発見。Nekojira 軸の収穫
  - 意図的なら超強い設計、無自覚なら**ここを意識化することが再現可能技術への変換ポイント**

- **3.4 線画段階の混み [-]**:
  - 線画情報なし、判定不能

---

### Layer 4: 整合性

- **4.1 形メッセージ × 可読性 [✅]**: 円キャラ + 人型可読 = 矛盾なし
- **4.2 形メッセージ × ネガティブ [⚠️]**: 3.3 の通り、○ キャラに △ ネガティブの二重性。**意図的ならピンナップの強さの源泉、無自覚なら再現性なし**
- **4.3 表情・配色・小道具 × 形メッセージ [✅]**: 暖肌・健康色・大きな丸瞳 → 全部 ○ メッセージと整合。色彩設計の詳細は [[takeda-beach-illust-contrast-analysis]] 参照

---

## 次のラフで 1 つだけ直すなら

> **Layer 3.1 / 4.2 の意識化**: 主題が「身体」なら、胴体周囲のネガティブを意図的に作る。具体策 = (a) 片腕をもっと体から離して胴体側面に空白を作る、または (b) 背景の暗要素(ヤシ葉)を胴体側まで降ろして「キャラ胴体 vs 葉の暗マス」のネガティブ境界を作る。
>
> + 隠れた発見: **腕-頭間の逆三角ネガティブ(○ キャラに △ ネガティブ)が視線吸引の隠しエンジン**。次回からこれを意識して、円キャラには必ず 1 箇所だけ鋭いネガティブを作る癖をつけると、無意識の強さが再現技術になる。

## 精度評価(チェックリスト試運転の本体)

### Nekojira 軸が対比軸では見えなかったもの(= 軸の独自価値)

| # | 発見 | 既存分析での扱い |
|---|---|---|
| 1 | **キャラ本体の形要素が全部 ○ で一貫している統一感**(髪・体・水着・ヘイロー・シュシュ・瞳) | 対比軸では色温度・明度の話に終始、形態言語の話は出ていなかった |
| 2 | **環境 = △ / キャラ = ○ の対比構造が形態言語レベルでも成立**している | 「補色対比」「暖寒対比」までは見えていたが「形態対比」は未言語化 |
| 3 | **腕-頭間の逆三角ネガティブが視線吸引の隠れエンジン**(○ キャラに鋭い △ 空白の二重性) | 対比軸では空白でしかなかった。形メッセージとの**矛盾性**こそが強さの源と捉え直せる |
| 4 | **上半身はシルエット主導、下半身は内部明度主導**という二段構造の分離 | 対比軸では「胸の局所コントラスト」までで、シルエット主導 vs 明度主導の境界線は言語化されていなかった |

### Nekojira 軸でも対比軸でも一致した弱点(= 真の弱点)

- 左右に垂れる長髪のシルエット反復 — Nekojira 1.2 と Ye Jji [[silhouette-check]] の繰り返し回避原則が**両方とも引っかけた**。これは最優先で再現性を持って直すべき項目

### Nekojira 軸では見えないもの(= 軸の射程外)

- 色彩設計(対比軸の本領)
- 明度ヒエラルキー(対比軸の本領)
- 視線誘導の数値的設計
- 量感・テクスチャ
- キャラ識別性(「Blue Archive のキャラ X」までは届かない)

→ **結論**: Nekojira ch03 軸は「形のメッセージ設計と読みやすさ」専用の補助レンズ。対比軸と**組み合わせて初めてフルカバレッジ**になる。これは想定通りの結果で、軸の重複(無価値)でも軸の競合(混乱)でもない、**直交軸として機能していることが検証できた**。

## チェックリスト改版の必要点(精度試運転からの差分)

実走させて気づいた、[[nekojira-feedback-checklist]] への追加・修正提案:

1. **Layer 0 の重要度を強調する文言を追加**: 「意図宣言なしでも判定は走るが、信頼度が下がる」と明記。今回の遡及推測で Layer 1〜4 の判定の半分以上が「[推測] 親しみやすい」を前提にしている。意図が違えば判定が全て覆る
2. **Layer 1.4 に「装飾品の形」の独立項目を追加**: 今回シュシュ・ヘイロー・水着の形要素が全部 ○ で揃っている発見は重要。チェックリストに「アクセサリー/小物の形を列挙してメッセージ整合を確認」を追加すべき
3. **Layer 3.3 に「意図的二重性」のスコア区分を追加**: 「○ キャラに △ ネガティブ」のような形メッセージとネガティブの矛盾は、無自覚なら整合性低下だが**意図的ならアクセント強化**。この二択を明示的に user に問う設計に変える
4. **Layer 2.1 の射程注記**: 「キャラ識別性は射程外」と明記。「人型として読めるか」までで OK、「あのキャラだとわかるか」は別レイヤー
5. **「シルエット主導 vs 内部明度主導」の上下半身分離**は Nekojira ch03 にない概念だが、ピンナップ系ではよく出るパターン。次の章を取り込んだ時に拾えるかチェック
