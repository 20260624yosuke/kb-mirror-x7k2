# 長乳の構造把握と描画整理

## 現在の回答

ここでの「長乳」は、単に胸を大きくすることではなく、乳房の量感が **縦方向または前方向に伸びた状態** として扱う。成人キャラクターの誇張表現を前提に、性的場面の説明ではなく形体設計として整理する。

## 構造モデル

1. **土台**: 胸郭は卵型 / 釣鐘型の立体。胸の向きは胸郭の前面・側面・下面の向きに依存する。
2. **支持面**: 大胸筋は鎖骨・胸骨側から上腕骨へ集まる扇状の土台。乳房は大胸筋そのものではなく、その上に乗る柔らかい量感。
3. **乳房本体**: 水風船モデルで考える。付け根は胸郭に固定され、先端側・下側・外側が重力や圧迫で流れる。
4. **長乳らしさ**: 乳房の重心が胸郭から遠い、または低い。丸い球ではなく、付け根から先端までの「流れ」が見える。

## 3タイプ

- **前方突出型**: 横から見た奥行きが長い。服越しでは砲弾・水袋・楕円柱に近い。下辺は張り、上面はなだらか。
- **下垂型**: 重心が下に落ちる。上胸は薄く、下側に質量が溜まり、乳頭位置も低くなりやすい。
- **横流れ型**: 仰向け・開脚・腕上げなどで外側へ広がる。左右の胸が中央から離れ、付け根から外へ流れる。

添付例で言うと、1枚目は服越しの前方突出型、3枚目は仰向けの横流れ型、4枚目のラフは手で支えたときの下垂 / 横流れ混合として読むと整理しやすい。

## 描く順序

1. 胸郭の中心線と左右の胸郭面を取る。
2. 鎖骨・胸骨・脇下で、胸の付け根の範囲を決める。
3. 乳房を球で置かず、付け根から先端へ伸びる雫形 / 楕円体で置く。
4. 重心点を先に決める。長乳では重心点を「胸郭から遠く」または「低く」置く。
5. 下辺の張り、谷間の近接影、脇側の接続を最後に整理する。

## 破綻しやすい点

- 付け根を狭くしすぎると、胸が胴体に貼り付いた球に見える。
- 左右を完全な同型にすると、柔らかさより記号感が勝つ。
- 乳頭だけを外側に置くと、胸全体の軸と矛盾する。乳頭は「乳房軸の先端側」に乗せる。
- 谷間の線を濃く描きすぎると、構造ではなく線記号になる。谷間は近接影、下辺はフォームシャドウとして分ける。
- 服越しの長乳では、乳房そのものより布のテンション線・肩紐・アンダーの締め付けが形を説明する。

## 練習メニュー

- 同じ胸郭に、前方突出型 / 下垂型 / 横流れ型を 3 つ描き分ける。
- 乳房を「球」ではなく「付け根付き水袋」として、重力方向だけ変えて描く。
- 服ありでは、輪郭線より先に、肩紐・アンダー・布の張り方向・食い込み影を置く。
- 仕上げでは、胸の柔らかい面はソフトエッジ、谷間や接触部はシャープエッジに分ける。

## 矛盾・未確定

- 「長乳」は既存 source 由来の用語ではなく、添付例と既存 concept を組み合わせた描画上の仮整理。
- 目標が「リアル寄り」か「誇張フェチ寄り」かで、付け根幅・下垂量・乳頭位置の許容量が変わる。
