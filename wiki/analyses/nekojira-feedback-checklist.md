# Nekojira フィードバックチェックリスト(章 03 派生)

## 目的

[[takeda-yohsuke]] が描いたキャラ絵を見せた時に、Claudian が **[[coloso-nekojira-ch03-shape-intro|Nekojira 章 03]] の枠組みで具体的に指摘する**ための質問リスト。「シルエット大事ですよね」のような曖昧な反応を排し、必ず **(該当 Nekojira 概念, 文字起こしのタイムスタンプ, PSD レイヤー or 主要スライドへの参照)** をセットで返すことを強制する装置。

このチェックリストは Nekojira 章 03 のみから導出される暫定版。後続章を取り込むたびに **追記・修正される**。

## 使い方(私 = Claudian の動作)

1. user がキャラ絵を提示したら、まず **Layer 0(意図の確認)** を user に問う
2. Layer 1〜4 を順に走査し、各項目について「✅ / ⚠️ / ❌」を判定
3. ❌ ・ ⚠️ には必ず Nekojira の出典 + 救済テクニックを併記
4. 最後に **「次のラフで 1 つだけ直すなら」** を 1 行で提示(優先度付け)

---

## Layer 0: 意図の確認(user に聞く)

絵を見る前に、または絵と一緒に確認:

- [ ] このキャラの **性格を一言で**(優しい / 知的 / 活発 / 攻撃的 / 危険 / 守護者 / ...)
- [ ] **主題はどこか**(顔 / 全身ポーズ / 武器 / 服のディテール / 場面のドラマ)
- [ ] 想定鑑賞サイズ(X タイムライン / フルサイズ / スマホ縦)

**意図が決まっていないと残り全項目が判定不能になる。** これは Nekojira の枠組みの大前提([[shape-personality-map]]:「1 つ宣言してから描く」、[[silhouette-readability]]:「重要部位を 1 つ決める」)。

## Layer 1: 形態(Shape language)— [[shape-personality-map]]

| # | 項目 | NG だった時の返し |
|---|---|---|
| 1.1 | 宣言した性格と、輪郭・髪型・目・服シルエットの形要素の方向が **過半数で一致**しているか? | 「親しみやすい」宣言だがツノ・棘・鋭角髪が散在 → 章 03 0:22 と PSD `01_shape.png`(○ vs △ の差)を参照。アクセント以外の三角は丸要素に置き換え提案 |
| 1.2 | 同じ形を全身で **反復しすぎ**ていないか? | 章 03 3:28 警告。アクセント比率 1〜2 割を目安に対極の形を 1 箇所だけ入れる |
| 1.3 | **目の形** は性格と整合しているか?(○ = 親しみ / □ = 知的・静謐 / △ = 攻撃的) | 章 03 2:21 + PSD `Shape/2/square eyes` レイヤー(leaves 048–052)。目を 1 段ずらすだけで人格が変わる事実を提示 |
| 1.4 | 服 / 装飾 / 武器の形が、キャラ本体の形メッセージと **矛盾していない** か? | 例: 円キャラに直線的な甲冑 → 「保護者キャラ」「内面と外殻のギャップ」など意図的なら可、無自覚なら整理 |

## Layer 2: シルエット可読性 — [[silhouette-readability]]

| # | 項目 | NG だった時の返し |
|---|---|---|
| 2.1 | 内部を全部黒で塗りつぶして外形だけにした時、**キャラの種別・ポーズ・武装** が即座に伝わるか? | 章 03 4:09 のスズメ例。30 秒テスト推奨。「これは [[silhouette-check]] の Ye Jji 流複雑化以前の段階。まず可読性」 |
| 2.2 | **重要部位**(顔・拳・武器・特徴アイテム)が他部位と重なっていないか? | 章 03 4:46。「肩 / 拳 / 頭が押し合っている」状態。ポーズ調整で引き離す案を 2〜3 提示 |
| 2.3 | 正面ポーズの場合、横向きにすることでシルエットが改善するか **検討した**か? | 章 03 4:21。「正面を選んだ意図(対面性・カリスマ性)があるなら可。なければ横向きラフも 1 枚試そう」 |
| 2.4 | 武器・しっぽ・翼など **付属物のシルエット** は体と一体化していないか? | ネガティブシェイプで分離([[negative-shape]] へ) |

---

## Layer 3: ネガティブシェイプ — [[negative-shape]]

| # | 項目 | NG だった時の返し |
|---|---|---|
| 3.1 | **見せたい部位を 1 つ**決め、その周囲に意図的な空白があるか? | 章 03 5:07 + 主要スライド 3。「拳を見せたいなら拳の周りに空白。腕を体に貼り付けると死ぬ」 |
| 3.2 | その空白 **の形自体** に魅力があるか?(ただの「余り」になっていないか) | 章 03 5:23 の女性キャラ例。「空白を意識して整形」提案 |
| 3.3 | ネガティブシェイプが [[shape-personality-map\|形メッセージ]] を **補強** しているか?(円キャラなら丸い空白、三角キャラなら鋭い空白) | 整合性チェック。これが揃うと「絵全体の言語が一貫している」状態 |
| 3.4 | 線画段階で **混みすぎてネガティブが死んでいる**箇所はないか? | 引き算の提案。ライン削除でネガティブ復活 |

---

## Layer 4: 整合性(横断チェック)

| # | 項目 | NG だった時の返し |
|---|---|---|
| 4.1 | Layer 1(形メッセージ)と Layer 2(可読性)が矛盾していないか? | 例: 「親しみやすい」のに拳が体に埋没 → 可読性側を先に直す |
| 4.2 | Layer 1 と Layer 3(ネガティブ)が矛盾していないか? | 「攻撃的」キャラに丸い空白だけが目立つ → 空白の形を鋭く |
| 4.3 | 表情・配色・小道具が形メッセージと矛盾していないか?(章 03 範囲外だが、後続章で詳細化される予定) | TODO: 後続章取り込み待ち |

## このチェックリストの未検証点 / 限界

- **章 03 のみ由来**。色 / 明度 / 量感 / 線画 / ポージング詳細などは未カバー。Ye Jji 講座の [[me-do-tai-hi]] [[silhouette-check]] [[mitsudo-management]] と組み合わせる必要あり
- 「アクセント比率 1〜2 割」のような数値は Nekojira からは出ていない私の推測。実運用で要検証
- user の絵を 1 枚見るまでは **このリスト自体が機能するか分からない**。プロトタイプとして提示し、初回適用後に項目を増減する

## 残った問い

- このチェックリストで実際に user の 1.9 万いいね作 ([[takeda-beach-illust-contrast-analysis]] の対象)を再評価したら、何が引っかかるか? 過去作レトロ分析の価値あり
- Nekojira 後続章を取り込むたびに新概念(おそらく「比率」「ボックス」「人体」「シワ」)が増える。チェックリストの **Layer 数を増やすか、章別チェックリストを並列で持つか**は要設計判断
