# 成長志向のキャラ絵師(X 中堅)が Ye Jji 講座から得られるもの

## 問い

X (Twitter) で活動するキャラ絵師(フォロワー 3000・直近で 1.9 万いいねを獲得)が、さらに成長したい場合、[[coloso-ye-jji-illustration-course]] から具体的に何が得られるか。

## 回答(要約)

最大の収穫は「**再現性のための語彙**」。1.9 万いいねは技術差ではなく**視線設計が偶然うまくいった 1 枚**である可能性が高く、講座の [[wan-sei-do]] (= [[shi-sen-yu-dou]] × [[de-te-ru]]) という二元論はこの偶然を**意図に変換するメンタルモデル**を提供する。次点で重要なのは、フォロワー数と仕事獲得を切り分けて語る Section 8 ([[coloso-ye-jji-ch23-outro]]) のポートフォリオ戦略章。「フォロワーを増やすだけでは仕事は来ない」という講師の直接的言明と、目標会社別の具体的戦略表が含まれる。

## 詳細

### 1. 完成度の再定義 — 「描き込めば良い」からの脱却 (最重要)

[[wan-sei-do]] の核心は、章 02 で実演される「**描写を増やさず明度対比だけで完成度を引き上げる**」こと。

> 完成度の高いイラストとは、視線誘導の緻密な計算と描写のディテールを備えたイラストです。
> ― [[ye-jji]] @ [[coloso-ye-jji-ch01-intro]]

**3000 フォロワー帯での効き方**: 平均値の底上げ = いいね下限が上がる = 月単位の成長曲線が変わる。バズの再現性が出る。

### 2. 明度対比 = X のフィードでスクロールを止める力

Section 2 で扱う [[tai-hi]] の 4 種のうち、講師は [[me-do-tai-hi|明度対比]] を最重要と位置付ける。

X はサムネイル → タップで判断される媒体なので、**サムネイルでも崩れない明度設計**は直接的にエンゲージメントへ変換される。塗り順 ([[coloso-ye-jji-ch15-shadow-area]] → [[coloso-ye-jji-ch16-highlight]] → [[coloso-ye-jji-ch17-shadow-detail]]) で**設計プロセス自体を分解**できる。

### 3. Section 4 の「密度」と「余白」 — 中級者の壁を破る最小ペア

- [[mitsudo-management]] = [[coloso-ye-jji-ch09-density]] 「密度を下げる」+ [[coloso-ye-jji-ch10-blank]] 「余白を埋める」
- 「描き込み量を調整して主題を浮かす」というプロっぽさの正体に当たる節
- 中堅の典型的詰まり方 (全部描き込んで主題が埋もれる / 余白が不格好) への直接処方

### 4. 終章のポートフォリオ戦略 — フォロワー数の呪縛から外れる

[[coloso-ye-jji-ch23-outro]] における講師の明言:

> 単にフォロワーを増やすだけでは仕事は簡単には来ません。自分がどんな仕事を受けたいのか目標を設定すること。

案件種別別の戦略 (ch23-outro より):

| 目標 | 戦略 |
|---|---|
| 特定ゲーム会社の CG | そのゲーム / 似た雰囲気を多数描く。**SNS 反応は不要** |
| VTuber 関連 | **ファンの少ない VTuber のファンアート**で名前を売る |
| 服ブランド / 産業 | **オリジナルキャラ**(版権が自分にある)で運営 |
| 広告 | 流行ジャンルを素早く描いてフォロワー増 |

> 比較的人気のないジャンルは SNS での反応が少ないのは確かでしょう。しかしその分野で名前を知られるのはメジャージャンルより簡単です。そのため比較的仕事も入りやすいです。

1.9 万いいねの実績は強いカードだが、**それが仕事依頼へ変換されるかは別問題**で、講師はその分離を明確に語っている。

### 5. 4 サブスキル分解 — 自分の弱点を診断する地図

[[four-sub-skills]] = 色遣い / ドローイング / 比例感 / 観察力 への練習分解。注目点:

- **ドローイング**: 「30 秒クロッキーだけでは不十分」「曲線の極率変化を 1 つ 1 つ数える」
- **観察力**: 写真と同クオリティで写真を模写を 1〜2 度。頻度低くて良い

中堅で停滞する人に「クロッキーは続けてるが伸びない」が多い → 講師はこれに「曲線練習が抜けている」と明確に答える。

## 講座が与えないもの(対称性のため)

- **構図論はほぼ含まれない** ([[coloso-ye-jji-illustration-course]] 個人的所感)。視線誘導と構図は別概念扱い。
- **講師個人スタイル比率が高い**。「私の基準では」頻出 → 普遍法則と個人の好みを峻別して読む必要あり。
- **キャラ単体の描写理論**が中心で、X 戦略・SNS 運用ノウハウは終章のみ。

## あなたの位置からの ROI 順序

3000 フォロワー / 1.9 万いいね の中堅 X キャラ絵師に対して、ROI が高い順:

1. **Section 2 (対比)** — バズの再現性
2. **Section 4 (密度・余白)** — 平均値の底上げ
3. **Section 8 (ポートフォリオ戦略)** — フォロワー → 仕事の変換戦略
4. **Section 3 (量感・質感)** — 手を動かす段階での地図
5. **実践パート (色塗り 7 工程)** — 同上
