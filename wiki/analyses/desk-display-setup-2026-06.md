# デスク環境（液タブ + サブモニター上下スタック）アップデートの設計詰め

> [!note] 根拠レベル
> 本ページは grill-build による設計詰めの結果。機材構成・症状・実検証結果は **武田さん本人の申告（user-stated）**。
> 製品仕様（VESA 対応可否・耐荷重・M1 Mac mini の表示上限など）は 2026-06 時点の Web 公開仕様を参照（source 的）。
> 最終的な機材選定・購入・セットアップは未実施のため `status: uncertain`。

## 問い

液タブ（Huion Kamvas Pro 24）を急角度で使うため、サブモニターは上下スタックの「上」に置かれ
見上げる位置になる。これをもっと見やすくしたい。液タブ不使用時はサブを手前に出して使う、
その2モード運用も快適にしたい。改善アプローチを整理したい。

## 機材構成（user-stated）

- **液タブ**: Huion Kamvas Pro 24（約 6.3kg / VESA100）。アーム = **快適ワークス iggy LS112**（使用感良好）。
  急角度（立てた角度）で使用。
- **サブモニター**: **HP M27f**（27型 FHD / 約 2.9kg）。※当初「Dell m27f」と認識していたが Dell に該当機なし。
  HP M27f が該当（実機ロゴ要確認）。
- **PC**: M1 Mac mini。現在 Kamvas + M27f = **2枚**。
- 運用: 2本の別アーム。液タブ不使用時は液タブを横にずらし、サブを手前に出す。

## 不満（2点）

1. 上下スタック時、サブの位置/角度が決めにくい。**上下に動かすと画面の水平アングルがズレる**。
2. 液タブ使用/不使用の2モード切替・位置決めが快適でない。

## 検証で切り分けた原因（重要・user-stated）

- 廉価アームを **iggy LS112 級に替えても固定できなかった** → **アーム単体は主因でない**。
- アダプタの**ガタは無い**（両面テープで強固に接着、剥がれ防止に保護フィルムを一部残すほど）→ **ガタも主因でない**。
- **HP M27f はネイティブ VESA 非対応**。クランプ/テープ式アダプタで「無理やり VESA 化」している。
  → 残る最有力原因は **アダプタの VESA 面が画面と直角・平行に出ておらず、基準面そのものが傾いている**こと。
- **M1 Mac mini はネイティブ最大2枚**（HDMI×1 + USB-C/TB×1）。現在すでに上限 → **3枚目は不可**
  （要 Mac 買替 or DisplayLink）。

## 現在の結論：問題を2つに分離する

- **問題A（本丸）**: サブの水平/角度が決まらない・見にくい。→ 解決可・最小コスト。
- **問題B（別物）**: 3枚ディスプレイ運用。→ 問題A を解決せず、配置問題を悪化させうる。Mac 依存。要切り離し。

## 推奨アプローチ：フェーズ分離

### フェーズ1（今 / 問題A の根本解決）

- **HP M27f → VESA ネイティブの27型に買い替え**（推奨: 1440p IPS、sRGB そこそこ良、VESA100、
  重量が iggy LS112 の耐荷重 2〜20kg に収まる＝ほぼ全機種 OK）。現 M27f は FHD で27型だと粗く、解像度も底上げ可。
- **既存の iggy 級アームを流用**（新規アーム購入は不要。原因はアームでないため）。
- M27f は**アーム運用から引退**（非 VESA で構造的に筋が悪い）。スタンド運用で別用途 or 手放す。
- セットアップ指針:
  - 液タブモード時: サブを**クリアランスぎりぎりまで下げ**、画面を**下向きにチルト**して目線に正対させる。
    VESA ネイティブ化で水平が出るのでこの追い込みが効く。
  - 低コスト実験: 上下固定は「やってみた上での確信ではない」とのことなので、一度サブを**横/斜め**配置も
    試す価値あり（首負担が減る可能性）。ダメなら上下に戻すだけ。

### フェーズ2（後で / 任意 / 問題B）

- 3枚目が本当に欲しくなった時点で判断（フェーズ1と切り離す）。前提として**机の幅・奥行を実測**し、
  急角度の液タブ周りに物理的に3枚置けるか先に確認。
- 用途が**資料/パレット表示（静的）**なら選択肢:
  - **DisplayLink 暫定（安い）**: M1 mini 維持で増設。60Hz 上限・HDCP 制限・CPU 負荷は静的資料ではほぼ無害。
    色が "そこそこ" 気になる点だけ軽い注意。
  - **Mac 買い替え（クリーン）**: M2 Pro/M4 Pro mini か Mac Studio で3枚以上ネイティブ対応。投資大・デスク再設計。
- 留意: 武田さんは PureRef を使い込んでいる（[[pureref-session-restore]] / [[pureref-notion-link-workflow]]）。
  資料は今のサブ + PureRef で概ね置けるため、**3枚目は "あると便利" であって必須ではない**可能性が高い（買い過ぎ防止）。

## 未確定・次の判断材料

- フェーズ1 の確定に必要なユーザー選択: 解像度ティア（1440p 推奨 か FHD 据置）/ 予算 / 色要件（sRGB 重視か表示できれば十分か）。
- サブモニターが本当に HP M27f か（実機ロゴ確認）。
- 「水平アングルがズレる」が左右の傾き（ロール）か上下チルトのどちらか（買替後に再現しないか実機確認）。
- 3枚目を入れる場合の物理配置（机寸法の実測待ち）。

## 検証（解決確認の方法）

1. 新 VESA ネイティブ機を既存 iggy アームに装着 → 上下に動かしても水平/チルトが保持され、狙った高さ・角度で
   固定できることを実機確認（旧 M27f でできなかった点が解消するか）。
2. 液タブ2モードでそれぞれ快適位置に決め、切替がスムーズか確認。
3. 横/斜め配置の実験を1回行い、上下固定との首負担を比較。
