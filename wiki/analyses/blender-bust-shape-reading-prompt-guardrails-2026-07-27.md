# Blenderモデルの胸形状読解で断定してよいこと / いけないこと

## 問い

`ヘレン_SSR0101_礼服_930.blend` と `Sabrina_夏_水着.blend` を見比べたとき、
LLM が Blender オブジェクトとしてどこまで立体差を読めるか。
また、その差分を創作用フィードバックへ使う場合、どこまで断定してよく、
どこから先は推論に留めるべきか。

## 回答(要約)

LLM が比較軸として安定して扱えるのは、**前への出方、高さ、左右の距離、横への張り出し、
下側のカーブ、胴体とのつながり、衣装との接触位置** のような、形として見える立体差である。

一方で、**ブラジャーの有無、衣装が持ち上げているか、寄せているか、支えているか** のような
服飾構造や作用の断定は、モデル上にその構造が明示されていない限り危険である。
今回の会話では、私がこの境界を越えて「衣装で持ち上げて見せる」と述べたため、
ユーザーから見当違いだと訂正された。

## 経緯

1. 起点は `/Users/takedayousuke/llm-uploads/20260727-204401-話が変わるけど.md`。
   ここで、LLM が Blender オブジェクトから何を抽出できるか、ヘレンとサブリナのバスト形状差を
   創作フィードバックへ使えるか、という問いが出た。
2. 最初の回答では、「ヘレンは大人っぽい圧」「サブリナは軽い水着胸」など、印象語が多く、
   立体差として何を見ているかが曖昧だった。
3. ユーザーから「立体情報として何が発見できるのか、端的に」と再指定され、
   突出量・重心の高さ・左右の寄り方・下側カーブ・衣装との接触といった比較軸に絞り直した。
4. その後、私はヘレンについて「衣装で持ち上げて見せる」と説明したが、
   ユーザーから「ブラジャーをつけてないので、その判断は見当違い」と訂正が入った。
5. この訂正を受けて、問題は立体読解そのものよりも、
   **観察できた形状事実** と **服の仕組みの推論** を混ぜたことにあると整理した。
6. 最後に、今後はプロンプトで「何を根拠にしてよいか」「何を断定禁止にするか」を
   先に固定する必要がある、という形で再整理した。

## 今回の会話で確定したこと

- Blender オブジェクト比較として有効なのは、胸の大きさという曖昧語ではなく、
  前方突出、高さ、左右間隔、下辺の丸み、横方向の広がり、胴体との接続である。
- 既存レンダーから立体差の仮読みはできるが、**頂点計測をしていない段階では**
  「そう見える」という水準を超えてはいけない。
- 衣装の機能や下着の有無は、見た目の印象から短絡的に断定してはいけない。
- 形状比較を創作フィードバックへ使うこと自体は現実的だが、出力は
  「観察事実」と「仮説」を分けて返す必要がある。

## 今回の誤読

私が外したのは、ヘレンの見え方を
**「胸の位置が高く見える」「中央寄りに見える」** という観察で止めず、
**「衣装が持ち上げている」** という機構説明に飛ばした点である。

これは、[[gf2-sabrina-summer-bikini-center-refine-attempt]] で起きた
「メッシュが壊れていないこと」と「ビキニとして成立していること」を混同した失敗と同型で、
今回も **形がそう見えること** と **その理由が本当にそうであること** を混ぜてしまった。

## 今後のプロンプト制約

今後この種の比較を LLM にやらせるときは、次の制約を先に入れるべき。

- Blender オブジェクトとして見える形状だけを根拠にする。
- 前方突出、高さ、左右距離、横幅、下側の丸み、胴体接続、衣装との接触位置だけを比較する。
- 「持ち上げる」「寄せる」「支える」「ブラジャー」などの語は、構造がモデル上に見える場合だけ使う。
- レンダーからの印象と、頂点・位置関係から読める事実を分ける。
- 最後に、断定できないことを明示する。

## 返答フォーマットの推奨

1. 測れる立体差
2. レンダー上そう見える差
3. 断定できないこと
4. 創作フィードバックへの変換

この順で返させると、印象語だけが先走る事故を減らせる。

## 残った問い / 検証したい仮説

- 次に同種の比較をするときは、レンダー読解だけでなく、
  実際に胸周辺メッシュの代表点や外接箱を測った方が安定する可能性が高い。
- 「ヘレン型」「サブリナ型」のような言い方をするなら、
  まず数個の比較軸で型を定義してから名付けるべきで、印象語から先に入るべきではない。
