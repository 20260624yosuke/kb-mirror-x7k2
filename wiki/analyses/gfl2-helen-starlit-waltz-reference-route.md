## Web 調査で分かったこと(2026-07-15、実機確認なし)

| 論点 | 判明した内容 |
| --- | --- |
| 対応機種 | Windows / iOS / Android。Mac ネイティブ版は無いが、**iOS 版が Mac App Store から M1 以降の Mac に直接入る**(3.8GB) |
| 衣装の入手 | 「星夜のワルツ」は JP 版 2026-04-23 からストア販売の**有料スキン**(EN 版 $11.99、初回セール $4.99) |
| 無課金入手 | **現状ほぼ不可**。「衣装は課金のみ(過去の交換券イベントを除く)」 |
| スキン交換券 | 2026-01-23 のイベント報酬として**既存プレイヤーへ配布**。1580 クレジット以下の過去衣装が対象、期限 2026-12-31。新規アカウントが今から得られる見込みは低い |
| ヘレン本体 | 2026-04 のイベント「分かれ道」実装の**期間限定ガチャ**産。復刻時期不明。**2026-07-25 にガチャで入手済み**（内部ID 1067） |
| 未所持プレビュー | ヘレン入手済みのため未確認のまま終了 |
| クルーデッキ | 1周年アップデートの 3D 交流システム。新規アカウントの解放条件は不明。**未確認** |

当初はゲーム内ルートが「衣装が課金 + ヘレン本体が期間限定ガチャ」の二重の壁で塞がっていたが、
2026-07-25 にヘレン本体をガチャで入手し壁の片方は解消された。衣装「星夜のワルツ」は有料スキンのまま（`GameConfig.cfg` の `clothesId` フラグを
手動変更したが効果なし — 所持判定はサーバー側。変更は復元済み）。

## このルートの成果として残ったもの

ゲーム導入自体は完了し、**別目的で価値を持った**。ゲームキャッシュ(41GB・9,031 Bundle)が
[[gf2-helen-rest-room-motion-v22]] の休憩室モーション抽出の一次データ源になっている。
データ置き場の仕組みは [[gfl2-external-data-mount]]。

## 矛盾・未確定

- 上表のうち「無課金入手ほぼ不可」は二次情報(知恵袋・攻略サイト)ベースで、ゲーム内表示での
  確認は行っていない。
- 「未所持プレビュー」「クルーデッキ解放条件」は未確認のまま終了した。将来ゲーム内で
