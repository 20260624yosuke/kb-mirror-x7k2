# Eagle フォルダ予測パイロット(b案・2026-06-14)

「武田さんがどの視点で画像を保存しているか」という基盤が、最終的に
**未整理画像の自動振り分け**に使えるかを、最小規模で実測した自己テスト。
[[canvas-eagle-connection-strength]] / [[art-canvas-ingest-design|Eagle 書き戻しパイロット]] の続きの検証。

## 目的(このテストで確かめたこと)

- 設問: **すでに仕分け済みの画像**のフォルダを伏せ、LLM が画像を見て
  「武田さんならどのフォルダに入れるか」を当てられるか。
- 当たれば「保存の視点が、画像から機械的に復元できる」証拠になる。
- 外れ方を見れば「どの軸が画像だけでは復元できないか」が分かる。

## 方法(ブラインド)

- 母集団: 単一フォルダ所属・画像形式・`llmwiki__` タグなしの仕分け済み画像 **14,375 枚**。
- そこから乱数で **12 枚**を抽出(seed 固定)。正解フォルダは別ファイルに封緘し、
  予測を確定するまで開かない設計にした。
- LLM は各画像を **vision で観察 → 第1候補/第2候補を確定**してから正解を開封。
- 採点は **意味フォルダ単位**(末尾連番 `_NN` や `_生成ai_NN` は同一バケツに畳む)。
- ファイル名に作者タグ(`mx2j` `modare` 等)が含まれる場合があり、画像内容と
  ファイル名でヒント源を分けて記録した。

## 現在の統合見解(最重要の発見)

武田さんの保存視点は **2 つの軸**が混在していて、軸ごとに「画像だけで復元できるか」が
はっきり分かれた。

### 1. 視覚テーマ軸 — 画像から高精度で復元できる

構図・ポーズ・季節・人体パーツ・服装・質感・表情(`03_` `04_` `05_` `06_`)のような
「画面を見れば分かる」軸。
**該当 7 件中、第1候補 6/7・第2候補まで 7/7。** 03 は「アズレン公式アート」という
下位バケツまで的中、11 は連番まで完全一致。この軸は **今のLLM+visionで実用域**。

### 2. 出自軸(作者・キャラ)— 画像だけでは復元できない

`02_絵柄_<作者>` `07_キャラ_<キャラ>` `07_作品_<IP>` のように
「**誰が描いたか / 誰を描いたか**」で仕分ける軸。ここに外しが集中した。

- 07: 見た目は線画 → でも武田さんは **キャラ(アスナ)**で分類。
- 10: 見た目は2面図 → でも武田さんは **作者(モ誰)**で分類。
- 04・08: 見た目は夏ビーチ / 胸 → でも **作者(MX2J)**で分類。

出自軸の第1候補一致は **1/5** にとどまる。ただし重要なのは、これらの
**ファイル名には作者タグ(`mx2j` `modare`)が入っていた**こと。
ファイル名を主信号にすれば 04・08・10 は拾え、出自軸は **約4/5** まで上がる。
純粋に難しいのは 07 だけ(ファイル名に作者 `modare` はあったが、分類軸は
キャラ `アスナ` で、名前からも画像からも直接は出ない)。

### 自動振り分けへの含意

- 視覚テーマ軸は **vision で振り分け可能**。
- 出自軸は **vision では不可。ファイル名・source URL・既存タグ・作者スタイル認識**が要る。
  → Canvas の `source-artist` や Eagle の url/tag という**メタデータ側の信号**が、
    まさにこの穴を埋める部品。基盤は「vision」と「メタデータ」の二段構えが要る。
- よって自動振り分けは **(1) 名前/source から出自を判定 → (2) vision で視覚テーマを判定 →
  (3) 確信度ゲート**、の二段+人間確認が妥当。

## 矛盾・未確定(このテストの限界)

- **N=12 と小さい**。傾向の方向は見えるが数値は目安。
- **単一ラベル前提**。実際は1枚が複数フォルダに該当しうる(02 は夏でもありポーズでもある)。
  正解を武田さんの1フォルダに限定したため、58% は**下振れの下限値**。
- **自己採点**(同一エージェントが予測と採点)。ブラインド封緘で緩和したが、完全独立ではない。
- 出自軸の「ファイル名で拾える」は、ファイル名に作者タグが入っている画像に限る。
  名前が `画像.jpg` `29.jpg` 等の無名画像では出自軸は依然困難。

## 次にやるなら(候補・未承認)

- N を 50〜100 に増やし、**視覚テーマ軸だけ**に絞った精度の再測定。
- 「vision のみ」vs「vision+ファイル名+既存タグ」の比較(出自軸がどれだけ埋まるか)。
- 未整理プール(`未整理_*`)数枚で実地振り分け提案 → 武田さん確認(書き込みはしない)。
