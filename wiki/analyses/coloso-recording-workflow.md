# Coloso 講座動画の録画ワークフロー(Mac → iPad キャプチャ)

> このページは **ユーザー本人の作業ノウハウ** を記録したもの。`raw/` 由来のソースではないため `sources:` は空。確定情報と推測を明示的に分離している。

## 問い / 背景

[[coloso]] の講座動画を、プレイヤー UI ごときれいに録画する方法をユーザーが確立しており、忘れたとき参照できるよう記録しておきたい。

**なぜこの構成が要るのか**: Coloso のプレイヤーは録画防止がかかっており、**Mac で直接画面収録すると黒画面になる**(2026-05-14 ユーザー確認)。そこで Mac の映像を HDMI 経由でいったん iPad に「外部映像」として送り込み、iPad 側で収録することでこの制限を回避している。

## 確定している手順

1. **Mac の映像出力を、USB-C 映像キャプチャ機器を介して iPad に取り込む**。
   - ユーザーが「HDMI のハブ」と呼んでいる機器の実体は、HDMI 入力を iPad に映像として渡せる **USB-C 接続のキャプチャ機器**(2026-05-14 ユーザー確認)。単なる HDMI 分配ハブではない。
2. iPad 側で **「CamX」というアプリ**を開く。これは取り込んだ**外部映像を表示するビューアアプリ**(2026-05-14 ユーザー確認)。ここに Mac の Coloso 画面が映る。
3. iPad の**画面録画ボタン**(コントロールセンター等)を押す。CamX に映った Coloso の映像が、プレイヤー UI ごときれいに収録される。
   → つまり **録画機は iPad、再生元は Mac**。
