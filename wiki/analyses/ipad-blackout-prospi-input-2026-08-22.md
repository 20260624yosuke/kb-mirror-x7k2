# iPad画面ブラックアウト後のプロスピA入力手段の検討(液タブ併用は不可)

## 経緯

2026-08-22、iPad本体画面がブラックアウト(HDMIで外部ディスプレイ接続して運用中)。

- iPadの主用途はプロ野球スピリッツA / メジャースピA の対人戦。「大画面 + ペンシル操作」が対人戦で有利に働くことが採用理由。タブレット自体への需要は失った(AI時代の認識)が、このゲームのためだけに端末を買い替えたくない。
- ユーザー仮説: 「Huion液タブ(Kamvas)は公式iPad非対応だがAndroid向けアプリがある。アプリをスワップしてiPad向けにレンダリングすれば液タブをiPadでも使えるのでは」
- `/plan-gate` + `/hold` で計画化を試みた。plan-gateの自動ガード(hook)はこの実行環境(opencodeアプリ)に未登録だったため技術停止し、hold運用で継続。
- 検証過程での追加質問: Amazonの廉価Bluetoothペンシルが成り立つ仕組み / 筆圧を妥協するなら「液タブ+そのペン」を使える環境を別ベクトルで実現できないか。
- 結論として目的(液タブ併用)達成不能と判明 → **ユーザー判断で計画を中断**(user-stated)。デジタイザ生存テストは未実施のまま。本ページは経緯と判定の記録。

## 判定一覧

| 案 | 判定 | 主な理由 |
|---|---|---|
| Huion Androidアプリを差し替えてiPad向けにレンダリング | **不可** | ① iPadOSは外部メーカーのドライバー(機器を動かす土台ソフト)を後から導入できない仕様 ② Kamvasは「描けるモニター」であり映像入力+独自プロトコルのペンデータが必要。iPadのUSB-Cは映像出力専用(CamXキャプチャ経由なら表示のみ可だがペン情報は戻らない) |
| 液タブ+そのペンでiPadを操作する環境(別ベクトル案) | **不可(既製品)** | Huionペンは電池レス電磁誘導方式(EMR)。**センサーはタブ本体基板側にありペン単体は不活性**=「ペンだけ使う」分離が物理的に不可能。Huion独自USB→標準HID変換器の市販品は存在しない。マイコン自作(ESP32等でUSB読取→無線HID再送)は研究開発級で、カーソル遅延がバッティング操作に響くリスク大 |
| 液タブをiPadの描けるモニターとして使う | 実質**不可** | 映像単体は理論上可能性があるが未検証。ペン入力がどうしても戻らず片手落ち |
| Amazon廉価Bluetoothペンシルで代用 | 条件付き可 | 静電容量式の指エミュレート。パッシブ式=導電ゴムで指の電気を真似るだけ / アクティブ式=電池式の細い先端が「精密な指」として認識。位置検知にBluetoothは使われず(電池表示・ボタン用)、Apple Pencilプロトコルは突破していないため筆圧・ホバー・本物の手のひら拒否なし。プロスピAはタッチイベントで足りるため実用可。**ただしタッチ感知層依存はApple Pencil・指と同一** |
| Apple Pencilの排他性 | 事実確認 | ペン先から電磁信号を出し画面側が高頻度走査で位置検知する独自プロトコル+ライセンス制(Logitech Crayon等一部メーカーのみ)。「権威性を保つ措置」というユーザー理解は正しい |

## 本命ルート(未検証・中断により未遂行)

- タッチ感知層(デジタイザ=指やペンの位置を感知する液晶とは別の層)は、黒画面になっても生存している可能性が高い。
- 生存なら: HDMI鏡像(TV)+ 黒いガラス面への直接タップ/ペンシルで**購入ゼロ**続行可能(鏡像なのでTV上の見た目とガラス上の座標が1:1対応)。手持ちApple Pencilは廉価ペンの上位互換なので購入不要。
- 全スタイラス・指は同じ感知層経由のため、**層ごと死んでいた場合は廉価ペン購入も無意味**。代替は Bluetoothマウス/トラックパッド(iPadOSではカーソル操作)/修理/買い替え。
- 判定テスト: プロスピA起動→TV表示→黒ガラス面の該当UI位置をペンシル/指でタップ(約2分)。今回未実施。
