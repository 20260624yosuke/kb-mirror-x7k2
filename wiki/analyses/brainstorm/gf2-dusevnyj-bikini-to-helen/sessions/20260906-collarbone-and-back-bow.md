## 測定 1: 鎖骨は力点か（判定 = 半分当たり）

原作（ドゥルシーヌヴイ着装）の右側の肩ひも 96 頂点・道のり 285.7mm を、
縫い目から首の後ろまで順にたどって体との符号付き距離を測った。高さの原点は骨 `Neck_M`。

| 紐のどこか | Neck_M からの高さ | 体からの距離（中央・幅） |
|---|---|---|
| カップ上端の縫い目（14 頂点） | −79.6〜−70.2mm | **+3.37mm**（+1.96〜+4.35） |
| 鎖骨のあたり（18 頂点） | −58.3〜−25.4mm | **+3.43mm**（+1.20〜+4.49） |
| 首の横（23 頂点） | −19.9〜+4.6mm | **+3.66mm**（+0.76〜+5.75） |
| 首の後ろ（24 頂点） | +16.6〜+28.1mm | **−0.62mm**（−1.94〜+1.08） |

- **当たり**: 鎖骨〜カップの間、紐は一度も肌に触れない（37 頂点・中央 **+3.40mm**・最小 +0.76mm）。
- **外れ**: 力点は鎖骨ではない。**体に押し当たっているのは首の後ろだけ**（中央 −0.62mm・最深 −1.94mm）。
  縫い目・鎖骨・首の横はどれも +3.4mm 前後でほぼ一定に浮いており、**鎖骨だけが特別な場所ではない。**
- したがって鎖骨を力点にすると、原作では触れていない場所を肌へ押し付けることになる。
  採るべきは「鎖骨からカップまでは触れない」という部分だけ。

（訂正前の値: 鎖骨 +7.3〜+8.1mm・首の後ろ −4.86mm・縫い目 +2.71mm。頂点法線で測っていたため。）

成果物の同じ区間は 66 頂点・中央 **+3.55mm**（+0.85〜+5.74）。**触れていないこと自体はすでに満たしている。**

## 測定 2: 「着ている感」の物差しの候補（新規）

張った紐は両端を結ぶ直線（弦）に沿い、体の出っ張りで外へ押し出されることはあっても、
**内へ落ち込むことはできない**（縮まないと起きない）。これは好みではなく紐の性質なので機械判定できる。

| | 原作 | 成果物 |
|---|---|---|
| 道のり | 168.6mm | 250.1mm |
| 弦 | 163.7mm | 243.7mm |
| たるみ（道のり÷弦） | 1.030 | 1.026 |
| **弦からのふくらみ 中央** | **+3.29mm（外へ）** | **−4.90mm（内へ）** |
| 同 最小 | −4.51mm | −9.62mm |

左右とも同じ（成果物の左は −4.87mm）。差は 8.19mm。
**この項目は測り方を直しても結論が変わらなかった**（+3.11→+3.29 / −5.01→−4.90）。
成果物の紐は張り渡らず、体表面の凹みをなぞっている。
**検査 G19a**「紐は弦より内側へ入らない」。合格線は原作の実測から毎回計算する。
**2026-09-06 に武田さんが「関所にする」を承認（S025）し、実装した。いまは FAIL**
（成果物 −4.88mm / 下限 +0.29mm）。変異試験 7/7。

## 測定 3: 背中のリボン結びのズレ（原因特定）

原作 2129 頂点 ↔ 成果物 2129 頂点は**同じ番号・同じ面**で対応が取れる（確認済み）。

### ズレの正体

| | 原作 | 成果物 |
|---|---|---|
| 結び目の高さ | 1197.3mm | 1267.3mm |
| 帯（背中側）の高さ | 1197.8mm | 1278.1mm |
| **その差** | **−0.54mm** | **−10.85mm** |

結び目が帯より 10.85mm 下に落ちている。帯が結び目の上を素通りする形になっている。

### 原因

リボン結びは **中間（輪）+ 小物（結び目）+ 垂れ（端）** で出来ている。
2026-09-05 に帯へ「体に対する高さの基準」を入れて帯だけが持ち上がったが、
**中間・小物には体に対する基準が 1 つも無い**（`wiki/builds/gf2-helen-swimsuit-wearing-law.json` に
「なし・調べていない」と明記）。垂れは体 UV 対応率 8.7% で判定に使われていない。
その結果、帯が上がった分だけリボンが取り残された。
**これは「未測定の側面 1 個」（GOAL-LAW）そのもの。**

### リボン自体は無傷

辺の伸び（原作→成果物）: 中間 1.000（最大 1.005）／ 垂れ 1.000（最大 1.007）／ 小物 1.000。
左右対称性も原作と同じ（鏡像距離 中央 1.36mm → 1.33mm）。結び目の X 中心 0.68 → 0.63mm。

### 帯の別件（**訂正あり。測定 5 を見ること**）

当初「帯が原作の 2.42 倍に太って波打っている」と書いたが、周方向 24 区間で測り直すと
**太ってはいなかった**（区間ごとの上下の幅 原作 3.79〜4.38mm / 成果物 3.73〜5.60mm）。
全体の上下の広がりが大きく見えたのは、**帯の高さが周に沿って上下する**ため
（原作は 1.3mm の範囲、成果物は 4.1mm の範囲）。詳しくは測定 5。

## 測定 5（2026-09-06 夜・武田さん承認 S026）: 帯が食い込む原因

**悪化しているのは左右の脇腹だけ。** 原作と同じ番号の頂点で比べた（角度は原作の位置で 30° 刻み）。

| 角度 | 頂点 | 原作 中央/最深 | 適合の段階 中央/最深 | 悪化 |
|---|---|---|---|---|
| −165° | 28 | +1.25 / −0.36 | **−0.25 / −2.03** | −1.50 |
| −15° | 28 | +1.25 / −0.36 | **−0.25 / −2.09** | −1.50 |
| −135° / −45° | 各 10 | +1.79 / −0.00 | +1.68 / −0.19 | −0.12 |
| +45° / +135° | 各 30 | +1.79 / −0.10 | +1.83 / −1.15 | +0.04 |
| +15° / +165° | 17・16 | +1.74 / +0.30 | **+6.13 / +0.47** | +4.38 / +4.74 |
| −105° / −75° | 5・10 | +2.56 / +1.36 | +4.55 / +3.06 | +1.99 / +0.79 |

分かったこと:

- **殻（厚み）を付ける工程は悪化させていない**（最深 −2.09 → −2.09mm。割合はむしろ 22.7% → 19.8% に減る）。
  **原因は適合の段階にある。**
- 原作の帯は全周でほぼ一定（+1.25〜+5.26mm）。成果物は **前後で +4.4〜+4.7mm 浮き、左右で −2.1mm 食い込む**。
  つまり**断面の形がゆがんでいる**。位置がずれているのでも、太っているのでもない。
- 帯は「役割ごとに一律 ×1.074 で伸ばして剛体で置く」やり方で置かれている。**周方向のどこも同じ倍率**なので、
  ヘレンの胴体の断面の形（前後に厚く・左右に狭い）に追随できない。

**「帯が原作の 2.42 倍に太って波打っている」は訂正する。** 周方向 24 区間で測り直すと、
区間ごとの上下の幅は 原作 3.79〜4.38mm / 成果物 3.73〜5.60mm で、太ってはいない。
全体の上下の広がりが大きく見えたのは、**帯の高さが周に沿って上下する**ため
（原作は 1.3mm の範囲、成果物は 4.1mm の範囲）。

**直し方はまだ承認を取っていない。**

## 【訂正 2】役割の割り当てが誤っていた（2026-09-06 夜）

成果物の頂点に役割を付けるとき、「適合の段階のいちばん近い頂点」から写していた。
**肩ひもは作り直しで大きく動くので、近さで写すと別の部品を掴む**
（実測: 写し距離の中央値 39.84mm・最大 93.55mm。355 頂点中 337 個が 3mm 超）。
そのため一時 肩ひもの断面を 8.21mm・胴に回す紐のめり込みを 19.8% と出していた。
**頂点の対応で引き直した**（`tools/skin_contact_check.py` の `deliverable_roles`）。
引き直した後: 肩ひも 296 頂点・断面 8.14mm、胴に回す紐 185 頂点・めり込み 22.7%。
**結論は変わらないが、数値は入れ替わっている。**

## ドゥルシーヌヴイはどう肌に食い込んでいるか（武田さんの質問・優先度は低いと明言あり）

穴を塞いだ体で測った実測: **どの役割も浅い。** 肩ひも 最深 −1.94mm ／ カップ −0.76mm ／
