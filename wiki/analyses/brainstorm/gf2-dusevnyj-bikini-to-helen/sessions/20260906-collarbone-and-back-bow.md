## 測定 1: 鎖骨は力点か（判定 = 半分当たり）

原作（ドゥルシーヌヴイ着装）の右側の肩ひも 96 頂点・道のり 285.7mm を、
縫い目から首の後ろまで順にたどって体との符号付き距離を測った。高さの原点は骨 `Neck_M`。

| 紐のどこか | Neck_M からの高さ | 体からの距離 |
|---|---|---|
| カップ上端の縫い目 | −79.6mm | +2.71mm |
| 鎖骨のあたり | −49〜−33mm | +7.3〜+8.1mm（最大 9.02mm） |
| 首の横 | −15〜0mm | +5.5〜+6.4mm |
| 首の後ろ | +21〜+27mm | +0.64 〜 **−4.86mm** |

- **当たり**: 鎖骨〜カップの間、紐は一度も肌に触れない（37 頂点・中央 5.46mm・最小 3.30mm）。
- **外れ**: 力点は鎖骨ではない。押し当たっているのは **首の後ろ**（−4.86mm）と
  **カップ上端の縫い目**（+2.71mm）の 2 点だけ。鎖骨のあたりは**この紐の中で一番浮いている**。
- したがって鎖骨を力点にすると、原作では 7〜8mm 浮いている場所を肌へ押し付けることになる。
  採るべきは「鎖骨からカップまでは触れない」という部分だけ。

成果物の同じ区間は 66 頂点・中央 8.21mm（最小 4.87）。**触れていないこと自体はすでに満たしている。**

## 測定 2: 「着ている感」の物差しの候補（新規）

張った紐は両端を結ぶ直線（弦）に沿い、体の出っ張りで外へ押し出されることはあっても、
**内へ落ち込むことはできない**（縮まないと起きない）。これは好みではなく紐の性質なので機械判定できる。

| | 原作 | 成果物 |
|---|---|---|
| 道のり | 168.6mm | 250.1mm |
| 弦 | 163.7mm | 243.7mm |
| たるみ（道のり÷弦） | 1.030 | 1.026 |
| **弦からのふくらみ 中央** | **+3.11mm（外へ）** | **−5.01mm（内へ）** |
| 同 最小 | −4.60mm | −9.19mm |

左右とも同じ（成果物の左は −4.99mm）。差は 8.12mm。
成果物の紐は張り渡らず、体表面の凹みをなぞっている。
**検査案 G19a**「紐は弦より内側へ入らない」。合格線は原作の実測から毎回計算する。

## 測定 3: 背中のリボン結びのズレ（原因特定）

原作 2129 頂点 ↔ 成果物 2129 頂点は**同じ番号・同じ面**で対応が取れる（確認済み）。

### ズレの正体

| | 原作 | 成果物 |
|---|---|---|
| 結び目の高さ | 1197.3mm | 1267.3mm |
| 帯（背中側）の高さ | 1197.8mm | 1278.1mm |
| **その差** | **−0.54mm** | **−10.85mm** |

結び目が帯より 10.85mm 下に落ちている。帯が結び目の上を素通りする形になっている。

### 原因

リボン結びは **中間（輪）+ 小物（結び目）+ 垂れ（端）** で出来ている。
2026-09-05 に帯へ「体に対する高さの基準」を入れて帯だけが持ち上がったが、
**中間・小物には体に対する基準が 1 つも無い**（`wiki/builds/gf2-helen-swimsuit-wearing-law.json` に
「なし・調べていない」と明記）。垂れは体 UV 対応率 8.7% で判定に使われていない。
その結果、帯が上がった分だけリボンが取り残された。
**これは「未測定の側面 1 個」（GOAL-LAW）そのもの。**

### リボン自体は無傷

辺の伸び（原作→成果物）: 中間 1.000（最大 1.005）／ 垂れ 1.000（最大 1.007）／ 小物 1.000。
左右対称性も原作と同じ（鏡像距離 中央 1.36mm → 1.33mm）。結び目の X 中心 0.68 → 0.63mm。

### 帯が太って波打っている（同時に見つかった別件）

| 帯の測り方 | 原作 | 成果物 |
|---|---|---|
| 上下の幅 | 5.22mm | 12.66mm（×2.42） |
| 横の広がり | 190.3mm | 286.0mm（×1.50） |
| 上下のばらつき（Y の標準偏差） | 0.32mm | 1.53mm（×4.8） |
| 辺の伸び 中央 / 最大 | — | ×1.289 / ×2.184 |

横 ×1.50 は体格差で説明できるが、**上下の幅 ×2.42 と ばらつき ×4.8 は説明できない**。原因は未調査。

## 測定 4: めり込みの実測（「ゼロ」は原作と矛盾する）

**両方とも穴を塞いだ体で測った。**

| 役割 | 原作 中央/最深/めり込み% | 成果物 中央/最深/めり込み% |
|---|---|---|
| カップ | +3.39 / −6.45 / 11.0% | +4.76 / −7.16 / 5.6% |
| 帯 | +3.32 / −7.54 / 13.5% | **+4.08 / −12.75 / 31.6%** |
| 肩ひも | +4.22 / −4.86 / 18.9% | +6.39 / −6.15 / 20.0% |
| 中間 | +8.37 / −7.17 / 0.8% | +9.36 / +3.16 / 0.0% |
| 垂れ | +12.64 / +6.71 / 0.0% | +13.72 / +7.99 / 0.0% |
| 小物 | +10.67 / +5.41 / 0.0% | +13.40 / +8.63 / 0.0% |

**原作にもめり込みがある。** ゼロを目標にすると布がどこにも押し当たらなくなり、
2026-09-05 の「すき間 0.00mm ＝ 貼り付き 100%」と向きが逆なだけの同じ失敗になる。

**いま超えているのは帯だけ**（割合で 2.34 倍・深さで 5.21mm 超）。

## 提案した仕組み（プロジェクト限定・未承認）

- **P3 提案の関所**: 「食い込ませる／めり込ませる」を**手段**とする案を、計画・申し送り・承認カードに
  書けなくする。S021「そのまま着せる（食い込ませる）」が承認まで到達した経路を塞ぐ。
