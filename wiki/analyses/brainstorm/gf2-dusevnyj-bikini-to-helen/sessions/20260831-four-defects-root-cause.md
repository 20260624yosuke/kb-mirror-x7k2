## 2. 骨の向きで裏返った原因（前回「平行移動だけにした」で済ませたのは症状潰し）

骨ごとに、ドナーとヘレンの静止姿勢の**回転角の差**を測った（実測）:

| 骨 | 回転角の差 | 位置の差 |
|---|---|---|
| `Spine1_M` / `Spine2_M` / `Chest_M` / `Neck_M` / `Head_M` | **0.00°** | 72〜102mm |
| `Scapula_L` / `Scapula_R` | 4.28° | 95mm |
| **`Chest_L`** と胸の連鎖3本 | **124.91°** | 64〜101mm |
| **`Chest_R`** と胸の連鎖3本 | **115.32°** | 64〜101mm |

上衣の 2562 頂点は**全部が2本以上の骨を混ぜており**、そのうち **1192 頂点が 60°超の差を持つ骨**を
混ぜている。線形混合スキニングは回転差が大きいと折り畳まれる（キャンディラッパー）ので、
502 枚の裏返りと帯の厚み ×8.9 はその結果。**姿勢の差ではなく、胸まわりの骨の軸の取り方が
キャラごとに違う**（背骨の連鎖は 0.00° で完全一致しているので、姿勢差では説明できない）。

**私が前回「骨組みは同じ・42本が42本とも対応」と書いたのは言い過ぎ。**
名前は対応するが、**カップを担ぐ骨の向きは 115〜125° 違う**。ここを確かめずに
「向きを入れるとねじれるから平行移動だけにする」と書いたのが、武田さんの言う「原因が分かっていない」。

## 3. 水着が透明な原因（原作再現側にも同じ欠陥がある）

- 産出側 `ce_build_blend.py` は、albedo が RGBA のとき **α を 0.5 で二値化して不透明度へつなぐ**
  （151〜191行）。
- ドナーの上衣のテクスチャ `c_DusevnyjSSR0101_slg_P3_cloth1_da` は **α=0 が 80% / α=255 が 15%**。
- 面積で測ると、**ドナー自身の原着装ですら不透明なのは 14.9%**（成果物は 12.1%）。
  ＝ この α を不透明度として使うと、ビキニの 85% が消える。
- RGB だけで描くと**灰色に白い英字が入った完全なビキニ**になる（欠けは無い）。
  つまり **この `_da` の α は不透明度ではない**（マスクか別用途）。
- したがって **ヘレン用の変換の問題ではなく、原作再現の産出側の問題**。
  ドゥルシーヌヴイ本人の再現 Blend でも同じ症状が出るはず（未実測）。
- 水着の英字（`YTI…NITY`）は**原作テクスチャの柄**であって不具合ではない。
- 色が無彩色（中央値 119,119,119）なのは、抽出時に `ramp`（色を決める段）を
  `deferred` にしているため（`extract-manifest.json` の `deferred: [lighting, outline, ramp, animation]`）。

## 4. 肌の色が統一されていない原因

継ぎ目の両側で、実際に使われているテクスチャを UV で引いて中央値を測った:

| 場所 | 使っている画像 | 中央値 RGB |
|---|---|---|
| 首メッシュの下端（継ぎ目） | `c_HelenSSR0101_slg_body_d` | (220, 158, 140) |
| 胴体の上端（継ぎ目） | `body1_d`（材料フォルダで差し替え） | (229, 171, 152) |
| 顔の下端 | `c_Helen_slg_face_d` | (236, 182, 166) |
| 脚の上端 | 共有肌アトラス `body_d` | (239, 189, 169) |

継ぎ目の差は **ΔR+9 ΔG+13 ΔB+12**。肌に**4種類のアトラス**が混ざっていて、
それらが一致することを確かめる検査が無い。

## 5. 腕

腕は `c_HelenSSR0101_slg_P1_hand_lod0`（4502頂点・Y0.966〜1.435）しかなく、
台帳で「手袋（ドレスの部品）」として **show: false**。武田さんの指示は **表示させる**。

## 決めたいこと（カードで聞く）

1. 胸の変種を **General** に戻すこと（現段階の指定どおり）。
2. 腕（`P1_hand`）を表示に変えること。
3. 上の4件を止める検査を作ること: **V7 変種と用途の一致 / W8 肌の継ぎ目の色差 /

4. 明言台帳 `explicit-statements.json` を実装して、機械が読む場所に明言を置くこと。
