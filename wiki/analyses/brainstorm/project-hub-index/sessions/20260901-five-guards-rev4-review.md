## 所見

## critical 2件（2件とも私が独立に再測して確認した）

### C-1 穴4「要素との一致 48枚」は**私の計測の誤り**。実際は 11枚

- rev.4 R-2 の表に書いた「要素との一致: 51枚中48枚が不合格（`div.mb-figure` 47 ほか）」は誤り。
  原因は私の照合が単語境界の部分一致で、`<div class="mb-figure-frame">` や `<p class="mb-quote-ja">`
  （**どちらも正本 CSS に定義された正しいクラス**）を不一致として数えていた。
- **再測（`class` 属性を空白で分割して厳密照合・2026-09-01）**: 要素不一致は **11枚**。
  内訳は `div.mb-quote` 7枚 ＋ `dl.mb-glossary` 4枚。`div.mb-figure` と `p.mb-quote` は **0枚**。
- 残った11枚は、**穴4 が本来捕まえたかった欠陥そのもの**（計画本文79行「今回 `div.mb-quote` を4件やっていた」）。
- → **「51枚中48枚が落ちるから止められない」という格下げの理由は成立しない。**
  R-2 の「要素との一致＝報告のみ」の決定は、**誤った数字に基づいていた。決め直しが要る。**

### C-2 R-7 の「カウンタ増加を PostToolUse へ移す」は、**必ず新規フック登録を伴う**

- 実測（私も確認）: `~/.claude/settings.json` の `hooks` は
  `PostCompact / PreCompact / PreToolUse / SessionEnd / SessionStart / Stop / StopFailure /
  SubagentStart / SubagentStop / UserPromptSubmit` の10種。**`PostToolUse` は無い。**
  スキル側 `SKILL.md` の frontmatter も `PreToolUse` と `Stop` のみ。
- rev.4 R-7 は「実装できない場合（PostToolUse の登録が必要になる等）は承認を取り直す」と
  条件付きで書いたが、**その条件はすでに満たされている**。
- rev.3 N-1・rev.4 が維持する方針「新規のフック登録は行わない（マシン全体に効く変更を避ける）」と
  正面から衝突する。**承認を求める前に決着させる必要がある。**

## major 5件

- **M-1**: 「実在しないクラス」の切り分けが実測と合わない。`mb-font-mono` `mb-accent` は
  正本 CSS に **CSS 変数（`--mb-font-mono`）としてしかなく、クラス定義は 0件**（私も確認）。
  `mb-lead` と同種の欠陥であり、「広く使われている＝慣行」ではなく「同じ誤りが広まっている」。
  → 3つを同じ根拠で揃えて決め直す。
- **M-2**: 骨格検査は、rev.4 自身の除外規則（`mb-` を1つも使わない HTML を除く）を適用すると
  **対象50枚すべてを通す＝現状の検体では恒偽**（私も確認: 骨格不合格 0枚）。
  誤検知ゼロは良いが、発火することを示す実在の検体が無い。意図的に壊した検体での発火試験が要る。
- **M-3**: R-6 の「そのターン」の定義では、brainstorm の実運用で **最大185イベント**に広がる。
  brainstorm は毎ターンをカードで閉じ、武田さんの回答は `tool_result`（＝定義上の除外対象）で届くため、
  「最後の生の user 発話」が何往復も前になる。**恒常ブロックは範囲が狭まっただけで残っている。**
  実測: 直近6セッションで 7 / 15 / 49 / 50 / 99 / 185 イベント。
- **M-4**: R-8 の新ゲートは実装の書き方しだいで**恒偽**になる。既存の照合文字列は `'"skill": "%s"'`
  （コロンの後に空白）で、これは `json.dumps` で再シリアライズした文字列にしか一致しない。
  生の transcript は `"skill":"html"`（空白なし）。照合対象と取得関数を実装項目に明記しないと、
  **全新検査が黙って無効になる。**
- **M-5**: 穴1 の `## 未確定の順序` 節は **LLM が書かなければ永久に発火しない**（現在この節を持つメモは0件）。
  rev.3 の「恒真」を「恒偽」に置き換えただけになりうる。この逃げ道が rev.4 の限界節に書かれていない。
